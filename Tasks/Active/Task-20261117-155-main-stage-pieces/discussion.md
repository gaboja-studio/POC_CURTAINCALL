## 1. 변경된 기물 내용 — 효과 변경 폭이 큰 제안

역할을 동료 구출 / 붙잡고 버티기 / 공중 경로 조절 / 높이 확보로 나눈다. 수치 증가보다 사용 전후 행동 변화가 보여야 한다.

| 기물 | 사용 가능 상황·제안 효과 | 추가 도전 | 연출 |
|---|---|---|---|
| 구조 장갑 | 안정적으로 서 있고 근처에 공중 또는 매달린 동료가 있을 때, 바라보는 유효 대상 1명을 자기 쪽의 안전한 받기 위치로 끌어온다. 거리·장애물·받을 공간 검사가 필요하다. | 동료가 위험한 포인트에 도전하고 사용자가 복귀를 지원한다. | 큰 장갑이 뻗어 동료를 잡고 회수, 붙잡는 충격음. |
| 끈끈이 장갑 | 매달린 상태에서 사용하면 일정 시간 매달림 제한시간 감소를 멈춘다. 대상 자체의 움직임과 장애물 위험은 유지한다. 한 매달림당 사용 횟수는 결정 필요. | 이동하는 봉에서 더 좋은 이탈 위치·타이밍을 기다린다. | 손바닥 점착 흔적과 늘어지는 접착물, 남은 효과시간 표시. |
| 광대 벌룬 바지 | 공중에서 펼치면 하강을 크게 늦추고 수평 조작 여유를 준다. 상승 추진은 주지 않는다. 접기·재전개·최대 지속시간 규칙은 결정 필요. | 원래 궤도 옆에 있는 포인트를 거쳐 착지한다. | 바지가 크게 부풀고 천·바람 소리, 착지 또는 해제 시 수축. |
| 스프링 신발(효과 확정, 명칭 검토) | 공중에서 사용하면 한 번 더 점프한다. 착지 전까지 최대 1회, 실제 이단 점프 적용 시 내구도 1 소모. 지상 강화 점프·착지 자동 반동은 이 효과에 포함하지 않는다. | 공중에서 한 번 더 높이를 얻어 포인트 또는 착지 위치에 도달한다. | 발밑의 짧은 원형 파동과 튕김 소리, 추가 점프 동작. 연출은 제안. |

구조 장갑은 지원형이며 모든 기물에 직접 포인트 획득 능력을 억지로 부여하지 않는다. 대신 구조 지원 중에도 기존 협동 환호와 본인 포인트 획득 기회가 있어야 한다. 끈끈이 장갑은 단순 수명 연장만으로 적극적 도전 가치가 충분한지 코스와 함께 검증한다.

공통 제안: Q=첫 슬롯, E=둘째 슬롯. 입력 불가/가능/사용 중/소진을 시각적으로 구분한다. 유효 발동이 시작된 경우 1 소모하고 무효 입력은 소모하지 않는 안을 우선 논의한다. 구조 장갑의 대상 지정 실패는 실제 효과 없는 사용으로 구분할 필요가 있다. 마지막 사용 효과는 끝까지 유지한다. 구체적인 발동 취소·연속 사용·양 슬롯 동시 사용은 개별 효과 확정 뒤 결정한다.

설명은 상황·행동 중심으로 작성한다. 예: “공중에서 펼치면 천천히 내려오며 방향을 조절합니다.” 수치가 확정되면 지속시간 등 필수 정보는 별도 표기한다. 실제 적용 범위는 설명과 일치해야 한다.

신발 설명: **“공중에서 사용하면 한 번 더 점프합니다. 착지 전까지 1회만 사용할 수 있으며, 추가 점프가 실제로 발생하면 내구도 1을 소모합니다.”** 기존 정체성을 유지하되 효과·사용 방식의 큰 변경은 사용자가 허용했다. 이름 후보는 **곡예사의 도약화**: 공중을 한 번 더 딛는 곡예 신발. 명칭·외형은 미확정이며 새 모델 제작을 전제하지 않는다. 점프 높이·하강 속도 처리·매달림 및 탑승 전환의 사용권 처리는 후속 설계 항목이다.

## 2. 환호 포인트 에셋 — 후보와 제작 기준

사용자 방향: 다크 서커스, 얼굴이 있는 불쾌함과 낡은 공연 소품의 음산함 모두 가능. 실제 `_ThirdParty` 에셋을 활용한다. 2026-11-18 아래 4종의 FBX·프리팹·머티리얼 참조와 실제 형상을 확인했다.

- 대기 제안: 가면을 공중에 띄우고 작은 상하 움직임·좌우 기울임, 테두리의 약한 발광으로 수집 목표를 표시한다. 완전 회전은 가면 뒷면이 노출되므로 우선 피한다.
- 획득 제안: 가면이 짧게 떨렸다가 수축하며 사라짐 → 관객 환호 → 획득자에게 실제 호응 증가값과 게이지 변화. 파편 메시 신규 제작 없이 원본을 활용한다. 다른 플레이어 화면에서도 소멸한다.
- 일반/기물 활용 포인트는 우선 같은 외형을 사용하고 위치·접근 경로로 도전 차이를 보여주는 안. 기물 전용 색상으로 정답을 직접 지정할지는 별도 논의.
- 약 6:4는 배치 목표로 취급한다. 포인트 수가 적으면 정수 배분을 조정한다. 기본 경로에서도 위험과 도전은 존재한다.
- 기존 로컬 보상 규칙의 공용 선착 1인 획득·소멸·기본 +15·인원×단계별 2/3/4개는 참고 기준이다. 신규 초안은 보상량을 확정하지 않았다. 단계 배율·호응 상한·가격 대비 획득 가치까지 검토 후 결정한다.
- 프리팹 준비 시 모델·발광·대기 동작·획득 효과·소리·접촉 판정을 분리한다. 에디터 윈도우에서는 위치와 예상 접근 경로, 기본/기물 활용 분류를 확인할 수 있도록 한다.
- 원본 에셋 수정 없음. ‘금이 간 웃는 가면’ 완제품과 정확히 일치하지 않는다. 균열 추가는 후속 선택 사항이며 기존 가면 형상 활용을 우선한다. 최종 외형은 비교 렌더를 보고 결정한다.

사용자는 공연 중 통과하는 불 고리를 예로 들며, 단독 가면의 부유보다 공연 행동·보유 VFX와의 자연스러운 결합을 요청했다. All In 1 Sprite Shader는 이미 프로젝트에 설치되어 있다.

| 시안 | 실제 프리팹 | 표현·용도 제안 |

- 결과 이미지·움직임 GIF·UI 순서 캡처는 작업 로그 경로를 참고한다.

## 검증할 플레이 경험

1. 효과 설명을 읽고 사용 가능한 순간·키를 알아볼 수 있다.
2. 같은 구간에서 기물 유무가 도달 범위·안전성·선택 행동에 명확한 차이를 만든다.
3. 신발 도약 → 바지 전개 같은 조합으로 추가 경로가 열리되 필수 클리어 조건이 되지 않는다.
4. 획득 보상을 기존 호응 상한이 가리지 않아야 한다. 최적 경로 반복으로 무제한 보상을 만들지 않는다.
5. 호스트/클라이언트의 사용·내구도·마지막 효과·동시 포인트 접촉이 일치한다.
