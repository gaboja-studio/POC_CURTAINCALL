각 구간의 전원에게서 서로 다른 발신자와 앱 세션을 확인했다. 8개 런의 로컬 이벤트 5,966건을 운영 Drive 원본과 대시보드 세션 상세에 대조한 결과, 고유 이벤트 ID 5,966개가 모두 일치했다. 17시 41분 KST에 확인한 후보 38묶음은 이미 적재되어 있었다.

실제 MPPM 검증은 bf51b031과 수집 수정에서 진행했다. Windows 빌드는 이후 dev의 대기실·탈출로·인간대포·밧줄 변경을 받아 e59a4cb2를 기준으로 생성했다. 이후 추가한 절단기 소지 도착, 런 포기 결과, 탈출로 보스 상태 필드는 위 실측 건수에 포함되지 않는다.
