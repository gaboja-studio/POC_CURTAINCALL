# 스케줄표 2인 LAN 검증

2026-11-14. Unity 6000.3.25f1, 같은 PC의 Multiplayer Play Mode 에디터 두 프로세스를 게임의 LAN 접속으로 연결. 호스트 ID 0, 참가자 ID 1, 양쪽 인원 2. Unity Input System의 키보드·마우스 입력 이벤트로 재현. 개발 시작 지점과 테스트 데이터로 대기실·공연 해금 조건을 준비했다.

- **공연과 난이도 동기화 PASS.** 2일차 첫 칸을 두 화면에서 `줄타기 1단계`로 확인했다. 호스트 슬롯 클릭 후 열려 있던 참가자 화면에 `인간 대포 1단계`가 표시됐다. 화살표 클릭의 `인간 대포 2단계`가 참가자에게 수신됐고, 참가자 화면을 열어 둔 상태에서도 `2→1` 변경을 확인했다. 참가자 슬롯과 좌우 화살표는 비활성.
- **캐릭터 가림·클릭 PASS.** 참가자 인스턴스에 전진·점프를 입력해 실제 네트워크 캐릭터를 판 앞에서 이동시켰다. 호스트 프레임 19523에 참가자 렌더러의 경계와 화살표 시선이 교차하고 캐릭터 깊이가 판보다 얕았다(1.17 m / 2.00 m). 그 프레임에 호스트의 마우스 누름을 넣었다. 첫 UI 히트는 `NextTier`, 클릭 결과는 공연 유지 및 `1→2`, 피드백은 `2단계 적용됨`.
- 최종 참가자 화면에서 같은 `인간 대포 2단계`를 확인했다. 참가자 읽기 전용 검사와 클릭 증거를 `2p-client-result.json`, `2p-crossing-result.json`에 보관했다.

캡처: `Captures/2p-remote-in-front.png`는 마우스 누름 프레임의 월드 카메라만 기록한 장면이다. `Captures/2p-host-applied.png`는 같은 클릭 직후의 호스트 게임 화면, `Captures/2p-client-after.png`는 참가자 최종 게임 화면이다. `2p-client-before.png`, `2p-client-show-changed.png`, `2p-client-live-tier-1.png`는 참가자 변경 과정의 캡처다.
