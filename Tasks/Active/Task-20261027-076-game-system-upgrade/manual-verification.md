# M2 2차 묶음 사용자 플레이 확인

자동 회귀 확대 대신 기능별로 한 번에 확인한다. 아래는 미확인 항목이며 통과 기록이 아니다. 가능하면 호스트·참가자 2인으로 실제 Start 흐름에서 확인한다.

## 시스템·대기실
- [ ] 생존 호응×2, 사망 호응 절반 인정, 실제 도착자만 단계별 완주 보너스. 실패도 호응 보상 지급, 기본 자금·전원 생존 보너스·잡힘 박탈 없음.
- [ ] 개인별 관심 감소는 20초 뒤 시작. 환호·시간 끌기 야유 시 유예 초기화. 사망/도착자의 값은 더 줄지 않음.
- [ ] 쉬는 시간 진입 즉시 5분 시작. 만료 시 무대 입구 밖 인원 잡힘. 입구 집결·다음 공연 진행 확인.
- [ ] 쉬는 시간·밤 신체 복구 가능, 공연 중 불가. 1~3부위 선택, 첫 단가100·팀 이용 후125, 새 세대100 초기화.
- [ ] 난이도는 깬 단계+1까지(최대3) 선택, 실제 공연 단계와 보상에 반영.
- [ ] 원형 시계의 시간대·중앙 시각·일차·쉬는 시간 고리가 읽히며 기존 UI를 가리지 않음.

## 공연장: 인간 대포
- [ ] 바닥 추락 시 2곳 절단 후 바닥에서 이동·재탑승·트램펄린 가능. 총4곳 상실 시 즉사.
- [ ] 바닥 없는 낙하는 마지막 탑승 대포로 돌아가며 부상이 중복 적용되지 않음.
- [ ] 철망 위 비행 중 불필요한 절단이 없는지 확인(자동 검사 간헐 실패 미해결).

## 공연장: 외줄 (2인 우선)
- [ ] 균형 게이지 초과 시 매달림, 7초 경과 시 낙사. 줄 밖 착지는 기존 낙사 유지.
- [ ] 외줄 추락 매달림 시 Hanging Idle이 즉시 재생되고 손이 줄을 잡는 위치에 맞음. 일반 균형/추락 위험은 동결되고 표시 추락 게이지만0에서7초 동안 다시 참.
- [ ] 근처 동료 F로 2초 구조, 구조 중 버티기 시간과 표시 추락 게이지 정지, 완료 후 줄 위에서 조작 복구·균형 및 추락 게이지0 초기화.
- [ ] 인간 대포/외줄 그네·매달리는 리프트에서도 Hanging Idle 손이 봉을 잡고 일반 균형/추락 위험은 동결됨. 이 장치에는 외줄 추락 구조 안내·7초 제한·구조 입력이 적용되지 않음. 내리면 정상 애니메이션과 계산으로 복귀.
- [ ] 구조자 부상·사망·거리 이탈·F 길게 취소 시 남은 버티기 시간 재개.
- [ ] 목마 붕괴 시 아래부터 가까운 빈 줄 배정, 줄이 모자란 사람 낙사. 구조 후 목마 추종/조작 잠금 잔류 없음.
- [ ] 호스트·참가자 화면의 위치·남은 시간·안내 일치, 공연 재시작/종료 뒤 매달림 잔류 없음.
- [ ] 피날레에서 목마 상대가 바뀌지 않고, 위층 점프 때 아래 담당자가 추가 절단되지 않음(관련 자동 검사3건 실패 미해결).

## 런 포기·그래픽 설정 (2026-10-28 추가, 실제2인/PC 빌드 미확인)
- [ ] 대기실 ESC→설정→런 포기: 호스트만 클릭 가능, 참가자는 호스트 전용 비활성 표시. 아니요/ESC로 취소하면 런 유지.
- [ ] 예를 누르면 방·접속을 유지한 채 두 화면 모두 다음 세대1일차 첫 공연으로 이동. 공동 자금·소지품·부상·난이도 기록·복구 가격 초기화, 가판대 등 세션 데이터 유지.
- [ ] 공연/로비/탈출/전환 중 포기 불가, 확인 중 시간대가 바뀌면 이전 요청 거절. 재시작 후 입력/커서 정상.
- [ ] 설정→그래픽 탭에서 전체 화면/전체 화면 창/창 모드·해상도를 PC 빌드에서 전환. 전체 화면 창은 데스크톱 크기이며 해상도 선택 비활성. 독점 전체 화면의 플랫폼 실제 적용 모드 확인.
- [ ] FPS30/60(기본)/90/120/144/165/240/제한 없음 적용. 취소/ESC는 미적용, 적용 후 씬 전환·앱 재실행에서 선택 유지. 성능에 따라 실제 FPS는 요청값보다 낮을 수 있음.
- [ ] 키보드·게임패드 분류/선택 이동과 서로 다른 화면비 확인. v2 탭 이동에도 음량 편집값 유지, 기존 마이크/팀원 음성 정상.

## 설정 v2 프리팹 후속 실기 확인
- [ ] 제공 디자인의 실제 가독성·색/크기·투명도·본문 스크롤·고정 푸터·확인창 외형 승인. 1920×1080 캡처/합성 포인터 회귀는 통과했으나 사람 디자인 승인이나 다른 화면비 실기는 아니다.
- [ ] 시작/로비에서 게임 탭 비활성, 런 중 활성·공연 중 포기 버튼 비활성. 탭 이동·스크롤·뒤로·적용 후 입력/커서 정상.
- [ ] 조작 키 변경 후 실제 이동/자세/행동/상호작용/달리기/앉기·씬 전환/재실행 유지·기본값 복원 확인. ESC/M 고정·중복 거절, 표시 안내의 고정키 잔존도 확인.
- [ ] 사운드 전체/효과음이 종·금속음과 실제 음성에 적용되고 BGM/SFX가 음성에 중복 적용되지 않음. BGM 재생 코드는 아직 없으므로 배경음 슬라이더는 Bgm 등록 음원 연결 후 청취 검증 필요.
- [ ] 기기 목록 불러오기·마이크 권한·기기 전환/분리/재연결/재실행 복원·2인 마이크on/off·입력/수신/개별 팀원 음량 검증. 출력 선택은 음성 전용, 게임 소리 출력은 OS 설정을 따름.
- [ ] 기타 개발자 표시명/역할 승인, BM 등 추가 폰트·에셋·패키지의 배포 조건 확인 및 필요한 고지 보완. 현재 UI는 전체 라이선스 검토 완료를 뜻하지 않음.
- [ ] 각 탭 스크롤 끝 초기화 버튼 외형 확인. 그래픽/조작/사운드만 해당 탭 기본값 복원·적용 후 앱 재실행 유지, 취소 시 기존값 유지. 음성 준비 상태의 입출력 시스템 기본 기기 전환은 실제 장치로 확인. 게임/기타는 비활성, 런 진행 데이터는 초기화하지 않음. 개별 팀원 음량/음소거는 현재 세션 메모리 전용으로 재실행 영구 저장 대상이 아님.

## 이번 완성 범위 밖
- 기물7종 실제 효과·개별 내구도·소진 처리 미구현. 상점 임시 품목은 7종 완성품이 아니다.
- 밤 탐색 제한·침대 수면 종료·대기실 방 랜덤 배치는 다른 작업자 담당.
- 실패 제보는 공간/난이도, 호스트 또는 참가자, 직전 행동, 예상/실제 결과와 가능하면 영상을 함께 남긴다.
