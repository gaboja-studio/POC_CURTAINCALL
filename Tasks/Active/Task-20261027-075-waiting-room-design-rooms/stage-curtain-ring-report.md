# 무대 입구 커튼 연출·연습실 링 40m

## 무대 입구 (`WaitingRoomLayoutA.StageCurtain.cs`, 런타임 `StageCurtainReveal.cs`)

- 비균일 스케일(2.6×1.8×1.55) 그룹 안에 있던 기존 천 커튼은 비활성, 상자형 주름 8개는 렌더러만 끔(충돌체 유지). 스케일 없는 `StageProcessionalRoute/StageCurtainReveal`에 13.3×7.8m 천 커튼 한 쌍을 새로 만듦.
- 천: 불규칙 주름(주기 0.42~0.66m, 깊이 0.12~0.17m), 정점 3,540개, Cloth 바람(draft 2.6, random accel). 벨벳 재질은 생성한 섬유 결 기본/노멀 텍스처.
- 열림: 집결 판정 `StageEntranceGather.InsideCount > 0` → 커튼 좌우로 걷힘(상단 1/3로 모임, 밑단 들림), 커튼 뒤 0.5m 황금빛 면(방사·햇살 그라데이션), 바닥까지 뻗는 가산 빛줄기 4면, 금색 스폿·포인트 조명, 금가루 낙하(초당 180, 수명 11~15초, 바닥 평면 충돌로 정지) + 열림 순간 버스트 1,200개. 모두 떠나면 닫히고 빛 1.4초 페이드, 입자 방출 중지.
- 플레이 확인(오프라인, 시험용 PlayerMover 1명): 열림·닫힘, 금가루 2,200개 중 바닥 1,598개·바닥 아래 0, 버스트 재생 확인. 원격 다인원·성능은 미측정. 후처리(Bloom)가 꺼진 공용 카메라 설정은 바꾸지 않음.

## 연습실 링 (`WaitingRoomLayoutA.PracticeRing40.cs`)

- 링 평면 16→40m: 데크·별 바닥·나무 테두리 평면 2.5배, 치마 120장·난간 기둥 60개·난간/깃발 판·전구를 새 둘레에 재배치(계단 2곳 개구). 높이 0.6m·난간 높이 유지. 계단 2세트는 새 가장자리로 이동.
- 외줄 11.5→28.8m: 탑·사다리·사다리 충돌 보정·앵커를 바깥으로 이동, 줄·바닥 테이프 연장.
- 외줄 남쪽 6.5m 레인에 인간 대포(PerformanceArtKit/HumanCannon, 동쪽 발사)·발사대·착지 매트·안전망을 90° 회전 배치, 북쪽에 트램펄린(CarryTrampoline 4m).
- 관중석 3단(반경 22.9/24.0/25.1m, 높이 0.45/0.9/1.35m)·등받이 난간 94구간. 출입구(-40°±13°)·계단 앞·조명탑 4곳 비움. 기존 소형 스탠드는 새 링 안에 들어가 비활성.
- 조명탑 4개를 반경 23.6m로 옮김(입구 쪽은 -62°로 회피). 천막에서 이어진 전구 줄·로프는 새 탑까지 늘림. 스테이션 스폿·링 스폿은 새 외줄·대포·착지·트램펄린을 향하게 조정. 중앙 천막(22m)은 돔 간섭 때문에 유지.
- 확인: 출입구→링 계단·둘레 통로 캡슐 62지점 중 막힘 1(계단 경사 충돌체 자체), 관중석과 다른 충돌체 겹침은 외벽 충돌체뿐. 외줄 탑·사다리 하단은 이전처럼 데크를 관통(데크 위에서 오르는 구조). 실제 이동·사다리 오르기·연습 기능은 미검증.
