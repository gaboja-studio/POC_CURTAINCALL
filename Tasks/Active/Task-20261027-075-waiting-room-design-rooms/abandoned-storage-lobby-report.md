- `WaitingRoomLayoutA.Abandoned.cs`: Frame8 로컬 좌표 기반 보관소/로비 독립 진입점. 기존 Greybox 원본은 Snapshot 대조. 기존 보관소 Archive·UnderSheets·기물 묶음은 비활성 보존하며 외피·기둥·두 출입구는 유지.
- 보관소: 철망/철판 격벽 4개로 기록·모니터링, 로커/전시, 적재의 3개 구획. 컴퓨터 2대·대형 6분할 모니터·깨진 단체사진 액자 2개·로커 5칸과 전기 캐비닛 3칸·만재 선반 4개·기록책·폐기 장비 팔레트.
- 단원 4명: 곰 인형탈 기대앉음/왼팔 결손, 토끼 인형탈 엎드림/오른다리 결손, 단장 옆으로 쓰러짐/머리 결손, 광대 주저앉음/오른쪽 하퇴 결손. 후속 지시로 자세·회전을 유지한 채 캐비닛 옆 동쪽 빈 벽면에 일렬로 모아 긴 전시대와 번호판 설치. 현재는 기존 인형탈과 절차적 의상/신체 조형을 사용한 환경 오브젝트다.
- 스파크: 손상된 배전함 3곳에 지연·반복 버스트 파티클. 실시간 그림자는 추가하지 않음.
- 로비: 통로 입구를 피한 외벽 8개 구역에 노후 패널·녹슨 배관·배전함·드럼통·상자·판자·기름 얼룩. 상부 배관과 천장 고정 부재, 기존 로비 조명을 따뜻한 색으로 조정. 돔·계단·서비스·방 배치 유지.

## 확인

- Unity 현재 씬: WaitingRoomBase, 작업 전 dirty=false, 원본 Greybox 비활성.
- Frame8 Validate PASS: 상점 참조·스폰·로비 통로 중심. missing script 0.
- 보관소 두 출입구↔중앙 통로↔기록석/북쪽 적재/전시대 접근을 반지름 0.28m·높이 약 1.9m 캡슐로 132지점 확인, 막힘 0. 실제 PlayerMover/4인 플레이 검증은 별도.

- 파티클 3곳 각각 버스트 후 살아 있는 입자 10개 확인.
- 보관소 입구·로커·선반·전시대, 로비 2개 시점 렌더 확인. 글자 반전·인형탈 접합·공중 책 배치 수정.
