# 전문가 승강기·충돌·통로·기계실 세부 수정 — 2026-10-28

## 범위와 결과

- 전문가: 별도 홀과 커튼 부스는 비활성 보존, 기존 승강기를 로비 동벽에 직접 부착. 3.2m 폭·2.7m 깊이의 승강기 하나와 작은 문턱만 사용한다. 문 분할·금속 보강대·손잡이·호출 패널을 두고 기존 ExpertRoomView 인스턴스와 UI 참조를 유지한다. 새 금속 문·실내/복귀 지점·상태 표지·조명을 연결했다.
- 연습장: 원복돼 있던 SM_Ladder1의 약 1.06×3.60×0.89m 수입 충돌 상자를 비활성화하고 0.82×3.60×0.12m 뒤쪽 면으로 교체. 링·타워·사다리 시각과 링 높이를 변경하지 않았다.
- 무대 통로: 위치만 늘려 배치한 원본 파이프 조각의 이음새가 벌어지는 원인 확인. 조각을 제외하고 같은 높이/지름의 연속 주관·보조관을 로비 전이부부터 끝벽 안까지 연결. 커튼 전면에 낡은 목재 띠/기둥, 이어진 목재 바닥 동선을 사용하고 과한 바닥 화살표·노란 운반선·긴 붉은 러너를 제거했다. 원본 커튼·측면 공간·소품과 기존 외곽 크기는 유지한다.
- 기계실: 25.8×15.1m에서 37.8×27.1m로 확장(약 2.63배), 기존 이층 설비 피트/계단/상부 통로 보존. 대형 기계 4대, 압력 탱크·펌프 스키드·배관 랙·서비스 칸막이·드럼과 기름때를 추가해 서로 어긋난 설비 섬과 통행로를 구성했다. 주 배관 분배실 및 목적지 표지를 비활성화했다.
- 탈출 연결: 상부 통로에서 바로 들어가던 연결을 피트 바닥(-10m)으로 내려 설비 가림막 뒤로 숨겼다. 계단으로 내려가 설비 사이를 탐색하고 뒤쪽 반환 통로로 들어간다. 기존 봉인 문과 탈출 입구는 유지하며 퍼즐 기능은 추가하지 않았다.
