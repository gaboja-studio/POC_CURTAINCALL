# 9단계 마감 1차 — 외부 노출 구멍·연결·기능·성능 (2026-10-28)

## 외부(하늘) 노출 수정

- 사용자 화면의 구멍: 로비 동벽 무대 통로 입구. 원본 아치는 둥근데 로비 개구부는 9.2m 머리보까지 사각이고, 접근부(x14.7~27)에는 지붕이 없었다. 아치 양 윗모서리로 하늘이 보였다.
- `WaitingRoomLayoutA.Enclosure.cs`의 `SealExteriorOpenings()` 하위 `ExteriorEnclosure`:
  - `StageApproachSpandrel`: 실제 아치 단면을 따라 로비 쪽 양 모서리를 막는다. 재질은 머리보와 같다.
  - `StageApproachRoof`: 접근부 벽 위 지붕.
  - `LiftShaft*`: 높이 3.7m 승강기 위가 열려 있어 추적 카메라가 하늘을 보았다. 로비 지붕 높이까지 승강로로 막았다.
  - `InfillSlotCap`: 로비 남서 모서리의 두 벽체 사이 7cm 틈 끝을 막았다. 기존 LogisticsFrontages는 건드리지 않았다.
  - `DarkOuterShell`: 전체 배치 밖 16m를 두른 안쪽 면 Unlit 어두운 상자다. 그림자·충돌체·프로브가 없다. 카메라가 외벽 뒤로 빠질 때 하늘 대신 어둠을 보이게 하는 마지막 보호막이다.
- 새 물체에는 충돌체가 없어 동선이 바뀌지 않는다. 원본 Snapshot 보존 검사를 통과했다.
