# 다듬기 3차 — 낡은 천막·스폰 앞 쓰러진 조명·벽 너머 글자·꺼진 모니터·사실적 인형탈 (2026-10-29)

생성기: `WaitingRoomLayoutA.Polish3.cs`(진입점 4개), 천막은 `Polish.cs`, 모니터·컴퓨터·전시 라벨은 `Abandoned.cs` 생성 코드도 함께 수정.

## 로비 천막
- 캔버스 질감 텍스처: 바닥에서 올라온 흙때, 흘러내린 물자국, 곰팡이 점, 햇빛에 바랜 부분.
- 구멍 4곳(모양 다름), 들쭉날쭉 늘어진 밑단(일부 면 빠짐), 떨어져 나가거나 처진 물결 장식, 해진 천 조각 22개, 굵은 바늘땀으로 꿰맨 덧댐 7개.

## 스폰 앞 쓰러진 조명
- 스폰 4곳 중앙에서 앞쪽(바라보는 방향) 2.4m: 쓰러진 철망 작업등(켜진 전구), 부러진 스탠드, 바닥에 늘어진 전선, 깨진 유리.
- 낮은 주황 포인트 조명(3.2, 6.5m, 부드러운 그림자) + 바닥의 따뜻한 빛 웅덩이, 장작불처럼 계속 흔들리는 약한 깜빡임. 스폰 막힘 0.

## 벽 너머로 보이던 글자
- 원인: 생성한 TextMesh가 기본 글꼴 재질(GUI/Text Shader, 깊이 무시)을 써서 벽을 뚫고 보였다. 깊이 검사 재질 `GB_Text`로 바꿈(씬 18개 + 생성 코드). 남은 기본 재질 글자 0.
- 깊이 검사로 바뀌자 전시 벽 라벨이 벽의 가로 철골과 기둥에 가려져, 2.9m 높이·기둥 사이로 옮김.

## 모니터
- 대형 모니터 벽: "CAM / NO SIGNAL" 글자·화면 패널·주사선과 위 "ARCHIVE / 04" 글씨 제거. 6대 모니터를 플라스틱 베젤 + 꺼진 화면 유리(검은 광택, 먼지·얼룩, 조명 반사) + 꺼진 대기 LED로 재구성.
- 컴퓨터 2대: 누렇게 바랜 베이지 플라스틱 본체·키보드, 오목한 베젤 안 볼록한 꺼진 브라운관, 꺼진 전원 LED, 플로피 드라이브. 깨진 단말은 화면 금 유지.

## 인형탈
- 기본 도형 조합이던 곰·토끼·광대 머리를 펠트 질감(섬유 노멀·보풀·때)과 울퉁불퉁한 솜 형태로 재제작(각 45~49 부품). 기획 문서의 이전 세대 코스튬 설정 반영:
  - 초록 곰: 단추 눈 하나, 반대 눈은 체크무늬 천 덧댐, 작은 실크해트, 꿰맨 솔기, 뺨이 터져 솜이 비어져 나옴.
  - 노란 토끼: 각지게 꿰맨 얼굴, 한쪽 귀 꺾여 처짐, 앞니·수염·분홍 코, 이마 덧댐.
  - 파란 광대: 분칠한 얼굴, 빨간 코, 처진 입, 눈물 무늬, 벗겨진 분장, 뭉친 파란 머리, 해진 러프 칼라.
- 기존 도형 머리는 비활성으로 보존, 자세·결손 유지. 엎드린 토끼는 귀가 몸 반대쪽을 향하도록 방향 보정.
