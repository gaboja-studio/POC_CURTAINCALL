# Task-20261104-101

- **Title:** 추격자 인식 상태 눈 스프라이트와 로컬 피드백 적용
- **Type:** feat
- **Assignee:** @MoHoDu
- **Branch:** feat/pursuit-eye-art

## Context
추격자 머리 위에 표시할 인식 상태 눈 아이콘과 열림/닫힘 스프라이트를 GPT 이미지 생성으로 제작한다. 2026-11-04 사용자가 디자인 컨펌과 실제 Unity 적용을 승인했다.

## 계획
1. 인게임 이미지의 어두운 산업 공간에 맞는 간결한 눈 모양 제작.
2. 모든 프레임은 흰색, 투명 배경, 별도 검은 아웃라인 없음. 색상과 발광은 Unity 에디터에서 설정.
3. 사용자 승인(2026-11-04)에 따라 코드 후처리로 검은 배경 제거·프레임 정렬·투명 PNG·애니메이션 미리보기 제작.
4. 8프레임, 16fps 기준 0.5초 열림/역순 닫힘. 일반은 첫 프레임, 경계·추격은 마지막 프레임을 공유.
5. 승인된 8개 PNG를 Unity Sprite로 임포트하고 PursuitDirector의 로컬 전용 표시 컴포넌트로 연결한다.
6. 기존 행동 상태·대상 정보를 재사용한다. 로컬 플레이어를 실제 추격할 때만 빨강, 공격 준비는 노랑. 대상 없는 경계/조사/수색은 범위 안 로컬 화면에 노랑으로 표시한다.
7. 범위는 현재 단계 시야/걷기/달리기 청각의 최댓값(3D 거리), 방·순찰 제한도 적용한다. 위치 무관 추격 단계에서도 UI는 이 유한 거리만 쓴다. 머리 추적 빌보드, 일반 깊이 검사로 벽 뒤 아이콘은 가린다.
8. 색·발광·번짐·크기·높이·시간을 Pursuit.Eyes와 Mannequin Designer에서 조절한다. 프레임은 상태에 따라 코드로 재생하여 중간 전환도 연속 유지한다.

## 미정·주의
- 실제 적용 승인: 로컬 조작 플레이어 기준만 표시, 네트워크 동기화 제외, 인식 범위 안에서만 보임, 머리보다 조금 작은 크기. 범위 진입/이탈 알파 전환 각각 0.5초.
- 경계는 노랑·눈 열림 0.5초 후 유지. 일반 복귀는 흰색·닫힘 0.5초. 추격은 혈색 빨강·약한 발광. 추격 종료 시 경계 또는 일반으로 전환.
- AI 생성 프레임의 중간 모양·동공 변화는 시안이며 최종 체감은 사용자 확인 대상.
- Unity 지정 버전·외부 에셋·기존 Task 중복 문제는 이미지 제작과 분리하여 기록. 2026-11-04 사용자가 전체 검증 완료 및 모든 변경 commit/push·dev PR을 요청했으며 추가 검증은 생략한다.
