## P1 복도 추격을 플레이하는 방법
개별 동작을 보려면 같은 씬에서 Play한 뒤 **F6**을 누른다. 플레이어를 직접 움직이면서 **1**은 오른쪽 벽 부수기, **2**는 걷기, **3**은 내 쪽으로 돌아서 추격, **4**는 중앙 문틀에서 숙여 통과, **5**는 오른쪽 벽 앞 8m 구간의 달리기를 볼 수 있다. **6**은 같은 벽 앞에서 몸을 낮췄다가 앞으로 뛰고 양발로 착지하는 동작이다. **R**은 지금 동작을 다시 시작하고 **F6**은 일반 추격으로 돌아간다.

1. 독립 첫 등장 테스트 씬에서 Play하고 오른쪽 콘크리트 벽을 본다. 벽이 무너지고 거구의 네 번째 발이 닿으면 추격이 시작된다.
2. 중앙 문틀로 달린다. 추격자는 현재 플레이어 위치로 선회하며, 3.8m 인방 아래에서 무릎과 상체를 굽히고 속도를 낮춘다.
3. 문틀을 지난 뒤 왼쪽 작업대의 정비 카트를 지나 왼쪽 가장자리를 따라 달린다. 일반 추격 중 추격자가 이 경로를 선택하면 카트를 뛰어넘고 착지한 뒤 추격을 이어간다. 중앙에는 걸어서 통과하는 길이 있다. 카트에서 12m 이내일 때는 **F6 → 6**으로 실제 카트를 넘는 동작만 반복할 수 있다.
4. 착지 후 작업등을 따라 직진해 Z 66의 벽기둥을 지나고, 복도 끝에서 오른쪽으로 꺾어 첫 대포 발판에 올라간다. 플레이어가 발판 안으로 들어가면 추격자는 문밖 남쪽 (18.65, 0, 73.10)으로 향한다. 대기점에 닿으면 몸을 돌려 안쪽을 바라본다. 복도로 되돌아오면 일반 추격을 재개한다. 다인에서는 복도에 남은 정상 대상이 우선이다.
- 보행면은 최신 A와 같은 폭 12.5m, Z 22.5~83이다. 카트는 A의 `EscapeBackground/15_ServiceContext/작업대/SM_ToolCart`이며 중심 (11.07, 0.46, 45.25)이다. 도약 링크의 양 끝은 (11.77, 0, 42.80)과 (12.43, 0, 47.65)다. [도약 검사](Review/understage-gallery-jump.json)
- 카트의 전방 착지점에서 문밖 대기점까지 최단 이동 경로는 26.20m다. 입구의 폭은 6m, 높이는 4m다. 실제 대포 탑승 기준점 (27.50, 0, 75)에서 대기점까지는 9.05m이며, 포신과 탑승 지점은 A의 원래 배치다. 발판은 추격자 이동면에서 제외하고 플레이어용 충돌은 유지했다. 뒷길 추가 없이 기존 바닥만으로 5m 모델의 보행·달리기·선회 공간이 확보됐다. [카트부터 대포 앞까지 검사](Review/understage-first-cannon.json)
- 이 테스트 구간의 지형이 바뀌면 원본 A의 입구와 발판을 대조하고 대기점·탑승 구역을 옮긴 뒤 **Tools → CurtainCall → 탈출로 → 추격자 테스트 씬 이동면 굽기**를 실행해 저장한다.

## 기존 테스트 씬에서 2~4인 추격 보기
1. UnderstagePursuerPlaytest 씬을 열고 **Tools → CurtainCall → 탈출로 → 추격자 테스트 인원**에서 전체 인원을 선택한다.
2. **Window → Play Mode → Scenarios**에서 메인 Editor 1개와 **Additional Editor Instances** 1~3개로 같은 인원을 구성한다. 이 시나리오를 선택한 뒤 메인 Editor에서 일반 **Play**를 누른다. 설정한 인원이 접속하면 자동으로 시작한다.
3. 한 사람이 대포 발판에 들어가고 다른 사람이 복도에 남아 목표 교대를 본다. 전원이 발판 안에 들어간 뒤 한 사람이 복도로 나와 다시 따라오는지도 확인할 수 있다.
4. 혼자 F6 동작을 볼 때는 **추격자 테스트 인원 → 1인**과 메인 Editor만 실행하는 시나리오를 선택한다.

## 첫 대포 건너편에서 다시 만나는 추격자

1. 일반 Play에서 첫 대포에 탑승해 발사한다. 기본 발사 방향의 탄도는 약 1.90초 뒤 (47.53, −6, 75)에서 첫 외줄에 닿는다. 호스트가 첫 대포의 실제 외줄 착지를 확인하면 그 라운드의 우회가 시작된다. 후속 탑승자는 같은 대포를 계속 이용할 수 있다.
2. 추격자는 문밖 대기점에서 남쪽 정비 셔터 (21.75, 0, 66.8)로 돌아선다. 붉은 안전선 너머로 들어가 외줄 남쪽 가림벽 뒤의 경사로를 따라 6m 내려간다. 대기점에서 망루까지의 기준 경로는 약 48.7m다.
3. 착지한 플레이어가 외줄을 따라 첫 봉을 향해 가면 우측으로 정비 출구의 주황빛이 보인다. 추격자는 가림벽 안에서 감속하고, 끝을 돌 때 상체부터 드러낸 뒤 X 54까지 걸어온다. 기본 착지점의 눈높이에서 가림벽 너머로 몸통이 나타나는 위치는 X 약 49.5다.
4. 이후 외줄을 건넌 참가자가 앞선 만큼만 옆 발판에서 따라온다. 통로 진행 방향으로 3.5m 이상 벌어지면 달리고, 1.5m 안으로 좁혀지면 감속한다. 첫 봉 옆 (60.4, −6, 66.8)에서 더 나가지 않고 플레이어를 향한다. 첫 등장 직후에도 최소 3m를 걸은 뒤 달리기를 허용한다.

테스트 씬에서 대포 문 남쪽 벽체 일부에 정비구를 냈다. 외줄·봉·포구는 최신 A의 배치를 사용하며, 플레이어의 대포 진입선과 추격자 통로 입구는 분리돼 있다. 첫 봉에서 원본 상단 외줄에 닿는 반동 궤적을 검사한 뒤 추격자 발판 끝을 줄였다. [우회 경로·시야·착지 검사](Review/understage-post-cannon.json)

## 실측에서 수정한 판단
- 첫 복도는 바닥이 있지만 벽 뒤 포켓·측면 정비대는 대부분 공중이다. 바닥과 실제 지지/외피를 새로 만들어야 한다.
- 컨베이어 레일 중심 X35~67,반동/좌석 발 위치는 약X33.5~68.5. X35를 외측 안전 통로로 쓰는 초안은 제외하고 X26으로 이동했다.
- 기존 그네15개의 좌석·41각도·순환32위상 표본에서 초기 제안 P2/P3 바닥과 보수적 플레이어 몸통 AABB 간섭0. 자유 비행/놓기·새 확대 폭의 최종 판정이 아니다.
- 후반은 접이교3곳 때문에 중앙 직선만으로 추격할 수 없다. 북측 기둥/반출기/정비대도 있어 전용 하부 우회가 필요하다. 현재 검토 모듈은 연속 경로가 아니다.
- 5m 정지 외형을 P1/P2/P3/P4/P5에 두고 안전 여유를 포함한 AABB로 원본 Collider 간섭0 확인. P2/P3 바닥은 검토용이므로 실제 지지 검증과 구분한다.
- P1 독립 씬에서는 걷기·선회·숙이기·벽 파괴를 1인으로 검증했다. 나머지 구간의 이동과 공격·도약, 2~4인 조작 시간·성능·공포감은 미검증이다.
