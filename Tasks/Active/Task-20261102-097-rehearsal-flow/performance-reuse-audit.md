## 현재 확정한 다섯 단계

사용자 정정: **1 → 2-1 → 2-2 → 2-3 → 3 순서와 전환 흐름은 유지하고 학습 내용만 실제 활성 기물에 맞춘다.** 30초 유지 제한은 제외한다.

| 단계 | 학습 내용 | 기물 |
| --- | --- | --- |
| 1 | 이동·균형 | 공연 외줄 |
| 2-1 | 줄 전환·손잡기 범위 착지 | 공연 외줄/손잡기 범위 표시 |
| 2-2 | 출발 봉→먼저 건너기→반대편 교대 봉 | 원본 네 해제봉, 무작위 연결 규칙 |
| 2-3 | 목마 연결·2m 이동·분리 점프·도착 착지 | 원본 목마 |
| 3 | 목마로 첫 봉 진입·동료 매달림·비행·다음 봉 잡기 | 원본 첫 두 공중그네 봉 |

- 모든 단계의 코스 설정은 실제 공연 `GameSettings.Tightrope.Course.Clone()`에서 복사한다. 연습실에 맞춰 앞뒤 거리·시작 위치와 단계별 활성 기물만 바꾼다. 줄 수/간격/굵기/지지 폭/발판/색/그네 간격/목마 연결은 원본 설정이다.
- 휴면 일반 그네 UseSpots와 지정 자리 트리거/BlockSegment 제어를 제거했다. 원본 해제봉이 실제 연결 줄과 기하를 관리한다.
- 기존 다섯 단계의 전원/과반 투표, 2-3 한 명 성공, 출발대 무패널티 복귀, 선택 재연습, 완료 후 집결은 보존한다. 성공 판정에는 현재 기능 학습 증거가 필요하다.
- 시간·환호·공연 진행도는 기존 사용자 요청대로 숨긴다. 기존 PracticeMode에서만 해제봉/공중그네의 30초 강제 해제와 유지 시간 표시를 끈다. 일반 공연은 계속 30초 제한을 쓴다.
- 공연 준비 프리팹, 아트 프로필, 플레이어 프리팹, 조작 클래스와 공용 UI를 재사용한다. 신규 아트는 없다. BalanceCanvas의 실제 씬 override(Expand, 위험 게이지23/15px)도 적용한다.
