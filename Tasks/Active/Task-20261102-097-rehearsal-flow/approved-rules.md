# 공연 리허설 최종 승인 규칙

> 최신 사용자 지시: 대기실 Dev 모드에서 리허설을 선택해 개발·확인한다. Start/전체 씬 연결은 마지막에 수행한다. 기능 구현 우선, 두 단계씩 진행하며 상세 수치는 플레이어가 조정한다.

## 공통 완료·투표

- 1단계·2-1·2-2·3단계는 같은 규칙이다. 2-3은 한 명만 도착해도 바로 다음 구간으로 간다(사용자 2026-11-04).
- 한 명 도착 후에도 다른 참가자는 계속 연습한다. 전원 도착 또는 현재 접속 참가자 과반수 동의 시 다음 구간으로 즉시 전환한다.
- 투표는 최초 도착 이후 가능하며 각자 동의 체크를 켜고 끈다. 4명=3표, 3명=2표, 2명=2표다.
- 도착자는 도착대 안에서만 이동 가능하다. 조작 퀘스트는 제거하고 동료 진행·투표 현황을 표시한다.
- 최초 필수 리허설은 포기할 수 없다. 단계 넘기기 투표는 리허설 포기와 다르다.

## 개인 체크포인트·배치

- 기물 이용 직전 안전 위치를 개인 체크포인트로 저장한다.
- 비상호작용 기물은 끝나기 3m 전을 배치 기준으로 하되, 공중·끊긴 줄이면 안전 지점으로 조정한다.
- 마지막 유효 체크포인트에서 추락 1.5초 후 무패널티 복구한다. 획득 전에는 소구간 출발점을 쓴다.
- 배치 원칙은 확인·승인됐지만, 실제 기물 좌표와 안전한 복구 위치는 아직 전부 검증하지 않았다. CC-211에서 기물별 기록, CC-216에서 실제 입력·추락 검증을 한다.
- 중간 발판은 기존 공연 발판을 재사용한다. 리허설 전용 발판 아트·받침·틀은 만들지 않는다.

## 장치·가이드·첫날 연결

- 실제 공연 장치·물리·입력·HUD를 재사용한다. 인간 그네는 혼자 F 잡기→W/S 반동→Space 놓기, 연속 구간 공중 F로 다음 그네 잡기를 유지한다.
- 가이드 패널은 최종 기획서의 설명/퀘스트 패널대로 구현한다. 별도 디자인 재논의는 하지 않는다.
- 단장 모니터: 통로 진입→잡음→얼굴 3초→종료, 리허설당 1회다.
- 최초 교육 이수 후 연습실에서 단계 선택 재연습과 자유 종료를 허용한다. 앱 완전 종료 전까지 이수 상태를 유지한다.
- 첫 공연은 외줄 고정, 대기실 안내 완료 후 호스트가 스케줄표에서 두 번째 공연을 선택·확정한다.
- 인간대포 리허설은 후순위이며 상세 공란을 이전 Confluence 내용으로 자동 채우지 않는다.
