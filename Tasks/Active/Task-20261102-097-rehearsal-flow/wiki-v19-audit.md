- 3단계 도면/본문이 달라 확인했고, 사용자 답변 **현행 유지**를 우선했다.
- 대포 운송은 문서의 최신 dev 원본 규칙 우선을 적용했다. 현재 2명 이상 출발 거부/overloadTrap=false이며 안내도 실제 규칙을 설명한다.
- 거리·발판 수치는 문서의 기존 임시값이다. 새로운 확정 디자인 값으로 기록하지 않는다.
