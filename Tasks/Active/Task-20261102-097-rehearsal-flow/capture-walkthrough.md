# 리허설과 이후 퀘스트 캡처 모음

2026-11-03. 리허설은 기존 공연 시스템 재사용 수정본의 실제 키 입력 검사 화면이다. 각 시나리오 시작 위치·단계는 준비했으며 전체 2인 협동 완주는 확인하지 않았다. [입력 검사와 전체 11장](reuse-verification.md).

후속 순서: 리허설 완료·무대 집결 → 첫 공연 → 대기실 안내 → 두 번째 공연 준비·집결 → 두 번째 공연 → 첫날 밤 일정 확정 → 취침 준비.

후속 연결 검사: W6_FirstDay_GuideSecondPerformanceAndNightQuests. 첫 실행은 밤 퀘스트 표시 대기에서 실패했다. 캡처·진단을 추가한 재실행은 1/1 PASS(68.6초). 처음 실패 원인은 확정하지 않았으며 제품 버그를 수정했다고 주장하지 않는다. 해당 검사는 집결 위치를 준비하고 EndPerformance 공개 신호로 공연 종료를 요청한다. 실제 공연 두 번의 조작 완주 증거는 아니다.

두 번째 공연 준비 화면은 개발 시작 도구로 공연 사이 상태를 별도로 준비하고 메모리에서 안내를 끈 뒤 실제 패널을 캡처했다. 이 설정은 PC에 저장하지 않는다. 두 번째 공연 전환 중 찍힌 커튼과 준비 패널이 숨겨진 프레임은 퀘스트 증거에서 제외했다.
