# 개인 체크포인트 배치 기준

현재 코스 데이터를 읽어 계산한다. 아래는 배치를 바꾼 값이 아니라 기존 배치에 승인 규칙을 적용한 결과다. 상세 조정은 플레이어가 RehearsalStage의 배치 데이터를 변경한다.

| 대상 | 후보 위치 | 저장 조건 |
| --- | --- | --- |
| 1단계 각 줄 | 해당 줄 끝에서 3m 전 | 실제 줄 위에 서서 해당 위치 통과 |
| 인간 그네 | 기물의 From에서 기존 RopeWalkWidth만큼 앞 | 실제 줄 위·기물 이용 전 안전 여유 |
| 트리거 | 기존 트리거 Distance | 실제 줄 위에서 접근 |
| 연결 단절 앞 줄 | 단절 From에서 3m 전 | 연결 상태와 무관하게 유지되는 줄 |

- 줄 지지 판정은 기존 TightropeCourse.IsOnRope, 안전 여유는 기존 RopeWalkWidth를 쓴다. 새 코스 길이·기물 간격·높이 조정은 없다.
- CharacterController 접지와 코스 줄 판정을 모두 만족할 때만 저장한다. 공중 통과·다른 줄·기물 밖 바닥에서는 저장하지 않는다.
- 닫힌 줄 또는 트리거 해제 시 없어지는 구간은 후보에서 제외한다.
- 2-2의 두 그네 사이에는 고정 줄이 없으므로 두 번째 그네 앞 후보는 저장하지 않는다. 마지막으로 저장한 첫 그네 앞 안전 체크포인트를 유지한다.
- 추락 뒤 1.5초 무패널티 복구 때 개인 저장 Pose를 사용한다. 저장 전에는 기존 소구간 출발점을 사용한다.
- 새 소구간이 만들어지면 이전 복구점·도착대 복귀점이 초기화된다.
- 후보 계산과 저장/복귀 기능, 실제 다인 조작 체감은 별도의 검증 범위다.
