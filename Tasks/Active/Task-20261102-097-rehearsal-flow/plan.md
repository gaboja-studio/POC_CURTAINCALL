2. 대기실: 리허설 중 연습실 통로만 열고 작업실·하역장·지하 철창을 닫는다. 리허설 완료 뒤 무대 입구 통로 전원 집결 → 공연.
3. 리허설 3단계(같은 씬, 현재 단계 코스만 활성): 기존 외줄 코스 생성 모드(`TightropeCourse` + `TightropeRun` 외부 관리·연습 모드)로 연습실 링 위에 코스를 만든다.
   - 1단계: 2줄, 왼줄이 중간에서 끝나 Q/E+Space로 옆줄 전환 → 전원 도착.
   - 2-1·2-2: 인간 그네(끊긴 줄 + 회전봉, W/S 반동·Space 놓기). 2-2는 그네 시스템이 코스당 끊김 1개만 지원해 더 긴 끊김으로 둔다(후속).
   - 2-3: 트리거 그네(`TightropeRelayGate`, 3줄) — 봉을 잡는 동안 가운데 줄 연결.
   - 3단계: 4줄 종합(트리거 그네 상호 연결) → 1명 이상 도착.
   - 추락: 대가 없이 그 소구간 출발대에서 재시작(호스트 1.5초 뒤 복구, 소유자 이동).
4. UI: 좌측 설명(`WaitingRoomTutorialPanel`), 우측 퀘스트(`WaitingRoomRightPanel`), 바닥 점선 길안내(런타임 NavMesh), 포기 투표(통로에서 F 길게, 전원 즉시·과반수 30초).
5. 개발: Dev 시작 지점에 "리허설" 추가.
