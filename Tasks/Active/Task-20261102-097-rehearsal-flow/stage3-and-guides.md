# CC-214·CC-218 구현 범위

- Base 대기실 Dev 리허설이 진입 기준이다. Start/전체 씬 연결은 마지막에 진행한다.
- 3단계 네 줄·인간 그네·1↔2/3↔4 트리거 배치와 길이/간격/높이를 유지한다. 완료 판정은 공통 전원 도착/과반 동의다.
- 완료 시 추락자를 복구하고 코스를 비활성화한 뒤 실제 연습실 DeckCollider 상단으로 배치한다. 기존 바닥 경계와 플레이어 반지름으로 안전 범위를 정한다. 새 발판·좌표·간격 수치를 만들지 않는다.
- 설명 문구는 기획서 4.3의 내용을 WaitingRoomTexts.txt에 반영한다. 최초 소개가 단계 설명으로 즉시 덮이지 않도록 순서를 유지한다. 소개/단계/완료 10초, 복구4초는 기획값이다.
- 줄 전환 체크포인트와 실제 PiggybackSystem.FindMountTarget 근접 판정에 설명을 연결한다. 구간/재시도마다 필요한 안내를 다시 표시한다.
- 기존 툴팁 프리팹을 유지하며 가이드 제목의 느낌표·연한 주황색을 적용한다. 색상은 WaitingRoomTexts.txt의 guide.title-color로 편집한다. 패널 위치·크기·글자 크기는 기존 설정을 유지한다.
- 단장 연출은 Base에 이미 있는 Zone_StageApproach/Zone_StagePassage의 BoxCollider 구역 진입을 사용한다. 거리9m 근사 판정을 제거하며 기존 통로 구역을 이동/확대하지 않는다.
- 호스트가 최초 진입 시각을 공유한다. 각 화면은 경과시간으로 잡음→얼굴3초→종료를 표시한다. 완료 시각을 보존해 재진입·늦은 합류로 연출/소리가 다시 시작되지 않는다.
- 단장 얼굴 그림과 잡음은 기존 임시 자원이다. 이 작업에서 신규 아트·사운드를 임의 제작하지 않는다.
