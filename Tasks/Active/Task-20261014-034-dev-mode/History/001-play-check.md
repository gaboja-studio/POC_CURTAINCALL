# 플레이 확인 결과

1. 꺼짐: LAN 호스트 1명 → `MinPlayers=2`, `StartGame()` 거절(경고 "최소 2명 필요"), 배지 없음. Play 중 메뉴 실행 → 거부되고 값 그대로(잠김 확인).
2. 켜짐: 1명 → `MinPlayers=1`, `StartGame()` 성공, 배지 표시. 런을 1명으로 도입 → 공연 1 → 쉬는 시간 → 공연 2 → 밤 정비(준비 1/1) → 2일차 아침까지 진행.
3. 생존자 판정은 `DevModeTestUI`에서 확인: 켜짐 = 0명일 때만 실패, 꺼짐 = 1명 이하 실패.
4. Console 오류 0(경고는 1의 정상 거절 1건). 확인 후 개발자 모드는 꺼짐으로 되돌려 둠.
