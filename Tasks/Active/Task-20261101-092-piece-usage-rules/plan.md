## Context
기물 시스템 기획서(Confluence 31784961, 10-30)와 비교해 덜 된 부분을 구현한다. 도구만 1·2키로 손에 들고 집어넣는다. 장비는 슬롯에서 자동 적용하고, 오브제는 슬롯에 넣지 않는다. 공연용 장비 4종의 효과를 연결한다. 메인 폴더는 다른 작업 중이라 `D:\github-worktrees\POC_CURTAINCALL\piece-usage-rules`에서 작업하며, Unity도 이 워크트리 전용 에디터를 쓴다.

## 사용자 결정 (2026-11-01)
- UV 등: 현재 구현을 유지한다(장비, 내구도 없음, 슬롯에 있으면 우클릭으로 비춤). 기획서의 도구·3회 규칙과는 다르다.
- 1·2키: 도구 칸을 누르면 손에 들고, 다시 누르면 집어넣는다. 장비 칸은 손에 들지 않고 칸 선택만 강조한다. F 길게(버리기)와 가판대는 선택한 칸을 대상으로 한다.
- 획득 직후: 빈손이면 새로 얻은 도구를 자동으로 손에 든다. 장비는 슬롯에만 넣는다. 아무것도 고르지 않았을 때 마지막 기물을 손에 든 것으로 보던 처리는 없앤다.
- 배치 기물(트램펄린·대포): F로 획득해 해금하는 현재 방식을 유지한다.
- 구조 장갑: 적용 거리 2m(카탈로그 effect2). 손잡이 완화와 겹치면 큰 값 하나만 적용한다. 장갑 완화가 가장 클 때만 1 소모한다.
- 끈끈이 장갑: 제한 시간이 있는 매달림 전부를 1.5배로 늘린다(외줄 추락 7초, 트라페즈·해제봉 30초, 인간 대포 톱날 연동 봉 40초). 동료가 끌어올리는 동안에는 기존처럼 타이머를 멈춘다. 기본 시간을 실제로 넘길 때만 매달림마다 1 소모한다.
- 스프링 신발: 추락 부상이 나는 바닥에서는 부상 대신 트램펄린과 같은 반동을 한다. 쿨타임 중이면 기존 부상을 준다. 바닥 없는 낙하와 안전 착지면에서는 발동하지 않는다.

## 계획
1. 슬롯 규칙: `PropCarry`에 손(도구)과 칸 선택을 나눈다(`InHand`). 탐색·열쇠·손 외형·HUD를 손 기준으로 바꾼다. 오브제는 소지 장부에서 거절한다. EditMode 테스트로 확인한다.
2. 스프링 신발: 호스트 `HumanCannonSystem.HandleLanding`에서 부상 전에 판정한다. 반동 시 소유자에게 알리고, 착지 대기를 해제한다.
3. 벌룬 바지: 소유자 `HumanCannonPilot.SimulateFlight`에서 하강 감속을 적용한다. 대포 발사·트램펄린 비행마다 호스트에 1회 소모를 요청한다. 봉에서 놓은 비행은 제외한다.
4. 끈끈이 장갑: 매달림 시작 때 총 시간을 늘리고, 기본 시간을 넘길 때 소모한다. 위험 비율 UI는 매달림별 총 시간으로 계산한다.
5. 구조 장갑: 꺼져 있던 받기 경로를 장갑 기반 자동 완화로 연결한다. 호스트가 착지를 확인할 때 착용자 내구도를 깎는다.
6. 공통: 기물별 쿨타임, 발동 연출 문구, 파괴 알림. 상점에서 공연용 기물 판매를 연다.
7. 묶음마다 컴파일·관련 테스트를 돌리고, 끝에 check-work와 Unity 실제 플레이 확인을 한다.
