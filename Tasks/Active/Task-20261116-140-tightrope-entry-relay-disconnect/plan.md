# Task-20261116-140

- **Title:** 첫 외줄타기 공연 배경 로드로 인한 Relay 연결 종료 수정
- **Type:** fix
- **Assignee:** @RagSpirin
- **Branch:** fix/tightrope-entry-relay-disconnect
- **Base:** dev

## 목적

튜토리얼 연습실을 마치고 첫 외줄타기 공연으로 진입할 때, 첫 배경 로드의 메인 스레드 정지가 Relay 연결을 종료하지 않도록 수정한다.

## 계획

1. 로그에서 집결, 외줄 씬 로드, 배경 로드, Relay 종료를 대조한다.
2. 정상 진입 로그와 소요 시간을 비교하고 첫 배경 로드를 조사한다.
3. Relay 할당 전에 양쪽의 배경 준비를 마치고, 로컬 시각 오브젝트를 유지해 첫 공연 진입의 재로드를 없앤다. 공연 외 비활성·조명·커튼·접속 취소는 기존 흐름을 유지한다.
4. 새 에디터 프로세스와 새 Windows 실행 파일의 실제 2인 Relay로 첫 튜토리얼 → 외줄 진입을 검사한다. 같은 PC/OS 캐시 조건과 미검증 환경을 구분해 기록한다.
