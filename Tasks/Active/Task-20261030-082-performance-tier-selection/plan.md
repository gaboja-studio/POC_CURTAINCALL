- **Type:** fix
- **Assignee:** @MoHoDu
- **Branch:** fix/waiting-room/schedule

## Context
공연은 1·2·3단계로 나뉘고, 해당 묘기의 단계를 깨면 다음 단계를 고를 수 있다(이미 `RunState`에 구현됨).
지금은 밤 정비 때만 고를 수 있어 같은 날 앞 공연에서 연 단계를 다음 공연에 쓸 수 없다.
2026-10-30 사용자 결정: 단계는 스케줄(밤 정비)에서 고르고, 공연 직전 쉬는 시간에 호스트가 단계만 다시 조정한다.

## 계획
- 런 진행: `RunState.AdjustNextTier` — 쉬는 시간에 바로 다음 공연의 단계만 바꾼다(2일차부터, 깬 단계 + 1까지).
- 장부: `ScheduleBook.AdjustTier`(잠긴 칸도 단계만), `ScheduleBoard.AdjustTier`·`IsNextPerformance`(호스트만 변경, 상태 동기화).
- UI: 카드 클릭은 묘기만 바꾸고, 카드 아래 줄에 `1단계/2단계/3단계` 버튼을 실행 중에 만든다(씬·프리팹 YAML 수정 없음).
  아직 안 열린 단계는 비활성, 고른 단계는 색으로 표시. 참가자는 보기만 한다.
- 안내: 쉬는 시간 바닥 문구에 "N단계가 열렸습니다 · 입장 전까지 올릴 수 있음"을 보인다.

## 미정·주의
- 해금 범위는 늘기만 해서 밤에 고른 단계가 공연 시작 때 내려가는 경우는 없다. 그래서 하향 안내 대신 해금 안내로 바꿨다.
- 외줄타기는 단계가 보상만 바꾸고 플레이는 같다(별도 작업).
- `SchedulePanelView`는 `_ThirdParty` 비공개 저장소에 있어 이 Task에서는 고치지 않는다.
