- **Type:** fix
- **Assignee:** @MoHoDu
- **Branch:** fix/main-stage/cheer-points-toggle

## Context
초기 OFF 요청 후, 사용자가 다시 ON과 긴 줄에 매단 고리의 회수 연출로 수정했다. 이어 외줄타기·인간 대포 각각 난이도 1~3에서 환호 포인트뿐 아니라 공연 장애물·대포·착지 지점까지 편집하는 시각적 배치 창을 요청했다. dev PR 제출까지 진행한다.

## 계획
1. 호스트 기준 ON/OFF를 유지하며 기본 ON. 획득 고리는 아래로 조금 내려갔다가 상승하고, 최소 높이와 화면 밖 조건을 모두 만족한 뒤 숨긴다.
2. 환호 포인트 난이도 마스크와 공유 배치 분리·추가·복제·삭제·드래그·회수 미리보기를 제공한다.
3. 인간 대포는 실제 장치 참조를 유지하며 난이도별 위치·회전·크기·사용 여부를 저장한다. 추가 장치를 기존 시스템 목록에 등록하고 네트워크 인덱스를 보존한다.
4. 외줄 생성 코스는 GameSettings의 난이도별 독립 배치로 편집한다. 기존 코스·추가 톱날을 복사해 다른 난이도에 영향을 주지 않고, 제외된 톱날 번호와 작동 순서를 보존한다.
5. 편집 미리보기·참고 경로·선택 공연/난이도 실제 플레이 진입, 저장/재로드·난이도 격리·표시/보상 회귀를 검증한다.
6. 보유 Synty 로프·매듭·서커스 고리와 불꽃을 조합한 새 외형을 연결하고 링 배율과 통과 판정을 함께 조절한다. 외부 파생 에셋은 private 저장소에 추가한다.
7. 문서·Confluence를 갱신하고 관련 변경만 commit/push, dev PR을 제출한다.

## 주의
GameSettings는 공통 규칙, 씬 배치 데이터는 위치/사용 여부다. 온라인은 같은 캠페인 난이도와 호스트 환호 설정을 따른다. 미리보기 오브젝트는 저장하지 않으며 씬 저장 전 기본 위치를 복원한다. 예상 탄도는 입력·바람·충돌을 제외한 참고선이다. 원격 다중 프로세스 검증 여부는 별도로 기록한다. 폰트·머티리얼·Vivox·기존 private·이전 Task 변경은 이번 PR에서 제외한다.
