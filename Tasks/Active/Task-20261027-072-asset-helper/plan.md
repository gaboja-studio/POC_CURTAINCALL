## Context
Unity에서 에셋 추가·수정·삭제와 기능 확인을 끝낸 뒤 저장·공유한다. GitHub Desktop/Fork에서 브랜치를 이동한 뒤 현재 브랜치의 에셋 버전으로 맞춘다. 기획자는 터미널 명령어를 입력하지 않는다.

## 계획
- Windows 더블클릭 실행 + 로컬 브라우저 UI. 메인 버튼은 저장·공유와 현재 브랜치에 맞추기 2개.
- private 먼저 업로드, 게임은 별도 인덱스로 gitlink만 커밋·업로드. 다른 게임 변경과 스테이징을 보존.
- 불일치·LFS·미초기화 처리, 내 수정과 커밋 보관, 보관 목록에서 복구. Unity 실행 중 버전 변경 차단.
- 중단 후 재시도 기록과 동시 변경 감지. private main과 갈라지면 별도 검토 브랜치 공유.
- 사용자 실제 테스트 후속: 작업 브랜치 업로드를 팀 공유 완료로 표시하지 않는다. private 통합·게임 작업 업로드·origin/dev 반영을 구분하고, sparse 임시 worktree로 에셋 전용 dev PR까지 자동 준비한다. 지정 팀원 검토 후 원격 dev 연결 확인만 최종 완료로 인정한다.
- 로컬 Git/LFS fixture 회귀와 실제 브라우저 화면 확인. 실제 에셋 저장·업로드는 실행하지 않는다.
- 병합 확인 후 receipt에 기록된 도우미 임시 브랜치만 로컬·원격에서 정리. 작업·복구 브랜치와 다른 도구 worktree 보존. 에셋 연결만 있는 작업 브랜치는 PR에 재사용하며 sparse worktree 누락 파일·삭제 실패를 검출한다.

## 미정·주의
- 에디터 임포트·이동·편집과 게임 브랜치 전환은 제공하지 않는다. dev 직접 반영·강제 push·작업 폐기 없음.
- 기존 하네스 개편과 같은 작업 트리를 보존하며 feat/asset-helper로 분리. 2026-10-27 사용자 커밋·업로드 및 origin/dev 반영 요청에 따라 함께 제출한다.
- Windows에서 확인하고 Mac 런처는 실기기 검증 전임을 보고한다. 현재 도구의 실제 GitHub 인증·원격 업로드는 사람 확인이 남는다.
