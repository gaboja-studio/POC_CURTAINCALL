## 실제 적용 순서 제안

1. **시작 전망/하강 공동:** 1번 공장 배관 + 2번 대표 기계 + 3번 고정 승강 설비. 큰 실루엣·층 높이 차이로 압도감 형성.
2. **컨베이어/대포 구간:** 2번 구동부 + 5번 실제 조작 장치 외형. 기존 그네 궤적·탄도·3인칭 카메라 공간을 확보.
3. **마지막 탈출:** 6번 발전기와 전원함 외형 + 15번 절단 접점 피드백 + 13번 먼 화재 연출. 24가닥 배선·수평 톱 발사선은 계속 읽히게 배치.
4. **연결된 공간의 소리:** 17/18번으로 멀리 있는 시설의 크기와 작동 상태를 전달. 시각 장식을 늘리기 전에 소리로 빈 공간을 보완.

모든 추천은 기존 동선·난이도·버튼의 독립성을 유지하는 방향이다. 새로운 승강기 이동/우회로/안전 발판을 추가하자는 제안이 아니다. 실제 배치 단계에서 벽의 단면 노출·에셋 겹침/관통·카메라/그네/외줄 간섭과 LOD 소실을 확인한다.

## 선정에서 제외한 예

- MS3 - MODULAR Shipyard: 이름과 달리 산업 조선소 배경이 아니라 우주선 조립 파츠 팩이므로 제외.
- Dynamic Fire / Fire VFX(FXMonster): 사이트상 스프라이트 기반·Built-in 표기라 3인칭 거대 화염의 우선 후보에서 제외.
- Platformer - Game show Pack / Stylized traps pack: 사용 가능성은 있으나 현재 거친 산업 시설과 톤 차이가 커 이번 우선 목록에서 제외.
- 기존 Confluence에서 찾은 Sci-Fi Pipes / Creepy Circus는 이번649항목에서 동일 이름이 확인되지 않아 이 목록에 포함하지 않았다.

공식 호환 표시는 제조사의 특정 Unity 버전 지원 정보다. 현재 Unity6000.3/URP17에서 직접 검증한 것은 아니며 파이프라인 공란은 미지원이 아닌 정보 미기재로 해석했다. 목록의 패키지 용량을 실행 메모리 비용으로 판단하지 않는다. 이번 작업은 웹 조사·문서 정리만 했고 구매/import/씬 편집·Play/MPPM은 하지 않았다.
