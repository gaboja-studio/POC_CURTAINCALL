# A 구조 이음새·겹친 면 폴리싱

2026-11-03 @RagSpirin. 사용자가 맵 유격과 지지직거리는 면의 품질 보완을 요청했다.

## 조치

- 렌더 묶음을 복원해 원본 기물을 점검했다. 축에 정렬된 공장 직육면체803개에서 같은 방향의 면 겹침 후보113쌍, .001~.08m 간격 후보21곳이 나왔다. 간격 후보에는 버튼·동적 계단·토출구의 의도된 간격도 포함된다.
- 입구 문턱/연결 바닥, 계단 접합부, 탈출문 금속 보강재 등을 포함한 원본 메시57개에 깊이 차이를 주었다. 기본3mm이며 겹침 단계에 따라 최대15mm다. 완전히 닫힌 직육면체 형상과 기존 UV를 사용한다.
- 모든803개를 같은 조건으로 재검사해 같은 방향의 면 겹침 후보0쌍을 확인했다. 비직육면체 메시와 모든 카메라 거리에서의 깜빡임까지 보증하는 검사는 아니다.
- 벽 보수판4곳의 약2.5cm 뜬 간격을 맞췄다.
- 주 설비 코어12개의 높이19.92→20m로 수직 이음을 맞췄다. 이 부분은 통행 발판 외부의 건축 구조다. 작성 도구에도 코어 높이와 보수판 위치를 반영했다.
- 최적화 묶음을 재생성했다. 원본617개→78묶음 구성으로 저장했다.

## 확인

- MonoBehaviour 설정과 Collider1,648개의 직렬화 필드가 동일하다. 코어의 Transform 높이 조정에 따라 해당 건축 충돌체의 월드 범위는 위아래4cm씩 늘었다.
- 입구·문턱·주 설비 코어·첫 대포·하강·컨베이어·협동·화염 복도·마지막 구간의 편집9구도를 확인했다.
- 새 메시를 모서리에 정렬해 닫힌 면을 유지했고, 재검사에서 수정 메시도803개 대상에 포함되는 것을 확인했다.
- 실제 플레이 이동 중 시각 검증은 하지 않았다. 자동 게임 테스트도 선택하지 않았다. 최종 check-work 결과는 log.md에 기록한다.
