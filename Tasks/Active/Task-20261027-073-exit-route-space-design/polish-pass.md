## 편집 도구와 순서

- `EscapeVariantPolish.cs`: B/C `ApplyVariantStructureFinish()` → `AddVariantServiceFinish()`.
- `EscapePlacementPolish.cs`: A `PolishAPlacement()`, B/C `AlignVariantExterior()`, 공통 `FitSurfaceDressing()`·`PolishExteriorVegetation()`.
- `EscapeSurfacePolish.cs`: 배치를 확정한 뒤 마지막에 `PolishStructuralSurfaces()`. `20_SurfacePolish`가 있으면 반복 적용하지 않는다.
- 씬별 `escape_route{,_b,_c}-polished-surfaces.asset`에 파생 메시를 저장했다. 기존 원본 에셋과 private 저장소는 변경하지 않았다.
- 표면을 정리한 구조물은 접한 이웃과 함께 굳어진 모양이다. 이후 이동/삭제하면 감춰진 면이 드러날 수 있으므로 해당 원본 메시를 복원하고 정리해야 한다. B 작업 슬래브 제거 뒤 노출된 바닥과 옮긴 등기구는 전용 복원 함수로 복구했다.
- 기존 재생성 메뉴는 수동 편집을 덮어쓰므로 검토할 때는 A/B/C 씬 열기 메뉴를 사용한다.
