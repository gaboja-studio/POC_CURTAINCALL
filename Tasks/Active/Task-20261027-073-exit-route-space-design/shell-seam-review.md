# 심부 연속 외피·전체 정적 면 재검사

2026-11-03 사용자 요청. A만 수정하고 저장한다. 대기실/B/C·게임 규칙·실제 Play/MPPM은 이번 범위에서 제외한다.

## 원인과 보수

- 심부 연속 외피3개가 기존 검은 낭떠러지 차폐와 겹쳐 있었다. 특히 서측은 약5,742㎡의 같은 방향 면이 완전히 포개졌다. 편집 캡처에서도 검은 면/회색 면이 사선 무늬로 싸우는 현상을 확인했다.
- 겹친 외피3개의 Renderer만 껐다. 원래 충돌과 프레임은 유지하고, 검은 차폐2면은 폭3→4m로 상부 벽과 맞췄다. 해당 차폐는 충돌체가 없는 심부 시각 구조다. 넓은 검은 낭떠러지 표현과 외부 차폐를 유지한다.
- 이전 IsPolishBox 검사는 Cube/block/ConcreteBlock 이름만 허용해 일부 파생 메시를 놓쳤다. 이름 조건을 제거하고 실제 삼각형·모서리/축 정렬 판정을 유지했다. 임의 형상의 모델을 직육면체로 바꾸지 않는다.
- 코어/인방·하강 외벽/집수정·점검대 모서리·레일/보강보의 같은 방향 중복면을 재검사했다. 물체를 이동하거나 발판을 낮추지 않고, 겹친 영역만 삼각형 차집합으로 잘라 나머지 표면을 유지한다.
- 모델 자체에 겹친 점검대/기계 바닥 면도 보수했다. LODGroup의 서로 다른 단계는 동시에 표시되지 않으므로 중복으로 오판하지 않았다.
- 총41개 MeshFilter에53개 파생 메시를 적용하는 두 단계를 수행했다(구조 간35개, 모델 내부18개; 일부 중복 대상). 원본 패키지는 수정하지 않았고 파생 파일은 private Task073/SurfaceReview에 둔다. 현재 씬은 최종 파생만 참조한다.

## 검사 범위와 결과

- 배칭을 복원한 상태에서 정적 불투명 메시1,678개를 검사했다. 읽기 비활성6개도 Editor에서 실제 정점 읽기가 가능함을 확인해 포함했다. 축 정렬 평면 삼각형 약9.5만개를 면 이름과 관계없이 비교했다.
- 차폐 보수 후 동시에 표시될 수 있는 서로 다른 물체의 같은 방향 중복면169쌍→0. 모델 내부 중복297개 평면 그룹→0. 면 교차 면적0.005㎡/거리1mm 기준이다.
- 남은 2cm 이내 근접 후보731쌍은 맞닿는 반대 방향 접합면·구조 두께·표면 도색/습윤층 등을 구분했다. 같은 방향177쌍은 거리1~20mm의 별도 층이며, 같은 면 중복 수치와 섞지 않았다.
- 곡면/비축 정렬 면·투명/식생·움직이는 기믹 전체에 대한 자동 무겹침 보증은 아니다. 편집 다중 구도와 실제 플레이 시각 검증의 수준을 구분한다.
- 기존 Collider1,653개와 MonoBehaviour370개 씬 문서/도착 볼륨 전후 동일. 모든41개 수정 필터의 기존 정점62,193개·UV0~7·법선/탄젠트/색·서브메시 분할 보존을 확인했다. 추가 정점은 원래 삼각형 안에서 속성을 보간했다.
- 기하 회귀5/5 PASS: 부분/전체/비중첩 제거, 양쪽 감기 방향, 반복 제거, 파생 메시 이름에 무관한 직육면체 검사/비직육면체 보호.
- 심부 외피 전후4구도와 입구~출구 편집9구도 확인, 최적화 묶음 재생성·A 저장. 최종 수치/컴파일/check-work는 log 참조. 실제 이동 중 시각과 프레임 성능은 미측정이다.
