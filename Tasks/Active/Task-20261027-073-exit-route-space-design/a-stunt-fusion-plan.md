# A 묘기 융합 적용 결과

2026-10-29. 담당 @RagSpirin, 브랜치 feat/exit-route/design-map. A03~06 전체 융합과04B 확장·순환 그네의 구현/저장을 승인받아 적용하고 A 씬을 저장했다. 최종 시각·mesh 검사를 마쳤으며 check-work와 Git 저장 결과는 log에 기록한다. 실제 Play·입력·멀티플레이 검증은 하지 않았으며 사용자 확인 대상이다.

A 선완성/B·C M2 이후를 유지한다.07 마지막 질주 대개편은 보류했고, 이번에는 가까운 중간 그네1개를 제거해 두 그네의 역할만 구분했다. 구현 전 현황 조사·제안과 제작 순서 원문은 [History/009-a-stunt-fusion-proposal.md](History/009-a-stunt-fusion-proposal.md)에 보존했다.

## 적용 기준과 범위

- 앞 묘기의 착지·놓기·반동이 다음 묘기의 진입이 되게 했다. 숨은 넓은 바닥, 강제 흡착, 별도 Solo 물리로 원본 전환을 대신하지 않는다.
- 사용자 중간 피드백에 따라 고정 그네 간격을 다시 맞췄다. 첫 그네에서 뒤의 묘기를 전부 생략하는 배치를 피하고,05는 반동 후 버튼 합류와 하강 출구의 두 역할로 나눴다.
- 거대한 외피·깊은 집수정·무거운 콘크리트 설비는 유지한다. 불필요한 재상승/회랑은 비활성 보존하고, 기물 탑승·협동 역할/복귀와 위험을 읽는 데 필요한 바닥을 남겼다.
- 상시 조작 HUD는 추가하지 않는다. 원본 F/테두리 후보, 점유·부상·호스트 승인, 운반 트램폴린과 마지막 동료 복귀 규칙을 유지한다.

## 04B 순환 그네와 선택 하차

- 원본 그네6개가 속도5m/s로 둘레106.83m 폐회로를 돈다. 한 바퀴21.37초, 다음 그네 도착 간격3.56초이며 발사 시점과 공중 보정으로 잡는 경험을 의도한다.
- 정밀 하차는15m 직선 외줄과5.66m 꺾인 외줄로 구성했다. 지지보를 관통하지 않도록 하차줄을 꺾었으며 외줄 아래 숨은 넓은 바닥을 두지 않는다.
- 바닥 하차는 별도 착지대로 받는다. 두 경로는 고정 그네를 통해 톱2개가 있는 합류줄로 이어지고 마지막 그네·압착기1개·복귀 대포로 연결된다.
- 원본 점유/자발적 놓기를 유지한다. 공유 시각으로 경로 위상을 맞추며 운반 속도와 그네 반동을 합성하고, 호스트가 승인한 잡기/놓기 pose를 공유한다. 실제 지연/멀티플레이 체감은 미검증이다.

## 원본 조작 인계와 접촉면

- 비행→외줄: 실제 지지 BoxCollider에 HumanCannonLandingZone을 연결한다. 원본 착지 승인 뒤 이동기를 반환하고 CourseControlSwitcher가 외줄 조작을 이어받는다.
- 외줄→그네: 끝 영역의 동일한 유효 후보를 F/테두리에 사용하고 원본 요청/호스트 승인 뒤 조작권을 인계한다. `allowCannonPoleExit`는 A만 활성화했으며 기존 외줄 상호작용 우선순위를 유지한다.
- 옛 옆점프 목표/수직속도는 원본 ResetExternalMotion 인계로 정리한다. TightropeHangSystem도 독립줄의 실제 방향을 사용하도록 수정해 매달릴 때 잘못된 축으로 몸통이 돌아가지 않게 했다.
- 공중 대포 탑승은 추가하지 않는다. 대포 앞에는 실제 작은 탑승대를 두며, 씬당 원본 운반 트램폴린1개는05 협동 구간에서 유지한다.

## 자산·충돌 보수와 현재 검사

- 서측 배관·플랜지·브래킷·문·흔적45개를 새 벽과 함께17.5m 옮겼다. 순환 구간 중앙의 뜬 배관을 정리하고,30_SealedJoints의 옛 갤러리 맞댐/난간/천장·집수층 중복을 비활성 보존했다.
- 04A 외벽/05 입구 흉벽의 몸통 간섭2건은 개구부로 해결했다.05 출구 전단벽은 비행 개구부를 만들고 상하부 콘크리트 무게를 유지하며,06 대포는 기존 코어 끝을 돌아 비행한다.
- 정적 감사에서 대포4·기물 전환12·순환 하차2경로·트램폴린→그네·순환 몸통·첫 grip 전체 생략 샘플이 통과했다. 이는 실제 입력·재미·멀티플레이 완료 판정이 아니다.
- 외줄 보행과1.9m 아래 매달림을 키1.73m/±25도 몸통으로 확인해 간섭0을 기록했다. 기물 연결부0.75m는 해당 연속 표본에서 제외했다. 의도되지 않은 보이지 않는 고체 지지면은0이며, 시각 메시1494개 몸통 표본에서는 의도된 합류줄 톱2개만 접촉했다. 검사 임시 collider는 모두 제거했다.
- 배관 이동 후04B 화면과03/05/06 화면을 확인했다. 최종 컴파일·저장 결과는 [log.md](log.md) 최상단 구현 기록과 검사 기록을 따른다.
