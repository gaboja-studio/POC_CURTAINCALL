# 탈출로 A 동적 공간 연출 개정안 · 2026-11-04

이후 적용한 인간 컨베이어의 절단·회수, 처리조 확장, 창살 철거와 최종 배치는 [공장 처리선 작업 기록](factory-process.md)에 정리했다.

플레이어가 첫 대포까지 걸으면 시설이 무엇을 흘려보내는지 보이고, 공중을 건너면 무엇을 운반하는지 보인다. 후반에는 자신과 동료가 기계를 움직이고 멈춘다. 아래 공정은 컨베이어의 인간 도축장 설정을 제외하면 연출 제안이다. 기존 P1의 평형추·폐기 호퍼·표시등은 보조 단서로 둔다.

## 제작 순서와 판정
1. **복도 왼쪽 오폐수 한 곳부터.** 첫 대포를 향해 걷는 정상 속도의 3인칭 영상 한 번에 토출구, 낙수, 받이 세 부분이 보이는 위치를 정한다. 주기 안은 큰 토출 2초, 잔류 흐름 3초로 시작해 실제 통과 시간에 맞춘다. 보행면 왼쪽의 도랑과 배수구로 물이 이어지고, 캐릭터·도약 지점·목적지 표식을 가리지 않아야 한다.
2. **협동교 불티와 하강 그네 환적.** 스위치와 다리를 각각 보는 두 플레이어 화면에서 행동의 결과를 확인한다. 불티는 시작 0.2초 안팎의 단발 후보이며 바닥으로 떨어뜨리지 않는다. 물과 불티는 가까이 보이는 구역에서만 갱신한다.
3. **최종 배선과 기존 장면 연결.** 팬의 감속을 절단·초기화 상태에 연결하고 남은 구간은 실제 동선에서 용도가 안 읽히는 곳부터 보강한다. 네트워크에는 장식용 물방울·불티 개체를 만들지 않는다.

기존 설치 목록은 installed-art-inventory.md에 있다. 원본 썸네일과 메시 실루엣, 재질 호환성을 먼저 확인하고 무음 기본 3인칭에서 평소 방향을 유지한 채 두 동작 단계 이상을 식별할 수 있어야 채택한다. 점검 영상은 장치를 향해 카메라를 돌려 찍은 컷과 구분한다. 아래는 저장한 A 씬의 구현 결과다.

## A 씬 적용 결과 · 2026-11-04

| 위치 | 소리 없이 보이는 동작 | 플레이 동선과의 분리 |
|---|---|---|
| 첫 대포 진입 복도 왼쪽 | 굵은 토출구에서 회녹색 폐수의 폭이 주기적으로 변한다. 물이 측구에 부딪히고 거품이 하류 철망 쪽으로 흐른다. | 기존 측구에 배치하고 지하 측면까지 방호망을 맞췄다. 망을 관통하던 장식 릴 한 개를 제거했다. |

전망홀 권양추, 작업섬 옆 폐기 드럼, 기존 첫 대포 화물선·컨베이어 처리선·바깥 갈대밭을 연결했다. 폐기 드럼은 전 낙하 구간에 보호망을 두고 분전반 덮개 여섯 곳은 설치된 렌더 파이프라인용 재질로 마감했다.

저장된 씬의 전용 연출 에셋 16개와 애니메이션 바인딩 42개를 확인했다. 5개 클립을 201개 자세씩 샘플링해 환적 고리 인계 오차 0m를 확인했다. 7개 기계의 동작 범위와 외부 메시를 비교하고 22,146개 대포·그네·보행/추락 궤적을 검사했을 때 2.5m 안에서 보호물 없이 움직이는 부품에 접근한 표본은 없었다. 검사는 Unity 편집 모드였고 실제 4인 플레이와 프레임 측정은 별도다.
