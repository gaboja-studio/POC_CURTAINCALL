# A/B/C 구조 검토 (2026-10-28)

**최신 A 전체 수정:** [A 브루탈리즘 확장](a-brutalist-route.md)이 아래 A 초기 설명과 치수보다 우선한다. B/C는 기존 상태다.

사용자 요청: A의 분위기를 유지하며 반복 배치·설비 사용 흔적·시선 목적지를 보완하고, 나머지 B/C 구조도 제작한다.
아래의 순서·높이·배치는 이번 배경 제작 제안이다. 묘기 사거리·공중 잡기·다인 운용·추격·난도 확정값이 아니다.

## 공통 원칙

- 네 묘기를 모두 포함한다. 실제 기믹 대신 설치 자리·시각적 외줄·그네 지지선을 둔다.
- 낮은 문틀→큰 공동, 중성 회색 콘크리트, 짧은 재합류와 긴 질주, 햇빛이 강한 갈대밭을 유지한다. B/C는 28m 층고·60m 깊이이며 A는 최신 브루탈리즘 확장 기준을 따른다.
- B/C 외곽은 약 240×95m급이며 각 주행면 범위는 도면을 따른다. 외부 배경 지형·원경까지 이 외곽에 한정한다는 뜻은 아니다.
- 외부와 렌더 설정은 A에서 복제하고, 내부 구조·동선은 별도 생성했다. A의 플레이어/카메라 원본 참조를 유지한다.
- 진행 문·지연 셔터·출구 장치는 자리 표시다. 런타임 A/B/C 선택, 대기실 세트 연결은 이번 범위에 포함하지 않는다.

## A 분위기 보완

### 후속: A 첫 공동 수직 설비실

- 사용자 승인: 더 깊고 거대한 시설 안에 갇힌 감각. 회색 콘크리트·내외부 빛 방향은 유지하고 단면과 설비 관계를 바꾼다.
- 외피: X22.5–72.5 / Z62.5–112.5m, Y-90–44m. 주 설비 지름12m·높이120m, 지지 교각·주관·상부 크레인과 연결한다.
- 동선: 3.6m 높이 입구→Y0 캔틸레버→Y-6 고립 정비대→대각 외줄→Y-6 도착부→40단 계단(단높이0.2m)→기존04의 Y+2 착지. 단절부는 여전히 실제 묘기 기능이 없는 구조안이다.
- 점검층 Y+16/-18/-42/-68에 난간·작업등·사람 크기 문을 배치한다. 장식 점검층은 비충돌로 주 경로를 우회하지 않는다.
- 편집: `EscapeBackground/16_VerticalFacility` 아래 Shell/Route/MainPlant/ServiceLevels/Lighting. 생성 코드 `EscapeVerticalCavern.cs`. 재생성은 이 새 그룹의 수동 편집을 덮어쓴다.
- 이전03/14 및 해당 천장·보조 설비는 비활성 보존했다. 기존 구형 조명·03 압도감 메뉴를 다시 적용하면 새 구조와 겹칠 수 있으므로 수직 설비실 도구를 사용한다.
- 정적 검사: `ValidateVerticalCavern()`으로 바닥·40단 계단·단절·연결부·재질/스크립트·비행 컴포넌트를 조회한다. 실제 이동·묘기 통과는 사람이 확인한다.

- 진입로의 규칙적인 드럼통 반복을 줄이고 두 작업 구역에 모았다. 원본 프리팹은 수정하지 않고 씬 인스턴스만 조정했다.
- 가장자리 배수 홈·그레이팅·습윤 흔적, 케이블 릴·작업대·팔레트·점검함과 작은 벽면 표식을 추가했다.
- 작업등 강약을 나누고, 끝막이의 작은 방향 표식과 굽이 너머의 반사광으로 진행 방향을 예고한다.
- `Label_` 제작 라벨은 편집 화면에 유지하고 Play Mode에서만 숨긴다. `Wayfinding_` 현장 표식은 남는다.

## 둘러보기

1. 플레이를 종료하고 `Tools/CurtainCall/탈출로/A·B·C 구조 씬 열기` 중 원하는 씬을 연다.
2. Play를 누르고 Game 화면을 클릭한다. WASD 이동·마우스 시점, Space 상승·Ctrl 하강, Shift 가속, Esc 커서 해제.
3. 조립 검토 라벨을 보고 싶으면 편집 모드에서 확인한다. 구조 씬을 여는 데 재생성 메뉴는 필요 없다.
