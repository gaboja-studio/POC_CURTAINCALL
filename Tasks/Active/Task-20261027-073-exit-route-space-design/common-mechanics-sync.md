# 원본 묘기·탈출로 공통 동작 동기화

2026-11-02 / @RagSpirin / feat/exit-route/design-map / 사용자: 맵별 설정은 유지하고 나머지 공통 동작 동기화.

## 변경·대조 결과

| 항목 | 공통 동작 | 유지한 맵 설정 |
|---|---|---|
| 외줄 이동 | 생성 묘기/독립 외줄 모두 진입 방향 보존, 좌우 점프 방향 변환, 반대 방향 동료 뒤 착지 부호 일치 | 줄 위치/길이/방향/간격/소실·형상/동선 |
| 조작 인계 | 실제 조작권을 기준으로 외줄↔기본/대포 복귀. 비지정 기본 조작은 비지정으로 복원 | 명시적 플랫폼 조작 에셋·구간 기물 |
| 봉·그네 | 모든 HumanCannonPole에 연속 반동, 지상/일반 점프/낙하 잡기, 벽 가림, 목마 역할의 안전한 인계 | 좌석/길이/앵커/이동 레일/잠금·필요 인원/장치별 반동 조정값 |
| F 입력 | 공용 조작 규칙에서 처리. 탈출로 전용 선행 소비 제거. 매달림 구조/별도 묘기 장치의 입력 처리 후 가까운 인간대포 봉 후보를 처리 | 서로 다른 협동 장치 종류·배치. 실제 거리/점유/장벽/잠금 검사 유지 |
| 대포·트램폴린 | 기존 공용 발사/공중 조절/반동/잡기·운반/놓기 API·입력 에셋을 계속 공유하고 회귀 검사 | 발사 방향/속도/반동면/원형·사각형·운반자 필요 조건/진행 기믹 |
| 신체·장비 | 원본 생성 묘기도 실제 외줄 조작/균형 상태에 따라 부상 정책 적용. 초기 외줄 정책을 대포가 덮지 않음. 벌룬 바지 소모 보고 재전송/세대·순서 ACK/중복 소모 방지, 응답 전 재발동 차단 | 탈출로 추락 보호 및 직접 함정 규칙. 스프링 신발은 기존 '부상이 날 착지에서 대체 반동' 조건 유지 |
| 안내 | 공용 C6에 대포 발사/내리기·그네 반동/도약 추가. 포신/전원 미가동은 발사 대기로 표시. C6가 있으면 원본 C7 중복 안내 방지 | 장비/일반 알림 폰트·레이아웃·구간 제목 유지. C6가 없으면 원본 C7 안내 유지 |
| 시간·성공·보상 | 기존 호스트 상태·시각 및 공통 플레이어/장비 서비스를 재사용 | 탈출480초·공연 채점/보상·맵별 성공 조건·재시작 대상 장치 |

옛 bidirectionalSceneTraversal/continuousSwingInput/allowPlatformJumpGrab/independentInteraction/requireClearGrabPath 값은 기존 에셋 참조·직렬화 보존용으로 남겼다. 공통 동작을 다시 분기하는 스위치로 사용하지 않는다.

## 검사

- 선별 EditMode24필터281/281 PASS. 단독/호스트 fixture·클라이언트 보고 큐 회귀이며 실제 네트워크 플레이가 아니다. 증거: `.harness/local/common-mechanics-sync/`.
- 생성/배치 외줄 양방향·좌우/동료 뒤 착지·기본 축 복원, 부상 정책/입력 버퍼, 연속 반동/목마 인계/벽 가림, 발사/착지/트램폴린 접촉·운반, 장비 재보고·중복 ACK·세대 거부/응답 전 재발동, 점유 중 C6/전원 대기, 타이머/협동 상태/글리프를 확인했다.
- 실제 A/원본 Tightrope/HumanCannon 씬을 프리뷰로 읽어 원본과 A의 반대 방향 진입 내적-1.00, 연속 반동 A15/15·원본7/7, 원본 봉 legacyFlag=false에서도 sharedInteraction=true, 원본 TightropeCourse 프리팹의 역방향 벡터(0,0,-1)를 확인했다.
- 세 씬 누락 스크립트0. 탈출 제한480초, 열린 씬 dirty0/Play 중지. 씬·프리팹·Resources 설정/폰트·ThirdParty 파일 변경0.
- 대포/그네 C6 편집 렌더의 발사·도약·긴 키/본문3사례에서 한글/박스 수납 확인. `cannon-pole-layout.png`, `prompt-metrics.txt`.
- 회귀 중 기본 조작이 명시적 오버라이드로 남는 문제를 수정했다. 새 blocker fixture의 수동 OnEnable 등록을 OnDisable로 정리해 다른 테스트에 영향을 주던 잔여 참조도 제거했다. 최종 실패0.
- 실제 Play/MPPM·자동 입력은 실행하지 않았다. 사용자 플레이 감각/네트워크 지연/1~4인 연속 완주는 미검증이다. 최종 check-work는 log에 기록한다.
