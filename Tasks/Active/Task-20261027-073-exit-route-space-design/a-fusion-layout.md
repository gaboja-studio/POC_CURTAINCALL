# A 묘기 융합 레벨 디자인

> 이 파일은 이전 배치 기록이다. 2026-10-29 최신 계획은 [A 묘기 직접 연결 계획](a-stunt-fusion-plan.md)이며 아래 '03에 바로 외줄 착지를 강요하지 않는다'는 옛 방향을 대체한다. 현재 구현 수치는 variants.md를 따른다.

> 최신 사용자 교정: 기존 묘기 시스템 재사용이 목적이다. 아래 Solo 조작/피격은 미채택 임시 구현이며 완성된 통합으로 쓰지 않는다. [재사용 계획](a-reuse-plan.md)을 우선한다. 공간 좌표/별도 검토 수치는 실제 기존 메커니즘에 맞춰 재검토한다.

2026-10-28. 사용자 요청: 다른 PC에 기록된 묘기 융합 의도와 현재 공간을 파악해 A부터 레벨 디자인. 아래 구체 배치는 그 요청에 대한 설계안이며 사용자 최종 플레이 승인이나 완성된 기믹이 아니다.

## 설계 기준

- 각 맵에 대포·외줄·트램폴린·그네가 모두 등장한다. 구간마다 네 가지를 강제로 연속시키지 않고 일부를 조합한다.
- 거대한 콘크리트 시설을 빠져나가는 압박과 급박함. 묘기는 독립 전시물이 아니라 단절된 정비 동선을 이어 주는 수단이다.
- 큰 외피·90/100m 깊이·중성 콘크리트·최종 출구 시야는 보존한다. 새 공간은 기존 전단벽에 지지되는 작업대와 짧은 정비 시설로 설명한다.
- 낙하 전에 받는 곳을 보여 준다. 기믹 사이에 긴 설명/대기 공간을 반복하지 않고 어려운 연결 뒤에는 넓은 착지/가속 공간을 둔다.

## A의 흐름

| 구간 | 플레이 의도 | 이번 배치 |
|---|---|---|
| 01–02 | 낮은 보 아래 진입, 다음 공동의 깊이 노출 | 현행 유지 |
| 03 | 대포로 깊은 공간 진입 → 착지 후 방향 전환 → 외줄로 이탈 | 임시 대포/안전 착지 보존, 발 높이에 맞춘 외줄 시각선·접속부·진행 도색 |
| 04 | 달리며 숨 돌리는 정비 선반, 다음 공동 예고 | 현행 유지 |
| 05 | 짧은 외줄 → 끝난 정비대에서 낙하 → 트램폴린 → 그네3개 → 넓은 착지 | 이번 핵심 공간 재배치. 하부 접근 계단과 준비 작업대도 제공 |
| 06 | 동료 재합류, 계단으로 올라가 출구 방향 확인 | 현행 유지 |
| 07 | 가속 → 측면/정면 톱 → 낙하/불/바람 → 그네 단절 → 종합 장애물 → 밝은 출구 | 기존260m 외피에14개 장애물 배치, 현재 씬의1인 검토 동작 연결 |

03은 대포 착지 직후 바로 외줄에 걸리도록 강요하지 않는다. 8×9m 착지대에서 다음 대각선과 동료를 읽고 이동한다. 05에서 행동 간 전이를 강화한다. 기존처럼 입구 트램폴린에서 멀리 놓인 그네만 바라보는 구성은 대체한다.

## 05의 높이와 조합

1. 상층 Y0에서 X89→96.2, Z28의 약7.2m 외줄을 탄다. 끝의1.4×2m 정비대는 다음 발판이 끊겨 있다.
2. 정비대 끝X96.9 앞에서 아래 반동 면(98,-4.1,28)이 보인다. 예고 없는 자동 파단은 추가하지 않는다. 우선 의도적으로 내려가는 동선이다.
3. Y-4.6의8×8m 작업대에 기존 크기의 트램폴린 시각 프리팹을 둔다. 첫 반동 목표는 손잡이(101,1,28), 매달린 발 기준Y-0.5다.
4. 그네 중립 손잡이 X101/107/113, Y1/0/-1, Z28. 간격6m. 천장 부착Y19.5. 실제 진자 궤적/놓는 타이밍은 기능 단계에서 확인한다.
5. X119,Y-8,Z28에 착지한 뒤 Z45의 재합류/상행 계단으로 달린다. 착지 공간에는 추가 위험물을 겹치지 않는다.

별도 하부 접근: X90→98.05, Z21.4–24의23단(단높이0.2m)으로 Y-4.6 작업대에 내려간다. 동료가 먼저 받는 곳을 준비하거나 외줄을 피해서 접근할 수 있는 느린 동선이다. 따라서 이 짧은 외줄은 모든 플레이어에게 필수는 아니다. 후발 주자도 하부에서 반동으로 나갈 수 있어야 하며, 실제 동작 연결 시 마지막 사람의 탈출과 기물 운반 정책을 확인한다.

## 구현 경계와 남은 결정

- 사용자 추가 요청으로 현재 A 씬에 오프라인1인 검토를 연결한다. `EscapeSoloReview_A`가 걷기·대포·외줄 이동·낙하 반동·그네·재시작을 담당한다. 실제 네트워크 균형·부상·운반 규칙을 재현한 완성본은 아니다. 외줄 아래에 보이지 않는 넓은 바닥을 추가하지 않는다.
- 별도 씬을 만들지 않는다. 기존 미리보기 카메라/플레이어와 네트워크 대포 시스템은1인 검토에서 정지한다. 공유 코드·프리팹은 바꾸지 않으며 기존 대포/착지 설정은 보존한다.
- 공용 GroundBounce는 점프뿐 아니라 반동 면보다 위에서 내려오는 공중 낙하도 허용한다. 실제 외줄 상태에서 그 요청으로 전환하는 흐름과 호스트 검증은 후속이다. 이번1인 반동은 그 통합 완료를 증명하지 않는다.
- 트램폴린 기본12m/s 반동·3m/s 공중 조절·현재 중력으로 첫 손잡이에 도달할 수 있는 이론 공간만 확인한다. 씬 전용 물리 수치나 공용 규칙은 바꾸지 않는다.
- 외줄은 기존 공연 코스의 좌표/상태 종속 분리가 필요하다. 단순 회전 설치나 공연 결과 정산 호출은 하지 않는다.
- 그네 점유·후발 처리/공용 진자 동작, 07의 실제 다인전 위험물 예고·작동·회복 시간,2–4인 통과는 후속이다. 검토용 로컬 진자는 W/S로 반동하고 Space로 놓는다. 자동 플레이/입력 주입 없음.
