직전 완료 묶음은 운반 트램폴린 높이, 하강 단절당 그네1개, 지상 F 그네 잡기, B 장거리 대포와 중간 그네, 화염6쌍, C 연속 그네4개다. 이는 보존할 기존 결과이며 B·C의 최종 완성을 뜻하지 않는다.

최신 승인 범위는 **A03~06 묘기 융합,04B 확장·순환 그네를 구현하고 저장**하는 것이다. 대포→외줄 직접 착지→그네와 협동 반동을 연결하고 의미 없는 복도·재상승을 줄였다. 적용 결과와 남은 확인은 [a-stunt-fusion-plan.md](a-stunt-fusion-plan.md). 마지막 질주 대개편은 후속이며, 이번에는 가까운 중간 그네1개만 제거해 두 그네의 역할을 구분했다.

중간 피드백에 따라 모든 고정 그네의 간격에 의미를 부여하고 첫 그네에서 뒤의 묘기를 전부 건너뛰는 배치를 보수했다. 자산 충돌·보이지 않는 벽/바닥·외줄 매달림 때의 배관 관통과 순환 구간의 뜬 배관도 이번 보수 범위다. 정적 검사 결과와 최종 시각/mesh/check-work·저장 대기 상태는 log에 구분한다.

A에 누적한 사용자 피드백을 먼저 완성한다. 깊고 거대한 시설 안에 갇힌 압도감, 거친 중성 콘크리트와 실제 설비, 의미 있는 이동/회피, 대포·외줄·반동·그네의 연속 경험이 기준이다. 전시회장처럼 매끈하거나 비어 있는 복도를 길이만 늘리는 방식은 피한다.

직접 플레이는 사용자가 한다. 작업 전 dev 최신화를 확인하고 필요한 변경을 통합한다. 불필요한 1인 실행/반복 테스트에 시간을 쓰지 않고 A의 이동·묘기 연결·상호작용 오류를 우선 고친다. A에 필요한 공용 코드 수정은 가능하지만 B·C 전용 제작·튜닝·마감은 M2 이후 범위다. 기존 씬 GUID를 유지한다.

## 확정 기준

- A/B/C는 같은 시스템·조작·환경의 개발 테스트 씬이다. 지금은 Play 즉시 혼자 검토하지만 최종 게임은 2인 이상이며 협동/호스트 판정은 원본 다인 메커니즘을 유지한다. 현재 방 만들기/참가 UI·게임 오버·공연 진행은 넣지 않는다.

## 검사와 남은 사람 확인

- 변경에 필요한 기물 참조·이동 경로 충돌/도달·화염 배타성·컴파일과 편집 시각 확인만 수행한다. 1인 자동 시작 반복·새 자동 플레이/테스트 시나리오 작성은 이번 검토 범위에서 제외한다.
- AI는 플레이어 이동·발사·횡단 입력을 자동 주입하지 않는다. 정적 궤적 통과는 실제 재미/통과 난도/멀티플레이 완료를 뜻하지 않는다.
- 사용자가 A의 실제 묘기 연결감, 1키 전환, 최종 밝기/성능을 확인한다. B·C 검토는 M2 이후로 미룬다. 멀티플레이 검토·방 시스템은 후속 범위이며 지금 활성화하지 않는다.
- 런타임 A/B/C 선택·대기실 연결·추격 AI·공식 승리 판정은 별도 범위다. 이번 추가 요청의 구간 화염 추격과 배선 절단 출구 문은 현재 A 범위다.
- 기존 Vivox 403은 프로젝트 계정 권한 문제로 남아 있다. 개인 인증값을 읽거나 출력하지 않는다.
