## 현재 목적

2026-10-29 최신 우선순위: **지금은 A만 먼저 완성한다. B·C 작업은 M2 이후로 미룬다.** 이전의 A→B→C 연속 완성·세 맵 동시 마감 계획을 대체한다. 현재 수정·폴리싱·플레이 피드백 대응과 완료 검토는 A를 기준으로 한다. 기존 B·C 씬과 연결 결과는 보존하고, 이번 A 변경을 B·C 씬에 반복 적용하거나 재생성하지 않는다.

직전 완료 묶음은 운반 트램폴린 높이, 하강 단절당 그네1개, 지상 F 그네 잡기, B 장거리 대포와 중간 그네, 화염6쌍, C 연속 그네4개다. 이는 보존할 기존 결과이며 B·C의 최종 완성을 뜻하지 않는다.

A에 누적한 사용자 피드백을 먼저 완성한다. 깊고 거대한 시설 안에 갇힌 압도감, 거친 중성 콘크리트와 실제 설비, 의미 있는 이동/회피, 대포·외줄·반동·그네의 연속 경험이 기준이다. 전시회장처럼 매끈하거나 비어 있는 복도를 길이만 늘리는 방식은 피한다.

직접 플레이는 사용자가 한다. 작업 전 dev 최신화를 확인하고 필요한 변경을 통합한다. 불필요한 1인 실행/반복 테스트에 시간을 쓰지 않고 A의 이동·묘기 연결·상호작용 오류를 우선 고친다. A에 필요한 공용 코드 수정은 가능하지만 B·C 전용 제작·튜닝·마감은 M2 이후 범위다. 기존 씬 GUID를 유지한다.

## 확정 기준

- A/B/C는 같은 시스템·조작·환경의 개발 테스트 씬이다. 지금은 Play 즉시 혼자 검토하지만 최종 게임은 2인 이상이며 협동/호스트 판정은 원본 다인 메커니즘을 유지한다. 현재 방 만들기/참가 UI·게임 오버·공연 진행은 넣지 않는다.
- 전체 기본 조작은 인간대포, 외줄 위만 외줄, 모든 그네는 HumanCannonPole. [확정 조작](../../../Harness/Project/Decisions/escape-control-baseline.md).
- 실제 묘기 씬의 기물·시스템·상호작용 테두리와 탑승 안내를 재사용한다. 별도 Solo 물리로 대체하지 않는다.
- 대포→그네→다음 기물의 연결 경험, 기존 트램폴린 반동/운반·외줄 균형·점유/피해 규칙을 보존한다.
- 톱은 날의 평면 안으로 이동하며 외형과 실제 접촉 판정 방향을 맞춘다. 빨간 임시 구체는 기존 화염 파티클로 전부 교체한다.
- 긴 하강은 넓힌 계단→대기대→그네 단절→회복대로 연결한다. 단순한 복도 연장이 아니다.
- 마지막 260m는 낙하·양옆/정면 톱·철퇴·회전 칼날·불·송풍과 그네, 끝에 밝은 외벽 출구/갈대밭을 둔다.
- 1키는 실제 플레이어 위치·시선과 동기화된 자유비행/플레이 복귀. 별도 테스트 씬을 만들지 않는다.
- 벽·바닥·계단·기믹 접합부의 의도치 않은 틈과 겹침을 보수한다. 의도한 묘기 단절·낭떠러지는 유지한다.
- 외부 에셋은 기존 Assets/_ThirdParty 참조를 사용하고 원본·GUID를 보존한다. 파생 재질/메시는 탈출로 폴더에 둔다.

## 검사와 남은 사람 확인

- 변경에 필요한 기물 참조·이동 경로 충돌/도달·화염 배타성·컴파일과 편집 시각 확인만 수행한다. 1인 자동 시작 반복·새 자동 플레이/테스트 시나리오 작성은 이번 검토 범위에서 제외한다.
- AI는 플레이어 이동·발사·횡단 입력을 자동 주입하지 않는다. 정적 궤적 통과는 실제 재미/통과 난도/멀티플레이 완료를 뜻하지 않는다.
- 사용자가 A의 실제 묘기 연결감, 1키 전환, 최종 밝기/성능을 확인한다. B·C 검토는 M2 이후로 미룬다. 멀티플레이 검토·방 시스템은 후속 범위이며 지금 활성화하지 않는다.
- 런타임 A/B/C 선택·대기실 연결·추격 AI·최종 탈출 판정은 별도 범위다. 현재 기존 씬에서 수동으로 혼자 검토한다.
- 기존 Vivox 403은 프로젝트 계정 권한 문제로 남아 있다. 개인 인증값을 읽거나 출력하지 않는다.
- 같은 Task의 doctor 실행 결과를 재사용하며 묶음 완료 후 check-work를 실행한다. commit/push/reset/discard는 별도 명시 요청 때만.
