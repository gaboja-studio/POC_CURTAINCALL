## Context
@RagSpirin의 최신 요청에 따라 현재 브랜치에서 **배경 맵만 제작**한다. 기존 에셋을 우선 배치하고 없는 오브젝트는 이름 텍스트가 붙은 그레이박스로 표현한다. 기믹·추격 AI·탈출 판정은 구현하지 않는다.

- 작업 씬: `Assets/Scenes/Levels/escape_route.unity` (기존 `PlaySetup`·`TempFloor` 확인).
- 공간 의도: 공연장 하부 기계실 → 긴 콘크리트 설비 공동 → 폐공장 반출동 → 외벽 → 갈대밭. 넓고 꺾이는 진행 방향, 깊은 설비 공간, 국소 높이차와 배관 밀도를 표현한다.
- 기준: [공통 기본 맵과 A·B·C 변형](https://hrjoo122770.atlassian.net/wiki/spaces/bYmkRlnpusng/pages/21528579/A+B+C). 이번에는 공통 배경 1개를 만들며 A/B/C 선택이나 묘기 기능을 추가하지 않는다.
- 2026-10-27 수정 방향: 단순 복도 초안을 폐기하고 문서의 평면도·단면도와 구간별 컨셉아트에 대응시킨다. 공연장에서 느낀 압도감을 하부 설비 공간으로 이어 간다. [공통 공간 기준](space-baseline.md)에 규모·감정·B/C 변형 경계를 기록한다.
- 최신 재질 방향: 영화 `Curve`를 참고한 평탄한 중성 회색 노출 콘크리트. 큰 벽과 기둥의 면이 읽히도록 강한 손상·박락과 주황빛을 줄인다.
- 최신 빛 방향: 내부는 흐린 낮처럼 칙칙하지만 진행 바닥·착지점·출구는 읽힌다. 갈대밭 출구에 도달했을 때만 햇빛이 강한 맑은 외부가 드러나도록 대비한다.
- 최신 규모 방향: 원본 평면 배치를 X/Z 1.25배로 확장하고 Y는 유지한다. 진입 폭 15m, 굽이·질주 폭 20m, 03 공동 50×25m, 05 공동 50×37.5m·단절 폭 25m. 공동 층고 28m·하부 깊이 60m는 유지한다. 천장을 포함한 외곽 기준은 240×95m이며 실제 주행 바닥의 최대 Z는 87.5m다. 원본 중심선 약 345m는 이번 확장에서 약 431m가 된다.
- 별도 추격자·정비 통로 `09_MaintenanceReservation`은 제거한다. 넓어진 주 진행 공간 자체를 배경 기준으로 삼는다.
- 소품·라벨·실제 캐릭터의 크기는 보존한다. 회색 캡슐 대신 현재 플레이어의 Humanoid 모델을 1.73m 크기로 맞춰 3곳에 놓고, 기존 씬 `Player`와 `LevelPreviewCamera`로 사용자가 실제 눈높이를 확인할 수 있게 한다. 기본 눈높이 기준은 `1.73 × 0.92`, 약 1.59m다.
- 사용자의 최신 수정에 따라 별도 조작 안내나 추가 미리보기 기능을 만들지 않는다. HUD·구역 순간이동·자동 복귀는 추가하지 않는다.
- 플레이테스트는 사용자가 직접 한다. AI는 플레이 모드 진입 상태를 유지하며 입력 주입·이동 시험·자동 플레이를 하지 않는다.
- 에셋: `Assets/_ThirdParty/`의 기존 에셋을 직접 참조·배치하고 원본·`.meta`/GUID를 보존한다.
- 작업 기준: [하네스 간소화](../../../Harness/Project/Decisions/harness-simplification.md), [에셋 지도](../../../Docs/Domains/assets-structure.md).

## 계획
1. 이 plan과 todo를 읽고 [start-work](../../../Harness/Core/Skills/start-work.md)로 현재 브랜치에서 이어 간다. 씬 편집 전 [integrate-editor](../../../Harness/Engine/Unity/Skills/integrate-editor.md), [코드 위치](../../../Harness/Engine/Unity/Policies/code-folders.md), [에셋 협업](../../../Harness/Engine/Unity/Policies/asset-ownership.md)을 확인한다.
2. 기존 원도면 치수와 이번 X/Z 1.25배 확장 치수를 구분해 기록한다. Y 높이와 구역 연결은 유지하고 별도 추격자·정비 통로를 제거한다. 구조물·횡단 연결부의 연속성을 확인하며 소품·라벨·모델 크기는 보존한다.
3. Escape 전용 재질과 조명으로 평탄한 중성 회색 콘크리트, 흐린 낮 같은 내부, 햇빛이 강한 갈대밭 외부를 표현한다. 원본 에셋과 공용 머티리얼은 보존한다.
4. 실제 Humanoid 모델을 크기 기준으로 배치하고 기존 `PlaySetup/Player`·`LevelPreviewCamera` 연결을 준비한다. 충돌·바닥·눈높이·카메라 시야·지상 이동은 사용자가 직접 플레이하며 확인한다. AI는 추가 플레이테스트를 하지 않으며, 묘기용 단절부의 통과 기능과 별도 미리보기 조작은 추가하지 않는다.
5. 플레이 모드를 유지한 채 `pwsh -File Scripts/check-work.ps1 -SkipUnity`를 실행하고 결과·미검증 사항을 log에 기록한다. 플레이 모드에서는 Unity 검증이 실행을 거부하므로 이번 묶음의 재컴파일 검사는 생략하며 자동 테스트도 실행하지 않는다. 현재 도구 검사는 진행 중이고 이전 PASS를 이번 완료 결과로 사용하지 않는다. 공간의 재미·방향·최종 플레이 경험은 사용자가 확인한다.
