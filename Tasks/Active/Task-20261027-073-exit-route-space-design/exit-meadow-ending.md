# A 출구 갈대밭·The End?

2026-11-03 사용자 요청. A의 출구 바깥 에셋과 임시 엔딩만 추가한다. 기존 내부 동선·사용자 삭제·대기실·B/C는 유지한다.

## 화면과 흐름

- 기존 출구 문이 열린 상태에서 로컬 플레이어가 FinalArrival 구역에 도착하면1초 뒤 `The End?`와 얇은 레터박스가1.8초간 나타난다. 도착 상태가 확정된 뒤에도 유지한다.
- 자유비행·문 잠김·리타이어/추락 상태에서는 도착 제목을 새로 시작하지 않는다.
- 첫 도착만으로 파티 성공을 확정하지 않는다. 기존 EscapeCampaignContent가 참가자 전원의 도착/리타이어/이탈을 집계하고 도착자1명 이상이면 성공한다.
- 성공 Ending에서는 A를 즉시 숨기지 않는다. 갈대밭을 보는 고정 카메라와 제목을 약6초 보여주고 기존 Hub 전환을 계속한다. 실패·일반 공연 전환은 지연하지 않는다.
- 전체 성공 장면 동안 조작과 관전 안내/인벤토리 표시를 정리한다. 재시작/비활성화에서 제목·엔딩 카메라·자기 입력 차단을 해제한다.
- 새 네트워크 성공 판정이나 별도 타이머를 추가하지 않는다. Campaign 상태가 각 클라이언트의 표시를 구동하고 호스트의 기존 장소 전환만 잠시 기다린다.

## 에셋

- 원래 낮은 풀255군락은 유지하고 직접 만든 키 큰 갈대를20개 공간 묶음으로 추가했다. 줄기·좁은 잎·이삭 및 작은 바람 흔들림을 사용한다.
- 새 갈대399,672정점/199,836삼각형. 추가 실시간 조명·그림자·투명 알파 중첩·식생 충돌체는 없다. 최종 게임 FPS는 측정하지 않았다.
- 기존 AbandonedFactory의 SM_Rock1/2/3을 각각1곳 재사용하고 LOD1 외형/URP 파생 재질로 배치했다. 원본 패키지는 수정하지 않았다.
- 콘크리트 마당의 표면을 연속 흙색/비주기 노이즈로 맞췄다. 출구 정면 통로와 바위 주변은 갈대 생성에서 비우고 바닥 높이를 맞췄다.
- 직접 만든 메시/재질은 Assets/Scenes/Levels/EscapeEndingArt, 셰이더는 EscapeMeadow.shader. 외부 바위 파생 재질은 비공개 Assets/_ThirdParty/Task073/Ending에 둔다.
- 정적 렌더 묶음을 복원한 뒤 표면을 수정하고 다시 생성했다. 편집 도구 EscapeEndingBuilder.Apply는 중복 생성을 거부한다. 기존 생성분은 RefineReeds 또는 직접 편집하며 사용자 배치를 덮어쓰지 않는다.
