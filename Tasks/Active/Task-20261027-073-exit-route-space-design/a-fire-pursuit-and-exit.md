# A 화염 추격과 절단 출구

2026-10-30 사용자 요청. 기존260m 최종 질주와 협동교3곳을 유지하고 양옆의 큰 불이 뒤에서부터 순차적으로 삼키는 연출/피해,트램폴린 운반 조작을 재사용한 휴대 톱 출구를 추가한다. 최신 추가 요청은 긴 다색 배선을 여러 지점에 배치하고 톱날을2초마다 발사하는 방식이다. 담당 RagSpirin,브랜치 feat/exit-route/design-map. 이전 구간은 [협동 고도화](a-cooperative-upgrade.md).

## 배치와 동작

- 39_AFinaleInferno: X140~400을20m씩13구역. 양쪽 내벽Z57/99에서 번갈아 기존 FX_Flame_Thrower_01을 확대해 전체 폭/높이를 덮는다. 뒤쪽의 불은 꺼지지 않는다.
- 살아 있는 플레이어가 X140~164 진입 바닥에 서면 호스트가 시작시각을 확정한다. 최초20초 유예,이후6초 간격,각3초 예고/폭발. 마지막 구역은 진입92초 후 점화한다. 모두 Inspector에서 조절할 초깃값이며 다인 난도 확정값은 아니다.
- 1키 검토 비행은 시작/피해에서 제외한다. 낙사 임시 해제와 별개로 직접 화염은 원본 피해 규칙으로 처리한다. X400을 넘으면 안전, R은 화염/운반/배선/문을 함께 초기화한다.
- 40_AExitCableSaw: X366.5/Z75.2·80.8의 독립 기계2대를 F로 들어 문 직전 배선으로 옮긴다. 길게 F로 놓는다. 기존 트램폴린의 운반 방향·카메라·속도 제한과 기계 충돌 검사를 연결했다. 기존 트램폴린 싱글턴은 하나로 유지한다.
- 최신 배선은 (370,73),(374,83),(380,73),(383,83),(387,74),(388,81)의 X/Z6지점·4가닥씩24개다. 높이5.8~9.55m의 긴 곡선으로 늘어뜨리며 빨강/청록/노랑/초록/보라/주황 피복과 구리 절단면을 쓴다. 기계가 발사한 날에 닿으면 한 가닥씩 잘려 양 끝이 튕겨 내려오고 불꽃/절단음이 난다.
- 기계를 들고 실제 접지 상태에서 바라보는 수평 방향으로2초마다 날을 자동 발사한다. 초기2초 충전,속도18m/s,수명2.5초,반경.55m/반두께.12m. 날은 수평 원판 평면 안으로 날아가며 벽에 막히고 플레이어 피해는 없다. 놓기/비행 검토/재시작은 발사를 정리한다.
- 필수24가닥을 모두 끊으면 X390 셔터가 열린다. 문이 열린 뒤에도 들고 있으면 발사는 계속한다. 현재 A는 직전 단일 노란 배선3초 접촉을 대체했다. 빈 cables 설정의 레거시3초 방식은 기존 호환 검사에만 남는다. 호스트 절단 상태와 실제 절단점을 공유하고 늦은 참가에는 지나간 효과를 다시 재생하지 않는다.
- 새 화염 음원은 기존 오디오 에셋이 없어 내부 생성한 짧은 저음/분사 소리다. 외부 에셋 원본은 수정하지 않는다.
