# 플레이어 기본 외형 설정

Project에서 `Assets/Resources/Settings/PlayerAppearanceCatalog.asset`를 선택한다.
Inspector 하단 **플레이어 1~4**에서 **모델/의상**을 이름 드롭다운으로 변경한다.
변경한 기본값은 다음 참가/플레이어 생성부터 적용된다. Play를 끈 상태에서 편집해야 저장된다.

| 플레이어 | 모델 | 의상 |
|---|---|---|
| 1 | 토끼 | 노랑 |
| 2 | 곰 | 초록 |
| 3 | 파란 삐에로 | 파랑 |
| 4 | 분홍 소녀 | 분홍 |

- Models: 캐릭터 이름/기본 프리팹. Outfit Prefabs에 의상별 프리팹을 지정할 수도 있다.
- Outfits / Outfit Colors: 네 의상의 표시 이름과 색상. 현재 곰·삐에로·소녀의 원본 재질 색상을 사용한다.
- Outfit Patterns: 의상 무늬. 0 마름모, 1 줄무늬, 2 점, 3 격자. 현재는 원본 재질처럼 모두0이다.
- 로비의 **모델 변경/의상 변경**은 개인의 해당 세션 선택이다. 이 에셋의 기본값을 바꾸지 않는다.
- 먼저 들어온 사람이 의상을 바꿔 다음 참가자의 기본 의상을 사용 중이면, 다음 참가자는 남은 의상으로 배정된다.
