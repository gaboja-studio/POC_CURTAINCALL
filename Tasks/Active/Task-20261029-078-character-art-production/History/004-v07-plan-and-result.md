# v07 계획·결과 원문

## v07 우선 작업 — 봉제 인형의 자연스러운 연결
- 사용자 추가 피드백에 따라 v06d의 smooth normal만으로 외형 보완을 완료했다고 보지 않는다. 각진 관절 띠·독립 팔꿈치·꽃잎형 커프스·촘촘한 칼라가 기계 부품처럼 읽히는 형태를 우선 수정한다.
- v06d와 원화를 보존하고 Blender에서 별도 v07을 만든다. 어깨부터 손바닥까지 이어지는 연속 팔 메시로 교체하고 손목의 딱딱한 띠/리벳/뾰족한 커프스를 덜어 낸다. 작은 분절 대신 완만한 부피 변화와 필요한 관절 루프를 사용한다.
- 노랑/아이보리 3단 프릴은 유지하되 잔잔한 톱니형 반복을 적고 넓은 비정형 물결로 바꾼다. 옷자락의 칼날 같은 끝과 패널 음영을 완화하고 바지의 무작위 정점 요철을 줄인다. 무조건 고밀도 subdivision으로 덮지 않는다.
- 먼저 실제 Blender 형태를 확인한 뒤 기존 본/절단 소유 규칙을 적용한다. 이전 시험용 자동 생성기를 재사용하되 v07 전용 결과로 저장하고 정상·굴곡·절단의 외형과 수학 검사를 구분한다.
- 통과 기준: 정상 몸체 삼각형 감소, 팔꿈치/손목의 메시 연결, 넓고 부드러운 프릴 실루엣, 기존 4단계 절단 계약과 애니메이션 유지. 의도한 천 주름까지 없애거나 둥근 플라스틱처럼 만들지 않는다. 손가락·잔여 관통·콜라이더와 실제 게임 통합은 확인 전 완료 처리하지 않는다.
