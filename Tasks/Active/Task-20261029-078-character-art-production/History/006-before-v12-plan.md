## 구현 순서와 통과 조건
### 1. 기존 Unity 자산 실물 조사
- 실제 Player 슬롯/모델 Prefab/Avatar/Controller/클립/본/스킨/절단 본체·사지/머티리얼과 기준 크기를 읽기 전용 조사한다.
- 정상/부상/Carry/매달림/사망/래그돌/복구/모델 교체/1인칭/페이드/네트워크 표시를 호환 목록으로 만든다. 코드 설명과 실제 자산 상태를 구분한다.
- 통과: 자산 경로·참조·기준값을 기록하고 다음 단계가 가정에 의존하지 않음.

### 2. 관절·절단 구조 설계 및 시험용 리깅
- 관절 위치와 관절 루프를 먼저 정리하고 Humanoid 필수 본·손가락·필요한 귀/옷자락 보조 본을 구성한다. 원본 외형에서 독립한 시험 버전을 만든다.
- 절단은 왼다리→오른다리→왼팔→오른팔. 정상 1종+누적 몸체 4종+분리 사지 4종을 같은 bones/bindposes 기준으로 만든다. cap은 마지막 submesh다.
- 바지/소매는 해당 사지와 함께 잘리고, 골반에 붙은 옷자락은 몸통 소유로 유지하되 절단된 다리를 가리거나 비어 있는 다리처럼 보이지 않는지 검사한다. 복수 절단 경계/닫힌 단면을 지원하며 기존 단일 경계 생성기를 무조건 재사용하지 않는다.
- 통과: 시험용 뼈 매핑, 정규화 웨이트, 미할당 정점, 좌우/축/스케일 검사를 통과. 아직 최종 외형/웨이트 승인과 구분한다.

### 3. 기존 애니메이션 조기 시험
- 독립 시험 자산에 유효 Humanoid Avatar와 기존 Controller를 연결. applyRootMotion=false, squashWhenCrouched=false 유지.
- Idle/Walk/Run/Crouch/CrouchWalk/JumpStart/JumpLoop/JumpLand/Crawl/Tightrope/Flying/Fall/Death/Hanging 및 Carry 상체 레이어를 검사한다.
- 발 접지·손가락/손 접점·어깨/골반/팔꿈치/무릎/옷자락 변형을 확인한다. 기존 임시 Crawl 재사용과 신규 부상 모션 제작을 구분한다.
- 통과: 전 상태 재생과 대표 극단 포즈의 결함을 기록·수정. Animator 연결 여부만으로 PASS하지 않는다.

### 4. 절단 조기 시험
- 왼다리 1단계에서 캡·포즈 연속성·분리 사지 스킨/물리부터 확인한 뒤 누적 4단계로 확장한다.
- 기존 HumanoidModel 계약, 관절 래그돌, 매달림 손 보정, 복구/재활성/재시작/모델 교체 시 신체 상태 복원을 검사한다.
- 통과: 5개 신체 상태에서 몸/옷/단면이 일관되고, 사지 조각의 본 참조가 원본과 잘못 공유되지 않음.

### 5. 외형·표면·웨이트 최종 마감
- 앞 단계 결함을 반영해 원화의 귀·러프·봉제·천 접힘을 다듬는다. 전면 고밀도 스컬핑은 필수가 아니며 필요한 부위만 사용한다.
- 최종 토폴로지·내부 면 정리·전체 UV·패치/마모 텍스처·머티리얼 아틀라스·웨이트를 완성하고 애니메이션/절단 회귀 확인.
- LOD0는 우선 1만~1.5만 triangles 이내, 필요 시 2만 부근까지 증량 사유 기록. 표면 재질 2~3개+cap 목표. 최종 절단 조각/동시 4인/그림자 비용 별도 측정.
- 고유 의상색과 플레이어 식별색을 분리한다. 현재 SetColor의 표면 전체 덮어쓰기를 그대로 적용하지 않는다.
- 추가 완성 목표(사용자 2026-10-29): 의상 형태·메시를 바꾸지 않고 같은 몸/의상 스킨에 깨끗함 / 소량의 피 / 많은 피와 오염의 3단계 재질 프리셋을 적용한다. 공통 UV·오염 마스크를 재사용하고 단계마다 메시를 복제하지 않는다. 정상/절단 몸체와 분리 사지에서 무늬가 이어지고, 조각은 분리 당시 상태를 유지해야 한다. 단계 변화의 게임 조건은 별도 결정이며 임의로 부상 수에 결합하지 않는다.

### 6. 실제 Player 교체 및 종합 확인
- 독립 시험 통과 후 실제 슬롯을 연결한다. 원래 더미는 보존하며 이동/공연/네트워크 판정은 외형 작업 때문에 바꾸지 않는다.
- 정상+부상 4단계, 운반·매달림·죽음/래그돌·복구/재시작·1인칭 숨김·가림 페이드·원격 표시를 확인한다.
- 온라인 2인 및 사람의 외형/최종 플레이 확인은 기능 묶음 완성 후 진행하며 자동 검사와 구분한다.
