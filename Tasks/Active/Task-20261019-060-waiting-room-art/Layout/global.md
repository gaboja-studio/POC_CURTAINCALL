# 공통: 재질·색·조명·제작 순서

[index.md](index.md)로 돌아가기

## 전체 인상

- 낡고 방치된 **서커스 백스테이지**. 공장 같은 어두운 벽과 배관 속에 빛바랜 붉은 천과 전구가 남아 있다.
- 어둠이 기본이고, **따뜻한 전구색 빛 웅덩이**가 기능 지점(천막, 침대, 거울, 커튼)에만 떨어진다.
- 예외는 화장실 하나다. 청록 타일에 차가운 백색 빛이 비친다.
- 깔끔하지 않다. 바닥 균열, 먼지, 흩어진 종이, 덧댄 판자, 녹슨 배관이 있다.

## 재질

- 바닥: 회색 돌 타일(약 1m 격자)에 균열·얼룩 데칼을 얹는다. 거칠기 높음, 금속성 0.
- 벽: 두께 0.3~0.5m. 어두운 벽돌·콘크리트이며 윗단에 철제 프레임과 리벳이 있다.
- 천: 붉은 벨벳(약한 광택), 천막 캔버스(무광, 바랜 줄무늬).
- 금속: 녹과 기름때가 있는 배관, 밸브 휠은 청동색.
- 외곽: 6 통로 북·남 바깥과 5 서쪽 바깥에 지름 0.6~1m 굵은 배관이 지나간다.

## 조명 기준

| 공간 | 주조색 | 밝기 | 특징 |
|---|---|---|---|
| 1 로비 | 전구색 | 중앙 밝음, 모서리 어두움 | 천막 위 전구 줄, 천막 아래 웅덩이 |
| 2 숙소 | 전구색 | 낮음 | 침대마다 작은 램프 |
| 화장실 | 냉백색·청록 | 중간 | 다른 공간과 대비되는 유일한 차가운 방 |
| 8 전문가 | 전구색·진홍 | 중간 | 윗벽 전구 줄, 붉은 반사 |
| 6 통로 | 전구색 | 반복되는 빛 웅덩이 | 북쪽 벽 전구 등간격, 바닥에 리듬 |
| 7 입구 | 주황 | 가장 밝음 | 커튼 둘레 전구 틀, 커튼 틈 역광 |
| 3 상점 | 전구색 | 작은 스폿 | 수화기 위 단일 램프 |
| 4 소품실 | 전구색 | 중간 | 분장 거울 전구 열이 가장 밝음 |
| 5 폐기물 | 호박색 | 낮음 | 책상 램프, 짙은 안개 |

- 앰비언트는 낮은 청록(현재 Trilight 설정 유지). 그림자 진하게.
- 동선은 밝기로 안내한다: 로비 중심 → 6 통로 → 7 입구 순서로 점점 밝아진다.

## 권장 계층 구조

```
WaitingRoomLayout
├─ Shell        (바닥·벽·문틀·천장, 공간별 하위)
├─ Rooms
│  ├─ R1_Lobby  ├─ R2_Dorm  ├─ R2b_Restroom  ├─ R3_Shop
│  ├─ R4_PropRoom  ├─ R5_Storage  ├─ R6_Corridor  ├─ R7_StageEntrance  └─ R8_ExpertRoom
├─ Pipes        (외곽 배관)
├─ Lighting     (공간별 하위 그룹)
└─ Gameplay     (스폰·상호작용 지점, 기존 것 재사용)
```

각 Room 아래는 `Floor/`, `Walls/`, `Furniture/`, `Props/`, `Decals/`, `Lights/`로 나눈다.

## 제작 순서

1. Shell: [index.md](index.md) 표의 범위로 바닥과 벽을 만들고, 각 문서의 "출입구"대로 문을 뚫는다.
2. 큰 가구: 각 공간 표에서 "핵심" 표시된 것부터 놓는다.
3. 소품·데칼: 상자 더미, 종이, 균열, 바닥 마크를 놓는다.
4. 조명: 위 표의 기준대로 놓는다. 공간 가독성 보조광(`VisibilityLighting`)은 마지막에 맞춘다.
5. 기능 연결: 스폰, 집결 구역, 수화기, 배송구, 분장 거울 등 기존 상호작용 지점을 새 위치로 옮긴다.

## 검증

- 위에서 내려다보는 정사영 카메라(로비 중심, 크기 약 30m)로 캡처해 [reference.webp](reference.webp)와 나란히 비교한다.
- 확인 항목: 방 비율, 문 위치, 천막 위치, 붉은 커튼 반복, 화장실 색 대비, 7 입구가 가장 밝은지.
- 플레이 시점(3인칭)에서 각 방의 핵심 가구가 한눈에 읽히는지 방마다 한 장씩 캡처한다.
