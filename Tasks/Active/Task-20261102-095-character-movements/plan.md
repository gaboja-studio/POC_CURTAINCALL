# Task-20261102-095

- **Type:** fix
- **Assignee:** @MoHoDu
- **Branch:** fix/character/movements
- **Base:** dev

## Context
현재 브랜치에서 캐릭터 움직임 수정사항을 처리한다. 1차: 계단·경사로 내리막에서 "전진 후 살짝 낙하" 반복 대신 경사면을 따라 자연스럽게 이동.

## 계획
- 원인: `PlayerMover`가 땅에서 수평 이동 + 고정 하강(-1m/s)만 넣어, 내리막에서 발이 떠 `Fall` 상태로 바뀜.
- 수정: 걷던 프레임에 접지가 풀리면 `SnapToGround`로 같은 프레임에 발밑 땅에 붙인다. 범위는 stepOffset 또는 수평 이동×최대 경사 이내의 걸을 수 있는 면. 더 깊거나 급경사면 기존처럼 떨어진다.

## 미정·주의
- 계단 한 칸(최대 stepOffset 0.3m)은 한 프레임에 내려간다. 카메라·모델 보간이 필요하면 후속으로 다룬다.
- stepOffset 이내의 낮은 턱은 걸어 내려가면 떨어지지 않고 바로 붙는다(공중·착지 이벤트 없음).
