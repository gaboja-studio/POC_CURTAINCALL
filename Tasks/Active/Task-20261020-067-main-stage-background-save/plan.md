# Plan

## Context

묘기 씬들이 공용으로 쓰는 지름 1164의 원형 폐공장 서커스 배경. 2026-10-21 사용자 참조 이미지 4장 기준으로, 하부를 위협적이면서 황홀한 철골 지하 도시로 구성한다.

## Approach

1. 최초 바닥 Y-404의 어두운 기초와 여러 높이의 발판·철골·작업실·다리로 수직 도시를 만든다. 이후 깊이 확장은 10번 참조.
2. 관객 실루엣이 있는 원형 관람대 9곳, 사슬·전선·톱날을 배경 요소로 배치한다.
3. 추가 참조에 따라 금빛 주황 심부 조명과 옅은 스모그 8곳, 따뜻한 작업등, 먼 푸른빛으로 깊이 층을 구분한다.
4. 기존 OrderedAbyss 시안과 원본 복잡한 구조는 비활성 상태로 보존해 비교 가능하게 한다.
5. 사용자가 실제 묘기 카메라의 미감·간섭을 확인한 뒤 성능 측정과 최적화 여부를 결정한다.
6. 바닥 Y-404는 유지하고 하부 구조 배치만 바닥 기준 Y 1.045배로 높인다. 상단 Y-60 부근은 약 15.48m 상승.
7. 외곽은 3층×6줄의 끊김 없는 원형 관중석으로 교체하고 통로는 계단으로 연결. 붉은 좌석·금색 테두리·정적 관객을 배치하고 하부 원형 관람대도 좌석 보강.
8. 원본에서 활성 구성만 공유 프리팹으로 추출. 인간 대포/외줄 코스는 유지하고 배경 배율 1/3, 중심 Z81.125/82.5로 배치.
9. Light 거리 ×1/3·세기 ×1/9·안개 밀도 ×3로 외형 비율을 보정하고 배경/코스 광원 마스크 분리. 장식 케이블만 인스턴스에서 숨김.
10. 아득한 깊이 요청으로 바닥을 원본 Y-1080/적용 씬 -360으로 내린다. 기존 상부 배치는 유지하고 심부 작업장 54개/3층, 철골 기초·외벽·안개 3곳을 아래로 확장한다. 원본과 공유 프리팹에 동일 반영.
11. 후속 요청으로 6번의 상승분을 취소한다. 하부 도시·관람대·톱날·심부 작업장을 외벽 주변에 모으고 통로와 받침으로 외벽까지 연결한다. 중앙 하부를 비우고 원형 상부 관중석/바닥 깊이는 유지한다.
12. 최신 요청으로 관객 모델을 제거하되 4800석과 관람대 구조는 유지. 인간 대포/외줄의 배경과 환경 설정을 적용 전으로 복구하고 공유 프리팹을 제거한다. 당분간 원본 공연장만 편집한다.

## Risks

- 관객 제거 후 정점 약 745만, Renderer 1221, 켜진 Light 44. 실측 프레임 시간 미검증.
- 배경 톱날은 고정 장식이며 게임의 실제 피해 장애물과 구분되는지 사용자 확인 필요.
- 배경 전용으로 콜라이더·플레이어·카메라가 없으며 실제 게임 동작은 별도 묘기 씬에서 소유한다.
- 직전 EditMode가 리로드 후 종료되지 않아 취소한 이력이 있어 테스트 통과로 보고하지 않는다.
- 외줄 SafetyNet은 기존 불투명 판으로 하부 시야를 가린다. 이번 배경 적용에서 동작/외형은 유지.
