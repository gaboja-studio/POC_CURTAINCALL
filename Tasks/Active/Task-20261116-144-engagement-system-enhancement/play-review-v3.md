## 표시와 프리팹 키트
- 지정 순서 완료: GPT Image로 실제 화면 기반 시안 생성 → 배경/테두리 투명 PNG 각각 생성 → Unity 9-slice 스프라이트 → `AudiencePopupKit.prefab` → 기존 `Feedback.prefab` 연결.
- 생성 시안: `Previews/popup-gpt-v3.png`. **실제 실행 화면: `Previews/Runtime/popup-v3-live.png`**. 외줄에서 호스트 보상 API의 +6 입력이 실제 +12로 반영되고 −5와 함께 표시되는 장면이다.
- 좌상단 호응도 게이지 옆, 숫자 44px / 1.2초. 실제 증감량만, 0.2초 이내 같은 부호 합산, 반대 부호 두 줄. 기존 게이지 합계도 해당 방향의 색으로 짧게 반응한다. 큰 확대/흔들림/아이콘 없음.
- 레이어: Background / Frame / Subject / Positive / Negative / Handhold. 숫자·대상 표시는 TMP이므로 해상도와 실제 값에 대응한다. 평소에는 숨기고 사건 때만 표시한다. 단일 반응 184×104, 양방향 겹침 184×152 기준 픽셀.
- 키트: `Assets/Resources/Prefabs/UIs/Roles/Retained/Feedback/AudiencePopupKit.prefab`. 기존 공용 Canvas 아래 재사용 가능. `AudiencePopupKitBuilder`는 기존 숫자 뷰에 레이어를 적용하고 독립 키트를 저장한다. 실제 연결은 `AudienceFeedbackInstaller.Apply()`로 재생성 가능하다.
- 스프라이트: private `Assets/_ThirdParty/AudienceReactionsTask144/PopupKit/`. 실제 alpha 검사: 프레임 중앙 0, 외부 모서리 0. 배경 중앙 253. 원본 1448×1086은 보존하고 런타임 import 상한 512, mipmap 없음. 프레임/배경을 각각 조절 가능하다.
- 생성 방식과 원문 프롬프트는 `Previews/popup-prompts-v3.md`. 코드로 대체한 장식 이미지는 없다.

## 소리와 동시 반응 기준
- 환호는 높은 Yay 중심의 이전 녹음을 제외하고, 약한 환성이 포함된 실제 실내 관객 박수 녹음으로 교체했다. 환호 4종 / 야유의 서로 다른 발성 4종, 직전 변형 연속 반복 방지.
- 야유만 약 두 반음 낮춤, 박수 원래 피치 유지. 날카로운 고역과 저역 잡음을 줄이고 짧은 확산 잔향을 오프라인으로 처리했다. 실제 귀로 느끼는 자연스러움과 억압감은 사용자의 청취 확인이 필요하다.
- `audition-cheer-v3.wav`와 `audition-boo-v3.wav`: 각 4종을 0.5초 간격으로 이어 놓은 청취 파일. **잔향 포함 클립 미리듣기이며, 게임의 카메라 방향에 따른 공간 처리까지 녹화한 파일은 아니다.**
- 공간 음원은 배우 위치가 아닌 객석의 네 위치 중 하나에서 재생한다. 3D 65% + 2D 35%, 넓은 spread, Doppler 없음. 고개를 돌려도 피드백을 잃지 않도록 완만한 감쇠를 사용한다. SFX/마스터 설정을 그대로 따른다.
- **조작 중에는 본인, 관전 중에는 현재 관전 대상만** 개인 숫자/소리의 기준이다. 다른 사람의 반대 반응은 섞이지 않는다. 대상 전환 시 소리와 대기 사건을 지우고 기준 스냅샷을 다시 잡는다. 같은 대상의 반응이 반대로 바뀌면 앞 소리를 120ms에 줄인다. 최대 재생 2개, 추가 네트워크 패킷 없음.
- 8개 24kHz mono PCM 사전 준비; 준비되지 않은 음원은 그 사건에서 생략한다. 런타임 합성/리버브 필터/반응 시 파일 디코딩 없음. 원본/라이선스/편집 내역은 private 음원 폴더 `sources.md`.
