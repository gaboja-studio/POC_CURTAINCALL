# 1차 플레이 시안 — 2026-11-17

이 문서는 1차 결과 기록이다. 최신 팝업·소리·관전 처리와 실제 화면은 [v3 결과](play-review-v3.md)를 따른다.

숫자와 사람 녹음을 먼저 적용했다. 군중은 한 구역 시험 옵션이며 기본 꺼짐이다. 추가 요청에 따라 공연장은 어둡게, 전등과 가까운 공연 구간은 상대적으로 밝게 조정했다.

## 적용
- 숫자: 실제 증감량만 28px / 0.85초, 균형 HUD 오른쪽 위. 0.2초 이내 같은 방향은 합산, 반대 방향은 두 줄로 분리해 게이지 위에 쌓는다. 박스·아이콘·점프 애니메이션 없음. 메뉴/관전/종료 시 숨김, 상한 성공은 소리만, 0점 야유·자연 감소·초기/중복 수신 제외.
- 소리: CC0 실제 관객 녹음에서 환호 3개(2.05초), 야유 3개(1.65초)를 편집. 피치 변조·합성 파형·추가 금속 효과 없음. 같은 방향의 녹음을 중간에 다시 시작하지 않으며 동시 음성 최대 2개, SFX/마스터 설정 적용. 24kHz mono PCM 사전 로드, 미준비 음원은 건너뛴다. 6개 float PCM 이론치 약 1.02MiB. 실제 믹스에서의 자연스러움은 사용자 청취 판단 필요.
- 군중: 72명, 메시 1개, 864삼각형, 1,728정점, 런타임 메시 메모리 163,992B. GPU 자세 보간, 개별 Animator/Collider/NetworkObject 없음. 기존 반응 스냅샷만 이용하며 새 메시지 발송 코드는 없다. 원본 객석은 보존하고 한 구역에만 시험 실루엣 추가. 공유 반응의 셰이더 값 `+1` 전달을 실제 실행에서 확인했다.
- 조명: 환경광 프로브 0.45배, 환경 반사 0.3배, 공연 씬의 기본 방향광 0.35배. 배경 재질의 기본색 0.65배/약한 자체 발광 0.25배, 전등 발광 2.5배. 33개 공유 재질의 런타임 복제본을 재사용하며 private 원본은 변경하지 않는다. 가까운 공연 구간에 범위 42m의 그림자 없는 보조광 1개. 공연 종료 시 재질/조명/환경값 복원.
- 조정 위치: `GameSettings.Base.AudienceFeedback`, `GameSettings.Base.PerformanceLighting`. 점수·부상·물리·판정 규칙은 변경하지 않았다.

## 실제 화면과 측정
- `Previews/Runtime/popup-cheer.png`, `popup-boo.png`, `popup-both.png`: 실제 외줄 플레이 씬, 호스트 보상 API로 검증용 사건을 발생시킨 캡처. 예: 입력 +6 → 기존 배율 적용 실제 +12, 야유 −5. 합성 UI/컨셉 이미지가 아니다.
- `crowd-full-view.png`는 일반 플레이 시점, `crowd-inspection.png`는 배치를 확인하는 별도 근접 검사 카메라다. 후자를 일반 플레이 시인성 근거로 쓰지 않는다.
- `lighting-before.png`와 `lighting-after-probe.png`: 같은 외줄 위치/카메라에서 비교한 조명 시험. 광량 비교 중 게임 시간을 멈춰 위치·위험물 변화의 영향을 줄였다. **최종 적용 화면은 `popup-both.png`**이며, 저장된 설정으로 새 플레이를 시작해 실제 시간이 흐르는 상태에서 +12/−5를 캡처했다. 이 실행의 Unity Console 오류는 0개였다.
- 군중 A/B: Ryzen 7 9700X / RTX 5070 Ti / Editor 1920×1080, off/on/off/on 각 4초. 메인 스레드 중앙값 각각 16.66 / 18.58 / 16.04 / 16.20ms. p95는 23.76 / 26.67 / 23.79 / 23.14ms. 렌더 스레드 카운터는 미지원. 원본: `Previews/Runtime/performance.json`.
- 위 A/B는 **조명 변경 전** 측정이며, 에디터/움직이는 배경/복수 뷰 변동이 섞여 군중의 순수 CPU·GPU 비용을 분리하지 못했다. 이 수치로 성능 상한을 통과했다고 판단하지 않는다. 추가 보조광을 포함한 빌드 성능·첫 반응·초기 로딩·4인 네트워크 검증은 아직 수행하지 않았다.

- EditMode `PerformanceFeedback` 3/3 통과: 합산 시간창·부호 분리·실제 0·초기/중복/로컬 필터.
- PlayMode `AudienceNumbers` 2/2 통과: 실제 외줄/인간대포 각각에서 숫자 합산, 양·음 동시 표시, 녹음 중첩 억제, 숨김 시 소리 정지/과거 이벤트 재생 방지.
- 조명 후 기존 `PerformanceEnvironmentAndCameraAreRestoredOnExit` 1/1 통과. 실제 외줄 최종 명암/숫자 캡처도 완료했다.
- 묶음 최종 `check-work.ps1`: 안전성/문서/컴파일/공통 설정 PASS. 자동 테스트는 위의 선별 실행 결과로 별도 기록했다.
- 더 넓은 기존 `C12_BothActualPerformances_RecordAndDisplay`는 첫 외줄 표시/종료를 지나 두 번째 인간대포 씬 전환에서 실패했다. 원인은 아직 확정하지 않았으며 전체 회귀 PASS로 기록하지 않는다. 각 공연의 독립 표시 검사는 통과했다.

- 군중은 일반 시점에서 작고 먼 배경에 묻히므로 현재 단계에서는 확대하지 않는다. 숫자 위치·사람 소리·새 명암에 대한 사용자 피드백 후 다음 단계를 정한다.
- 커밋/push 없음. 새 음원은 private `Assets/_ThirdParty/AudienceReactionsTask144/`에 있으며 출처·라이선스·편집 방식은 그 폴더의 `sources.md`에 기록했다.
