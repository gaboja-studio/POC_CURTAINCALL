## 직전 baseline: 출발지·접근 경계 정리

- 출발지의 낮게 겹친 옛 보·기둥을 정리하고 12m 유효 높이의 반입 압력실, 기존 낮은 출입구, 16.5m 높이의 가공 통로 보로 재구성했다. 기존 바닥·스폰·첫 등장·대포·공통 이동을 보존한다. 당시 비충돌 바닥 도색은 후속 사용자 요청으로 생성 코드에서 삭제했으며 현재 가독성 설계로 유지하지 않는다.
- 통로의 통과되는 자재·불필요한 카트·릴·팔레트를 정리했다. 공유 추격 NavMeshLink와 연결된 실제 충돌 작업대는 남겼다. 반입 창 양끝의 0.6m짜리 막다른 턱은 9.1m 높이의 콘크리트 반환 벽으로 교체했다.
- 같은 이름의 기존 조명이 여러 개여서 `Transform.Find`만으로는 바닥 근처의 폐기된 조명을 놓치는 점을 확인했다. 높이·소속으로 해당 조명을 찾아 새 격자/벽에 재부착하고 화면에서 낮게 떠 있는 함체 제거를 확인했다. 공개 발판의 등 지지대에도 보이는 크기와 동일한 충돌을 적용한다.
- 서사 설비 5곳에 측벽·뒷벽·지붕을 추가하고 앞 격자를 높여, 장식을 통과하는 우회 진입을 차단했다. 보이는 메시와 동일한 실제 충돌체를 사용한다. 공통 서기/숙이기 캡슐, 일반 점프와 2~4단 목마 높이, 상부 하강을 포함한 **13,485개 표본**과 165개 차단체 외형을 검사했다. 가능한 모든 발사·낙하 궤적을 완전 증명한 것은 아니다.
- 최종 추격자 arena 확장에 더해, 회피 돌진의 양끝 몸통 겹침과 이동 중 발밑 지지를 검사한다. 실제 작업장 코너의 공중 틈을 재현한 회귀 포함 5개 추가 테스트가 통과했고 탈출로 EditMode 합계 **468/468**이다.
- 초기 전체 빌드 두 실행의 19/24·20/24 배선 후 전원 탈락은 `labyrinth-play-qa.md`에 별도로 기록했다. 해당 실행은 이번 출발지·실체 차단·돌진 수정 전 빌드다.
- 이후 `labyrinth-entrance-3-01`은 새 출발지부터 첫 대포와 **이전의 쉬운 검사동 분기**를 거쳐 22/24에서 전원 탈락했다. 전체 빌드 errors 0, 체크포인트·재시작 없는 연속 입력과 실패 카메라 대체 캡처 성공을 확인했다. 타임라인의 봉은 기존 15개뿐이며 **최신 10봉 설계의 실기 증거가 아니다.**

## 배치 중 발견한 문제와 반영한 수정

- EscapeBackground의 XZ 1.25배 스케일을 생성 루트에서 상쇄하고 현재 에셋 경로와 재질·대포 외형을 사용한다.
- 새 외줄의 몸통 충돌, 아래에 남는 벽 조각, 중복 난간·기둥, 착지대의 겹친 윗면을 정리했다. 기존 계단 위를 가로지르던 대각선 외줄은 공통 대포 연결로 바꿨다.
- 반출교 우회 합류대와 기존 화염 분사함의 겹침을 피하고, 새 출입구를 막던 정적 장식 잔해를 복사 씬에서 정리했다. 기존 위험 장치의 위치나 규칙을 바꾸는 방식으로 해결하지 않는다.
- 초기 1인 실행에서 반입 장식이 첫 등장 경로를 막는 원인을 분리했다. 이후 반입 설비를 옮기고 기존 등장·보행·도약의 몸통 여유를 감사 대상으로 추가했다. 하부 홀·귀환 부두·화염 지지대와 가공 설비도 해당 경로를 피하도록 재배치했다.
- 일부 옛 외벽은 BoxCollider가 아닌 **MeshCollider**여서 이름 기반 절개에서 남는 문제가 있었다. 해당 큐브형 패널의 두 충돌체 형식을 처리하도록 수정하고 최종 작업장 양측 통로와 가공 설비 포켓의 벽 절개에 반영했다.
- 기존 마지막 질주면의 깨진 모서리가 확장 바닥과 만나 이음새 틈을 만들었다. 공유 원본을 수정하지 않고 독립 메시에서 로컬 Z 가장자리를 71/85로 정렬한 뒤 렌더 메시와 충돌 메시를 함께 갱신한다.
- 중앙 새 등장 출구와 착지, 양측 작업장·출구 프레임은 기존 타격·도약·문 회전 범위를 고려해 조정했다. 수정 코드 반영 사실과 최종 생성본의 물리·실기 검증 결과는 구분한다.

- 최종 보스의 기존 추적 영역 폭 14m가 확장 작업장 옆길을 포함하지 않는 누락을 발견했다. 공통 보스 코드와 문·불꽃 X 경계를 보존하고 복사 씬 영역 폭을 34m로 맞췄다. 양측 작업장 바닥 중심과 네 모서리, 총 10곳을 `InsideArena`로 검사한다.

## 검사 증거와 남은 검증

실제 3·4인 입력 실행과 실패 결과는 [플레이 기록](labyrinth-play-qa.md)에 분리한다. DEV 동기화 전 빌드에서 **당시의** 기존 전체 경로 및 새 외줄 6개·대포 2개의 통과를 관측했다. 출발지 수정 baseline까지 포함해 성공 엔딩은 미확인이다. 초기 `solo-03`은 첫 신규 봉 15만 잡은 뒤 포획됐고, 이후 봉 재잡기·착지는 위 준비 위치 구간 시험에서 별도로 확인했다. 입구부터의 연속 검증과 합산하지 않는다.

로컬 원자료는 `.harness/local/pursuer-remake-planning/`의 감사 JSON·충돌 여유 자료·배치 캡처에 있다. 최종 측정치와 테스트 합계는 실제 실행 결과에 따라 별도로 기록한다.

- 편집 감사는 새 충돌체 크기·중복, 등록 외줄 아래의 새 바닥 침범, 서사 장식 범위, 착지 지지와 기물·등장 경로 여유를 대상으로 한다. **DEV·arena 수정 직후, 출발지/서사실 봉쇄 및 10봉 재설계 이전** 감사는 failures 0, 누락 스크립트 0, 고립 소품 0이었다. 당시 새 루트 충돌체 781개, 등록 외줄 21개, 서사 설비 5곳, 바닥 윗면 후보 1,240표본이었다. 벽·구조물 윗면 교차 경고 222개와 새 공개 발판/작업장 경고 0도 해당 시점의 값이다. 최신 생성본의 수치나 전체 에셋 무결성 보증으로 재사용하지 않는다.
- 이전 첫 분기 묶음에서는 실제 1인 입력으로 입구→첫 대포→기존 착지 외줄→새 검사동 갈림 외줄→검사동 발판→다음 검사 외줄 일부를 이동했다. 당시 위치 준비·체크포인트를 쓰지 않은 부분 실행이며, 이후 전체 공간 재구성의 완주 증거가 아니다. 원인 분리를 위한 런타임 장식 비활성화 실험도 정상 플레이 결과와 분리한다.
- 이전 씬의 다인 부분 시나리오, 준비 위치를 사용한 후반 배선·엔딩 확인, 정적 공간 감사는 현재 미궁의 입구부터 연속 완주를 입증하지 않는다.
- **현재 전체 경로의 3인·4인 무체크포인트 성공 엔딩 검증은 완료하지 않았다.** 준비 위치 구간 시험 이후의 연속 연결, 분산 추격·유인자 사망 후 생존자 진행, 목마·트램펄린·대포 점유 조합과 기존 첫 대포/봉 정지 재제보 회귀도 최종 확인 대상으로 남긴다.
- 기존 재제보와 대포 정면 출현 문제는 `remake-regression.md`에 유지한다. 새 공간이나 분기 추가만으로 해결됐다고 표시하지 않는다. 현재 기록은 구현 범위와 발견된 문제의 수정 내역이며, 전체 맵 플레이 PASS·버그 없음·최종 경험 승인으로 해석하지 않는다.


## 바닥 표식 제거와 국소 조명 보정

- 바닥 경로선·승차선·발판 가장자리·작업장 표식을 생성하지 않는다. 복사된 기존 바닥 도색은 두 지정 재질, 수평 두께 3cm 이하, 자식/게임플레이/충돌 컴포넌트 없음 조건으로 제거한다. 공유 메시·난간·봉 외형은 수정하지 않는다.
- 생성 후 FloorMarks 조회에서 해당 경로선과 평면 도색이 모두 0개임을 확인했고 입구/작업장 화면을 확인했다.
- 새 봉 10개의 빔 고정 작업등을 넓고 부드럽게 보정하고 같은 렌즈 위치에 전방 보조 spot을 추가했다. 열 회수/상부 반출 캡처에서 다음 착지면과 인접 벽의 가시성 개선을 확인했다. 전체 맵의 최종 조명·사용자 경험 검증은 남아 있다.
- 이 생성본 감사: failures 0, warnings 271, colliders 952, ropes 20, stories 5. 경고를 오류 없음이나 전체 진행 PASS로 해석하지 않는다.
