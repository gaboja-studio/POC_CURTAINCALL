## 봉 정지 재제보 후 수정·검사

- 봉 탑승 후보를 복도 근접 공격으로 취급하던 분기를 수정했다. 후보마다 외줄/기물 경고를 정하며, 봉은 경로 진입 후에도36m 사거리를 유지한다. 일반 노출 바닥22m 제한은 유지한다.
- 투척은 실제 생존자 표적을 먼저 찾고, 폐기 지점은 먼 곳부터 검사한다. 공용40m 범위, 실제 비행과 같은 중심높이0.8m/반경0.55m의 궤적으로 벽·천장·도착 충돌을 검사하며, 벽이 있으면 실제 비행도 멈춘다.
- 포효는 원본 Idle와 HandFlex 손가락을 활용한 파생 클립이다. 발 고정, 양팔·가슴·고개 동작을 생성하며 원본 FBX는 보존한다. 기존 클립 번호를 유지하고 Roar를 마지막에 연결한다.

음원2개는 자체 생성 mono24kHz/8초 루프이며 파형 클리핑0, 반복 경계 변화가 일반 샘플 변화 범위 안이다. 전체5개 입자계 최대234입자, 장식 회전체/작업등2개만 주기 제어한다. 새로운 피해 규칙이나 플레이어 동작은 추가하지 않았다. 원본 두 씬의 SHA256은 복사 당시와 동일하다.

공장 연출의 공용 시계·회전 복원·입자 구간·음향 재진입 회귀4개를 포함한 최종 탈출로 EditMode324/324 통과(33.22초). PlayMode는 실행하지 않았다.

이번 최종 check-work: 안전성·문서/규칙·컴파일·공용 설정 PASS, 공통 진행 EditMode706/706 통과(73.75초). 기존 문서 길이 경고는 남아 있으며 검사 실패는 없다.

1. 실험 씬의 첫 대포에서 봉을 잡고 머문다. 장거리 공격과 벽 뒤 복귀/재등장이 이어지는지, 다른 팀원이 바닥에 있을 때 후보 전환 후에도 공격하는지 확인한다. 이후 외줄→컨베이어→복귀 대포와 역주행을 확인한다.
2. 시작 포효에 지목/표식이 없는지, 숙인 접근과 벽 파괴·도약을 확인한다. 포획 후 넓은 낭떠러지에서는 멀리 던지고 벽·천장에서는 멈추는지, 선 잔류와 손 모션도 확인한다.40m는 충돌이 없는 경우의 최대 범위다.
3. 컨베이어 대포에서 좌우 봉이 다가오는 시야와 타이밍, 새 계단의 달리기/점프/역점프, 어둠 속 기물 식별을 확인한다. 대포/봉/목마/운반 기물을 쓰는 중 피격·포획 후 관전과 재시작을 확인한다.
4. 마지막 배선 작업장을 먼저 밟은 팀원과 뒤에 남은 팀원이 있을 때 추격 전환, 오른손 절단 후 공격, 출구 진행을 확인한다.
5. 호스트와 원격 참가자에서 같은 절단·벽 파괴·발사 시점이 보이는지 확인한다.
6. 컨베이어 봉을 타며 작업장의 시신 이송·절단과 끓는 처리조가 보이는지, 모터/절단음이 추격자 접근 소리를 가리지 않는지 확인한다.
