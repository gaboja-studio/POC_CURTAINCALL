- 2026-11-15 사용자 구현 승인: 기존 수정본을 보존한 `EscapeRouteLabyrinthPrototype.unity`에서 리메이크한다. 공통 기물·조작·물리·GameSettings를 사용하며 탈출로만의 이동 규칙을 만들지 않는다.
- 첫 구현의 독립 검사동 우회, 가공동→상부 반출 우회, 협동 반출교 외측 외줄 선택에 이어 입구부터 최종 작업장·출구까지 공간 재구성을 확장했다. 최종 작업장에서는 중앙 설비 양측으로 접근하고 같은 배선 목표와 출구로 합류한다. 기존 톱·케이블·문·도착 판정·별도 엔딩 리그를 보존하며, 문을 우회하는 경로를 만들지 않는다. 공간 생성 완료를 전체 맵 플레이 통과나 버그 없음으로 표시하지 않는다.
- 구역 서사는 인간 공장을 점거한 미지의 존재의 반입·인체 가공·알 수 없는 생산물 출하로 통일한다. 장식은 플레이 동선 밖의 지지된 설비대에 배치한다.
- 추가 지시(2026-11-15): 출발지 첫 조우실도 전면 리메이크한다. 공개 보행·묘기 목적지와 배경 설비를 분리하고, 의미 없는 접근용 턱은 높은 실체 벽으로 정리한다. 첫 조우실의 높은 천장→낮은 출구→가공 통로를 구성하며, 서사 설비 5곳은 앞·옆·뒤·상부를 보이는 실제 구조물로 차단한다. **후속 사용자 지시에 따라 입구 6개 경로선·대포 승차선·공개 발판 가장자리 유도선을 모두 제거한다.** 생성 코드 삭제와 재생성 뒤 확인을 구분하며 구조·목적지·조명으로 경로를 읽히게 한다.
- 각 묶음에서 에셋 맞춤·유격·뚫림·겹침·외줄 아래 낙하 공간·착지·시야를 확인하고, 새 우회로의 추격자 등장/재추적은 별도 검증한다.
- 편집 상태 공간 검사와 자동 EditMode 결과를 기록한다. 사용자 플레이에서 이동·공포감·원격 표현과 코스 난이도를 확인한다.
- 대기실 NavMesh 재굽기와 대기실 포획 검증은 대기실에서 증상이 나온 경우 해당 작업 기록을 기준으로 확인한다.
