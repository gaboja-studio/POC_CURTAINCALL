# 덮어쓰기·코드 고정값·씬별 차이

## 공통 값이 있어도 최종 적용이 달라지는 곳

| 대상 | 현재 경로 | 분류 |
|---|---|---|
| 기본 점프 | 반영 후 Base.Character.JumpHeight 저장값 직접 반환 | 바닥 덮어쓰기 제거 완료 |
| 외줄 점프 | RopeMovement 안에서만 기존 콘텐츠별 기준값 × 외줄 배율을 CourseJumpHeightOverride에 전달 | 사용자 요청으로 기존 외줄 동작 보존 |
| 외줄 코스 판정 | useSceneGeometry가 true이면 GameSettings.Tightrope.Course 대신 sceneShape | 배치와 판정이 한 묶음으로 우회 |
| 외줄 방향·독립 줄 | independentSceneRopes는 배치 방식 선택, bidirectionalSceneTraversal는 남은 저장 칸이며 현재 분기에 사용하지 않음 | 양방향 진입은 이미 공통. 옆줄 판정·시점 입력은 별도 검토 |
| 봉 도약 상한 | HumanCannon 공용 상한을 개별 releaseHorizontalSpeedLimit이 대체 가능 | 기물별 덮어쓰기 |
| 봉 인원 | linkedGate가 있으면 RiderCapacity는 1, 아니면 설정값을 최대 4로 제한 | 종류별 코드 분기 |
| 부상 | BodyDamageEffects.startPolicy 및 콘텐츠별 SetPolicy, 대포의 최소 이동 80% 보정 | 정책 교체·추가 하한 |
| 이동·공중 조작 | 기본 조작·외줄 조작·대포 비행이 각각 동작을 관리 | 같은 설정을 읽어도 규칙이 자동 통일되지 않음 |
| 목마 점프 | PiggybackFollow의 도약 시 점프 높이·배율 임시 변경 후 복원 | 동작 중 적용값 변경 |
| 추락 결과 | 개발 보호 또는 탈출 캠페인에서 FallInjuriesSuppressed | 모드별 결과 분기. 모든 위험물 피해가 사라지는 뜻은 아님 |
| 트램펄린 운반 | CarryMoveSpeed가 groundBounceAirControlSpeed를 공유 | 반동 공중 조절과 운반 속도가 결합 |
| 카메라 | CameraViewDirector의 씬별 충돌·시점 제한과 우선순위 | 별도 공용 에셋 + 코드 조건 |
| 개인 FPS·음량 | Base 프레임 설정과 ClientSettings/PlayerPrefs 적용 경로 | 사용자 옵션과 게임 규칙 구분 필요 |
| 아이템 이름 | ItemCatalog 실행용 복사본에 대기실 TXT 이름을 적용 | 의도된 문구 대체, 효과 수치 덮어쓰기와 구분 |
| 리허설 기물 | 생성·복제 프리팹과 전용 진행 코드 | 원본 설정 수정만으로 복제된 모든 값이 갱신된다고 볼 수 없음 |

접근·분기·입력 코드 위치는 [설정 접근 목록](Inventory/settings-access-sites.csv)에 기록했다.

## GameSettings에 칸이 없는 코드 고정 규칙

| 대상 | 고정된 항목과 확인 예시 |
|---|---|
| 봉 입력 | PoleSwingInput 반동 입력 유지 0.65초 |
| 봉 공중 조절 | CannonAirControl의 이전 W/S 유예 0.15초, 공중 보정 완화 0.1초 |
| 공중그네 | TightropeTrapeze 유지 30초, 최대 유지 60초, 사람 간격 1.45, 봉 수 제한 3 |
| 봉 재잡기 | TightropeSwingPole.Spots의 앞뒤·위아래 도달 한계, 입력 버퍼 0.3초·대기 1초 |
| 외줄 구조·목마 | 매달림 해제 중복 방지 0.2초, 목마 재시작 유예·도약 요청 제한·원격 도약 최소값 |
| 대포 연출 | 포신 내려감 1.2초·복귀 2.8초. 전체 쿨타임은 이미 GameSettings에 있음 |
| 착지·부상 | 대포 안전 착지 높이 오차 0.12, 추락 절단 수 2, 부상 이동 최저 0.8 |
| 운반물 복구 | 트램펄린 낙하 탐색 거리·수평 허용 오차·생존자 뒤 배치 거리 |
| 대포 난이도 | 위험물 속도 1 + 단계당 0.25, 바람 속도 0.6 + 단계당 0.2, 목표 시간 600초 |
| 일반 상호작용 | 탈출 스위치 기본 반경 2.5, 탐색 안내 거리 배율 0.7·최소 0.9, 연속 타격 최소 간격 0.08초 |
| 튜토리얼 | 숨은 기물 지연 60초, 문구 잠금 4초, 알림 5초, 전용 카메라 이동·유지·우선순위 |
| 리허설 | 회복 1.5초, 도입 10초, 종료 알림·페이드, 사용 거리 2.5, 경로 안내 주기·완료 조건 |
| 추격자 내부 행동 | 경로 재계산 0.4초, 막힘 회복·포기 시간, 경로 비용 갱신·계산 예산. 시야·속도 등은 이미 WaitingRoomSettings에 있음 |
| 카메라 충돌·사망 | 충돌 반경 0.25·여유 0.05, 복귀 속도, 매달림 최소 거리, 사망 하강·관찰 시간 |
| 카메라 모델 숨김 | 숨김 1.2 / 표시 1.5 거리 |
| 키 직접 읽기 | 인벤토리 숫자 1·2, 탐색 창·침대 F/Escape 등. 입력 에셋/재지정 경로 밖의 키 처리 |
| 소지·일정·결과 | 인벤토리 표시 2칸, 전달 선반 4칸, 일정 날짜·공연 슬롯·난이도 한계, 공식 보상 최소 생존자 |
| 네트워크·음성 | 기물별 상태 전송·접촉 허용 시간·요청 제한·재접속/음성 위치 갱신. 송신 주기는 기능별 필요를 검토 |
| UI·연출 | 안내 폭·줄수·노출 시간, 데모 엔딩 페이드, 소품 라벨 최대 거리, 시각 효과·애니메이션 타이밍 |

위 표는 의미를 확인한 주요 규칙이다. 선언된 상수 전체는 [상수 CSV](Inventory/code-constants.csv)에 있다. 메시지 바이트 크기·요청 ID·수학 상수까지 모두 GameSettings로 옮기지는 않는다.

## 씬에 직접 저장된 서로 다른 값

30개 씬의 직접 저장값에서 모은 예시다. 테스트·비활성 포함이며 프리팹 기본값까지 합친 최종 실행 범위는 아니다.

| 항목 | 발견한 값 |
|---|---|
| 외줄 판정 폭 | 0.4 / 0.55 |
| 봉 탑승 설정 | 1 / 4 |
| 봉 유지 시간 | 0 / 40초 |
| 봉 가속 | 150 / 180 / 210 / 225 |
| 봉 최대 각도 | 8 / 32 / 38 / 50도 |
| 봉 최대 각속도 | 100 / 140 / 150 |
| 봉 개별 수평 상한 | 0(공용 사용) / 8.5 |
| 트램펄린 운반자 필요 | 끔 / 켬 |
| 트램펄린 상승 속도 | 12 / 12.5 |
| 트램펄린 공중·운반 속도 | 4.5 / 6 / 7 |
| 대포 전방 발사 속도 | 약 7.22 / 7.30 / 8.00 / 8.08 / 11.79 |

원본 위치는 [씬 저장값 CSV](Inventory/scene-direct-values.csv)의 scene·script·component_id·line으로 찾는다. 저장된 수치가 서로 다르다는 사실과 통일해야 한다는 결정은 구분한다.
