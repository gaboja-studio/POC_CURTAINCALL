# 봉의 씬별 설정과 동작 차이

> 이 문서는 통일 전 조사 기록이다. 2026-11-10 구현 후 현재 규칙·제거한 차이·예외·검사 결과는 [전체 변경 목록](full-change-list.md)을 따른다.


2026-11-09, `refactor/common-game-settings`, 기준 `origin/dev 2d591802`.
사용자 요청에 따른 **조사 결과**다. 봉 코드·씬·프리팹·설정값은 변경하지 않았다. UI는 제외한다.

## 먼저 볼 결론

현재 봉은 통일되어 있지 않다. 그네의 물리 계산 일부는 `HumanCannonPole`을 공유하지만, 인원·잡기·놓기·비행·스위치 작동 규칙은 별도 코드가 담당한다. **GameSettings 값만 변경해서 모든 봉을 통일할 수 있는 상태가 아니다.**

특히 사용자가 정한 “모든 봉에서 사람 밑에 한 명을 더 잡는 최대 2인”은 현재 공중그네에만 구현되어 있다. 탈출로 A의 일반 봉은 봉 자체에 최대 4명이 나란히 붙고, 탈출로 B/C와 대포 봉은 1명이다.

## 씬별 현재 상태

각도는 앞뒤 각각의 최대 각도, 속도는 최대 각속도다. 실제 왕복 이동 거리는 줄 길이에도 영향을 받는다.

| 구간 | 인원·연결 방식 | 최대 각도 / 각속도 | 기본 매달리기 시간 |
|---|---|---|---|
| 외줄 공연 공중그네 | 위 사람 + 그 사람 밑의 사람, 최대 2명 | 80° / 180°/초 | 30초 |
| 외줄 공연 스위치 봉 | 봉마다 1명 | 고정 매달리기, 흔들림 없음 | 30초 |
| 대기실 봉·연속 봉·공중그네 연습 | 공중그네 코드 사용, 최대 2명 | 80° / 180°/초 | 무제한 |
| 대기실 스위치 봉 연습 | 봉마다 1명 | 고정 매달리기 | 무제한 |
| 대포 공연의 활성 스위치 봉 2개 | 봉마다 1명 | 50° / 100°/초 | 40초 |
| 탈출로 A 일반·이동 봉 12개 | 봉 자체의 여러 자리에 최대 4명 | 50° / 140 또는 150°/초 | 무제한 |
| 탈출로 A 협동 장치 봉 3개 | 봉마다 1명 | 8° / 100°/초 | 무제한 |
| 탈출로 B 활성 봉 9개 | 봉마다 1명 | 32 또는 38° / 100°/초 | 무제한 |
| 탈출로 C 활성 봉 10개 | 봉마다 1명 | 32 또는 38° / 100°/초 | 무제한 |

- 외줄 공연에는 `TightropeSwingPole`이라는 별도 1인 그네 코드도 남아 있다. **현재 공통 설정은 스위치 구간이 활성화되어 이 1인 그네 구간을 대신하므로, 기본 공연의 활성 봉으로 세지 않았다.** 이 경로를 다시 켜면 별도의 잡기·비행 규칙도 적용된다.
- 대기실 기본 씬에는 위 봉 컴포넌트가 저장되어 있지 않다. 외줄 리허설을 시작하면 준비 프리팹에서 생성한다. 대포 리허설용 `RehearsalCourseFromPerformance.prefab`에는 봉이 없으므로 대포 공연 봉과 같은 것으로 분류하지 않는다.
- 탈출로 B에는 총 23개 중 9개, C에는 총 22개 중 10개가 활성·등록되어 있다. 나머지는 비활성 구 배치다. 대포 씬의 등록 봉 4개 중 활성은 스위치 봉 2개다. 비교 수치는 활성 봉 기준이며 비활성 값은 별도 CSV에 남겼다.

## 실제 조작·판정 차이

| 항목 | 현재 차이 |
|---|---|
| 잡기 조건 | 대포/탈출로는 일반 상태의 바닥·공중에서 범위 내 빈 자리를 잡는다. 외줄 스위치는 해당 줄 위에서만 가능하고 공중·목마 상태는 제외한다. 높은 공중그네의 첫 봉은 목마 진입 조건을 요구하며, 낮은 연습 봉은 예외다. |
| 잡는 거리 | 정상 상태에서 외줄 공중그네·스위치는 기본 2.5m 구형 범위. 대포는 3.75m, 탈출로 B/C는 3.25m, A는 봉에 따라 약 3.88~5.38m. A 협동 봉은 약 4.19m. 기준점·부상 보정도 다르다. 별도 1인 그네 경로는 1.75m다. |
| 부상 시 잡기 | 공중그네·외줄 스위치에는 최소 75% 도달 거리 보정이 있다. 대포/탈출로 일반 봉에는 같은 최소 보정이 없다. |
| 장애물 사이 잡기 | 대포/탈출로 봉은 봉까지의 장애물을 검사한다. 외줄 공중그네·스위치·별도 1인 그네의 잡기 경로에는 같은 검사 호출이 없다. |
| 앞뒤 조작 | 그네는 W/S 유지 입력을 쓴다. 공중그네는 위 사람만 반동을 만든다. 탈출로 A의 여러 자리 봉은 탑승자 입력을 합산·평균하여, 반대 입력이 서로 상쇄된다. 외줄 스위치 봉은 W/S로 흔들리지 않는다. |
| 바라보는 방향 | 탈출로 A는 잡을 때 시점/몸 방향을 반영해 앞뒤를 정한다(`useGrabFacing=true`). B/C·대포는 봉의 고정 방향, 외줄 공중그네는 코스 방향을 사용한다. 외줄에 적용한 T 방향 전환은 봉에 공통 적용된 규칙이 아니다. |
| 놓기 입력 | 대포/탈출로는 Space 또는 F 길게 누르기로 놓는다. 외줄 공중그네는 Space로 도약한다. 외줄 스위치는 F 짧게/길게 또는 Space로 놓고 **잡기 전 위치로 복귀**한다. |
| 두 명일 때 놓기 | 공중그네는 아래 사람이 먼저 놓아야 위 사람이 도약할 수 있다. 대포/탈출로의 여러 자리 방식은 사람 밑 연결이 아니며 각자가 놓는다. |
| 다음 봉 선택 | 공중그네 비행 중에는 순서상 바로 다음 봉만 잡을 수 있다. 대포/탈출로는 범위·빈자리·장애물 등 조건을 통과한 봉을 찾는다. |
| 도약 속도·거리 | 대포/탈출로는 실제 반동에 봉별 추가 상승 속도·배율·상한을 적용한다. 외줄 공중그네는 다음 봉의 위치/높이를 기준으로 속도를 보정하고 비행 상한을 계산한다. 동일한 반동이라도 도약 결과가 달라진다. |
| 연습 보정 | 대기실 공중그네 계열은 일정 전방 각도(최대 각도의 절반 이상)에 도달하면 다음 목표에 맞춘 도약 보정이 추가된다. 공연에는 이 연습 보정이 없다. 낮은 봉 연습은 첫 봉에 목마 없이 진입할 수도 있다. |
| 공중 조절 | 공중그네 기본 3m/초, 대포 활성 봉 4.5m/초, 탈출로 B/C 6m/초, A는 3 또는 6m/초. 부상 배율·비행 상한은 별도로 적용된다. |
| 착지 | 외줄 공중그네/별도 1인 그네는 사용 가능한 외줄 착지를 처리하며, 일반 바닥 충돌은 실패 경로로 처리한다. 대포/탈출로는 대포 비행의 착지 구역·바닥 판정을 사용한다. 일반 바닥에 내려오는 의미가 공통이 아니다. |
| 시간 초과 | 외줄 공연 공중그네 30초, 스위치 30초, 대포 스위치 40초 후 놓임 처리. 끈끈이 장갑은 제한 시간이 있는 경로의 시간을 연장한다. 연습·탈출로는 무제한이다. |

위 거리 수치는 정상 도달 배율 1 기준이다. `HumanCannonPole`의 실효 구형 반경은 저장된 `grabDistance × 도달 배율 × 1.25`다. 서로 다른 기준점과 별도 진입 조건까지 포함하여 완전히 같은 잡기 판정이라고 볼 수는 없다.

## 스위치 효과도 다르다

1. **외줄 스위치:** 잡고 있는 동안 줄을 잇고, 놓으면 즉시 연결이 사라진다. 일반 공연은 필요 인원/줄 선택, 지정 연습 봉은 지정 줄 연결 규칙을 사용한다.
2. **대포 스위치:** 연결된 톱 문을 개방한다. 문 개방 상태가 유지되는 별도 장치 로직이 있으며, 외줄처럼 놓는 즉시 원상 복귀하는 구조가 아니다. `linkedGate`가 있으면 봉 정원을 1명으로 강제한다.
3. **탈출로 A 협동 봉:** 대포 잠금·다리·셔터 등의 장치와 연결된다. 도움 인원, 도착 및 가동 고정 조건에 따라 켜짐/유지가 결정된다. 봉의 기본 움직임은 대포 봉 경로다.

연결할 장치 자체는 씬마다 달라도 되지만, **스위치 봉을 잡고 놓는 기본 동작까지 달라진 상태**다.

## 도약에 영향을 주는 씬 수치

| 항목 | 외줄 공중그네 기본 | 대포 활성 봉 | 탈출로 A | 탈출로 B/C 활성 봉 |
|---|---|---|---|---|
| 가속도(°/초²) | 300 | 180 | 150 / 210 / 225 | 150 |
| 감쇠 | 0.4 | 0.4 | 0.25 / 0.65 | 0.65 |
| 도약 추가 상승 속도(m/초) | 6, 이후 목표에 따른 보정 | 6 | 2.4 | 2.4 |
| 도약 상승 속도 상한(m/초) | 봉 기본 상한 없음, 목표 보정 별도 | 없음 | 1.5 / 5.2 / 5.45 / 7.2 | 5.2 / 7.2 |
| 수평 속도 배율 | 1 | 1 | 1 / 1.08 / 1.12 | 1 |
| 수평 속도 상한(m/초) | 다음 목표까지 거리·비행 시간으로 계산 | 공통 8 | 공통 8, 운반 봉만 개별 8.5 | 공통 8 |
| 물리상 진자 길이(m) | 기본 1.5 | 약 8 | 약 3.27~5 | 4.2 / 5 |

모든 경로에서 중력은 Base 공통 설정을 읽지만, 천장 기준 줄 길이가 달라 동일한 각속도도 다른 접선 속도가 된다. 시각적 케이블 길이와 이동 거리·도약 관성이 연결되어 있다.

탈출로 A의 운반 봉 6개는 레일을 **5m/초**로 이동한다. 이 운반 속도가 도약 관성에 더해지며, 하차 구역에서는 자동으로 놓게 한다. 이는 일반 그네의 앞뒤 운동과 구분해서 다룰 배치 장치의 추가 동작이다.

## 공통 규칙과 대조한 다음 정리 순서

사용자 확정: 일반 그네봉/스위치 봉 두 종류, 모든 봉 동일한 앞뒤 운동·관성·도약·조작, 사람 밑 연결 최대 2명.

1. 모든 봉의 **사람 밑 2인 연결·위/아래 역할·놓기 순서**를 하나로 연결한다. 현재 1명/나란히 4명/위아래 2명 차이를 먼저 해소할 대상이다.
2. 모든 봉의 **앞뒤 범위·속도·가속·감쇠·줄 길이에 따른 물리 영향**을 공통 설정으로 정리한다. 외줄 스위치의 고정 매달리기도 대상이다.
3. 모든 봉의 **잡기 범위·진입 조건·방향·놓기 입력·도약·착지**를 통일한다.
4. 일부 상황의 예외로 남길지 결정할 항목: **연습 보정, 매달리기 제한 시간, 첫 봉 목마 조건, 다음 봉 순서 제한, 스위치를 놓은 뒤 장치 유지, 운반 봉의 추가 관성/자동 하차**.

위 순서는 제안이다. 이번 조사에서 새 공통 수치나 예외를 확정하거나 구현하지 않았다. 통일 후 기존 봉 사이 간격·높이·착지 구역이 도달 가능한지도 검토해야 한다.
