# 튜토리얼 공통 규칙 회귀 조사

- 대상: 최초 튜토리얼 → 첫 공연 이동 → 첫 공연 종료 후 일반 재연습. 최신 사용자 지시로 탈출로 전체 제외.
- 시작 동기화: Unity 정상 종료 후 origin/dev 806c8dab 반영. 기존 Inspector 확장/Task-112 변경 보존.
- 사용자 승인: 일반 낙하 부상4m·사망6m. 외줄에 정상 착지하면 높이와 무관하게 줄타기. 튜토리얼 추락은 사망 후 해당 소구간 출발점 복귀, 도착 투명 벽 유지. 연습실에 사람이 있으면 튜토리얼 문 열림. 첫 공연 이후 일반 규칙.
- 제약: 공통 GameSettings 밖 우회·별도 규칙 도입은 변경 전 사용자 질문. 미해결14개 전체 수정은 보류 유지.
- 조사 시 확보한 Editor.log는 이전 자동 검사 기록이므로 사용자 플레이 재현 증거로 사용하지 않는다.

- 스위치 봉에 2명이 매달리는 것 자체는 공통 정원2명에 맞는 정상 동작이다. 튜토리얼만 1명으로 제한하지 않았다.
- 너비 조정은 봉 길이·양쪽 케이블 간격만 변경한다. 케이블 높이·두께·잡는 지점·반동·도약은 유지한다.
- 사용자 사진의 긴 스위치 봉은 정본4.4m를 확인했다. 원본 모델의 잘못된 회전은 확인되지 않았으며 원본 회전을 보존한다.
- 설정 원본은 기존 BaseGameSettings / WaitingRoomSettings / PoleSettings다. 새 설정 에셋·씬 전용 수치는 만들지 않았다.

## 추가 발견 · 이번 수정에서 남긴 항목

- 대기실·대포 공연의 추가 발견8개는 [다른 구간 회귀 조사](cross-scene-regression-audit.md)에 장소·증상·원인·수정 상태별로 기록한다. 사용자가 수정 후 저장·제출을 승인했다.
- 인간대포 정상 도착 사망은 실제 PlayMode 재현. 후속 승인으로 공통 GameSettings의 안전 착지대 무피해 규칙을 추가한다. 일반 바닥4m/6m는 유지한다.
- 실제 두 클라이언트 스위치/낙하 동기화는 미검증. 로컬 LAN 호스트와 합성 원격 소유자/지연 순서 검사는 실제 두 PC 동시 입력·지연·재접속과 구분한다.

## 검증 기록

- 수정 전 재현: 외줄20m 정상 착지에서 사망, 튜토리얼 아래 바닥1m 착지에서 생존. 신규 PlayMode2개 모두 실패.
- 수정 후 같은 PlayMode2개 통과. 낮은 바닥 복귀는2회 연속 확인.
- 문 재개방·집결 대기·정책 경계·4/6m 경계 EditMode10/10 통과.
- 봉 외형 최초 EditMode8개 중7개 통과.1개는 EditMode에서 실제 OnDestroy를 기대한 검사 구성 오류. 순수 정리 검사와 실제 PlayMode 생명주기 검사로 분리.
- 봉 외형 EditMode15/15, 외줄 재연습 종료 포함 낙하 PlayMode3/3, 2인 봉·손 정렬 PlayMode2/2 통과. 마지막 봉 언로드 보완 전 결과이며 해당 보완 이후 PlayMode는 사용자 지시로 미재실행.
- 낙하 추적 최초6/6 통과 후 부활 위치 재통지 보완 재검사5/6. 나머지1개는 씬 종료 중 봉 외형 재생성 오류로 setup 실패. 해당 생성 경로를 수정했으며 재검사는 미실행으로 남긴다.
- 최종 후속 EditMode: 대기실 로직14/14·Inspector7/7 통과. 코드 컴파일 통과. 안전 착지대/대포 재연습/래그돌 귀환의 최종 PlayMode·실제 입력 검증은 사용자에게 맡김.
- 결과 JSON은 `.harness/local/tutorial-common-audit/`에 보관. 과거 통과 수치를 최종 전체 통과로 합산하지 않는다.
- 사용자 플레이 로그 원인은 단정하지 않는다. 실제 입력 완주·두 PC 검증은 위 자동 재현과 구분한다. 기존 미해결14개 전체 수정은 계속 보류.
