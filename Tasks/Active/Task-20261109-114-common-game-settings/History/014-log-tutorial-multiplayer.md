## 11/12 튜토리얼 출발대·멀티플레이
- 최초 튜토리얼 입장 시 연습실 바닥 배치를 제거했다. 커튼을 닫은 상태에서 코스를 준비하고 소유자 슬롯이 도착하면 출발대에 배치한다. 호스트가 실제 위치를 확인하면 배치 잠금을 해제한다.
- 참가자는 씬 로딩 중 먼저 수신한 코스·인원·배치 정보를 유지한다. 소유 캐릭터 교체나 추락 복귀 시 해당 슬롯의 출발대를 사용한다. 씬·GameSettings 변경 없음.
- Windows 개발 빌드 성공. 2·3·4인 LAN에서 커튼이 열린 뒤 첫 기록의 출발대 위치 및 원격 복제, 참가자 추락 복귀 확인. 2·3인은 실제 바닥 착지 후 복귀, 4인은 목마 탑승·하차와 다음 구간 배치도 통과했다. 무렌더 시도는 커튼 프레임 대기로 중단 후 렌더링을 켜고 재실행했다. 결과는 .harness/local/tutorial-multiplayer-20261112/.
- 인간대포 재연습 2인에서 사망 복귀 타이머가 끝나기 전에 포기 투표가 확정되면 참가자가 사망 상태로 대기실에 남는 문제를 재현했다. 종료 중에도 공통 자동 복귀를 적용하고, 사망 상태에서 받은 종료 잠금은 실제 부활 시 풀리게 수정했다. 새 2인 LAN 빌드에서 실제 발사·착지·체크포인트 복귀 및 사망 직후 포기 확정 뒤 대기실 복귀·조작 복원을 확인했다. 외줄 재연습 종료에서도 기존 자동 복귀가 켜진 경우에만 쓰러진 사람을 복구한다.
- 공통 EditMode 571/571, 컴파일·GameSettings 연결 검사 통과. 외줄 재연습 종료 3조건은 EditMode에서 확인했다. 최초 EditMode 안내 패널 준비 오류는 테스트만 수정했다. doctor의 기존 Task ID 중복은 실행에 영향 없음.
