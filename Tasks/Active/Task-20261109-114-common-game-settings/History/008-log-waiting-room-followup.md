## 11/11 대기실·튜토리얼 재보고 후속
- 시작: Unity 종료 후 DEV a976362e 반영, 무관한 기존 변경 보존. 사용자는 실제 대기실 씬이 여러 개인지도 질문했고 현재 연결은 WaitingRoomPursuit, 나머지 WaitingRoom/WaitingRoomBase를 구분해 안내했다.
- 트램펄린 후보를 다시 확인하고 사용자 최종 선택 A(가운데 별무늬 CC_Trampoline) 확정. TrampolineSettings 원본과 공연1·대기실3씬의 총13개 외형, 운반/재연습 원본 프리팹2개를 저장. 기존 CC 프리팹에 손잡이 앵커 추가·메시 원점과 운반 접점 분리·잡힘 표시 유지. 대기실 제작 도구의 옛 외형 직접 로드도 공통 원본으로 연결. 대포/발판 배치·반동 수치 변경 없음.
- 의료 승강기: Enter에서 목마 해제 누락 확인. 입장 전에 구매자와 그 위 사슬 해제·분리 위치 공유. 서비스 상태가 먼저 도착하면 해제까지 입장 지연, 소유자 Follow 정리 후 위치 이동. 2/3/4층 구매자 위치별 합성 상태순서 검사8개 포함 의료16개 통과. 실제 서로 다른 PC 전송 검증과 구분.
- 외줄: 공통 W/S 음수 입력과 양 끝 진입은 이미 사용 중이었으나 최초 튜토리얼 도착벽이 활성화되어 있었다. WaitingRoomSettings keepFinishBarrier=false 저장. 그네 수업 완료 위치 복귀는 벽 생성과 분리하여 유지. 목마 연습 첫 봉만 공통 튜토리얼 배치 설정0.5m 낮춤(줄 위5→4.5m). 연습 단계 재사용에도 적용.
- PoleSettings 수평 도약3.5→4.5m/s, 코드 기본값/한글 Tooltip 일치. 모션·축적·감쇠·상승6m/s 유지.
- 대기실 안전 착지: 기존 WaitingRoomSettings에 safeFallLandings=true 추가. 활성 씬이 대기실3종일 때 공통 CompleteFall의 착지 높이 피해 면제. 최초 튜토리얼 바닥 복귀가 우선이며 위험물·월드Y -15 즉사는 별개. 대기실이 배경으로 남은 공연에는 적용하지 않는다.
- 2층 부상: 현재 Base 에셋/공통 코드 부상5m·사망15m 확인. 실제 대기실 발판4.6m/5.6m, 기본 점프0.8m가 더해지면 5m 초과 가능. 사용자 해당 낙하의 정확한 위치/로그는 없어 단일 원인 단정하지 않음. 신규 대기실 보호로 해당 높이 피해 면제.
- 집중 검사: 의료16/16, 낙하 상태·안전 설정15/15, 봉50개와 외줄 표면69개는 실패 기대값을 수정한 대상만 재실행하여 최종 통과(고유150개). 봉3개는 낮춘 속도 상한 때문에 초기8초 감쇠가 가려지는 점을 반영해16초 무입력 후 비교. 외줄2개는 이미 적용된 실제 바닥 지지 제외 규칙과 옛 기대값 불일치 수정. 나머지 기존 실패14개 전체 수정은 미진행.
- 도구 보정: 낙하 검사의 추가 씬 생성은 TestRunner 미저장 씬 제한으로 실패해 테스트 씬 이름을 임시 전환·복원하도록 수정, 최종15/15. 외형 적용 스크립트는 모든 저장 후 닫힌 원래 씬의 빈 경로로 복귀하려다 오류; 별도 읽기 검사로 저장된4씬/2프리팹15개 외형 및 손잡이 연결 전부 확인. 증거 .harness/local/trampoline-review-20261111/.
