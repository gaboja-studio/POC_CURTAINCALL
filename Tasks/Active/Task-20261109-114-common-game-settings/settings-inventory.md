## 분류

- **공통 설정 안**: Base·외줄·대포·대기실 등 기존 설정과 폴더 안의 아이템·보상 에셋.
- **덮어쓰기/우회**: 공통 값을 읽은 뒤 다른 값으로 교체하거나 씬별 자체 값으로 분기.
- **게임 규칙이 밖에 있음**: 봉·발사·운반·추락·협동·탐색·회복·연습 등의 성능·조건·시간.
- **별도 공통 설정**: 카메라, 조작 규칙, 입력 에셋, 개인 옵션처럼 이미 다른 공용 체계로 관리.
- **배치·표현·개발용**: 위치·연결 대상·아트·UI·개발 카메라. 밖에 있다고 일괄 이관하지 않는다.
- **기술 상수**: 메시지 크기, 식별자, 수학 상수, 임시 상태. 기획 설정과 구분한다.

## 조사 한계

- 씬 값에는 테스트·비활성 오브젝트가 포함된다. 프리팹 상속값과 모든 프리팹 변형을 전개한 최종 실행 값은 아니다.
- 실제 Play 중 네트워크·생성·상태 전환은 검증하지 않았다. 에디터는 Start 씬의 비실행 상태로 유지했다.
- 상수 선언은 전수 추출했다. 메서드 안의 숫자와 조건식은 주요 동작 경로를 추가 확인했으며 전체 의미 분석을 완료했다고 보지 않는다.
- 에디터 생성 코드의 설정 접근·FindProperty 위치도 접근 목록에 남겼다. 모든 생성 메뉴를 실행하거나 결과를 재생성하지 않았다.
- 외부 에셋·패키지·URP·Unity ProjectSettings 자체는 게임 규칙 이관 대상에서 제외했다.
- 기본값 CSV는 소스 초기값이다. 적용값과 혼동하지 않도록 에디터 값·씬 저장값 CSV를 분리했다.

## 우선 조사 결과

공통 설정이 없는 구조가 아니라 **기존 공통 설정 + 일부 씬별 덮어쓰기 + 기물별 개별 성능 + 별도 공용 설정**이 섞인 구조다.
첫 반영 묶음은 기본 점프 덮어쓰기, 외줄 판정의 sceneShape 분기, 봉 개별 성능의 공통 연결부터 검토한다. 숫자는 아직 확정하지 않는다.
