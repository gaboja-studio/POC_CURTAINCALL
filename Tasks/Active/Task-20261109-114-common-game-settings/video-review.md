## 확인 범위
- 공통 설정: `GameSettings/Tricks/PoleSettings`의 Horizontal Speed Limit=5, `TightropeSettings/Rope Movement`의 Match Visual Support Width=true. 후자는 한글 툴팁 포함.
- 새 게임플레이 스크립트 없음. 기존 공통 코드·설정 에셋 수정. 탈출로 배치·에셋 수정 없음.
- 영상의 튜토리얼 바닥 사망 후 복귀는 기존 확정 규칙. 일반 공연의5m 이상15m 미만 부상·15m 이상 사망, 절대Y -15 사망선은 유지.
- 녹화의 트램펄린은 가운데 별무늬 원본으로 확인. 외형 재교체 없음.
- 실제 PlayMode·다른PC 다인 플레이는 사용자 담당. 합성 네트워크 수신 검사를 실제2·3·4인 플레이 통과로 쓰지 않는다.

- 최종 검사: 최신 DEV ec98657e 통합 뒤 관련 EditMode390/390 통과. 처음 발견한 도착대 경계 초과1건 수정, 공연 봉 자리 변경에 맞춘 옛 검사 기대값1건 보정. 전체 프로젝트의 기존 보류10실패는 이번 검사 대상이 아님.
