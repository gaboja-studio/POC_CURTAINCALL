# 추가 공통화 — 변경 전·후

2026-11-10 · UI 제외 · refactor/common-game-settings

- **위험물에 다시 닿았을 때**
  - 전: 외줄 톱·대포 톱·일반 함정마다 피해 간격이 달랐음.
  - 후: 모든 절단 위험물이 플레이어별 **1초 간격**을 공유. 계속 겹쳐 있는 동안은 중복 절단하지 않고, 나갔다 다시 닿으면 재판정.
- **벽·층·높이가 다른 대상 잡기**
  - 전: 같은 2.5m라도 발/몸 기준, 평면/공간 거리, 벽 차단 방식이 달랐음.
  - 후: **몸 중심부터 접점까지 3차원 2.5m**. 고체 벽·바닥에 가려지면 불가. 동료 구조 거리와 팔 부상 배율도 공통. 목마 연결 1.5m·UV 원거리 사거리는 유지.
- **F 한 번의 대상**
  - 전: 가까운 장치들이 각자 입력을 받아 함께 반응할 수 있었음.
  - 후: **사용 중인 장치 → 동료 구조 → 가장 가까운 사용 가능 대상** 순서로 하나만 선택. 누르고 있는 중에는 대상을 바꾸지 않음.
- **추락 중 줄 붙잡기**
  - 전: 줄 번호·생성/배치 방식에 따라 붙잡을 수 있는 줄이 달랐음.
  - 후: **발에서 실제 줄까지 1.5m 이내**, 벽에 가리지 않고 빈자리면 가능. 실패하거나 버티는 시간이 끝나면 **일반 낙하**. 같은 높이 옆줄 이동 3m와 별개.
- **카메라 벽 충돌**
  - 전: 대기실·탈출로 중심으로 적용.
  - 후: **모든 씬의 일반 플레이에 같은 벽 충돌** 적용.
- **낙하 피해**
  - 전: 외줄 이탈·대포 착지·일반 낙하의 결과가 달랐음.
  - 후: 실제 최고점에서 착지 바닥까지 **3m 미만 무피해 / 3m 이상 5m 미만 사지 2개 손실 / 5m 이상 사망**. 순간이동·재시작·매달림 전의 높이는 이어 붙이지 않음.
- **스프링 신발**
  - 전: 대포 쪽 낙하 처리에만 연결되어 있었음.
  - 후: **일반 낙하·외줄 이탈에도 적용**. 피해가 날 착지에서 준비된 신발이 먼저 반동하고 1회 소모. 맵 밖 추락이나 즉사 화염은 막지 않음.
- **화염 종류**
  - 전: 개별 옵션이나 연결 코드에 따라 결과가 달랐음.
  - 후: **일반 불기둥·분사 화염은 사지 1개 손실 / 추격 화염벽은 즉사**. 종류를 명시하고 결과를 뒤집던 옵션 제거.
- **옛 설정 항목**
  - 전: 안 쓰는 값도 씬·프리팹에 숨겨 보관하고 일부 제작 도구가 계속 쓰고 있었음.
  - 후: **옛 필드·제작 도구 참조·저장값 모두 제거**. 검사 대상 32개 타입·64개 필드. [상세 목록](Inventory/retired-settings.json).
- **씬 연결 스크립트**
  - 전: 배치와 공통 동작값을 함께 지정할 수 있었음.
  - 후: **위치·배치·장치 연결만 담당**. 외줄 판정 폭/높이도 배치 설정에서 빼고 공통 RopeMovement로 이동. 시점 반전·봉 잡기 허용·옆줄 이동 구간 같은 옛 스위치 제거.
- **다시 옛 설정을 넣었을 때**
  - 전: 씬을 다시 만들거나 연결을 빠뜨려도 쉽게 놓칠 수 있었음.
  - 후: **옛 필드 재도입·제작 도구 참조·옛 씬 저장값·공통 연결 누락**을 에디터 메뉴, 빌드, check-work에서 검사.

검사 결과와 남은 확인: [후속 검증](followup-verification.md).
