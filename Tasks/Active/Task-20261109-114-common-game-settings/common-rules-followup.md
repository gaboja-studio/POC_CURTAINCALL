# 추가 공통 규칙 구현

2026-11-10 · UI 제외 · Task-114 / refactor/common-game-settings.

## 사용자 확정
- 위험물의 재피해 간격은 외줄 톱 기준 1초.
- 근접 거리의 가림·층·높이, F 단일 대상 우선순위, 추락 시 붙잡는 줄의 조건은 에이전트가 정해 통일한다.
- 일반 플레이 카메라는 모든 씬에서 같은 벽 충돌 기준.
- 스프링 신발은 일반 낙하에도 적용. 외줄 이탈도 일반 낙하이며 바닥까지 떨어진 높이로 판단한다.
- 추가 답변으로 기존 보류를 해제: 3m 이상 사지 2개 손실, 5m 이상 사망.
- 화염은 일반형과 즉사형으로 종류를 구분한다.
- 안 쓰는 옛 설정과 제작 도구 참조 제거, 배치/연결 어댑터의 공통 동작 수치 지정 제거, 재생성/씬 전환/설정 누락 검사.

## 이번 구현 선택
- 피해: 위험물 접촉 시작에만 적용. 여러 절단 위험물도 플레이어별 공통 1초 유예를 공유한다. 즉사형 위험물은 부상 유예로 무효화하지 않는다.
- 상호작용: 현재 몸 중심부터 대상 접점까지 3차원 거리 2.5m. 같은 공통 팔 부상 배율, 고체 벽/바닥 가림 차단. 대상 자신의 충돌체와 플레이어 몸은 가림 제외.
- F: 이미 사용 중인 대상 조작/해제 → 동료 구조 → 거리순 사용 가능 대상. 한 입력의 대상은 하나로 고정하고 처리 여부를 모든 시스템이 공유한다. 동률은 안정된 우선순위로 정한다.
- 줄 잡기: **발에서 실제 줄까지 3차원 1.5m 이내**, 가림 없음과 빈자리로 고른다. 줄 번호/생성 방식에 따른 옆줄 한 칸 제한을 없앤다. 실패/시간 만료는 손을 놓고 일반 낙하로 넘긴다. 보행 옆줄 3m와 분리한다.
- 낙하: 마지막 지지/비행 최고점에서 착지까지 수직 높이. 3m 미만 무피해, 3m 이상 5m 미만 2개 절단, 5m 이상 사망. 순간이동/재시작/매달림 같은 강제 위치 변경은 낙하 누적을 초기화한다.
- 신발: 지면 착지에서 피해가 발생할 높이면 부상/사망보다 먼저 반동. 성공 시 1회 소모. 맵 밖이나 즉사 화염을 막는 장비는 아니다.
- 화염: 일반 불기둥/분사 화염은 사지 1개 절단, 추격 화염벽은 즉사. 기존 씬의 숨은 bool로 결과를 뒤집지 않는다.

## 구현 순서
1. 공통 피해/낙하/접근 설정과 경계 함수를 만든다.
2. 위험물·화염·카메라를 연결한다.
3. 상호작용 가림/거리 및 F 단일 대상 선택을 연결한다.
4. 외줄 매달림/실제 낙하·신발 반동을 연결한다.
5. 폐기 설정·제작 도구·연결 어댑터를 정리하고 자동 검사로 재도입을 잡는다.
6. 설정 에셋은 Unity API로 저장하고 필요한 회귀·컴파일·문서 검사를 수행한다.

## 보존할 범위
- 기물 배치·대포 발사 탄도, 튜토리얼 학습 진행, 코스 장치 연결, 운반 기물 회수 기준은 유지한다.
- 기존 사용자 미저장 변경과 폰트 캐시 사본을 보존한다. 실제 두 PC 수동 플레이를 자동 검사로 대신했다고 기록하지 않는다.

## 옛 설정 정리
- 32개 타입의 옛 저장 필드 64개 제거. 봉 인원/반동/시간/시점 반전, 트램펄린 반동/운반자 제한, 대포 점프/접근/부상 덮어쓰기, 개별 근접 거리, 화염 결과 뒤집기 등.
- 외줄 폭/높이/낙하 전환 깊이는 RopeMovement 공통 설정으로 이동. 씬의 옆줄 이동 허용 구간 저장값과 제작 도구를 제거.
- 씬 연결 어댑터는 배치·장치 연결/진행 알림을 담당한다. 봉 운동·점유·도약은 공통 서비스만 사용.
- 재도입/연결 누락 검사: CommonSettingsValidation을 에디터 메뉴·빌드·check-work에 연결. 상세 필드는 Inventory/retired-settings.json.
- 씬/프리팹/설정의 옛 저장값도 Unity API로 제거했다. 직접 YAML 수정 없음.
