## 추가로 발견한 같은 유형의 경계

- **복귀 직전 기물 점유:** 봉·대포·외줄 매달림·목마를 먼저 해제. 사망과 복귀가 같은 프레임이면 기물의 다음 Update에 맡기지 않음.
- **사망 상태가 원격에 생략되는 복귀:** 확정 부활 번호 신호를 받고 Normal·코스 준비 후 배치. Fallen 프레임 관찰 여부에만 의존하지 않음.
- **이전 비행·운반 잔류:** 체크포인트 배치 전에 Pilot 비행 정리. 사망 운반자의 실제 트램펄린 점유도 회수.
- **안전대 가장자리:** 몸 중심이 발판 밖이어도 실제 발밑 윗면이 안전대면 보호. 바로 위의 별도 일반 바닥·트리거에는 면제 전파 금지.
- **호스트 고낙하:** 큐 등록 직전 최고점 초기화로 2m 초과 착지가 거절되는 경계 수정. 같은 구간 실측값 보존으로 4m 부상·8m 사망 적용.
- **사망 중 스케줄표:** 남은 창·클로즈업·입력 잠금이 아침 암전/ACK를 막는 경계 수정. 첫날 난이도 정책과 UI 외형 유지.
- **의료실·침대 소유자 삭제/교체:** 최초 이용자를 기억해 자기 입력/카메라 잠금만 해제. 새 캐릭터를 이전 의료실 위치로 옮기거나 새 침대 표시를 지우지 않음. 의료실의 마지막 캐릭터 삭제를 오프라인 입장으로 재해석하지 않음.
- **재연습 안내:** GameSettings에서 복귀를 끄면 자동 복귀 문구도 해제.
