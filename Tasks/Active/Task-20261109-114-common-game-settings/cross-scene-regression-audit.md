# 대기실·묘기 공통 규칙 회귀 수정

- 범위: 튜토리얼·대기실·첫 공연 이후 재연습·외줄 공연·인간대포 공연.
- 사용자 최신 지시: 탈출로 전체는 조사·수정 대상에서 제외. 나중에 묘기·대기실 기준을 적용한다. 기존 실패14개 전체 수정은 계속 보류.
- 추가 발견8개 수정 후 저장·제출 승인. 안전 착지대 무피해는 GameSettings에 공통 규칙으로 추가하는 방향 승인.
- 플레이 테스트는 사용자가 직접 수행한다. 승인 이후 추가 PlayMode 실행 없이 코드 수정·컴파일·필수 검사 후 제출한다.

## 확인 근거와 한계

- 1번은 실제 Unity PlayMode에서 정상 도착대 착지 후 `Normal` 기대 → `Fallen` 재현. 발사 높이8.2m·상향 속도12m/s·도착대6.2m. 증거: `.harness/local/tutorial-common-audit/cannon-normal-landing-audit.json`.
- 2~8번은 코드·상태·참조 경로 확인. 2번은 밤 시간 제한·스케줄 상태에 따라 영향이 다르며 모든 밤 사망이 영구 정체된다는 뜻이 아니다. 8번의 실제 전환 영향·영구 고립은 미재현.
- 대기실 후속 EditMode14/14 통과: 의료 정산6·밤 모델2·생존 자격/밤 런타임/의료 사망/세대6. 이전 보류14개와 다른 검사다. 코드 컴파일 통과, 추가 PlayMode 미실행.
- 1번 기존 실패 검사는 수정 후 추가 PlayMode를 실행하지 않으므로 통과로 바꾸어 기록하지 않는다. 이전 보류14개와 별도다.
- 실제 두 PC 동시 입력·지연·재접속, 전체 코스 완주는 사용자의 플레이 확인 대상이다.

## 함께 수정한 공통 연결

- 봉 손·몸: 공통 반동 각도·탑승 순서 위치 사용. 종류별 너비1.8m와 케이블 표시 복구.
- 봉 종료: 이미 파괴된 외형을 씬 종료 중 다시 생성하지 않도록 기존 외형만 숨김.
- 외줄 재연습 종료: 사망자의 조작을 다시 켜지 않고 사망·사지·래그돌 유지.
- 낙하 통신: 순간이동 전 옛 높은 좌표 재축적, 부활 전 낙하 보고, 같은 비행 착지 중복 처리 차단.
- 공통 봉 외형 분리 후 상호작용 강조가 실제 외형을 참조하도록 연결 복구.

## 조정 위치

- `Assets/Resources/Settings/GameSettings/BaseGameSettings.asset` → 신체 손상 → Body Damage → 안전 착지대 낙하 피해 면제.
- 켬: 활성 `HumanCannonLandingZone`의 실제 수평 윗면 착지 무피해. 일반 바닥·착지대 밖·직접 위험물은 보호하지 않음.
- 끔: 해당 착지대도 일반 높이 피해 적용. 일반 바닥은 기존4m 부상·6m 사망 유지.
- 기존 튜토리얼·봉 조정 항목은 [Inspector 조정 안내](inspector-controls.md), 전체 전후는 [튜토리얼 조사](tutorial-regression-audit.md).
