# 트램펄린 충돌 레이어

- 2026-11-13 사용자 추가 요청. 앞선 리허설 인계 수정과 같은 PR에 제출.
- 조정 위치: Unity **Edit → Project Settings → Physics → Layer Collision Matrix**. 레이어 이름은 **Tags and Layers**에서 확인.

| 조합 | 설정 |
| --- | --- |
| Trampoline(8) ↔ DismemberedLimb(9) | 충돌 해제 |
| Trampoline(8) ↔ TrickHazard(10) | 충돌 해제 |
| 트램펄린·사지·위험물 ↔ 일반 바닥/벽 | 기존 충돌 유지 |
| 위험물 ↔ 플레이어 | 기존 충돌/피해 유지 |

- Trampoline: 운반 트램펄린 본체·자식, 대기실 운반 검사체, 공연/리허설 프리팹.
- DismemberedLimb: 몸에서 떨어진 뒤 생성되는 팔다리 조각. 살아 있는 플레이어의 팔다리에는 지정하지 않음.
- TrickHazard: 외줄의 생성 톱날/톱 관문, 인간대포의 톱·회전날·철퇴 등 위험물 외형/충돌체. 바닥·벽·발판·리프트·위험물 작동 시작 영역은 포함하지 않음.
- 런타임 생성도 기존 스크립트에서 같은 이름을 적용한다. GameSettings.cs의 공통 이름 정의는 레이어 번호를 고정하지 않고 Tags and Layers의 이름으로 찾는다. 충돌 ON/OFF의 기준은 Unity Physics 설정이다.

## 변경 전후

| 기능 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 실제 사지/트램펄린 접촉 | 매 물리 프레임 충돌체 쌍마다 IgnoreCollision 적용 | 전용 레이어의 충돌 매트릭스 사용 |
| 운반 중 충돌 확인 | 별도 겹침 검사로 톱에 막힐 수 있음 | 같은 충돌 매트릭스를 확인하여 무시한 레이어는 통과 |
| 바닥에 내려놓기 | 무시한 장애물 위에 놓일 수 있음 | 매트릭스에서 무시한 물체를 바닥 후보에서 제외 |
| 씬/기물 재생성 | Default 레이어 재생성 가능 | 기존 생성·활성화 경로에서 전용 레이어 적용 |

- 인간대포 씬과 관련 프리팹 변경은 레이어만 적용. 위치·크기·코스 배치 변경 없음. 탈출로 씬 파일은 변경하지 않음.
- 플레이어와 사지 사이의 기존 개별 충돌 제외는 유지한다. 트램펄린의 사지별 덮어쓰기만 제거하여 매트릭스 조정을 가리지 않게 한다.
- Unity 6.3 저장에 따라 DynamicsManager 직렬화 버전이 갱신됨. 기존 매트릭스에서 두 쌍만 변경하며 다른 물리 설정값은 유지.
- 실제 플레이는 사용자 담당. 검사는 임시 물리 씬, 실제 충돌 질의, 프로젝트 매트릭스 및 공통 회귀로 구분한다.
- 결과: 레이어7/7·공통713/713 통과, 실패/생략0. 컴파일·공통 설정 연결 검사 통과. 사지/위험물 생성 순서·운반/비운반·충돌체 재활성화·낙하 통과·바닥 착지·매트릭스 재활성화 시 질의 차단을 포함한다.
- 저장 시 위험물 프리팹 3개에 기존 기본값(cue 없음, boxSize 1, authoredPath 끔, showRail 켬)이 명시 직렬화됨. 기존 실행값은 동일하다.
