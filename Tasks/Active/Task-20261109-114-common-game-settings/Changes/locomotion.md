# 이동·점프·외줄·목마

[전체 변경 목록으로 돌아가기](../full-change-list.md)

## 1. 모든 일반 바닥·플랫폼·걷는 오브젝트

1. 모든 씬의 기본 걷기·달리기·앉기는 Base 공통 설정을 사용한다.
2. 모든 씬의 일반 바닥 점프는 Base의 0.8m를 사용한다.
3. 대포 시스템이 활성화되면 일반 점프를 1.2m로 덮어쓰던 경로를 제거했다.
4. 활성 씬 변경·대포 시스템 활성/비활성·전체 재시작이 바닥 점프 높이를 바꾸지 않는다.
5. 부상은 Base의 점프 높이 배율·몸통 높이·기어가기 규칙으로 적용한다.
6. 앉아 있는 동안 점프 금지와 머리 위 공간이 없을 때 앉은 자세 유지 규칙은 그대로 공통 적용한다.

## 2. 점프 입력·공중 조절

1. 일반 바닥과 외줄 모두 착지 직전 점프 입력을 0.15초 기억한다.
2. 점프가 실행되면 기억한 입력을 소비한다. 조작 잠금·입력 초기화 때도 제거한다.
3. 외줄의 별도 입력 유예 값을 없애고 Base Input을 참조한다.
4. 모든 봉·대포·트램펄린 비행의 수평 입력 보정 속도를 Base AirControl 3m/s로 맞췄다.
5. 기물 비행의 입력 반응 시간도 같은 0.1초를 사용한다.
6. 봉 도약 직전 반동을 주던 W/S가 즉시 공중 입력으로 중복 적용되지 않도록 공통 0.15초 유예를 사용한다.
7. 대포/트램펄린 비행도 같은 입력 보정 계산을 사용한다. 발사 자체의 탄도·속도는 각 대포의 배치를 유지한다.
8. 봉의 수평 속도 상한은 8m/s로 통일했다. 대포의 원래 발사 속도를 이 상한으로 잘라내지 않는다.
9. 일반 바닥 점프의 이동 입력과 외줄 옆줄 이동의 목표 고정은 각각 같은 행동끼리 모든 씬에서 동일하다. 외줄 옆줄 이동 중 카메라나 T를 돌려도 이미 정한 도착점은 바뀌지 않는다.

## 3. 모든 외줄

1. 모든 외줄의 정상 제자리 점프 높이는 탈출로 기준 1.5m다.
2. 모든 외줄의 지지 폭은 0.55m, 높이 허용은 0.3m다.
3. 발 중심만 보지 않고 몸통이 줄 모서리에 실제로 지지되는 경우도 같은 방식으로 판정한다.
4. 씬별 sceneShape의 옛 판정 폭·높이가 공통값을 덮어쓰지 않는다.
5. 같은 높이에서 실제 도착 가능한 지점까지의 수평 거리가 3m 이하인 줄로 옆 이동한다.
6. 3m를 넘는 줄이나 높이가 다른 줄은 옆줄 이동 대상으로 잡지 않는다. 높이 비교에는 계산 오차용 1mm 허용만 둔다.
7. 줄 번호 순서·배치 간격·기존 구간 제한으로 가까운 줄을 제외하지 않는다. 입력 방향의 사용 가능한 가까운 줄을 찾는다.
8. 모든 외줄은 시작점/끝점 어느 쪽에서 진입해도 양방향 이동이 가능하다.
9. T를 누르면 진행 방향이 180° 바뀐다.
10. 카메라 회전만으로 W/S 진행 방향을 바꾸는 동작을 제거했다.
11. 연습실 재연습에서는 도착 지점의 벽·강제 복귀·도착 즉시 다음 코스 전환을 제거했다.
12. 재연습 다음 구간은 기존 과반 ‘다음’ 투표로 넘어간다. 최초 튜토리얼의 도착 대기는 사용자 허용 예외로 유지한다.

## 4. 모든 목마

1. 모든 씬의 일반 바닥에서도 목마를 탈 수 있다.
2. 일반 바닥 목마에는 외줄 중심 잡기를 적용하지 않는다.
3. 일반 바닥에서는 안전한 바닥 위치로 그냥 내린다. 바닥 하차 자체로 추락·사망 처리하지 않는다.
4. 외줄 위 목마에는 외줄 중심 잡기와 기존 하차 안전 판정을 적용한다.
5. 일반 바닥용 공통 목마와 씬에 배치한 목마 시스템의 활성/비활성 전환을 연결했다.
6. 봉을 잡는 순간 이전 목마 연결·점프 목표를 정리해 중복 이동을 막는다.
