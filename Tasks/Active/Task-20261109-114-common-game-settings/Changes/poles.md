# 모든 봉의 공통 규칙

[전체 변경 목록으로 돌아가기](../full-change-list.md)

## 5. 모든 봉의 인원·시간·조작

1. 일반 봉과 스위치 봉 모두 최대 2인이다.
2. 2인은 나란히 매달리지 않고, 위 사람이 봉을 잡고 아래 사람이 위 사람을 잡는다.
3. 위 사람이 없는 봉에는 아래 자리만 먼저 잡을 수 없다.
4. 위 사람만 W/S로 반동을 만든다. 아래 사람의 입력을 합산하거나 평균하지 않는다.
5. 모든 봉의 매달리기 제한은 30초다. 연습실·탈출로도 같다.
6. 아래 사람이 추가로 잡아도 위 사람의 시간을 늘리지 않는다. 같은 남은 시간 안에서 매달린다.
7. 끈끈이 장갑으로 봉의 30초 제한을 연장하지 않는다.
8. 시간 초과 때는 아래 사람을 먼저 분리한 뒤 위 사람을 분리한다.
9. 위 사람 사망·이탈·장치 비활성 시 아래 사람만 공중에 매달린 채 남지 않게 정리한다.
10. 자발적으로 도약할 때는 기존 공중그네처럼 아래 사람이 먼저 놓고 위 사람이 놓는다.
11. 모든 봉은 F 짧게 잡기, W/S 반동, Space 또는 F 길게 놓기를 사용한다.
12. 봉의 앞뒤 방향은 배치된 봉의 방향을 사용한다. 잡는 순간의 카메라 방향으로 씬별 반전하지 않는다.
13. 실제 거리·빈자리·장애물 조건을 만족하면 바닥/공중에서 잡을 수 있다.
14. 첫 봉만 목마 진입을 강제하던 조건을 제거했다.
15. 바로 다음 순서의 봉만 잡기·출발 봉 재잡기 금지·중간 봉 건너뛰기 금지를 제거했다. 범위 안의 이용 가능한 봉을 찾는다.
16. 모든 봉의 접근 거리는 Base 2.5m에 공통 팔 부상 배율을 적용한다.
17. 외줄만 최소 75% 접근 거리를 보장하던 보정을 제거했다.
18. 모든 봉에서 벽·장애물을 뚫고 잡지 못하도록 같은 가림 검사를 사용한다.

## 6. 모든 봉의 운동·관성·도약

1. 모든 봉은 앞뒤로 흔들린다. 외줄 스위치 봉도 고정 매달리기가 아니다.
2. 최대 각도 80°, 최대 각속도 180°/초를 공통 적용한다.
3. 가속 300°/초², 감쇠 0.4를 공통 적용한다.
4. 실제 운동에 쓰는 진자 길이는 모두 1.5m다. 천장 케이블 외형 길이로 반동과 비거리가 달라지지 않는다.
5. 봉 위치·매달린 몸 위치·놓는 순간 접선 속도를 같은 운동식으로 계산한다.
6. 놓을 때 추가 상승 속도는 6m/s, 수평 속도 상한은 8m/s다.
7. 봉별 상승 속도 제한·수평 배율·수평 상한 덮어쓰기를 제거했다.
8. 외줄의 다음 목표 위치에 맞춘 별도 도약 보정·연습용 도약 보정을 제거했다.
9. 운반 봉의 레일 속도를 도약 속도에 더하지 않는다.
10. 하차장 도착 시 자동으로 손을 놓게 하던 동작을 제거했다.
11. 하차장이라는 이유만으로 봉 잡기를 막지 않는다.
12. 모든 봉이 공통 호스트 점유·입력·비행·착지 경로를 사용한다. 외줄의 중복 점유/비행 네트워크 구현은 제거했다.
13. 외줄 어댑터는 봉 배치·수업 완료·장치 연결·기존 표시만 담당한다.
14. 씬에 이미 공통 봉 서비스가 있으면 재사용한다. 생성 코스에도 하나만 만들어 중복 등록을 피한다.
15. 생성 코스의 맵 이탈 높이는 해당 코스 좌표계를 따른다.
16. 생성 봉은 계층 경로에서 만든 고정 네트워크 식별자를 사용한다. 클라이언트의 생성 순서·연습 재시작 이력이 달라도 같은 봉을 참조하고, 같은 배치를 다시 만들 때 상태와 이전 탑승자를 초기화한다.

## 7. 모든 스위치 봉·외형

1. 스위치 봉의 직접 잡은 위 사람이 놓으면 연결된 장치가 꺼진다.
2. 아래 사람만 놓을 때는 위 사람이 잡고 있으므로 장치가 유지된다.
3. 대포 톱 관문의 ‘한번 열면 계속 유지’를 제거했다. 해제 시 닫힌 상태와 떨어진 톱 조각을 복구한다.
4. 탈출로 협동 봉의 도착/인원 조건에 따른 영구 고정 활성화를 제거했다. 버튼만 쓰는 장치의 별도 진행 규칙은 유지한다.
5. 외줄 스위치는 위 사람의 점유로 줄 연결을 제어한다. 줄 선택과 연결 필요 인원은 코스의 협동 배치 규칙으로 유지한다.
6. 외줄 스위치의 별도 메시지는 연결할 줄 번호만 복제한다. 봉 인원·시간·운동은 공통 메시지를 쓴다.
7. 일반 봉은 기존 `SharedReleasePole.prefab`, 스위치 봉은 기존 인간대포 `CannonReleasePoleVisual.prefab`으로 표시한다.
8. 옛 봉 막대·케이블의 중복 렌더러/충돌체를 끄고 공통 외형을 붙인다. 공통 외형은 장식이어서 별도 충돌을 만들지 않는다.
9. 코스 비활성/소멸 시 공통 봉 외형과 점유도 정리한다.
10. 위 사람이 사망하거나 연결에서 사라졌으면 탈출로 스위치가 이전 점유 정보만으로 켜지지 않는다.
