# 트램펄린·부상·착지·상호작용

[전체 변경 목록으로 돌아가기](../full-change-list.md)

## 8. 모든 트램펄린

1. 반동 상승 속도 12m/s를 사용한다.
2. 운반 속도 4.5m/s를 사용한다.
3. 공중 조절은 Base AirControl 3m/s를 사용한다. 운반 속도와 분리했다.
4. 모든 씬에서 운반자 없이 바닥에 놓인 트램펄린도 반동한다. 연습 마지막 운반자의 혼자 뛰기(SelfBounce) 단계를 막지 않기 위해 선택한 공통 기준이다. 사용자가 직접 지정한 수치는 아니며 본편의 기존 운반자 필수 조건을 제거했다.
5. 잡기 거리는 Base 2.5m와 공통 팔 부상 배율을 사용한다.
6. 씬·리허설 복제본의 옛 반동·운반·공중 속도·운반자 필요 필드가 공통값을 덮어쓰지 않는다.
7. 운반 중 이동 배율은 일반 몸 상태 처리에서 적용한다. 특정 대포 씬의 부상 정책에만 의존하지 않는다.
8. 반동 면의 크기·형태, 손잡이 위치, 낙사 후 기물 복구는 실제 에셋/코스 배치 규칙으로 유지한다.
9. 휴대 절단기는 별도 기물의 기존 운반 속도(배치값)를 유지한다. 이번에 같게 만든 것은 트램펄린끼리의 씬별 운반 속도이며, 모든 종류의 기물을 똑같은 속도로 만든 것은 아니다.

## 9. 모든 씬의 부상 이동·접근

1. 한 다리를 잃은 이동은 Base ×0.8, 두 다리를 잃은 이동은 Base 기어가기 ×0.5다.
2. 대포 씬에서 최소 80% 이동 속도를 보장하던 규칙을 제거했다.
3. 대포·봉·트램펄린의 공중 조절에도 같은 다리 부상 배율을 적용한다.
4. 외줄·탐색·대포의 팔 부상 접근 배율을 Base로 맞췄다.
5. 대포 씬의 외팔 조작 지연 0.6초를 제거했다.
6. 외줄의 부상에 따른 균형 흔들림·착지 충격은 외줄 행동의 규칙으로 유지한다.
7. 부상에 따른 점프 높이·캡슐 높이·기어가기 점프 가능 여부는 기존 Base 설정을 유지한다.

## 10. 착지·추락

1. 봉·대포 비행에서 실제로 걸을 수 있는 바닥/플랫폼/오브젝트에 착지하면 일반 이동으로 돌아온다.
2. 대포 전용 안전 착지 태그가 없다는 이유만으로 같은 일반 바닥에서 사지를 잃지 않는다.
3. 경사 제한을 넘는 면, 트리거, 플레이어 몸은 일반 바닥 지지면으로 승인하지 않는다. 구형 접촉의 모서리 법선 대신 실제 면을 다시 확인해 급경사를 바닥으로 오인하지 않는다.
4. 외줄 착지는 다른 외줄 조작과 같은 실제 지지 판정을 사용한다.
5. 외줄 봉에서 일반 바닥에 내려왔다고 무조건 실패 경로로 보내지 않는다.
6. 비행 착지 후 이전 일반 점프·옆줄 이동 목표를 지워 착지 위치가 다시 튀지 않게 한다.
7. 호스트가 현재 비행 토큰·구간과 실제 도착 위치를 확인한 뒤 착지를 확정하는 구조는 유지한다.
8. **후속 승인으로 낙하 높이 3m 이상 사지 2개 손실 / 5m 이상 사망을 적용했다.** 일반 낙하·외줄 추락·대포 착지는 같은 높이 기준과 스프링 신발 반동을 사용한다. 맵 이탈·위험물·개발 보호·연습 복구는 별도다. [추가 변경 전후](../followup-before-after.md) 참조.

## 11. 상호작용 거리·키

1. 일반 근접 행동의 정상 거리를 Base 2.5m로 모았다.
2. 봉 잡기, 대포 탑승, 트램펄린 잡기, 탈출 스위치/운반톱, 연습 시작 상호작용에 적용했다.
3. 단서, 문, 부수는 벽, 도구 대상, 열쇠/돈/기물 줍기, 바닥 물건, 선반, 배달 슬롯, 상점 전화, 침대, 일정판, 의료실의 근접 거리를 공통값으로 바꿨다.
4. 탐색 대상마다 저장된 거리와 별도 0.7배/최소 거리 보정이 공통값을 바꾸지 않는다.
5. 로컬 후보 선택과 호스트의 탐색·물건 줍기·선반·의료실 승인에서 같은 팔 부상 거리 제한을 적용한다.
6. 후속 공통화로 몸 중심 기준 3차원 거리 2.5m·벽/층 가림 검사를 적용했다. 높은 버튼 등에 있던 별도 높이 보상은 제거했다. [추가 변경 전후](../followup-before-after.md) 참조.
7. UV처럼 멀리 비추는 도구는 원거리 도구로 구분해 기존 사거리를 유지한다.
8. 단서/암호 문 패널 닫기와 침대에서 일어나기의 직접 F 읽기를 공통 Interact 액션으로 바꿨다. 사용자가 키를 바꾸면 같이 따라간다.
9. 외줄 T 전환 액션을 입력 에셋과 키 매핑 경로에 추가했다.
10. 개발 카메라·디버그 재시작 단축키와 메뉴의 Esc/마우스 닫기는 게임 상호작용 F와 구분해 유지한다.
11. 목마 연결은 별도의 공통 목마 설정 1.5m에 팔 부상 배율을 적용한다. 일반 근접 대상 2.5m와 다른 행동이지만 씬별 차이는 없다.
