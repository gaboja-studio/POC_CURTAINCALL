# 공통 설정 조사 — UI 제외

> 이 문서는 통일 전 조사 기록이다. 2026-11-10 구현 후 현재 규칙·제거한 차이·예외·검사 결과는 [전체 변경 목록](full-change-list.md)을 따른다.


사용자 지시: UI는 이번 통일 대상에서 제외한다. 아래 목록이 현재 검토 범위다.
HUD·문구·아이콘·색상·외곽선·알림·메뉴·결과 화면·UI 애니메이션·UI 미리보기는 제외한다.
게임 행동에 영향을 주는 입력·상호작용·완료 조건은 코드가 UI 폴더에 있어도 유지한다. 카메라 조작·충돌은 UI와 구분한다.

## 공통 설정과 다르게 적용되는 곳

1. 기본 점프: **반영 완료** — 활성 대포 시스템의 바닥 덮어쓰기를 제거하고 Base 저장값만 읽는다.
2. 외줄 점프: **기존 동작 보존** — 콘텐츠별 기준 높이와 외줄 배율 계산을 외줄 설정 안으로 한정했다. 이번 사용자 요청은 외줄 통일이 아니다.
3. 외줄 판정: 공통 코스 설정 대신 씬별 sceneShape를 읽는 경로.
4. 외줄 방향: 독립 줄 배치 방식은 씬별 선택. 양방향 플래그는 현재 무시되고 진입 방향 선택은 공통이다. 시점에 따른 입력 해석은 기준 확인 필요.
5. 봉 도약: 공용 속도 상한보다 개별 봉의 상한을 우선하는 경로.
6. 봉 인원: 스위치 연결 여부에 따라 인원을 다르게 제한하는 코드.
7. 부상: 대포 전용 정책과 최저 이동 속도 보정.
8. 목마: 도약 중 높이·배율 임시 변경.
9. 추락: 개발 보호·탈출 캠페인에 따른 결과 분기.
10. 트램펄린: 공중 조절 속도와 운반 속도가 묶여 있는 설정.
11. 조작·공중 이동: 기본·외줄·대포 비행의 별도 처리 경로.
12. 리허설: 본편 기물의 복제 설정과 전용 진행 규칙.

## 이미 공통 설정에 있는 항목

기본 이동·점프·중력·자세·균형·부상, 외줄/목마/구조, 대포 재사용 시간·봉 수평 상한, 추격자 시야·속도·행동, 치료 가격, 아이템 효과·내구도·가격, 하루 진행·보상 등은 기존 설정을 먼저 재사용한다.

## 근거

- 소스·값·씬별 차이는 기존 [전체 조사](settings-inventory.md)와 [원본 색인](Inventory/index.md)에 보존한다.
- 원본 CSV의 수량은 UI 포함 전수 조사 수량이다. UI 제외 개수나 수정할 필드 개수로 사용하지 않는다.
- UI를 제외한다는 것은 조사·반영 범위의 변경이다. UI 코드나 에셋을 삭제하지 않는다.
