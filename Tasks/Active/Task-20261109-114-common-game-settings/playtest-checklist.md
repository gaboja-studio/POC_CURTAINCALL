# 통일화 후속 수정 플레이 체크리스트

멀티 항목은 호스트와 참가자 화면을 같이 본다. 공연 전환은 서로 다른 PC의 4인 방에서 먼저 확인한다. 재현되면 구간·행동·호스트/참가자·발생 시각을 적고 각 PC의 `Player.log`를 남긴다. 에디터에서 실행한 경우 `Editor.log`를 사용한다.

## 튜토리얼과 리허설

- [ ] **최초 입장** — 4인으로 시작한다. 전원이 각자 출발대에 나타나고, 바닥을 거치거나 기어가기·허우적 모션이 남지 않는다.
- [ ] **외줄 3단계 사망** — 3단계 도착대에서 한 명이 사망한다. 해당 참가자는 출발대로 복귀하고 도착대에 다시 보내지지 않는다. 팀원이 이전 도착자로 계속 세거나 투명벽에 갇히지 않는다.
- [ ] **닫힌 통로** — 튜토리얼 종료 후 출구 외 쇠창살을 향해 일반 점프와 목마 점프를 한다. 높아진 쇠창살과 투명벽이 통과를 막고, 지정 출구로는 나갈 수 있다.
- [ ] **기물·도구·목마 상태로 입장** — 트램펄린을 운반하거나 도구 사용 동작 중이거나 목마를 탄 상태에서 리허설을 시작한다. 출발대에 정상 배치되고 손·동작·목마·조작 잠금이 남지 않는다. 인간대포 연습을 끝내면 각자의 입장 전 위치·선택 도구·트램펄린 운반자가 복원된다.
- [ ] **인간대포 연습 중 사망** — 출구가 닫혀 있는 동안 안전 발판에 섰다가 링 바닥으로 떨어진다. 사망 뒤 마지막 안전 발판과 직전 부상 상태로 복귀한다. 복귀 대기 중 포기 투표로 끝내도 모두 조작을 돌려받고 출구가 열린다.

## 봉과 목마

- [ ] **봉의 반동과 입력** — 일반 봉과 스위치 봉에서 W/S로 반동을 키운다. 열린 공간에서 앞뒤 각 90°를 넘지 않는다. 반대 입력을 계속하면 중앙에 고정되지 않고, 입력을 놓으면 반동이 서서히 줄어든다. F 탭은 잡기, F 홀드는 아래로 내려놓기, Space는 도약으로 동작한다.
- [ ] **가로 외줄 충돌** — 외줄 가까이의 봉에서 몸이 줄 쪽으로 향하도록 흔든다. 혼자와 2인 탑승을 각각 해 보고, 호스트와 참가자 화면 모두에서 몸이 가로줄을 가로질러 반대쪽으로 빠져나가지 않는다.
- [ ] **팀원 잡기와 30초 표시** — 흔들리는 팀원의 몸통 중심에 앞·옆·아래에서 접근한다. 벽이 없는 3m 이내에서 잡을 수 있고, 3m 밖이나 벽 너머에서는 안 된다. 두 봉 종류 모두 30초부터 표시하며, 늦게 붙은 팀원은 남은 시간을 공유한다. 해제하거나 시간이 끝나면 표시가 사라진다.
- [ ] **앉은 상태의 목마** — 낮은 천장과 벽 옆에서 앉은 채 목마를 시도한다. 서기 전에는 탑승하지 않고 벽을 통과하지 않는다. 일어나 정상 탑승한 뒤에는 앉기 상태가 남지 않는다.

## 운반과 입력

- [ ] **대기실 트램펄린 출구** — 열린 연습실 출구로 트램펄린을 들고 양방향으로 지나간다. 통로에서 카메라 방향을 바꿔도 운반이 멎거나 손이 늘어나지 않는다. 실제 벽으로 밀면 기물과 플레이어가 벽을 통과하지 않는다.
- [ ] **인간대포 리프트** — 트램펄린을 들고 하단 리프트에 타고 도착점까지 간다. 참가자가 운반할 때도 기물이 출발점에 남지 않고, 도착 즉시 계속 운반하거나 내려놓을 수 있다.
- [ ] **톱날 발사기** — 호스트와 참가자가 각각 운반한다. 평지와 착지 직후 V를 눌러 한 발씩 발사되는지 확인한다. 발사 간격은 적용되고, 공중이나 손잡이에서 떨어진 상태에서는 발사되지 않는다. 벽 뒤 배선에는 닿지 않는다.
- [ ] **공중 WASD** — 일반 플랫폼에서 걷기·달리기로 점프하거나 가장자리에서 떨어져 WASD 방향과 달리기 입력을 바꾼다. 지상과 같은 방향·속도 반응을 보이며 키를 떼면 수평 이동이 멎는다. 대포·봉·트램펄린의 발사 직후에는 기존 관성이 남는다.
- [ ] **열쇠와 머리핀** — 기존 열쇠 위치에서 획득·사용 안내와 관련 모션이 나오지 않는다. 열쇠를 요구하던 문은 남아 있는 조건으로 진행된다. 마술사의 머리핀은 기존 대상에서 사용된다.

## 공연 전환

- [ ] **튜토리얼 → 외줄 공연** — 서로 다른 PC의 4인 방에서 튜토리얼을 마치고 공연으로 넘어간다. 네 화면 모두 연결을 유지하며 같은 씬과 출발대에 도착하고 커튼이 열린 뒤 조작할 수 있다.
- [ ] **인간대포 공연 사망 판정** — 출발대 배치 직후 정상 조작을 확인한다. 호스트와 참가자가 각각 위험물 또는 치명적인 높이로 추락한다. 둘 다 사망이 판정되고 다음 플레이어의 입장 보호에 영향을 주지 않는다.
