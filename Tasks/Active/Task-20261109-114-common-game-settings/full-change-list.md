## 12. 의도적으로 유지한 구분과 후속 사항

- **UI:** 메뉴·HUD·색·배치·디자인 통일은 하지 않았다. 행동 입력이 들어 있는 화면 코드와 기물 외형만 필요한 범위에서 수정했다.
- **발사/배치:** 일반 점프, 외줄 점프, 대포 발사의 높이·탄도는 서로 다른 행동이다. 대포별 발사 방향/속도, 이동 레일, 맵 구조와 위험물 배치를 같은 값으로 만들지 않았다.
- **튜토리얼:** 최초 수업의 진행 대기와 학습 조건은 유지한다. 이후 재연습에 도착 구속이 남지 않도록 분리했다.
- **낙하 피해:** 후속 승인으로 3m/5m 높이별 피해와 일반 낙하 스프링 신발을 적용했다. 기존 맵 이탈·개발 보호·연습 복구까지 모두 동일한 사망 정책이 됐다는 뜻은 아니다.
- **대포 바닥 톱:** 기존 상단 높이 0.42m는 두 다리 손실 시 공통 점프 0.4m보다 높다. 사용자와 앞서 논의한 톱 높이 낮추기는 구체 높이 미정으로 남긴다.
- **높은 버튼:** 다리 손실로 낮아진 목마의 높이를 상호작용 범위로 보상하던 예외를 제거했다. 실제 공통 범위 밖의 높은 버튼은 이제 잡히지 않으며, 이런 배치는 부상 조합별 협동 동선 확인이 필요하다.
- **수동 플레이:** 자동 검사는 최종 재미·난이도나 실제 두 PC의 지연 환경을 대신하지 않는다.
- **Git:** 사용자 저장·제출 승인에 따라 작업 브랜치에 저장하고 dev 대상 PR을 제출한다. 실제 PR 링크는 [작업 기록](log.md)에 남긴다.
