## 설정 위치
- `Resources/Settings/GameSettings/BaseGameSettings` → 공통 운반 장치: 발사기 크기·속도·발사 간격·충돌 여유.
- `Resources/Settings/GameSettings/BaseGameSettings` → 신체 손상/공통 위험물·낙하: 부상 낙하 높이5·사망 낙하 높이15·월드 Y 즉사 기준-15.
- `Resources/Settings/GameSettings/Tricks/PoleSettings` → 앞뒤 모션 속도 배율1.6. 기존 최대 흔들림 속도/추가 상승 속도 대신 이 항목으로 왕복 속도만 조정.
- `Resources/Settings/GameSettings/Tricks/TrampolineSettings` → 공통 외형·충돌 모양·외형 판정·잡기 기준 높이·반동/운반 속도. 외형 변경 후 `Tools/CurtainCall/트램펄린/현재 씬 공통 외형 적용`으로 저장된 씬에 반영.
- 게임 설정 → 조작 키 → 운반 장치 사용: 기본 V. 마우스 왼쪽 버튼은 기존 UI 전용 예약 유지.

## 씬·맵 비교 결과
- Start의 인간대포 연결은 최신 DEV의 HumanCannon.unity와 같음. 별도 옛 씬 또는 빌드 프로필 덮어쓰기는 발견하지 못함.
- 인간대포 씬의 11/5→현재 DEV에는 개별 설정122줄 제거만 있으며 대포·발판 위치/크기·발사속도 변경 없음. 이번 외형 정리도 기물 루트 배치와 발사 수치를 유지.
- 공중 조절4.5→공통3, 개별 봉/피해 규칙→기존 승인된 공통 규칙은 앞선 통일화 변경에 해당.
- 마지막 요청으로 일반 낙하5m 부상/15m 사망, 절대 월드 Y -15 이하 즉사로 변경. 반동 뒤 일반 바닥을 안전 지대로 바꾸지 않음.
- 대기실 발사기에 끊을 배선이 연결되지 않은 기존 코스 상태는 남아 있음. 배선 코스를 임의로 새로 만들지 않음.
- 탈출로 씬·예전 실패14개 전체 수정은 계속 제외.

## 확인 범위
- 최종 check-work는 안전성·문서/규칙·컴파일·공통 연결 PASS. 봉 모션1.6·부상5m/사망15m·절대Y-15 저장과 추가 바닥 복귀 수정까지 포함.
- 사용자 최신 지시: 자동 테스트·플레이 테스트는 실행하지 않음. 실제 4인 동기화 통과로 보고하지 않음.
- 입력 fixture의 앞선 실패는 준비 코드 수정 후 재실행하지 않음.
- 이번 네트워크 변경은 모든 참가자가 같은 새 빌드를 사용해야 반영됨. 실행 중인 기존 실행 파일은 저장·재컴파일만으로 갱신되지 않음.
- 기존 다른 작업의 문서·라벨 캐시·미리보기 변경은 보존하고 제출에서 제외. 마지막 사용자 요청으로 오후 변경까지 저장·제출 승인.
