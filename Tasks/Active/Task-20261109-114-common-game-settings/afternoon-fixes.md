## 설정 위치
- `Resources/Settings/GameSettings/BaseGameSettings` → 공통 운반 장치: 발사기 크기·속도·발사 간격·충돌 여유.
- `Resources/Settings/GameSettings/BaseGameSettings` → 신체 손상/공통 위험물·낙하: 부상 낙하 높이5·사망 낙하 높이15·월드 Y 즉사 기준-15.
- `Resources/Settings/GameSettings/Tricks/PoleSettings` → 반동 입력 가속도100(최대에 도달하는 빠르기), 흔들림 감쇠0.12(입력 중단 후 잦아드는 빠르기), 최대 흔들림 각도85·진자 길이2m(왕복 폭), 운동 속도 배율1.6(왕복과 도약 함께), 도약 수평상한4.5·추가 상승6m/s. 항목별 한글 Tooltip 포함.
- `Resources/Settings/GameSettings/WaitingRoomSettings` → 대기실 전체 착지 피해 면제=켬, 최초 튜토리얼 공통 규칙/도착 지점 투명 벽=끔, 목마 연습 첫 그네 낮춤 높이=0.5m.
- `Resources/Settings/GameSettings/Tricks/TrampolineSettings` → 공통 외형·충돌 모양·외형 판정·잡기 기준 높이·반동/운반 속도. 외형 변경 후 `Tools/CurtainCall/트램펄린/현재 씬 공통 외형 적용`으로 저장된 씬에 반영.
- 게임 설정 → 조작 키 → 운반 장치 사용: 기본 V. 마우스 왼쪽 버튼은 기존 UI 전용 예약 유지.

## 씬·맵 비교 결과
- Start의 인간대포 연결은 최신 DEV의 HumanCannon.unity와 같음. 별도 옛 씬 또는 빌드 프로필 덮어쓰기는 발견하지 못함.
- 최신 DEV c8228c0c에는 인간대포 출발대4→5m와 첫 대포3대 재조준 변경이 포함됨. 이번 작업은 공연 배치를 유지하고, 뒤처진 재연습 원본의 복사값만 맞춤.
- 공중 조절4.5→공통3, 개별 봉/피해 규칙→기존 승인된 공통 규칙은 앞선 통일화 변경에 해당.
- 일반 낙하5m 부상/15m 사망, 절대 월드 Y -15 이하 즉사 유지. 최신 승인으로 대기실의 착지만 높이 피해 면제.
- 실제 게임은 BaseGameSettings의 WaitingRoomPursuit로 연결. 별도 WaitingRoom 통합 씬·WaitingRoomBase 테스트 씬도 존재하며 같은 대기실 보호 설정 적용.
- 실제 대기실 발판 높이4.6m/5.6m 확인. 4.6m에서도0.8m 점프 최고점부터 떨어지면5m 초과 가능. 사용자 낙하 위치/영상이 없어 해당 한 번의 실제 높이는 미확정.
- 대기실 발사기에 끊을 배선이 연결되지 않은 기존 코스 상태는 남아 있음. 배선 코스를 임의로 새로 만들지 않음.
- 탈출로 씬·예전 실패14개 전체 수정은 계속 제외.

## 확인 범위
- 비플레이 확대 검사1,738개: 최초1,724통과·14실패. 후속141개:140통과·원본 복사 불일치1실패 → 원본 추가 보정 뒤 대포 관련76개 전부 통과.
- 현재 남은10개는 기존 보류 항목: 톱 높이1·난이도 준비5·통합 씬 추격자 크기1·보상 기대값1·문구2. 전체 통과로 표시하지 않음. [상세](nonplay-audit-20261111.md).
- 치료16개(2·3·4층 상태순서 포함)·낙하15개·봉50개·외줄 표면69개 최종 통과. 첫 봉 배치3개·튜토리얼 벽 설정2개 포함 후속 검사 통과.
- 최초 확대 실행에 내부적으로 Play 모드로 전환하는 StartConnectionTests가 섞여 들어가 확인 즉시 중단·Play 종료. 해당 종류를 제외하고 위1,738개 다시 실행. 실제 플레이·다른 PC 동기화 검증 완료로 계산하지 않음.
- 이번 네트워크 변경은 모든 참가자가 같은 새 빌드를 사용해야 반영됨. 실행 중인 기존 실행 파일은 저장·재컴파일만으로 갱신되지 않음.
- 기존 다른 작업의 문서·라벨 캐시·미리보기 변경은 보존하고 제출에서 제외. 마지막 사용자 요청으로 오후 변경까지 저장·제출 승인.
