## 현재 확정 규칙
- 모든 공통 조작·피해 설정은 GameSettings를 사용한다. 별도 규칙으로 벗어나야 하면 사용자에게 먼저 묻는다.
- 일반 바닥 이동·점프는 Base 원본 사용. 걷기3, 달리기×2, 앉기×0.5, 점프0.8m.
- 외줄 점프1.5m, 지지폭0.55m·높이허용0.3m. 양방향 이동, 같은 높이 옆줄 수평3m 이내, T180도 전환. 시점 회전으로 방향 반전 없음.
- 목마는 모든 씬 바닥에서도 가능, 균형은 외줄에서만 사용. 봉의 위 사람이 반동, 기본2인·30초·80도·180도/초. 놓으면 스위치 해제. 운반 속도 도약 영향·자동 하차 없음.
- 일반/스위치 봉 너비1.8m. 고정값은 기존 설정 Inspector로 조정하며 Tooltip 설명. 봉 정원1~4 확장은 이미 반영.
- 트램펄린 반동12m/s·운반4.5m/s·공중조절3m/s, 운반자 없이 바닥 반동 가능. 재착지는 피해 전에 재반동.
- 일반 낙하 부상4m/사망8m. 외줄/안전 착지대 무피해는 공통 설정. 일반 바닥에 반동 높이 일괄 공제 없음.
- 최초 튜토리얼 바닥 추락은 복귀, 도착벽 유지, 연습실에 사람이 있으면 문 열기. 교육 완료~첫 공연 시작까지 보호 유지.
- 재연습 사망은 기존 GameSettings에 따라 체크포인트 자동 복귀(기본 켬/1.5초). 첫날 모든 공연1단계 고정 유지.
