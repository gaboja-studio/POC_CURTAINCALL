# 외줄 씬별 차이와 통일 기준안

2026-11-09 초기 조사 기록. 조사 당시에는 외줄 코드를 변경하지 않았으며, 이후 사용자가 아래 공통화 구현을 요청했다. UI 제외.

## 후속 승인 및 반영 기준

- 공통 GameSettings: 외줄 제자리 점프 1.5m, 지지 폭 0.55m, 높이 허용 0.3m. 활성 대포에 따른 외줄 높이 덮어쓰기 제거.
- 옆줄은 사용자 추가 답변대로 **같은 높이에서 수평 거리 최대 3m**. 입력 방향의 최근접 사용 가능한 줄을 선택한다. 평행·배열 순서·기존 구간 제한은 쓰지 않는다.
- 높이가 다른 줄은 이동 후보에서 제외한다. 부상/목마 배율은 기존 정책을 유지한다. 목마 위층에서 같은 높이의 옆줄로 분리 점프할 때는 출발한 몸의 높이에서 실제 도착 줄까지의 낙하 시간을 사용한다.
- 모든 씬의 일반 바닥에서 F 탑승/F 홀드 하차. 바닥 목마에는 균형을 적용하지 않는다. 외줄에서 바닥에 도착한 목마는 기존 안전 하차 흐름을 공통화한다.
- T로 외줄 방향 즉시 180도 전환. 카메라 반전 제거. 진행 중 옆줄 점프 도착점 유지.
- 추락 피해는 후속: 3m 이상 사지 2개 손실, 5m 이상 사망. 이번 구현에서 피해 임계값을 바꾸지 않는다.

아래 표는 **변경 전 조사 결과**이며 현재 런타임 수치가 아니다.
기준: dev 2d591802 + 이 브랜치의 일반 바닥 통일 변경. 저장된 6개 씬을 Unity 미리보기 씬으로 열어 참조·충돌체를 읽었으며 플레이 측정은 하지 않았다.

## 현재 씬별 차이

| 항목 | 외줄 공연 | 대기실 외줄 리허설 | 탈출로 A | 탈출로 B / C |
|---|---|---|---|---|
| 외줄 구성 | 공통 코스 생성 | 공연 프리팹 생성 후 연습용 길이·줄 수 적용 | 씬에 놓은 줄 15개 | 씬에 놓은 줄 1개 / 2개 |
| 부상 없는 점프 높이 | 1.0m | 대포 시스템이 없으면 1.0m | 활성 대포 시스템 영향으로 1.5m | 활성 대포 시스템 영향으로 1.5m |

대포 단독 씬에는 TightropeCourse가 없다. 대기실 기본 씬에도 고정 코스가 없고 외줄 리허설 때 생성한다. 위 개수는 저장된 참조 개수이며 런타임 추가 생성까지 센 결과가 아니다.

## 이미 공통인 동작

1. 모든 외줄의 기본 이동은 Base.FreeMoveSpeed(현재 3m/s)를 읽는다. 균형·착지 충격·외줄 부상 배율도 기존 GameSettings를 읽는다.
2. 모든 외줄에 양쪽 진입을 지원하는 공통 코드가 있다. bidirectionalSceneTraversal 저장 칸은 남아 있지만 현재 분기에는 쓰지 않는다.
3. 외줄 위 제자리 점프·목마·옆줄 점프의 기본 기능은 존재한다. 달리기·앉기 입력은 현재 모든 외줄에서 별도 동작 없이 무시한다.

## 수치 외에 다른 판정

1. **줄 가장자리:** 씬에 배치된 외줄은 충돌면의 작은 위쪽 법선도 허용하지만 생성 외줄은 캐릭터의 경사 제한을 사용한다. 폭 값만 같게 바꿔도 같은 착지 판정이 되지 않는다.
2. **진입 방향:** 진입 때 캐릭터 또는 마우스 시점 방향으로 앞을 정한다. 이후 시점을 반대로 돌리면 W/S·Q/E 입력 해석이 뒤집힐 수 있다. ‘시작한 방향이 앞’과 입력까지 고정한다는 뜻을 구분해야 한다.
3. **옆줄 이동:** 단순히 범위 안에 있으면 되는 구조가 아니다. 정해진 간격의 착지점·높이·평행 방향·허용 구간을 검사한다. 독립 줄은 작성 방향이 반대인 평행 줄도 후보에서 제외한다.
4. **추락:** 균형 붕괴는 매달림·구조를 거칠 수 있지만 줄 밖 착지·깊이 초과는 별도 사망 경로다. 매달림 시간 만료도 사망으로 연결된다. 아래에 안전한 바닥이 있으면 내려온다는 규칙으로 전부 통일돼 있지 않다.
5. **목마 추락·구조:** 공통 목마 기능을 쓰지만, 독립 줄은 매달릴 옆줄 탐색 범위를 0으로 제한하고 생성 코스는 공통 범위를 사용한다. 하차 발판 등록 여부도 결과에 영향을 준다.

## 공통 규칙 초안

1. 모든 외줄은 모든 씬에서 같은 이동·균형·부상·점프 설정을 사용한다.
2. 모든 외줄의 점프는 외줄 공통 높이만 사용한다. 같은 씬에 대포가 있다는 이유로 높이가 바뀌지 않는다.
3. 모든 외줄은 같은 폭·높이 허용·가장자리 판정으로 올라서고 착지한다. 보이는 굵기·재질은 달라도 된다.
4. 모든 외줄은 양쪽에서 진입할 수 있으며, 진입한 방향을 앞의 기준으로 정한다.
5. 모든 외줄 위에서 점프와 목마를 사용할 수 있다. 부상·점프 중·인원 제한 등 같은 상태에는 같은 조건을 적용한다.
6. 모든 외줄은 공통 이동 범위 안에 있고 실제로 착지할 수 있는 옆줄로 건너갈 수 있다. 줄의 배열 번호나 씬별 고정 간격이 이동 가능 여부를 대신하지 않는다.
7. 모든 외줄에서 떨어지는 것과 사망하는 것은 구분한다. 안전한 바닥에는 내려올 수 있고, 위험물·낙사 구역은 별도 공통 규칙으로 판정한다.
8. 일부 상황의 예외는 부상·목마·매달림·장애물·명시적인 개발 보호처럼 공통 조건으로만 둔다. 특정 씬 이름만으로 외줄 조작을 다르게 하지 않는다.

## 적용 전에 정할 기준과 순서

1. **점프 높이부터:** 현재 공연 1.0m와 탈출로 1.5m 중 하나를 고른다. 사용자가 앞서 탈출로 기준을 언급했으므로 **1.5m를 첫 제안**으로 둔다. 아직 확정·적용하지 않았다. 일반 바닥 0.8m와 분리한다.
2. **줄 판정과 대상:** 0.4m 또는 탈출로 A의 보통 줄 0.55m 중 공통 폭을 정한다. A의 1.75~1.85m 접근·인계 구간도 실제 외줄인지, 일반 발판인지 구분한 뒤 판정에 반영한다.
3. **옆줄 이동:** 줄 배치 간격은 씬별로 유지하고, 이동 가능한 최대 거리와 높이 차이를 공통 규칙으로 정한다. 기울어진 줄·반대 방향으로 작성된 줄도 같은 기준으로 판정한다.
4. **추락·목마:** 추락 후 안전 착지와 사망을 분리한다. 매달림/동료 구조를 유지할지, 유지한다면 어떤 추락에 적용할지도 공통으로 정한다. 현행 매달림 7초·구조 2초는 확정 변경하지 않는다.
5. **방향 입력:** 앞의 기준은 진입 방향으로 통일하되, 시점을 돌릴 때 W/S 의미까지 고정할지는 조작 기준에서 확정한다.

모든 줄의 위치·길이·개수·높이·배치 간격·외형·연결된 관문을 같게 만들 필요는 없다. 판정을 통일한 뒤 기존 점프 도달 거리·줄 가장자리 착지·목마 하차·안전한 바닥 착지를 다시 검사해야 한다.
