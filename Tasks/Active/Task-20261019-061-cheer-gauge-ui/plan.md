# Plan
1. 기존 정본 프리팹/Canvas/게임 API 확인. 원본 PNG·9-slice·폰트와 제작 코드 변경 금지.
2. 사용자 추가 지시: 공통 UI 씬에 C1/C2/C3, 외줄 공간 씬에 P1 정본 인스턴스. 두 공연 UI 루트를 정리하고 공통 씬 additive 수명을 관리한다. 연결 코드는 독립 SceneIntegration 폴더에 둔다.
3. C1은 기존 보상 projection을 재사용. 사용자 확정 C2는 불의 안전 경계까지 남은 표시 시간, C3는 코스 거리·명부·추격 불, P1은 로컬 PlayerBalance를 읽는다. 인간대포 P1은 숨긴다.
4. 정본 API가 지원하지 않는 1인 진행도/미수신 값은 가짜 값 없이 숨김 또는 unavailable로 표시한다.
5. 에디터 조회/컴파일·테스트/실제 Play 후 결과를 기록한다. 기존 테스트 결과와 새 검증 결과를 구분한다.
6. 제작 채팅 전달용 제약과 Unity 확인 항목을 Integration 가이드에 남긴다.
7. 사용자 추가 지시: Start/Lobby보다 HumanCannon 후속 적용을 먼저 한다. Assets의 Guides/Tooltips를 공통 씬에 인스턴스로 두고, 공간 어댑터가 탑승·운반·봉·입력 차단 상태를 읽는다. 기존 구간 안내는 공간 UI에 유지한다.
## 인간대포 공동 확인
- 대포 접근→탑승→F 발사/F 길게 하차에서 툴팁과 안내가 중복되지 않고 상태에 맞게 바뀐다.
- 트램펄린 운반·봉 잡기/놓기와 메뉴·사망 때 안내 전환을 확인한다.
- 실제 공연 시작 후 C1/C2 및 2~4인 C3, 공간 전환 후 공통 UI 중복/잔상을 확인한다.
