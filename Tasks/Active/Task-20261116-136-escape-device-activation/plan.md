- 합류 이후 두 씬이 공존하는 순서와 입력·네트워크 수신기 수명을 조사한다.
- 탈출로 코드의 전환 구간에서만 기존 기물 등록을 해제하고 탈출로 장치를 활성화한다. 전환 취소 때 출발 씬 장치를 복구한다.
- 새 회귀 검사와 실제 저장 씬의 장치 등록을 편집 모드에서 점검한다.
- Start → 로비 → 집결실 → 탈출로 → 엔딩 및 복귀 연결을 대조한다. 늦은 카메라나 캠페인 메시지, 잘못된 착지 위치, 이동 제어가 다른 기물에서 넘어오는 경우를 점검한다.
- DEV의 공용 기물 변경을 반영한 뒤 신규·기존 EditMode 회귀를 다시 돌린다. 실제 씬의 분기와 말단 경로는 부상·좌석·입력 조합, 발사 경로, 물리 지지와 참조 검사를 포함한다.
- 휴대 UV등을 탈출로에서도 공용 조명 컴포넌트로 켠다. 공연 외줄과 이동용 외줄의 도구 제한을 구분하고 스프링 신발의 착지 발동 조건을 검사한다.
