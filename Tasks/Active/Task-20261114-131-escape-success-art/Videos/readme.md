- 성공: 기존 모델/바리에이션/결과 UI, 실제 부상 플레이어 달리기, 낮 하늘과 어두워지는 원경, 서커스/갈대/지면/오염 재질.

- 결과창에서 성공/실패 일차 표시. 성공은 로비로, 실패는 다음 런 시작으로 분기한다.

## 재현 조건과 범위
- 빠른 공유 검증을 위해 기존 개발 시작점/마지막 문 개방/체크포인트 이동을 사용했다. 모든 공연과 탈출로를 수동 완주한 영상은 아니다.
- 전원 사망 영상은 서버의 실제 Retired 상태를 적용해 기존 전멸 판정으로 진입했다. 시간 종료는 실제 타이머 만료를 진행시켰다.
- 이번 영상 런에서는 공연을 건너뛰었으므로 런 통계의 미시도/0은 실제 값이다. 결과 수치/명부를 채워 넣지 않았다.
- 2인 영상은 호스트 Game View 녹화이며 별도 MPPM 에디터를 LAN으로 연결했다. 3인 영상은 포함하지 않는다.
- 리허설/가이드 보존은 별도 상태 검증으로 확인했다. 영상 촬영용 새 세션에는 미열람 가이드가 보일 수 있다.
- 각 *-review.png는 MP4에서 직접 디코딩한 6개 시점의 검사 시트이다. 최종 공유본은 MP4 네 편이다.
