# 구조 A 배치 보정 — 2026-10-30 사용자 지적

숙소 막힘, 공중에 뜬 대상, 낙서가 벽에 붙지 않은 문제, 비밀번호 패드 위치를 보정했다. 대상 ID·연결·수치는 바꾸지 않았다. 보정은 `StructureAPlacementFix`(메뉴 `CurtainCall/Waiting Room/Fix Structure A Placement`)로 하며, 다시 실행해도 같은 결과가 나온다.

## 원인과 보정
- **숙소 막힘:** 원래 가구(옷장·사물함·책상)는 이동되지 않았다. 원인은 7단계 `Tool()`이 경첩을 월드 좌표 오프셋으로 만든 것이다. 그래서 회전된 방에서 캐비넷 문짝이 몸체 옆으로 비틀려 통로를 막았다. 캐비넷5(emptyCabinet·mapCabinet·cabinet3·lockedBox2·managementDrawer)의 경첩을 앞면(-z) 로컬 기준으로 복구했다. `StructureAPlacement.Tool()`도 같은 방식으로 수정했다. 숙소 캐비넷1·2는 화장실 문 옆 빈 남쪽 벽(z68.35)에 붙였다. 지도는 캐비넷2 앞 바닥에 놓인다.
- **낙서·UV·벽 단서:** 실제 벽 충돌면까지 쏜 레이에 맞춰 뒷면을 밀착했다(간격 3mm). 얇은 면이 벽과 평행하도록 회전도 맞췄다.
  - 화장실 1·2·UV1은 원래 벽에 붙였다.
  - 작업실 3은 봉인된 출입구 문틀에 파묻혀 있었다. 같은 서쪽 벽 z108.6으로 옮겼다.
  - 파이프 4는 5m 안에 벽이 없었다. 서쪽 벽 x10.85로 옮겼다.
  - 화물 숨은 낙서 3과 UV는 선반 끝에 있었다. 북쪽 외벽 z80.11로 옮겼다.
  - 잡동사니 암호 앞자리와 UV는 철망 칸막이에 떠 있었다. 동쪽 벽 x38.15의 선반 사이로 옮겼다.
- **기계실 모니터:** 사물함 문 앞에 떠 있던 판을 기록 책상 위 기존 CRT 화면 앞면에 덧댔다.
- **공연 기록:** 선반 앞 1m 높이에 떠 있었다. 같은 방 다른 기록 책상의 빈자리에 눕혔다.
- **바닥 대상:** 열쇠 6개(key1·관리실·계단·탈출1·key2·탈출2)는 7~10cm 떠 있었고, 신문·압수 노트는 3~16cm 떠 있었다. 모두 아래 실제 면에 내려놓았다.
- **문:** 기계실 숨은 문과 관리실 문이 20cm 떠 있어 바닥에 붙였다. 계단 문과 탈출문은 탐색용 판이 실제 문짝(잠금 핸들·보강대·로프)을 덮고 있었다. 판을 기존 문짝보다 1cm 작게 줄여 문짝 안쪽에 넣었다.
- **비밀번호 패드:** 바닥 근처에 따로 놓인 상자였다. 탈출문 옆 기존 키패드 뒤 받침판(벽과 키패드 사이, 사방 4cm 여유)으로 옮겼고, F 판정 지점은 키패드 앞이다.
- 같은 씬에서 사용자가 저장하지 않고 옮겨 둔 2층 침대 3개(x+0.5m)도 함께 저장했다.

## 측정
- 보정 뒤 전체 탐색 대상의 아래 면 간격·옆 벽 간격·겹침을 측정했다. 모든 대상이 바닥 또는 벽에서 3mm 이내다.

  - 모니터 판은 CRT 앞면에 붙는다.
  - 문 판은 기존 문짝 안쪽에 들어가 있다.
- 숙소·탈출문·화물·잡동사니·모니터·화장실·작업실 화면 캡처로 확인했다.

## 내구도 확인
`ItemCarryBook.Use`는 성공 때만 1 줄이고 0이면 손에서 없앤다. 탐색 판정(`ExplorationState.Use`)도 대상이 열린 때 1번만 부른다. 따라서 코드 결함은 없다.
한 번 쓰면 사라지는 이유는 카탈로그의 발견품 내구도 때문이다.
- 말뚝뽑개·UV등: 발견품 1회(새 제품 4·3회)
- 머리핀: 발견품도 새 제품과 같은 5회
- 로비 디버그 보급품: `FoundItemSpot.MakeItem`이 발견품 수치를 쓰므로 말뚝뽑개·UV등이 1회짜리다.

수치를 바꿀지는 사용자 확인 대상이라 바꾸지 않았다.
