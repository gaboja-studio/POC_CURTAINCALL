# 4단계 — 파괴·보상 대상 연결 코드

## 구현
- StructureAContainerRoute: 숙소2/배관1/화물3/휴게2의 파괴 상자8개에 고유 경로 ID를 연결한다. Breakable Gate만 받으며 현재 도구·타격 수·드랍 목록을 보존한다. 좌표·타격 수·미정 드랍을 새로 만들지 않는다. 미지정 참조는 건너뛰고 중복 참조/잘못된 지도 계층은 적용 전에 거절한다.
- 빈 캐비넷1: 명시적인 빈 드랍으로 기존 단일 보상 fallback을 막는다.
- 지도 캐비넷2: 기물을 지급하지 않고 기존 개방 연출로 지도 Clue를 공개한다. 지도는 별도 F 조사/오버뷰·발견 공유를 사용하며 슬롯에 넣지 않는다. 개방 전 직접 조사 요청도 거절한다.
- 잠긴 상자2: 명시적 ExplorationDrops가 없으면 보상 미정(Pending)으로 둔다. 이미 명시한 보상 설정은 보존한다. 미정은 빈 보상과 구분하며, 개방 후 보상이 지정되면 기존 지급 재시도·영수 표식으로1회 지급한다.
- ExplorationDrops: TryConfigure로 드랍 목록 내 UID 범위/중복·누락 아이템을 검사하고 오류 시 기존 설정을 보존한다. Pending은 지급을 보류하고 ConfigureEmpty는 명시적인 무보상이다.
- 현재 등록된 발견품·다른 개방 대상과 UID가 겹치면 지급 완료로 오인하지 않고 보류한다. 수정 후 재시도한다. 정식 배치 시에는 씬을 가로질러 전역 고유 UID를 지정해야 한다.

## 검사
- 여덟 상자를 실제 도구로 처리하며 중간 타격 차감/지급 없음, 마지막에1회 차감/개별 드랍, 마지막 사용 소진을 검사한다.
- 빈/지도 캐비넷의 fallback 기물 없음, 지도 공개 전 조사 거절·개방 후 오버뷰, 미정 보상 설정 후 지급과 소모 후 재지급 방지를 검사한다.
- 중복 드랍 설정의 원자적 거절과 서로 다른 상자 사이 UID 충돌/설정 수정 후 양쪽 지급을 검사한다.
- 검사용2타·도구8회·지정 드랍 ID는 테스트 입력이며 게임 밸런스/정식 보상 확정이 아니다. 최종 검사 결과는 log 참조.

## 제외·남음
정식 씬에 연결 컴포넌트나 대상 참조를 저장하지 않았다. 지도 모델/상세 내용, 상자별 타격 수·보상·랜덤 드랍표는 확정하지 않았다. 에셋/맵 배치 변경 없음. 실제 멀티 검증은 후순위·최대2인. 다음은5단계 조사·힌트 경로 연결 기능이다.
