# 대기실 탐색 타이머·UV 등 기획서 — 구현 기준 (2026-10-30)

Confluence 등록은 권한 거부로 보류. 작업노트(30015499) 하위에 같은 내용으로 올릴 것.

## 1. 탐색 타이머
- 개요: 대기실 탐색 동안 소모되는 시간 제한. 탐색(기물 찾기→탈출로)은 핵심 코어루프.
- 의도: 진행이 멈출 때 시간 제한으로 제약을 주어 분위기 환기·긴장감.
- 규칙(구현): 쉬는 시간 시작 시 전체 시간으로 **멈춤** 시작(전원 로비). 1명 이상 재생 구역 → 흐름. 전원 멈춤 구역(또는 구역 밖) → 멈춤, 재진입 시 남은 수치부터. 겹치는 자리는 멈춤 우선. 0이면 기존 규칙대로 공연 강제 이동(M2). 추격자 미구현(느린 걸음 기획안 후속). 호스트 판정, 발 위치 +0.5m.
- 멈춤 구역: 로비, 숙소/화장실, 연습실, 휴게, 상점, 전문가 서비스, 작업실, 무대 입구 통로, 소품실, 승강기 홀, 서쪽 복도.
- 재생 구역: 배관, 폐기물 보관소, 화물 적재, 무대 장치 보관실, 계단, 기계실, 관리실(연결 통로 포함), 탈의 방, 탈출로.
- 구현: `ExplorationTimerZones`(Frame8Areas 이름 분류) → `CampaignRun.SetRestTimerPaused` → `RunState.SetRestTimerPaused`. 규칙 검사 `ExplorationTimerZoneRule`.

## 2. 서커스 UV 등
| 항목 | 내용 |
| --- | --- |
| 라이트 | 가슴 높이에서 시선 방향 원뿔(50°, 12m), 닿는 자리에 원형 표시 |
| 색 | 보라 |
| 종류 | 장비. 슬롯에 있으면 자동 적용 |
| 내구도 | 없음 |
| 키 | 우클릭 유지 중 켜짐, 놓으면 꺼짐. 마우스 시선 추적, 이동 가능 |
| 대상 | 숨겨진 낙서(UvMark) |
| 성공 | 원뿔 안·시야 열린 낙서가 노란 형광으로 표시. 비출 때만 보임 |
| 최초 발견 | 0.5초 전기음 + 낙서 쪽 카메라 1회 회전(마우스 시선 시점). 발견은 런 동안 팀 공유 |
- 배치: 로비 `lobby-uv-lamp-1~4`(정식). 더미 UV 제거.
- 남은 결정: 키맵의 UV 버튼(마우스) 재설정 허용 여부, 정식 효과음·표시 그림·형광 농도.
