- 침대 밑 머리핀: Bed_B 실제 충돌체의 서쪽 가장자리에서8cm 밖, 약(17.996,.04,80.575)로 옮김. 기물 표시 일부가 침대 아래에 남고 접근/시야 검사가 가능해짐. UID/내구도/수량은 유지.

- 기존 계단 열쇠→문 조건과 개방 후 문짝/충돌 해제 재사용. 다른 방 배치·확률·내구도 변경 없음.
- 좁은 범위 Editor 메뉴: CurtainCall/Waiting Room/Fix Bed Pickup And Stair Access. 다른 탐색 배치를 전부 재설치하지 않음.
