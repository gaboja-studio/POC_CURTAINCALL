고정된 대기실 구조 A에서 조사·도구 사용·숨은 길 개방·밤 정비가 이어지는 플레이 흐름을 만든다. 개발 진행 중(PM 승인). dev에 같은 번호 Task-078(조작·외줄 구조)이 있어 이 Task는 079로 바뀌었다. 모든 기능은 최신 dev 병합본 기준으로 작업한다(2026-10-29 사용자).

공간 제작 Task-075와 공통 시스템 Task-076을 참조한다. 기존 코드의 존재를 M2 구현 완료로 간주하지 않고 착수 시 실제 반영 상태를 조사한다. 공통 런 상태·경제·기물 처리와 중복 구현하지 않는다.

## 확정된 범위 — 사용자 지시

- 랜덤 구조와 B·C는 제외하고 공간 구조 A부터 개발한다.
- 적합한 도구로 숨은 길의 벽을 반복 타격하면 파괴되고 통로가 드러난다. 타격 횟수·사용 도구·내구도 차감은 미정이다.
- 조사 가능한 단서를 배치하고, 들어서 회전·확대하며 앞뒤를 확인하는 오버뷰 기능을 추가한다.
- 기물 시스템을 참고해 탐색용 기물과 사용 대상을 추가한다.
- 밤 정비를 추가한다. 튜토리얼은 보류한다.
- **연습실 기능 개발과 대기실 로비 타이머 작업은 보류한다.** 외줄·인간 대포 무패널티 연습, 연습 기구 활성화, 로비 시계·타이머 구현/변경을 이번 실행 순서에서 제외한다. 기존 배치나 기능을 제거한다는 뜻은 아니다.
- 스케줄표의 공연 선택·편성은 보류한다. 기존 준비 완료 입력만 침대 상호작용으로 옮긴다. 전원 침대 준비로 밤 정비를 종료하며 스케줄표 준비 입력은 종료 조건에서 제외한다.
- 공연 기본값은 외줄타기로 고정한다. 공연 해금·튜토리얼·탈출 진행·세대 교체와 무패널티 범위의 기획/구현은 보류한다.

## 기존 기능 수정 대상 — M2 문서 기준, 착수 시 반영 여부 확인

| 대상 | 수정·연결 요구 |
|---|---|
| 상점·배송구 | 밤 정비 구매 제한, 공동 자금·배송·수령 연결. Task-076 반영 여부 우선 확인 |
| 전문가 서비스 | 일정·시설 서비스 제거, 신체 복구로 정리. 쉬는 시간·밤 이용과 M2 가격 연동 |
| 소품실 | 일반 보관과 기물 연동 확인. 가판대 계승·세대 교체 수정은 보류 |
| 낮·밤 공간 | 전력·철창·이용 가능 기능 변경 및 다음 날 복원 |
| 공연 복귀·전환 | 로비 복귀, 무대 입구 통로 집결과 공통 전환 연결 |

쉬는 시간 종료·추격·안전지대 폐지 요구는 문서상 남아 있다. 다만 **로비 타이머 보류에 따라 시간 기반 추격·경보·자동 전환의 구체 구현 순서는 재개 시 정한다.** 이번에 임의로 타이머 개발을 포함하지 않는다.

## 신규 기능

- 단서 조사·오버뷰: 대상 선택, 들기, 회전·확대, 종료와 입력/시점 복귀.
- 반복 타격 벽: 도구 판정, 진행 표현, 파괴와 충돌 전환, 통로 개방.
- 탐색 도구 대상: 머리핀–자물쇠, 말뚝 뽑개–판자/덮개/서랍, UV 등–숨은 표식. 반복 타격 벽에 사용할 도구는 별도 결정.
- 기물 획득·사용: 슬롯·손에 들기·내구도·소진을 공통 기물 시스템과 연결.
- 탐색 진행: 열린 문·파괴 벽·발견 단서 상태를 같은 런 동안 유지.
- 준비 완료 이전: 스케줄표 입력을 침대로 옮기고 기존 밤 종료 흐름에 연결. 기본 공연은 외줄타기 고정.
- 밤 정비: 전력 차단, 탐색 입구 철창, 상점·치료, 침대 준비·취소, 전원 수면·기상.
- 튜토리얼은 보류하며 현재 신규 기능에 포함하지 않는다.
- 탈출 진행·입구 집결·전환 연결은 보류한다. 숨은 통로 개방은 독립 탐색 상호작용으로 개발한다.

모든 공유 상호작용에 동시 사용·중복 획득 방지와 팀 상태 일치를 포함한다. 영구 저장·세션 밖 계승은 확정 범위가 아니다.

## 개발 순서와 완료 기준

1. 기존 구현 조사·연동 규약: Task-075/076과 기능별 유지·수정·신규 범위, 공유 데이터와 담당 연결 확정.
2. 조사·오버뷰: 단서 하나를 들고 회전/확대한 뒤 플레이로 정상 복귀.
3. 도구·개방: 기물 하나 획득→사용→벽/잠금 개방의 최소 탐색 경로 완주. 구체 도구·횟수는 기획 후 적용.
4. 상태 유지·다인원 검증: 중복 획득/파괴 없이 팀에 같은 상태 적용, 같은 런 재진입 시 유지. 공유 처리는 2~3단계부터 함께 작성.
5. 밤 정비·기존 서비스: 공연 복귀→전력/철창→구매/치료→침대 준비/취소→수면→다음 날 복원.
6. 구조 A 콘텐츠: 단서·도구·사용처와 숨은 길을 배치하고 탐색 상호작용의 연결을 확인. 튜토리얼·공연 해금은 제외.
7. 통합 확인: 조사→도구 획득→개방과 밤 정비→침대 준비→다음 날 외줄타기 기본값을 확인. 2~4인 동시 상호작용·중도 이탈 검증. 세대 초기화와 탈출 전환은 제외.

연습실·무패널티 범위·로비 타이머와 시간 초과 흐름·스케줄표 편성·튜토리얼·공연 해금·탈출 진행·세대 교체는 위 완료 기준에서 제외한다. 침대 준비 완료 이전과 외줄타기 기본값 고정만 스케줄 관련 현재 범위다. 재개 승인 후 별도 순서를 추가한다. 완료 여부는 코드 검토·플레이 검증 근거로 todo/log에 기록한다.
