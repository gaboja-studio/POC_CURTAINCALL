# 밤 정비 연결 (2026-10-29)

Task-079, 현재 feat/waiting-room/design-rooms. dev 통합본 위에서 작업. 보류한 연습실 기능·로비 타이머·튜토리얼·공연 해금·탈출 진행·세대 교체·스케줄 편성은 수정하지 않았다.

## 구현
- 구조 A 로비의 연습실 복도, 소품실/작업실 복도, 화물/무대 장치 복도, 지하 계단실 입구에 철창 4개. 낮에는 위로 접혀 있고 밤·수면에는 닫힌다. 기존 무대 통로 야간 셔터도 유지한다.
- NightPower: 조명170개를 밤·수면에 끄고 낮에는 각 조명의 원래 상태로 복원. 숙소·상점·전문가·휴게 공간의 회로와 숙소 방향 독립 비상등은 유지. 일시 비활성/씬 종료 시에도 조명 원래 상태를 돌려놓는다. 발광 재질과 서비스 화면 전원은 별도다.
- NightBed→BedRestView: 준비 시 침대 위 로컬 시점으로 부드럽게 눕고 이동 입력을 막는다. 밤에는 F/ESC로 준비 취소·즉시 시점 복귀. 전원 준비 시 기존 DemoRunEnding 암전 장벽과 다음 날 흐름을 사용하고 기상 시 시점/입력을 복원한다.
- 준비 인원 판정·호스트 공유는 기존 CampaignRun을 사용한다. 새로운 침대 예약/소유권 규칙은 넣지 않았다. 원격 캐릭터의 전신 눕기 애니메이션은 미구현이다.
- 생성기 ConnectNightMaintenance는 기존 NightMaintenance 그룹만 교체한다. 원본 Greybox와 다른 방 내부는 재생성하지 않는다. 백업 .harness/local/night079/before.unity.

## 검사와 다음
