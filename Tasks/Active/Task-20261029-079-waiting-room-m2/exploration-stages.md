# 구조 A 탐색 전체 작업 단계

범위(2026-10-30 갱신): 기존 내구도 유지. 사용자 배치도·최신 목록으로 실제 맵 단순 배치를 재개했다. 기존 패널·근접 외곽선 사용. 상세 아트·서사 문구·랜덤 드랍·엔딩은 후속. 멀티는 후순위, 최대2인.

| 단계 | 만드는 내용 | 현재 상태 |
|---|---|---|
| 1. 기존 기능·규칙 확인 | F/조사/획득/머리핀/UV/빠루/파괴/공유 상태 대조 | 완료 |
| 2. 공통 탐색 기능 | 조건 개방/보상/드랍/모니터/패드/숨은 문/협력 | 코드 및 단일 환경 검사 완료 |
| 3. 열쇠·도구 경로 | 열쇠1→강철상자→관리실 열쇠, 잠긴 상자→계단 열쇠→문, 캐비넷/서랍→탈출 열쇠 두 개 | 연결 컴포넌트·개방 후 도구 생성 구현, 전용 PlayMode1/1 PASS. 7단계에서 실제 씬 참조 연결 |
| 4. 파괴·보상 대상 연결 | 숙소2/배관1/화물3/휴게2 상자, 빈/지도 캐비넷, 잠긴 상자 보상 | 연결 코드·전용3/3 및 회귀6/6 PASS. 7단계에서 실제 씬 참조 적용 |
| 5. 조사·힌트 경로 연결 | 낙서/노트/신문/기록/모니터/UV/앞뒤2자리/숨은 낙서 | 연결 코드·전용2/2 및 회귀8/8 PASS. 7단계에서 실제 씬 참조 적용 |
| 6. 숨은 경로·탈출로 문 연결 | 화장실 벽/기계실 숨은 문/패드/두 열쇠+협력 문 | 연결 코드·전용3/3 및 회귀8/8 PASS. 7단계에서 실제 씬 적용·실제2인 미검증 |
| 7. 정식 배치·표현 | 11개 구역 배치/접근/충돌/모델/효과음/텍스트 | 사용자 지시로 재개, 실제 씬 배치·참조 저장 |
| 8. 전체 흐름 검사·수정 | 조사→획득→도구→개방→해석→탈출로 문 | 개별/일부 경로 검사, 전체 흐름은 미완료 |
| 9. 실제2인 검사 | 협력/공유/중복/이탈/상태 재수신 | 후순위, 최대2인 |

3~6단계의 참조는7단계에서 실제 WaitingRoomBase 씬에 저장했다. 아래 표의 미정값은 최초 연결 계약 이력이며 최신 확정값은 stage-07-placement.md와 실제 배치 명세를 우선한다. 전체 도보 동선 확인·실제2인은 여전히 미검증이다.

## 구조 A 연결표 (정식 배치 전 계약)

| 구역/대상 | 기능 연결 | 남은 지정 |

| 숙소 캐비넷1·2 | 머리핀 ToolTarget, 빈 보상 / 열리면 지도 Clue 표시 | 표시 자식 참조 |
| 숙소 강철상자 | Gate.requiredTargets에 열쇠1 획득 ID, 개방 후 관리실 열쇠 Gate 표시 | 관리실 열쇠 사용처 미정 |

| 폐기물 잠긴상자1→계단열쇠→계단문 | 머리핀 ToolTarget→열쇠 Gate 표시→문.requiredTargets | 자식/문 참조 |

공연용 인간 대포·트램펄린 연결과 탈출 엔딩은 제외. 앞/뒤2자리 단서는 사람이 해석할 힌트이며 자동 문자열 조합 기능을 임의 추가하지 않는다. 확정하지 않은 획득처·보상·밸런스는 기획 확정으로 기록하지 않는다.
