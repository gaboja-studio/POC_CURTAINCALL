# 완료한 씬·배치·카메라 후속 계획

## 플레이 중 배치 창 경량화·플레이어 추적
- Play에서는 3D Camera/RenderTexture/팔레트/SerializedObject 편집 UI를 해제하고 2D 방·경로·마커 및 추격 연결선으로 관찰한다. 10Hz 갱신, 층 기준 캐시, 숨긴 탭은 갱신 중단.
- 플레이어 선택/추적과 자유 모드를 제공. 추적은 위치·층·중심 방을 따라가고 드래그/방·층 선택 시 자유 모드로 전환. 관찰 대상 생성/제거·씬 이동·Play 종료 때 자원 정리.
- 실제 호스트 창의 자원/전환/이동 회귀, 기존 편집 층 검사, UI 확인 및 check-work.

## dev 통합 준비: 대기실 선택
- 공통 장소 전환 설정에 Base/Pursuit 선택, 실제 런·Dev/치트·카메라·로그·음성에 연결. Base 기본은 튜토리얼 작업용으로 추격 비활성, 두 씬은 모두 빌드 유지.
- 이동된 InGame Pursuit 경로 사용. 원본 씬·진행 중 대량 에셋 이동은 보존. 양쪽 라우팅/실기 회귀 및 check-work.

## 씬 경로 이동 내구성·Scene 뷰 확인
- 대기실 편집 경로를 GUID로 조회, 플레이어에서는 빌드 씬 경로 조회. 배치/Live 마네킹 더블 클릭으로 선택·Scene 뷰 근접 표시. 감시 지점은 프레이밍 범위에서 제외.

## Scene 이동과 순찰 분리
- Scene Transform 수정에도 순찰 지점의 월드 위치 보존. 순찰 선분까지 기본10m 초과 시 해당 배치만 경로 해제(개별 조정/0비활성), 배치 창3초 알림. Undo/Redo 및 공용 경로 보존 검증.

## 씬 이동 후 숨김 미리보기 잔류 수정
- 씬 닫힘/활성 씬 전환/열림/리로드/종료에 미리보기 정리. 숨긴 탭에서도 정리, 편집은 활성 씬 Director만 사용. 저장 데이터 불변·Pursuit→Start→Pursuit 회귀.

- CLI 상태 확인 Console 명령 오류: 호출별 Editor.log 횟수로 발생원 분리, verify-unity 직접 editor_status 조회로 교체·경로 검증 유지.

## 둥근 로비 천장 재투과
- 실제 로비 돔에서 카메라가 천장 위로 나가는 회귀 재현. 평면 OBB 적용 밖이던 로비/연습실 돔·원통 벽에 양면 메시 구체 스윕 적용, 문/빈 공간 보존 및 물리/NavMesh 불변. 실제 씬·곡면 수학·기존 평면 회귀 후 최종 검사.

## Base/Pursuit 전체 구조물 카메라 충돌
- 사용자 요청으로 원본 Base도 포함. 두 씬 활성 메시 전수 비교 후 방·통로·층간 바닥·천장·외벽·엘리베이터 구조물 공통 저작 규칙 적용. Cube만 OBB, 합쳐진 면/곡면/개구부는 양면 메시 검사. 시각적으로 열린 패널은 차단 해제. 배치/물리 불변·저장 후 면 샘플·통로 내부·실제 카메라 회귀/성능 확인.
