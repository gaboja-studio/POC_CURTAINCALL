## 플레이 피드백 수정 계획·결과
1. 사용자 첨부의 뒤틀린 관절을 기준으로 7개 모션별 정면/후면/좌/우 × 4키 원화를 먼저 제작하고 `_ThirdParty/curtaincall/Pursuit/Concepts`에 보관했다.
2. Blender MCP로 10종 전시 자세에 맞춘 관절/가중치와 결손 부위를 수정했다. 캐릭터 기준 회전축·발 IK·각성 local 보간으로 전체 70클립을 재생성했다.
3. 공통 UI의 고정 씬 이름 판정을 대기실 binding 기반으로 보완했다. Start/Dev 진입·재진입에서 ESC 메뉴와 인벤토리 표시를 검증했다.
4. Unity 실제 스키닝 샘플·4방향 검토 시트, 검사 결과와 한계를 기록한다. 사람의 모션/공포감 및 다인 실기는 기존 미완료 항목으로 유지한다.

## 포획 후 공연 외형 불일치 수정
- 사용자 실행 중인 Tightrope에서 LostParts=13/Model.Stage=3인데 Original.enabled=true인 상태 확보. 데이터와 기어가기 판정은 외팔, 렌더러만 온전한 몸이었다.
- PursuitVictimPose가 포획 전 Renderer.enabled를 복원하여 이후 절단 표시를 덮어쓴다. 포획 가림을 forceRenderingOff로 분리하고 현재 부상 메시 선택은 HumanoidModel에 맡긴다.
- 숨김 중 절단·가림 해제와 실제 호스트 포획→공연 이동을 반복 검사한다.

## 근접/추격 피드백 및 기획자 배치 도구
- 근접 마네킹에 빨간 외곽선. 실제 로컬 플레이어를 추격하는 경우만 부드러운 화면 가장자리 맥동. 거리·강도·폭·맥동 설정 제공.
- 레퍼런스: DBD 개발자의 Visual Terror Radius (https://forums.bhvr.com/dead-by-daylight/kb/articles/382-developer-update-march-2023), Dying Light 공식 추격 단계 (https://outpost.dyinglightgame.com/news/nightmare-mode-update). 전자는 위험의 시각적 맥박, 후자는 추격 심화에 따른 강도 변화를 참고한다. 화면 테두리 구성은 이 프로젝트에 맞춘 설계다.
- 기존 IMGUI 도구 패턴의 Mannequin Designer: 방 좌우 전환/탑뷰·천장 절단, 10종 팔레트 드롭·지면 보정, 선택/삭제/타입/회전/드래그, 개별 순찰 지점 추가/이동/순서, 전체 구조도와 Play 실시간 위치.
- 기존 방 공용 스폰/순찰은 보존하고 개별 PursuitPlacement로 전환. 호스트·클라이언트 모두 동일 배치 순서로 생성하며 추격 대상 ID도 동기화한다.
- 변경 후 컴파일, 배치/Undo/순찰 및 소유자별 피드백 회귀, 실제 창과 게임 화면 확인, check-work 1회.
- 후속 요청: 평면도와 함께 바닥 높이를 기준으로 한 층별 측면도(Z/Y·X/Y 전환)를 표시한다. 현재 방은 두 구조도에서 주황 배경/굵은 테두리를 최상단에 그리고 방 이름을 명시한다. 클릭 전환·Play 위치 표시를 공유한다.
- 후속 탐색 개선: 빈 공간 좌클릭/중클릭 드래그로 탑뷰 팬, 화면 중심·현재 층에 따른 자동 방 선택(카메라 위치/확대 유지), 층 선택/F 재프레이밍, 전체 중복 없는 배치 합계와 방별 수 표시. 마커 드래그 편집은 유지한다.

## 포획 정렬·인지 행동·렌더 최적화·유혈
- 포획 시작 시 누울 몸의 머리 방향과 골반 기준 공격 위치를 고정하고 호스트/수신 화면에 공유한다. 일반 상체 추적이 포획 자세를 비틀지 않게 한다.
- Unity Behavior 패키지의 실제 그래프로 순찰/청각 확인/조사/공격 준비/추격/마지막 위치 수색을 실행. 걷기·달리기 소리는 호스트에서 이동 및 동기화된 달리기 상태로 생성하며, 소리 위치만 기억한다. 단계별 반경/기억/준비·수색 설정을 배치 창에 노출한다.
- 모든 플레이어와 추격자의 최대 상대 접근 속도×5초에 여유를 더한 거리 밖에서 렌더러만 숨김. 포획·카메라 가시/관전 등은 보수적으로 유지하고 AI/내비/동기화는 지속한다.
- 기존 게임/개인 유혈 설정을 함께 준수하여 포획 중 반복 몸 파티클 및 피해자 화면 혈흔을 추가한다. 제작 에셋/Behavior 그래프는 _ThirdParty, 코드는 Scripts에 둔다.
- 경계·청각/시야 전환·포획 다방향·유혈 설정/정리·렌더 복귀 회귀 검사와 실제 플레이 확인 후 check-work 1회.

## 대기실 타이머·추격 치트
- F9 치트에 대기실 RestTime 전용 시간/추격 상태, 초기화·철회, ±60초, 60초 설정, 즉시 만료·추격 시작, 단계 고정/자동 복귀 추가. 호스트/오프라인 및 Dev 모드만 허용.
- 초기화는 현재 시간대 설정값(무제한 포함) 복원. 양수 시간 설정도 진행 중 추격을 철회하고 피해자 조작/관전을 풀되 이미 생긴 부상은 보존. 추격자·포획/유혈·단계 고정도 해제하며 같은 런의 클라이언트에 철회 상태를 동기화.
- 단계 고정은 설정 에셋을 수정하지 않는 런타임 override이며 시야/속도/청각 전체에 적용한다. 다음 추격/시간대에는 해제.
- 순수 시간 규칙 및 호스트 치트→포획 중 철회→재추격 회귀, UI 확인 후 check-work 1회.

## 배치 창 층 표시 일치
- 층 선택을 평면도/측면도/탑뷰 렌더/마커/히트 테스트에 공유. 방 전환 시 해당 층으로 전환하고 층 변경 시 유효한 방을 타겟한다.
- 탑뷰 카메라에 아래층 절단도 적용하여 다른 층의 바닥/마네킹이 보이는 문제를 제거한다. 같은 층에 보이는 마커는 중심 방과 달라도 직접 선택 가능하게 한다.
- 기존 배치·씬은 보존. 층별 표시/선택 회귀 및 실제 창 검토 후 check-work 1회.

## 로비 지면 판정
- Lobby 감지 볼륨 minY=-3 때문에 기존 ray 시작=-.5가 바닥(0) 아래였다. 배치/순찰/스폰 높이를 기준으로 ray를 시작하고 하부 다른 층은 제외한다.
- 로비형 볼륨·일반 방·실제 로비 배치 판정 회귀 확인 후 check-work.

## 드래그 중 층 이탈
- 숙소 마네킹 Y1.915를 방의 층으로 사용해 0m 층에서 방/마커/프리뷰가 사라지는 상태 확보. 층/지면 기준을 고정 스폰·방 순찰 기준으로 통일하고 가변 배치/가구 표면에서 분리한다.
- 사용자 현재22체 배치·위치 보존, 이동/삭제/재개방 후 층 유지 회귀와 실제 창 복구 확인.
- 후속 지시: 추격 전에는 장식처럼 보여야 하므로 근접 빨간 아웃라인을 표시하지 않는다. 추격 시작 후 활성화, 철회하면 즉시 제거.

## 부상 후 공연에서 부유
- 포획 해제의 모델 높이 복원과 정지 상태 애니메이션 전환을 조사. 기존 포획 회귀에 현재 부상 높이·정지 기어가기 자세 검사를 추가하고 최소 수정한다.

## 카메라 긴급 수정·추격 조정 편의
- 같은 브랜치에서 Pursuit 복제 씬의 스프링 암 활성 조건을 수정하고 벽/천장 회귀 검증. 원본 씬·사용자 배치는 보존한다.
