# 추격자 배치 창

`Tools > Curtain Call > Pursuit > Mannequin Designer`에서 연다. 테스트 씬은 `WaitingRoomPursuit`이다. 다른 씬이면 창의 **추격 테스트 대기실 열기** 버튼으로 이동한다.

## 방과 마네킹
- 상단 **이전 방 / 다음 방** 또는 방 목록으로 전환한다. 작은 전체 구조도에서 방을 클릭해도 이동한다.
- 탑뷰 **빈 곳을 왼쪽 버튼으로 드래그**하거나 **가운데 버튼으로 드래그**하면 화면을 이동한다. 마네킹·감시 지점 위의 왼쪽 드래그는 해당 요소를 편집한다. 감시 지점 추가 모드에서는 가운데 버튼으로 화면을 이동한다.
- **중심 방 자동 선택**이 켜져 있으면 화면 중앙 십자점이 들어간 방을 현재 방으로 선택한다. 이동 중 확대율과 카메라 위치는 유지하며, 같은 위치에 겹친 방은 **층** 목록의 높이를 기준으로 구분한다. 자동 선택을 끄면 현재 방을 고정한다.
- 중심이 방 밖이면 **중심에 해당하는 방 없음**으로 표시한다. **현재 방 맞춤(F)**으로 마지막 방에 복귀하거나 구조도/방 목록에서 방을 선택한다. 같은 층의 회색 마커도 직접 클릭하면 그 마네킹과 소속 방을 함께 선택한다. 팔레트 드롭은 화면 중심이 아니라 놓는 위치의 방을 사용한다.
- 상단 **전체 배치 N체**는 현재 대기실의 모든 방·층에 배치된 마네킹 합계다. 방 목록과 현재 방 정보에는 방별 개수도 표시한다. Play에서는 별도로 **실행 N체**를 표시한다.
- 상단 공통 **층** 선택은 **평면도(X/Z)·측면도·탑뷰 배치 화면**에 함께 적용한다. 해당 층의 방/마커/실시간 추격자만 표시하며, 다른 층의 메시가 비치지 않도록 탑뷰의 위·아래를 모두 절단한다. 선택 층의 방 수·배치 수와 모든 층의 전체 합계를 구분한다.
- 방 목록에서 MachineRoom 같은 방을 고르면 그 방의 층으로 자동 전환한다. 층 변경 시 화면 중심의 방을 타겟하고, 그 위치에 방이 없으면 해당 층의 가까운 방으로 맞춘다. 측면도는 앞뒤/높이(Z/Y) 또는 좌우/높이(X/Y)로 전환한다. 층은 방의 공용 순찰/고정 스폰 높이(m)를 사용하므로 마네킹을 가구 위로 옮기거나 삭제해도 변하지 않는다.
- 현재 탑뷰의 방은 두 구조도에서 **주황색 배경과 굵은 이중 테두리**로 표시하고 위에 **현재 방 이름**을 적는다. 겹치는 영역보다 마지막에 그려져 가려지지 않는다. 측면도에서도 방 클릭으로 전환하고 Play 중 이동 위치를 볼 수 있다.
- 왼쪽 10종 마네킹 카드를 가운데 탑뷰의 바닥으로 드래그한다. 벽/천장 대신 실내 바닥에 Y를 맞추며, 바닥이 없으면 배치하지 않는다.
- 탑뷰 원형 마커를 클릭해 선택한다. 끌어서 이동하고, 오른쪽 타입 목록으로 교체한다. **↶ / ↷** 또는 Q/E로 15도씩 회전한다. 각도 슬라이더도 사용할 수 있다.
- 오른쪽 **마네킹 제거**로 선택 개체를 지운다. Delete는 선택한 감시 지점이 있으면 지점을, 없으면 마네킹을 지운다.
- 휠로 확대/축소한다. 모델이나 벽이 가려지면 **천장 절단 높이**를 조절한다. 이 값은 미리보기 카메라만 바꾼다.
- Ctrl+Z / Ctrl+Y로 실행 취소/다시 실행. 마지막에 상단 **저장**으로 이 씬과 대기실 설정을 저장한다.

## 개별 순찰
- 마네킹 선택 → **바닥 클릭으로 감시 지점 추가** → 탑뷰에서 위치를 차례대로 클릭한다. Esc로 추가 모드를 끝낸다.
- 번호 마커를 끌면 바닥에 맞춰 이동한다. 오른쪽 목록의 ↑/↓로 순서를 바꾸고 ×로 제거한다.
- 화살표 순서대로 마지막 지점에서 첫 지점으로 반복한다. 지점 0개는 시작 위치 대기, 1개는 그 지점을 지킨다.
- 마네킹 시작 위치/각도를 바꿔도 감시 지점은 기존 월드 위치를 유지한다.
- 기존 방 공용 Count/SpawnPoints/PatrolPoints는 보존되지만, **UsePlacements**가 켜진 방은 개별 배치 목록을 사용한다. 기존 배치 가져오기는 다시 실행해도 중복 생성하지 않는다.

## 단계와 연출
- **단계 / 연출** 탭에서 전역 단계별 시작 시간, 기본 이동·달리기 m/s, 시야각·거리, 벽 투시·최인접 추격, 알림 문구를 바꾼다. 선택 단계의 시야가 탑뷰에 부채꼴로 표시된다.
- 단계는 추격 시작 후 누적 초를 기준으로 한다. 위치 무관 최인접 추격 단계는 시야 거리/각도를 무시한다.
- 근접 강조는 **추격 시작 후에만** 5m 이내 빨간색3px로 표시한다. 추격 전/만료 직전 경고 중에는 장식처럼 보이며 아웃라인이 없다. 추격 철회 시 제거한다. 벽을 투시하지 않고 실제 보이는 메시 윤곽을 표시한다.
- 화면 연출 기본값: 가장자리 강도 .65, 폭 .19, 맥동 .35. 실제 내 캐릭터가 추격 대상일 때만 거리·단계에 따라 빨간 테두리가 부드럽게 맥동한다. 맥동 0은 고정 테두리, 효과 사용 해제는 화면 효과 전체 끄기다.
- 전역 설정은 `WaitingRoomSettings`에 저장된다. 다른 방도 같은 단계 규칙을 사용한다.

## 청각·행동·렌더·포획 효과
- **단계 / 연출**에서 걷기/달리기 청각 반경(기본6/14m), 직접 조사 거리 비율(.65), 벽 뒤 청각 거리 배율(.6), 공격 준비(.7초), 두리번 확인(1.6초), 소리 조사 제한(7초), 놓친 위치 수색(3초), 추적 유지 거리(26m)를 단계별로 설정한다.
- 발소리는 이동한 거리마다 발생한다. 멈추거나 공중에 있으면 발소리가 나지 않는다. 가까운 소리는 순찰을 중단하고 그 위치를 조사하며, 먼 소리는 방향을 틀고 두리번거린다. 소리만으로 플레이어의 이후 위치까지 알지는 못한다.
- 시야로 발견하면 공격 준비 후 추격한다. 시야를 놓치면 마지막으로 본 위치까지 추격하고, 추적 시간/거리 제한을 넘으면 수색 후 순찰로 돌아간다. 마지막 위치 무관 추격 단계는 거리 제한을 무시한다.
- 실제 Unity Behavior 그래프: `Assets/_ThirdParty/curtaincall/Pursuit/Behaviour/PursuitBehaviour.asset`. 반복되는 Try In Order 아래에 준비→추격→소리 조사→소리 확인→수색→순찰 노드가 있다. 호스트가 판정하며 Play 탑뷰 마커에 현재 행동을 표시한다.
- 원거리 렌더 숨김은 모든 플레이어와의 상대 최대 이동 속도×최소5초에 여유를 더해 판단한다. 카메라에 보이거나 가까운 추격자·포획 중인 추격자는 유지한다. 숨겨도 내비게이션/행동/동기화는 실행되고 구조도에도 위치가 남는다.
- 포획 시 누울 몸의 축을 고정하여 골반 쪽에 올라앉고 머리를 향해 공격한다. 유혈은 기존 게임의 혈흔 사용과 개인 혈흔 표시가 모두 켜져야 한다. 몸 분출 간격/양과 피해자 화면 혈흔 강도를 조절할 수 있다. 설정 OFF·포획 종료·장소 전환 시 정리한다.

## Play 관찰
- Dev Mode에서 대기실 진입 후 **F9 → 대기실 · 타이머 / 추격**을 사용한다. 호스트/오프라인만 조작 가능하며 클라이언트에는 상태와 권한 안내를 표시한다.
- **초기화 및 추격 철회**는 현재 아침/가이드/공연 사이 기본 제한시간(무제한 설정 포함)을 복원한다. **-1분/+1분/1분 남음**은 유한 시간으로 설정하며 양수면 추격을 철회한다. 0 이하 또는 **오버 및 추격 시작**은 안전 구역에서도 즉시 추격한다.
- **단계 버튼**은 추격을 시작하고 해당 단계를 고정한다. **자동 진행으로 복귀**는 실제 추격 경과시간 기준 단계를 적용한다. 초기화·철회·시간대 이동은 고정을 해제한다. 설정 에셋에는 저장하지 않는다.
- 철회는 포획 자세·유혈·입력 잠금/리타이어를 해제하지만 부상은 보존한다. 완전 회복은 같은 F9 창의 **모두 되살리기**를 사용한다. 타이머 치트는 대기실 쉬는 시간에만 표시한다.
- Start → 호스트 → 런/Dev Mode로 대기실에 진입해 확인한다. 플레이 중 창은 가벼운 **2D 구조도**로 전환한다. 3D 카메라/렌더 텍스처·팔레트·편집 UI를 사용하지 않고 보이는 동안10Hz로 갱신한다. 방과 고정 벽/기둥 윤곽을 표시하며 문·가구의 상세 3D 모습은 Game 뷰에서 확인한다.
- **플레이어 추적**: 기본은 내 플레이어를 따라간다. 옆 목록에서 관찰할 플레이어를 선택할 수 있으며 위치·층·현재 방이 자동으로 바뀐다. 대상이 사라지면 내 플레이어 자동 선택으로 돌아간다.
- **자유 모드**: 기존처럼 드래그·휠·방/층 선택으로 둘러본다. 추적 중 드래그하거나 방/층을 직접 선택하면 자유 모드로 전환된다. 다시 플레이어 추적을 누르면 선택한 대상을 따라간다.
- 초록 마커는 플레이어다. 마네킹 점 또는 오른쪽 목록을 클릭하면 현재 행동·추격 대상·렌더 상태, 순찰 경로와 시야·추격 연결선을 표시한다. **전체 행동 이름**을 켜면 모든 마네킹의 행동을 함께 표시한다.
- 전체 구조도는 방별 현재 수와 이동 위치를 갱신한다. 빨강은 추격, 청록은 순찰/활성 상태를 나타낸다.
- 추격 테두리는 다른 팀원을 쫓거나 전시 중인 마네킹만 가까이 있을 때는 켜지지 않는다. 포획/관전/장소 전환 때 정리한다.
