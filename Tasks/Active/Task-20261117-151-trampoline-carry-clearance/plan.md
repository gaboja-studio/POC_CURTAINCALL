## Context
대기실과 탈출로에서 트램펄린을 들고 벽·기둥을 지날 때 가장자리의 겹침을 허용한다. 추격자는 운반 충돌로 밀리지 않아야 하며, 내려놓기에는 기존 전체 충돌체를 사용한다.

## 계획
- 대기실의 기존 1m 운반 검사를 두 공간에서 공유한다. 캐릭터 이동과 장치 반동은 각자의 기존 판정을 사용한다.
- 들고 있는 동안 전체 충돌체를 트리거로 유지한다. 호스트가 바닥과 전체 충돌체를 검사하고 배치 끝에 충돌을 복원한다.
- 대기실 추격자의 기물 밀어내기와 탈출로 추격자의 물리 충돌을 확인한다.

## 미정·주의
