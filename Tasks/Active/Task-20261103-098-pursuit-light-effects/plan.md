## Context
추격 단계별로 전등 느낌을 바꿔 위협을 전달한다. 1~4단계는 누적 적용, 플레이어 간 동기화, 기획/디자이너가 단계별 값을 조정할 창 제공.
- 공통(포획): 포획된 방의 전등이 깜빡일 때 꺼진 순간은 완전 암전. 그 방 안의 모든 플레이어 화면에 적용.
- 1단계: 밝기 저하. 2단계: 잦은 지직임 + 스파크 파티클. 3단계: 시작 시 2~3회 깜빡임 + 플레이어 방/근처 방 랜덤 주기 깜빡임. 4단계: 약간 붉은 색.

## 구현
- `PursuitLightSettings`(WaitingRoomSettings › Pursuit › Lighting): 추격 단계 인덱스와 같은 조명 단계 배열 + 포획 암전·스파크 공통값. 기본값은 누적형.
- `PursuitLighting`(PursuitDirector에 자동 추가): 방 지정 조명 + 미지정 점/스포트 조명(위치로 방 판정)의 원래 값을 보관하고 매 프레임 밝기·색·깜빡임 적용, 추격 종료 시 원복. 환경광은 `RenderSettings.ambientProbe`·반사 강도를 직접 스케일(런타임 Trilight 색 변경은 프로브에 반영되지 않음).
- 동기화: 단계·경과 시간은 기존 스냅샷, 방 깜빡임(방·시작 시각)은 호스트가 골라 스냅샷에 추가. 지직임·암전 모양은 공통 시드+위치 정렬 조명 인덱스의 결정적 해시. 클라이언트 경과 시간은 10Hz 사이를 보간.
- `PursuitRoom`: 직접 조명 조작 제거, 포획 암전 시간만 보관.
- `PursuitLightingWindow`(Tools/Curtain Call/Pursuit/Lighting Designer, 배치 창 단계 탭에서도 열기): 단계별 값, 누적 누락 표시, 색 견본, 플레이 중 단계 강제·방 깜빡임·시작 깜빡임·포획 암전 미리보기.

## 미정·주의
- 기본 수치(밝기 0.5, 환경광 0.6, 지직임 분당 5회, 방 깜빡임 14초, 붉은 색 35%)는 오프라인 캡처 기준 초안. 최종 체감은 사람이 확인.
- 다인 실기(클라이언트 화면 일치) 미확인.
