# 체크포인트 편집과 F9 부활

1. 외줄, 인간 대포 또는 탈출로 씬을 열고 `Tools > CurtainCall > Dev > 체크포인트 편집기`를 엽니다.
2. **씬뷰 클릭으로 배치**를 누르고 충돌체가 있는 바닥을 클릭합니다. 선택 오브젝트나 씬뷰 중심에서 추가할 수도 있습니다. 행을 드래그해 F9 순서를 바꿉니다.
3. 행을 더블 클릭하면 씬뷰가 그 위치를 비춥니다. 핸들이나 숫자 입력으로 월드 위치, 방향, 인정 반경을 맞춘 뒤 **씬 저장**을 누릅니다. 기존 자리·줄 연동이 필요 없는 지점은 **고정 좌표로 변경**을 선택합니다.
4. 호스트에서 Dev 모드를 켜고 F9를 엽니다. 순간이동 목록과 단원별 마지막 체크포인트가 함께 표시됩니다. 사망자가 있으면 **사망자를 각자의 마지막 체크포인트에서 부활**을 누릅니다.

인정 반경은 캐릭터 발과 체크포인트 사이의 3D 거리입니다. 앞쪽 지점을 다시 밟아도 이미 기록된 더 높은 순번은 유지됩니다. 외줄 지점은 쓸 수 있는 줄에서 기록합니다. 기록이 없는 사망자와 이동 전용 지점은 부활에서 제외됩니다. 새 시도·공간으로 이동하면 기록이 초기화됩니다.

Dev 모드에서만 기록합니다. F9의 **전원 사망 시 F9 부활 대기**를 끄면 일반 전멸 흐름을 바로 테스트할 수 있습니다. 갈대밭 엔딩 지점은 마지막 문이 열린 뒤 순간이동 목록에 나타납니다.
