# 월드 UI 원화 검토 · v2

상태: **부분 승인·공중 그랩 수정안 검토 중**, 실제 게임 캡처 아님. 독립 스프라이트/머티리얼/프리팹은 아직 없다.

2026-11-17 사용자 피드백: 그림자와 두 영역 UI의 프로그래스 바는 좋음. 위험 표시는 중앙 아이콘 없이 통일하고 피격 범위에 맞춰 조절. 그랩은 중간 경로에서도 잡히므로 공중 표시 가능성을 고려해 재검토 요청. A와 B/C 진행 표현은 승인된 내용으로 보존하며 다시 승인받지 않는다.

## 디자인 방향

기존 `curtaincall_performance_hud_v1/Source/style_contract_v1.json`의 C안(무대감독 계기판)을 기준으로 아이보리 `#F0EEDC`, 황동 `#BBA36B`, 위험 코랄 `#E06C78`, 버건디 `#A73546`, 경고 황색 `#F2B45B`를 사용한다. 실제 위험 위치에 놓는 경계·빗금·진행 표시로 번역한다.

- **A 그림자:** 추격자는 흐린 검정 원 1장, 테두리·기호 없음. 기존 플레이어 그림자와 옷 색/안전색 외곽선은 유지한다.
- **B 원형 위험:** 실제 원형 지면 위험·착지/도착 범위를 아이콘 없는 공통 링으로 표시한다. 그랩은 F로 이동한다. 투척의 도착 원은 공중 경로 전체를 대신하지 않는다.
- **C 사각 위험:** 낙하 장애물·화염 예고. 사각 경계, 옅은 내부, 가장자리 빗금, 바깥 진행 바. 중앙 아이콘 없이 실제 footprint에 맞춘다. 모서리 장식이 실제 피격 영역을 잘라 숨기지 않게 제작한다.
- **D 이동 경로:** 장애물 이동 통로·보스 돌진. 출발→도착 방향과 실제 통로 폭을 함께 표시한다. 왕복형은 양끝을 구분한다.
- **E 대포 궤적:** 포구부터 짧은 공중 곡선. `— — — ▶` 형태, 끝 화살촉 하나, 곡선을 따른 거리 설정. 전체 착지 위치 보장 표시는 아니다.
- **F 공중 위험 통로(새 검토):** 그랩 Origin→Aim의 구형 손 sweep 경계. 얇은 입체 경계선으로 폭·높이를 표시하고 중앙 점선/단일 끝 화살촉은 발사 방향만 표현한다. 진행 바는 바깥 경계에 붙인다. 지면 투영·도착점 원은 사용하지 않는다.

위험 표시는 실제 판정에 맞는 형태·크기와 공통 빗금/색으로 통일한다. 중앙 원인 아이콘은 모든 위험 영역에서 제외한다. 이동 방향을 전달하는 경로 화살촉은 별개다. 시안의 제목·라벨·설명·퍼센트 숫자는 검토용이며 게임 안에 표시하지 않는다.

- 생성 프롬프트: [concept-prompts.md](concept-prompts.md). 기존 HUD 아트를 눈으로 확인한 후 색·형태 계약을 프롬프트에 반영했다. 이미지 입력 없이 새 원화로 생성했다.

v1은 이력으로 보존한다. v1의 중앙 기호·그랩 도착 원 제안은 철회했으며 생산 기준으로 쓰지 않는다. 02의 길이 괄호는 설명용 수평 치수선이지만 실제 설정 계약은 곡선을 따른 거리다. 시안 배경의 대포/구조물은 분위기 예시다.

v2 시각 검토: B/C 중앙 비움과 진행 표시 유지, F의 지면에서 떨어진 경계·폭/높이·발사 방향·남은 경로를 확인했다. 원화의 통로 끝/인물/손 위치는 설명용이며, 실제 메시 양끝과 둥근 캡은 Origin/Aim 및 ArmRadius에서 계산한다. 시안의 인물은 경로 중간 접촉 예시로 게임 캐릭터 교체가 아니다.

## 검토 포인트

2026-11-17 사용자가 공중 그랩 통로 방향을 승인하고, 아이콘 없는 위험 표시와 함께 레이어 스프라이트·프리팹·GameSettings 연결 및 테스트 씬 캡처를 요청했다. 아래 제안은 승인 방향의 구현 기준이다.

이번 검토 대상은 F의 공중 캡슐 통로 표현이다. 방향 화살표만 있는 표시보다 폭·높이를 함께 읽을 수 있어야 한다. 준비 중에는 전체 예정 통로+시간 바, 발사 중에는 현재 손 위치부터 남은 통로, 회수·포획·취소 시에는 숨김을 제안한다. 실제 손 반지름·원격 공유 시각으로 조립하며 판정을 변경하지 않는다.

F의 경계선 개수·두께와 정면 가독성은 Unity에서 조절할 값이다. 공중 투척물에도 경로 중간 충돌이 있어 같은 뷰의 곡선 변형이 필요할 수 있으나, 이번 구현은 직선 그랩부터 적용한다. D/E는 v1의 짧은 단일 화살촉 궤적과 이동 통로 형태를 이어서 구현한다.

승인은 이 디자인 방향과 레이어 제작 착수에 대한 것이다. 전투 밸런스 변경·렌더 성능 측정 완료·최종 플레이 가독성 승인을 뜻하지 않는다.
