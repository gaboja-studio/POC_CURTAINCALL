# 승인 후 구현 계획

이 문서는 v2 승인 당시 설계 이력이다. 이후 그랩의 기본 표시가 대상 추적→공중 위치 고정으로 변경되었다. 경로는 기본 OFF이며 확정 후만 켤 수 있다. 현재 구현·설정·검증 정본은 [implementation-report.md](implementation-report.md)를 따른다.

## 표시 책임

- `IWorldIndicator`: Show/Update/Hide 공통 계약. 상태 입력에 위치/방향/실제 범위/시작 시각/지속 시간/종류를 포함한다.
- `WorldIndicatorView` 기반 클래스: 프로필 적용, 렌더러 캐시, 활성/비활성 수명주기. `AreaIndicatorView`(원/사각), `PathIndicatorView`(지면 경로), `TrajectoryIndicatorView`(대포 곡선), `SweptVolumeIndicatorView`(공중 공격 체적)로 필요한 동작만 파생한다.
- `IndicatorStyleProfile` ScriptableObject: 색·선·알파·애니메이션만 담당. 중앙 원인 아이콘은 제외한다. 상속 깊이보다 프로필 조합으로 변형한다.
- 기능별 어댑터: 추격자 공격/도약/돌진, 장애물 cue, 대포 탑승 상태를 읽어 뷰로 전달한다. 공격 AI나 피해 판정은 UI 인터페이스를 구현할 필요가 없다.
- 그림자는 `ActorShadowPresenter` 별도 계통으로 둔다. 원형 착지 표시와 공격 예고가 같은 상태 머신을 공유하게 하지 않는다. 기존 LandingShadowMarkers의 안전 판정/관전/트램펄린 정책은 재사용한다.

## 연결에서 지킬 사항

1. 공격 예고 진행도는 기존 공유 시각과 cue 시작 시각으로 계산한다. 각 클라이언트 Time.time으로 경고 종료를 추정하지 않는다. 타겟이 고정된 공격은 마커가 새 플레이어 위치를 계속 따라가지 않는다.
2. 공격 범위를 시안 크기로 하드코딩하지 않는다. 그랩은 Origin→Aim의 구형 손 sweep과 플레이어 캡슐 접촉이므로 공중 캡슐 통로로 표시한다. 원/사각 영역은 실제 지면 위험에 사용하며 중앙 아이콘 없이 범위로 구분한다.
3. 마커 경계는 처음부터 실제 크기를 유지하고 시간은 별도 아크/띠로 표현한다. 진행률에 따라 위험 반지름이 커지는 오해를 만들지 않는다.
4. `PresentAttack`의 기존 참조 null 검사에는 팔/애니메이션 진행도 연결되어 있다. 옛 aimRing/captureCable을 지우는 것만으로 예고를 교체하지 않는다. 뷰와 몸체 연출의 의존성을 분리한 뒤 레거시 렌더링만 전환한다.
5. cue.warning은 기존 정적 배칭 제외 대상이다. 새 월드 UI도 동적 표시로 유지한다. 취소·사망·씬 전환·재시작·소유자 비활성 때 즉시 숨기고 중복 프리팹 생성은 막는다.
6. 지면 표시는 작은 normal offset과 깊이 검사를 사용한다. 경사·계단·구멍·얇은 외줄에 공중 평면이 생기지 않게 지지면을 확인한다. UI 자체는 collider·shadow caster가 없다.
7. 플레이어 casting 정책은 PlayerModelSlot의 기존 자식/SetModel 및 Humanoid BindModel 경로에서 적용한다. inactive 바디 포함, 몸체만 대상으로 한다. receiveShadows는 유지한다.

## 공중 그랩 통로 · v2 제안

- 표시 입력은 동기화된 `AttackCue.Origin/Aim/Started/Phase`와 `ArmRadius`. Origin은 준비 동작의 손 소켓을 샘플한 고정 좌표다. 현재 움직이는 손이나 목표의 최신 좌표로 예고 통로를 바꾸지 않는다.
- 준비 중 Origin→Aim 선분을 ArmRadius로 확장한 캡슐의 경계를 표시한다. 얇은 종방향 선 4개와 양끝의 둥근 경계로 폭·높이를 표현한다. 채워진 튜브는 그리지 않는다. 크기는 월드 좌표로 고정하고 카메라를 향해 면 전체를 돌리지 않는다.
- 중앙 점선과 끝 화살촉 1개는 방향 안내이며 원인 아이콘이 아니다. 이동 방향을 반대로 읽지 않도록 손→목표로만 둔다. 공중 경로를 바닥에 투영하는 가짜 원/레일은 추가하지 않는다.
- 준비 시간의 진행 바는 경계 바깥에 얇게 붙인다. 통로 전체가 즉시 피격 영역이라는 뜻은 아니며, 실제 발사 후 손이 지나가는 순서로 충돌한다.
- Strike 때 공유 시각으로 구한 tip부터 Aim까지 남은 통로를 강조한다. 이미 지나간 뒤쪽을 위험하게 남기지 않고 현재 손의 단면을 표시한다. Retract/Grab/취소 시 통로와 예고 바를 숨긴다(현재 판정은 회수 중 새 포획 없음).
- 충돌은 손 반지름과 플레이어 몸체 캡슐 양쪽을 사용한다. UI는 손의 물리 sweep 반지름으로 그리고 모든 캐릭터가 점이라고 가정하지 않는다. 별도 임의 안전 여유 폭으로 공격 반지름을 바꾸지 않는다.
- 장애물 가림은 ClearReach의 레이어·예외 규칙과 일치시킨다. 씬 전체를 대상으로 하는 다른 raycast 규칙으로 가려진 경로를 뚫어 보여 주지 않는다. 같은 판정 입력을 읽는 공통 조회 API가 필요하다.
- 카메라가 통로 안에 있거나 거의 축 정면일 때 선/고리가 겹치는지, 고저차·좁은 외줄·4인 겹침을 검증한다. 진행 바 위치는 카메라에서 읽히는 바깥 경계로 고르되 위험 체적 자체는 회전시키지 않는다.
- 공중 경계는 절차적 선/메시로 조립하고 대시/빗금/진행 재료를 재사용한다. 평면 스프라이트 1장을 공중에 눕혀 폭·높이를 대신하지 않는다.

## 대포 궤적

- 로컬 탑승자의 SeatedStation과 Muzzle/LaunchVelocity, GameSettings.Base.Character.Gravity를 읽는다. 관전 표시 여부는 별도 설정.
- 기본은 입력 보정 없는 예상 출발 궤적. 실제 BallisticMotion 적분과 같은 계산을 사용한다. 바람이 있는 구간은 기존 바람 샘플을 읽을 수 있는지 확인하며, 발사 후 조작까지 보장하는 착지 예측으로 부르지 않는다.
- `maxArcLength`는 포구부터 곡선을 따라 잰 월드 거리(m). 수평거리/샘플 수와 구별한다. 누적 거리를 넘는 마지막 선분을 보간해 정확히 잘라낸다.
- 짧은 선분과 간격을 반복하고 마지막 접선 방향에 화살촉 1개만 표시한다. 중간 화살촉·전체 착지 타겟은 추가하지 않는다.
- 물리 표면을 만나면 선을 그 지점 전에 중단하고 위험 색을 적용한다. 실제 발사 규칙/충돌을 UI에서 바꾸지 않는다. 탑승 해제·발사·좌석/카메라 전환 시 숨김.

## GameSettings 배치 제안

경로: `Assets/Resources/Settings/GameSettings/WorldUiSettings.asset`, GameSettings의 `WorldUi` 참조로 연결. 기존 `Base.LandingMarker`의 의미와 에셋 참조는 유지한다.

| 묶음 | 조절할 값 |
|---|---|
| 공통 | 표시 켬, 기본/위험 색, 알파, 경계 두께(m), 지면 offset, 최대 표시 거리, 품질별 샘플 상한 |
| 원·사각 영역 | 형태별 프로필, 빗금 간격, 진행 아크/바 두께, 펄스 강도, 종료 페이드; 중앙 아이콘 없음 |
| 이동 경로 | 표시 폭 보정, 대시 길이/간격, 끝 표시 크기, 왕복/단방향 프리셋 |
| 공중 공격 통로 | 경계선 두께, 단면 선 수/품질, 대시 간격, 끝 화살촉 크기, 예고 바 두께/offset, 표시 거리; 반지름·예고 시간은 실제 공격 설정 참조 |
| 대포 | maxArcLength, 선분/간격(m), 선 두께, 화살촉 크기, 샘플 간격/상한, 가림 처리, 관전 표시 |
| 추격자 그림자 | 대기실/탈출로 적용 모드, 반지름, 불투명도, blur, 투영 거리/갱신 주기, distance culling; outline은 항상 없음 |

경고 시간·대포 속도·중력·피해 범위는 기존 GameSettings/원본 메커니즘에서 읽는다. 새로운 WorldUi 설정에 게임 규칙을 중복 복사하지 않는다. 기본 제안 값은 승인 후 실제 크기와 카메라로 조정한다.

## 승인 후 키트 산출물

- 공통 단색 알파 마스크: 얇은 링, 사각 테두리/모서리, 옅은 채움, 타일 빗금, 진행 아크/바 마스크, 경로 대시, 끝 화살촉. 원인 기호는 제작하지 않는다.
- 플레이어 그림자는 기존 shader/재료 유지. 추격자 그림자도 가능하면 기존 원형 shader의 무외곽선 프로필을 재사용한다.
- 원화는 분해 원본이 아니다. 승인 후 각 재료를 독립적인 투명 배경 스프라이트로 생성하고 알파·중심·여백을 검수한다. 합성된 시안 사진을 잘라 프리팹으로 쓰지 않는다.
- 레이어별 원본은 보관하되 실행 시 모든 레이어가 각자 draw call일 필요는 없다. 공용 머티리얼·아틀라스·하나의 셰이더 합성을 비교해 결정한다.
- 정본 프리팹: `Assets/Resources/Prefabs/UIs/WorldIndicators/`, 기능 코드: `Assets/Scripts/Systems/WorldIndicators/`, 비교 씬: `Assets/Scenes/Tests/WorldIndicators/` 예정.

## 검증

- 원형/사각형/선형 3종의 판정 경계와 시각 경계를 비교한다. 25/65/95% 예고 진행도, 취소·재시작·늦은 접속을 확인한다.
- 그랩은 목표 외의 플레이어가 경로 중간을 가로지름, 상하로 비켜남, 캡슐 경계 접촉, 손이 지난 뒤 횡단, 장애물 차단·회수, 고저차를 판정과 함께 검증한다. 공중 통로는 별도 3D 표시 범주다.
- 플레이어 모델/외형 변경·부상 바디·로컬/원격·관전에서 Realtime 그림자 중복이 없는지 확인한다. 지상 그림자 부재와 공중 그림자 fade를 사용자에게 보여 준다.
- 추격자 비용 비교는 같은 플레이 구간으로 수행하고 GPU/CPU 결과를 기록한다. 측정하지 않은 경우 개선 완료로 표시하지 않는다.
- 대포 거리 설정 최소/기본/최대, 수직 발사 근처, 장애물, 발사/하차에서 대시와 단일 화살촉을 검증한다.
- 사용자와 밝은 바닥/어두운 바닥·4인 겹침·계단·외줄·1인칭/3인칭을 확인한다. 예고 인지 시간과 실제 공격 오해 여부를 피드백 받는다.
