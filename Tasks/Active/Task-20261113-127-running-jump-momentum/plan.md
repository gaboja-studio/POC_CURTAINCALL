- **Type:** fix

## Context
달리다가 일반 바닥에서 점프하면 이륙 속도에서 공중 이동 속도로 부드럽게 이어진다. 공중 Shift는 가속을 만들지 않는다.

## 계획
최신 DEV에서 공통 PlayerMover의 지상 이륙 경로를 수정하고, 기존 공통 이동 검사에서 이륙·공중 입력·부상 배율을 확인한다.

## 미정·주의
이륙 방향의 속도는 상승 중에만 이어지며 정점에 공통 공중 속도로 돌아온다. 실제 조작감은 플레이에서 확인한다.

## 추가 범위
- 외줄 좌·우 클릭 옆줄 점프, 휠 클릭 방향 전환과 외줄·봉 카메라 연동.
- 설정 메뉴와 튜토리얼·공연 안내를 같은 입력 에셋에 연결.
- BaseGameSettings에서 공연 중 탐색 도구와 톱날 발사대 운반 중 외줄 제한을 적용.
- 11/13 후속: 외줄 시점은 줄 진입 방향과 휠 전환을 따른다. 봉 시점은 탑승 자세의 방향으로 한 번 맞추고 반동 입력은 받지 않는다.
- 후속: 접지 중 휠 클릭을 외줄 방향 전환 점프로 처리한다. 공통 외줄 구도가 대기실의 공간 구도보다 우선하고 카메라 각도는 공통 프레이밍 시간에 맞춰 보간한다.
