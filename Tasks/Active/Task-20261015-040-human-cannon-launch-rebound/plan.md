# Plan

## Context

CC-124의 첫 단계만 구현한다. 4인 지상 담당 1 + 비행 3으로 이동하는 받기와 발사 입력을 먼저 검증한다.

## Approach

1. 배정 문서 수신·실제 전달 확인 후 setup 구역 안에서 장애물 없는 장치를 구현한다.
2. F 탑승 완료 뒤 새 F 발사, F 홀드 취소, 공중 WASD 수평 조절을 구분한다. 10-15 사용자 선택: 지상과 같은 코스 방향으로 누르는 동안만 보정, 놓으면 기본 발사 속도. 수직 힘은 유지하며 대각선 보정 크기를 제한한다.
3. 트램폴린 F 잡기 즉시 정면 고정·WASD 운반/방향 회전 추종·Space 몸/장치 점프·F 홀드 놓은 위치/방향 유지. 반동은 자동 전진0·상승12m/s·WASD 유지. 사용자 추가: 지상 Space 점프 하강 접촉도 첫 반동, 윗면0.5m. 운반자는 제외. R 초기 위치/방향 복원, 호스트 segment·첫 반동 sequence/epoch·이동/회전 sweep으로 중복/지연 요청을 구분한다.
4. 지정 정상 착지와 비행 추락 사망을 구분한다. 사용자 승인 임시 쿠션(트램폴린 오른쪽6m, 주황4×4m, 윗면0.2m)에서 호스트 확정 후 비행 해제/지상 조작 복구, HUD 착지 횟수·R 초기화. 네 화면 일치를 검증하며 같은 공연 부활은 추가하지 않는다.
5. 공용 인터페이스가 부족하면 별도 소유 Task를 PM에게 요청한다. 분리 출발 장치는 3단계로 남긴다.
