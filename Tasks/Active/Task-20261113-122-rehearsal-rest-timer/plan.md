## Context
2026-11-13 사용자 요청.
1. 대기실 리허설(인간대포·외줄 재연습) 동안 쉬는 시간 타이머를 멈추고, 끝나고 대기실로 복귀하면 다시 흐르게 한다.
2. 추격전이 시작되면 리허설 이동 팝업을 닫고 리허설을 시작할 수 없게 한다.
3. 인간대포를 해금했지만 리허설을 이수하지 않았으면, 쉬는 시간이 시작될 때마다 호스트에게 팝업을 띄운다.
4. 복귀할 때 남은 시간이 1분 미만이면 1분을 더한다(새 공연을 편성할 시간 보장).

## 계획
- RunState: 멈춤 사유를 탐색 구역과 리허설 두 개로 나누고, 리허설이 끝날 때 시간을 보정한다(HoldRestTimerForRehearsal).
- WaitingRoomCannonRehearsal: 호스트가 매 프레임 리허설 상태를 알려 타이머를 멈추거나 푼다. 쉬는 시간이 시작될 때 미이수 안내를 대기열에 넣는다. 추격전 중에는 팝업을 닫고 시작을 막는다.
- 기준값·추가 시간은 GameSettings.WaitingRoom.Rehearsal(둘 다 60초)에 둔다.

## 미정·주의
- 탐색 구역 규칙은 그대로다. 복귀한 위치가 안전지대라면 리허설이 끝나도 타이머는 멈춘 채로 있다.
- 시간 보정은 리허설이 끝날 때마다 적용된다. 외줄 재연습에도 적용된다. 반복해서 쓰면 시간을 늘릴 수 있다.
- 추격전 중 외줄 재연습 투표도 막았다.
