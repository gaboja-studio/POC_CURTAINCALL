# Plan

## Context

묘기 플로우의 마지막 단계. 판정은 005 `TightropeRun`(Succeeded/Failed, 도착·사망 인원)이 이미 한다. 결과를 모아 보여주고 보상을 계산한다.

## Approach

1. `setup.md`의 작업 구역 안에서만 구현.
2. 새 로직은 가능하면 테스트를 함께 남김.
3. 공용 파일이 필요하면 직접 고치지 않고 PM에게 요청.
4. 검사 후 `integration/*`로 제출.
5. 수치는 코드·프리팹에 두지 않고 세팅 파일 칸으로(칸마다 한글 설명·단위).

세부(구현 전에 PM과 합의):

- 결과 데이터: 호스트가 묘기 종료 순간 확정해 공유(결과 종류, 걸린 시간, 도착/사망/접속 끊김 인원, 개인별 상태).
- 보상: 013의 `RewardTable`(추상 ScriptableObject)을 구현한 `TempReward` 하나. 계산 입력은 결과 데이터, 출력은 "보상 이름·수량" 목록. 다른 보상 규칙은 새 파일을 만들어 `TightropeSettings` 보상 칸에 끼운다(코드 수정 없이 교체).
- 임시 결과 화면(기본 레이아웃). 다듬기는 016.
- 결과·보상 표시 시간 등은 세팅.
