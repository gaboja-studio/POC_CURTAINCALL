## Context
부상(팔·다리 절단) 순간 절단 부위에서 혈흔이 튀는 파티클 연출을 추가한다(사용자, 2026-11-01).
- 내 시점 3인칭: 부상 위치에서 자연스럽게 튄다. 1인칭: 화면에 보이게 자연스럽게 튄다.
- 팀원 시점: 내가 다칠 때 부상 위치에서 튄다.
- Resources 게임 설정으로 연출 전체를 켜고 끈다. 끄면 게임 설정 화면에 항목이 없고 모두 꺼진다.
- 켜져 있으면 플레이어가 게임 설정에서 자기 화면 표시를 켜고 끈다.

## 계획
1. 신호: 모든 화면에 공유되는 `PlayerCondition.Changed`에서 새로 잃은 팔·다리만 재생한다.
   접속 직후 초기 상태 적용(`NetworkPlayer.IsApplyingInitialCondition`)·부위 복구는 재생하지 않는다. 네트워크 추가 없음.
2. 위치: 휴머노이드는 몸에 남는 위팔·허벅지 뼈(어깨·엉덩이), 그 외 모델은 몸 기준 위치. 이펙트가 몸을 따라가고 방울은 월드에서 떨어진다.
   내 캐릭터가 1인칭이면 카메라 앞 잘린 쪽에서 화면 안쪽으로 튄다(내 몸 위치 연출은 생략).
3. 설정: `BaseGameSettings` 신체 손상에 혈흔 사용·양. 개인 설정 `ClientSettings.ShowBloodEffect`, 그래픽 탭 토글(게임 설정이 켜졌을 때만 표시).
4. 파티클: 에디터 메뉴로 `Resources/Effects/Blood/`에 재질·프리팹 생성. 프리팹이 없으면 코드 기본값으로 만든다.
5. 테스트·문서 갱신, 검사.

## 미정·주의
- 플레이어 프리팹·공용 설정 화면 수정은 공용 파일이다. 프리팹은 건드리지 않고 런타임에 붙인다.
- 혈흔 양·색·크기의 최종 느낌은 사람이 플레이로 확인한다.
