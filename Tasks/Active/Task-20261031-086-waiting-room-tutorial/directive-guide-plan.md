# 대기실 지시형 가이드·런 단위 초기화 계획 (2026-10-31 초안)

사용자 요청(2026-10-31): ① 본 안내 기록은 PC가 아니라 **런 단위**(런이 끝나고 새 런을 시작하면 다시 출력). ② 지금은 아이템·규칙 **설명**만 있고, "무엇을 하십시오" 같은 **대기실 가이드(지시)**가 빠졌다. 기획서에 맞춰 계획한다.

## 근거 (기획서)
- 게임 흐름 기획 15564804 §4-4: 1일차 낮 가이드 쉬는 시간에 **대기실 기능(수화기·배송구·소품실·복귀 지점)**과 **서비스·상점 화면**을 안내. 기물 구매는 밤에만 → **첫 기물 구매 안내는 1일차 밤 정비**. 가이드 후 남은 시간은 자유 탐색.
- 같은 문서 §7-1: 행동 정보(하루 시계, 소집 경보, 복귀 지점, 수화기·배송구·소품실 사용법)는 **필요한 순간에 바로**. 발견 정보(탈출로 입구·단서)는 **숨김**. §5-1: 밤 정비는 스케줄표·서비스·기물 구매·정리 후 **각자 침대에 누우면** 끝. §6-2: 런 실패 → 세대 교체 → 1일차 줄타기부터(런 데이터 초기화).
- 대기실 2차 기획서 20348931 §3.2: 대기실은 "대기실과 탐색이라는 새로운 규칙을 가르치는" 곳. §4.1.3: 가이드 쉬는 시간에 **기물 구매·보관·지니기** 안내.
- M2 실행 계획 26116130·작업 계획 25755650: 플레이테스트에서 "다음 행동을 모름"이 다수 → **다음 목표·행동 대상·복귀를 읽을 수 있게**. 진행자 설명 없이 다음 행동과 목적지를 찾아가는지가 통과 기준.

## 기준 순서 (사용자 2026-10-31)
**현재 구현 > M2 변경점(27721807) > 대기실 2차 기획서 옛 내용.** 구현과 M2가 다르면 구현을 따른다. 2차 기획서의 M2 이전 내용(가이드 중 상점 구매, 1인 3개·배낭)은 쓰지 않는다. 가이드 쉬는 시간엔 상점 화면을 열어 보기만 하고, 첫 구매는 1일차 밤(구현: 구매는 밤에만).

구현 기준으로 그대로 안내하는 것: 쉬는 시간 시계는 생활 구역에서 멈추고 깊은 구역에서 흐름(G02 유지), UV 등은 장비형 무제한, 추격자 없음(시간 만료 시 통로 밖 즉시 잡힘), 구조 A 고정 배치, 선반 이름 "물려줄 선반".

## A. 런 단위 초기화 (→ 2026-10-31 사용자 변경: 앱 재시작 때만 초기화, plan.md 결정 4)
- 본 안내 기록 범위 = **런**. `CampaignSnapshot.Generation`이 바뀌면(런 실패·세대 교체, 로비에서 새 런 시작, 호스트 런 포기) 기록·대기열을 비우고 처음부터 다시 띄운다.
- 게임 중 재접속은 불가(런 규칙 #3)라 PC 저장(PlayerPrefs)은 쓰지 않고 메모리로 둔다. **안내 끄기**만 PC 설정으로 남긴다.
- 설정의 "안내 처음부터"는 테스트·재확인용으로 유지(지금 런 기록만 지움).

## D. 구현 순서
1. 런 단위 초기화(A) — 작음, 먼저.
2. 장부에 할 일 종류 추가: 단계 순서·완료 조건·팀/개인 범위. 팀 완료는 기존 공유 상태(구매·배송)로 판정.
3. 할 일 패널(결정 1) + 설명 패널 동시 표시 배치.
4. 완료 조건 연결: 상점 열림·서비스 탭·배송구·구역 진입·소지·집결·구매·배송·스케줄표·침대.
5. 문구 파일에 할 일 줄 추가(`T01 | 할 일 | 보조 문장`).
6. (선택, 결정 3) 목적지 표시.
7. 검사: EditMode(순서·완료·런 초기화), PlayMode(1일차 가이드→밤→2일차, 세대 교체 뒤 재출력), MPPM 2인(개인/팀 완료), 사람 플레이.
