# 대기실 화면 문구 직접 수정 계획 (2026-10-31 초안)

사용자 요청: 대기실에서 출력되는 모든 패널의 문구를 직접 고친다. 상호작용 안내, 아이템 설명, 탐색 시간 방송·소집 경보를 포함한다.
조사 결과: 별도 문구 표나 현지화 시스템이 없다. 문구는 C# 코드, 씬 직렬화 값, ItemCatalog.asset에 흩어져 있다.

## 현재 문구가 있는 곳 (대략)
| 구분 | 개수 | 위치 |
|---|---|---|
| 상호작용 안내([F] 옆 문구) | ~35 | C# 코드 + 씬 이름 조합("{이름} 줍기", "{label} 살펴보기") |
| 알림·거절·결과(토스트, 상점·서비스·스케줄 하단) | ~95 | C# 코드 |
| 상점·서비스·스케줄 화면 | ~90 | C# 코드 + 프리팹 고정 글자 |
| 방송·소집 경보·밤 배너·소지 안내 | ~10 | 씬 값 2 + C# |
| 나레이션(인간 대포 획득, 신체 복구 예약) | 3쌍 | C# |
| 아이템 이름 | 7 + 낡은 이름 5 | ItemCatalog.asset(\u 이스케이프라 손으로 편집 불가) |
| 아이템 설명(summary) | 7 | 에셋에 있으나 **화면 어디에도 안 나옴** |
| 단서·문·상자 이름(살펴보기 대상) | ~45 | 씬 직렬화 값 |
| 벽 표지판·CCTV | 128 + 10 | 씬 TextMesh |

## 방식 (추천)
- 문구 파일 하나 `Assets/Resources/Settings/WaitingRoom/WaitingRoomTexts.txt`, 형식 `키 | 문구`, 구역별 묶음.
- 바뀌는 값은 이름표로 표기: `{item}`, `{n}`, `{player}`. 조사 자동 선택 `{item:을}` → 받침에 따라 을/를.
- 코드는 `키`로 문구를 찾고, 파일에 없으면 지금 문구를 그대로 쓴다(빠져도 안 깨짐).
- 순수 로직 어셈블리(상점 장부·서비스 규칙 등)도 쓸 수 있게 엔진 의존 없는 문구 표 + 시작 시 파일 주입.
- 문구 비교로 동작하는 곳 4곳을 먼저 코드 값 비교로 바꾼다(선반 비었음, 손 가득, 다 씀, 비밀번호 틀림). 안 바꾸면 문구 고칠 때 기능이 깨진다.
- 문구 파일 전 키가 들어 있는지, 이름표 오타가 없는지 EditMode 테스트로 검사.

## 단계
1. 공통: 문구 표·파일 읽기·이름표·조사 처리·테스트. 문구 비교 4곳 정리.
2. C# 문구 이전: 상호작용 안내 → 알림·거절 → 상점·서비스·스케줄 화면 → 방송·경보·밤 배너·소지 안내 → 나레이션.
3. 아이템: 이름·낡은 이름을 문구 파일에서 덮어쓰기(아이템 id 기준). 설명 표시는 결정 필요.
4. (선택) 씬 값: 단서·문·상자 이름, 방송 문구, 공연 이름, CCTV, 표지판.

## 결정 필요
1. 범위: (추천) 1~3단계. 씬 값(4단계)은 지금처럼 Unity 인스펙터에서 고치고 필요할 때 추가 / 4단계까지 전부.
2. 아이템 설명: 지금 화면에 안 나옴. (추천) 상점 기물 목록의 설명 칸·마우스 올림 설명에 표시 / 지금처럼 안 씀.
3. 파일 구성: (추천) 대기실 문구 파일 1개(구역 주석으로 나눔) / 구역별 여러 파일.
4. 제외: 설정·메뉴·나가기 같은 공통 화면, 디버그 전용 문구는 제외(추천).

## 함께 발견한 것
- 소집 경보 배너 본문은 씬의 `recallMessage`를 안 쓰고 코드에 "무대 입구로 모이세요"가 박혀 있다.
- 탐색 결과 문구(상자 뜯음, 벽 무너짐 등)는 대상이 초점일 때 옛 IMGUI 상자로 2초만 보이고, 일반 문·단서 결과는 사실상 안 보인다.
- 공연 이름이 스케줄 "줄타기" / 결과 화면 "외줄타기"로 다르다.
- 다른 세션("게임 튜토리얼 및 일정 확정 버그")이 NightBed·ScheduleBoardView·WaitingRoomTutorial을 수정 중 → 해당 파일은 조율 후 작업.
