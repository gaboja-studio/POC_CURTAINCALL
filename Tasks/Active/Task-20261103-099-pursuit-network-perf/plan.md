## 피해자 접촉 판정 (2026-11-03 사용자 확정)
- AI는 호스트, 원격 포획 시작은 피해자 화면의 실제 표시 위치/자신의 현재 위치로 접촉 보고. 호스트는 소유자·캠페인/epoch·순서·시간·자신이 보낸 추격 경로·좌표/벽을 검증한 뒤 기존 포획 함수를 확정 실행한다.
- 호스트 거리만으로 원격 포획하지 않으며, 보고/확정 전 입력 잠금·절단·연출을 시작하지 않는다. 호스트 본인/오프라인은 기존 판정 유지. 상태/전등/절단/관전 경로 재사용, 프로토콜v4로 혼용 차단.
- 지연/유실/역순/중복/초기화 요청 회귀, 실제 포획 이후 기능 회귀와 비용 확인. 4인 최적화는 코드/측정/공식 문서 근거로 우선순위를 쉽게 설명한다.
