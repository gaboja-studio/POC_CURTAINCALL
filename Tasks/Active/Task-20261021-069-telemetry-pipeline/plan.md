## 계약 주의점
- D1P1은 표시 ID. attemptId는 별도 UUID, retryIndex도 별도.
- NGO clientId는 0~3 슬롯과 다름. 로그인 ID 길이를 추정해 강제하지 않음.
- 잃은 팔다리 개수(0~4)와 기존 bitmask를 혼용하지 않음.
- 마이크는 시작·종료 시간만. 음성 파일·인증값·입력 문자열 수집 안 함.
- 권위와 환경별 통계 분리. 미수집은 0으로 표시하지 않음.
- 원시 시간 UTC, 표시는 Asia/Seoul. 게임 일차와 달력 날짜 분리.
