# 대기실 HUD를 에디터에서 수정하기

Unity 메뉴 **Curtain Call → UI → 대기실 HUD 편집**에서 [대기실 HUD 설정](../../../Assets/Resources/Settings/UI/WaitingRoomHud.asset)을 연다. 설정을 저장하고 Play를 다시 시작한다. 배치와 공통 중복 표시 규칙은 [역할 프리팹 안내](role-hud.md)를 따른다.

**기존 안내 쓰기:** ①에서 **대기실 (G01)**을 누르면 ②에 표시 조건과 원래 문구가 보인다. 빈 제목·본문은 원문을 사용한다. G01과 N01은 글만 4초, G11은 무대 입구 클로즈업이다. 기본 단계는 ↑↓로 순서를 바꾼다.

**새 카메라 안내 쓰기:** ①에서 **+ 첫 휴식 안내 추가** 또는 **+ 밤 정비 안내 추가**를 누르고 제목·내용을 입력한다. 예를 들어 '스케줄표 확인' → '대기실 (G01) 다음' → 카메라 대상 '스케줄표'로 설정한다. 글만 선택하면 표시 시간을 바꿀 수 있다. **직접 저장한 Scene 뷰 시점**은 실제 대기실 씬의 3D Scene 뷰에서 구도를 잡고 **현재 Scene 뷰 구도 저장**을 누른다. 이 구도는 월드 좌표이므로 공간을 옮기면 다시 저장한다. 추가 안내의 ID는 자동 생성되며 제목을 바꿔도 유지된다. 같은 위치에 추가한 안내는 만든 순서대로 재생된다. 다시 확인하려면 Play 후 Esc → 설정 → 게임 → 안내 처음부터.

**시간과 조건은 구분한다.** 첫날과 밤에는 등록된 단계를 순서대로 재생한다. 필요한 단계는 빠뜨릴 수 없으며, 중복은 한 번만 재생한다. 각 단계의 문구를 비워 두면 기존 설정을 상속한다. 일반 안내의 표시 시간(초)이 0이면 기존 노출 시간을 사용한다. 카메라가 붙은 안내와 입력을 잠그는 단계는 연출 종료 시점을 따른다. 첫날 필수 확인, 투표 과반수, 예약 성공, 소집 시각 등 게임 판정은 이 설정으로 변경하지 않는다.

**오브젝트에 붙는 안내는 월드 좌표를 사용한다.** 예를 들어 전화기 자식으로 빈 오브젝트를 만들어 수화기 위에 놓고 UI Anchor에 연결한다. Available Action이 비어 있으면 현재 게임 행동명을 표시한다. 앵커와 Local Offset은 표시 위치만 옮긴다. 거리 밖이거나 가려져 실제 F 입력 대상이 아니면 대기실 행동 프롬프트를 표시하지 않는다. 입력 키는 실제 바인딩을 사용한다.

**다음 씬에 적용할 때:** 조건을 판정하는 기존 이벤트에 표시 요청을 한 번 연결한다. 계속 바뀌는 수치는 같은 카드의 내용을 갱신하고, 조건이 끝나면 해당 카드만 닫는다. 조작 방법을 배울 때는 가이드, 바로 누를 수 있는 행동은 대상 프롬프트, 이미 끝난 행동의 결과는 피드백이다.
① 추가 안내·② 기존 안내·⑤ 임무/방송/대상의 입력란 아래 **플레이어 문구 미리보기**에서 결과를 확인한다. 제목만 덮어쓰면 본문은 기존 값을 쓴다. {inside}/{alive} 같은 수치는 예시로 치환하며 일반 방송의 실제 본문은 실행 시 결정된다. 이 미리보기는 문구 확인용이며 프리팹 연출·게임 화면 위치는 Play에서 확인한다.

**리허설 HUD:** Unity 메뉴 **Curtain Call → UI → 리허설 HUD 편집**에서 외줄타기 또는 인간대포를 선택한다. 안내를 고르면 실제 발생 조건, 표시 역할, 원문, 편집란, 플레이어 문구 미리보기가 보인다. 예: 외줄타기 → 그네 잡기는 그네 진입 5m 전부터 학습 가이드로 뜨며, 오른쪽에는 구간 목표가 남는다. 인간대포 → 대포 탑승·발사는 탑승 가능 거리 또는 탑승 상태에서 회차당 한 번 예약된다. 앞선 설명이 끝나면 표시한다. 조작 설명에는 {interact}, {action}을 쓸 수 있다. 투표·집결·줄 번호는 표시된 변수 이름을 유지한다. 한쪽 문구를 비우면 그쪽만 기본값을 사용한다. 설정은 대기실과 같은 에셋에 저장하며, 변경 후 Play를 다시 시작한다.
