# HUD 초기 단계 · plan

## HUD 배치 변경 (2026-10-28)
- 공연 제한 시간 표시는 숨긴다. 게임의 시간·불 추격 판정은 변경하지 않는다.
- 대기실 원형 시계와 공연 팀 호응 게이지를 좌상단으로 이동한다.
- 공통 인벤토리를 2칸·1/2 입력 안내로 맞추고 우하단으로 이동한다. 기물 소지 규칙은 기존 2개 설정을 유지한다.
- 균형/추락 게이지는 1안 하단 중앙(기본), 2안 상단 중앙을 공통 세팅에서 전환한다. 실행 중 변경도 반영한다. 추가 지시: 2안에서만 추락 게이지를 균형 게이지 아래로 옮기며, 1안은 기존 위쪽 배치를 유지한다.
- 상단 팝업은 중앙 상단으로 올리되, 2안에서는 게이지 아래에 여백을 둔다.
- 기존 정본·비공개 원본을 재생성하지 않고 실게임 공통 씬의 배치와 공개 연결 코드를 수정한다.
- 묶음 완료 후 check-work와 관련 HUD 회귀 검사를 실행한다. 최종 외형·플레이 경험은 사람이 확인한다.

## 대기실 하루 시계 패키지 연결
- 사용자 지정 `Assets/_ThirdParty/curtaincall_dayclock_v2/` v2.2를 원위치에서 사용한다. 제공 조립기를 프로젝트 경로·기존 공용 Sprite 정본에 맞춰 연결하고 공개 Resources 아래 프리팹·일정 프로필·전용 머티리얼을 생성한다.
- 대기실의 코드 생성 임시 시계를 새 프리팹으로 교체한다. 좌상단 배치·기존 자금/집결/알림은 유지한다.
- 일정 프로필의 시간대별 시작·끝 시각을 실제 링·경계·바늘 데이터에 함께 반영한다. 남은 실제 초는 게임 타이머에서 공급한다.
- 아침/낮(가이드 포함)/밤 정비의 실제 제한 시간을 각각 설정하고 무제한을 지원한다. 밤 정비는 기본 무제한이며 기존 침대 종료 흐름은 유지한다.
- 시간 판정·네트워크 동기화·알림과 새 프리팹의 일치, 설정 변경·오류·무제한 경계를 검사한다.

- 팔레트 대비·색각 구분과 실제 링 색상·렌더링을 확인하고 색상/일정 시각/실제 초 설정 위치를 안내한다.
