- **Branch:** feat/csv-localization

## Context
게임의 화면·월드 문구를 한국어와 영어로 제공한다. 로컬 CSV를 게임에 포함하고 Google 시트에서 고친 행을 에디터에서 검사해 반영한다.

## 계획
1. 씬·프리팹의 텍스트, 덮어쓰기, 안내 파일, 인스펙터와 코드의 문구 후보를 위치와 함께 수집한다.
2. 기존 대기실 ID를 재사용한다. 고정 원문과 편집 가능한 한국어·영어를 분리하고 숫자·이름의 자리를 보존한다.
3. 기존 UI와 월드 렌더러에 연결하고 설정의 언어 선택을 PC에 저장한다.
4. 번역표와 실제 화면을 검사하고 Confluence에 결과와 두 언어의 사진을 기록한다.
5. 번역 수정 탭에 전체 문구를 제공한다. 마지막 동기화 이후 시트에서 바뀐 행만 검증해 로컬 파일에 반영하고, 로컬 수정과 겹치면 문구 코드를 알려 준다.
6. 키와 설명이 들어갈 자리를 화면을 그릴 때 언어별로 채운다. 공동 시트의 두 번째 열에는 기획자가 문구의 용도를 확인할 수 있도록 설명을 적는다.
7. 공간·콘텐츠별로 번역 탭과 CSV를 나누고 통합 문서 한 번으로 변경된 파일만 갱신한다. 분할 전후의 문구와 실제 표시 결과를 대조한다.
8. 모든 키와 참조를 대문자 영문으로 맞춘다. 탭과 소분류 한두 개, 항목은 밑줄로 나누고 단어는 하이픈으로 연결한다. 같은 항목의 변형에는 0부터 연속 번호를 붙인다. INDEX에서 설명으로 이동하고, 내려받은 파일과 두 언어의 화면·키 재지정·예전 다운로드 호환을 확인한다.

## 미정·주의
기존 비공개 에셋 작업 트리에는 다른 버전과 수정 파일이 있다. 현 작업은 해당 저장소를 갱신하지 않는다. 전체 영어 감수와 전 장면 레이아웃은 후속 플레이 확인 대상이다.
