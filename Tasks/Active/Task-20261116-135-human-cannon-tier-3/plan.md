## 목적

인간 대포 난이도 3단계에서 발견되는 버그, 진행이 멈추는 상태, 수치상 통과할 수 없는 구간을 찾아 수정한다.

## 계획

1. 실제 공연의 3단계 편성·로딩부터 출발, 중간 구간, 완주 판정, 정산까지 씬·프리팹·코드·GameSettings를 대조한다.
2. 필수 이동과 협동 구간에서 사거리·높이·충돌 여유·장애물 주기·제한 시간을 계산해 통과 가능한 조작과 타이밍 범위를 확인한다.
3. 실패·사망·이탈·연결 해제·재시작 때 상태가 복구되는지 참가 인원과 호스트·참가자 기준으로 점검한다.
4. 확인한 문제를 수정하고 검사 근거와 사용자가 직접 테스트 플레이할 구간을 기록한다.

작업 시작·재개 전과 제출 직전에 Unity 종료를 확인하고 origin/dev를 fetch해 작업 브랜치에 반영한다.

## 난이도 3단계 변경 범위

- 1구간 → 1구간 톱날벽 → 2구간 → 2구간 톱날벽 순서로 확인한다.
- 2단계 지상불은 기존 예고 3.5초, 분출 2초, 줄마다 4개를 사용한다. 좌우 그네 중 어느 쪽이든 잡으면 연결된 줄 전체를 끈다.
- 3단계 지상불은 예고 2초, 분출 3초, 줄마다 최대 5개를 사용한다. 좌우 한 쌍마다 그네 하나를 남기고, 최초로 잡으면 연결된 줄 중 무작위로 한 줄을 끈다. 선택은 재시작 전까지 유지한다.
- 기존 1단계 추격불 속도에 2단계는 0.2m/s, 3단계는 0.5m/s를 더한다. 생존자 전원 도착 시 적용되는 기존 구간 가속 조건은 그대로 쓴다.
- 기존 인간 대포 스크립트와 씬을 수정한다. 공용 이동·부상·그네 조작 규칙과 GameSettings 조정값은 유지한다.
