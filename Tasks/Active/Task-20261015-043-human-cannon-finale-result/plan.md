# Plan

## Context

043은 042 다음 예약 단계다. 폴더·빈 씬(root 0)만 준비됐으며 인간 대포 기능은 구현되지 않았다. 아래는 실행 근거가 아닌 예정 계획이다.

## Activation

1. PM이 042 integrated·실제 4인 공동 테스트 근거·소유권 반납·실제 JIRA URL을 확인한다.
2. 다음 1개인 043에만 Active Task/Allowed를 부여하고 승인된 준비 브랜치에 배정 문서를 Merge commit으로 sync한다.
3. 기존 feat 브랜치는 앞 단계 완료 후 최신 부모 이력을 받는다. 실제 전달 PM 확인 이후만 start-work한다.

## Approach

1. 마지막 필수 협동→마지막 봉/지상 탈출로→쿠션→최종 대포→톱→실제 목적지를 연결한다. 쿠션은 안전 준비만이며 성공·회복·부활·재시작이 아니다. 별도 불꽃/타이머 없음.
2. 각 1인 대포 4대는 같은 기본 높이·사거리·발사 힘, 개별 F 탑승/새 F 발사다. 부상 무관, 동시 출발 강제 없음.
3. 외줄 외형·기본 이동만 읽기/재사용한다. 거리/출현 시간/부위 피해는 그대로 복사하지 않는다. 가로 톱은 좌우 왕복; 수직 톱은 정해진 출현점→대포 방향 직선 이동 후 제거, 왕복·가속·추적 없음.
4. 첫 생존자 최종 진입→예고→공유 주기 시작, 후발 발사로 초기화 금지. 수직 톱 하나 퇴장→예고→다음 출현으로 빈 공간·회피 시간을 확보한다.
5. 마지막 필수 협동 뒤 혼자 남아도 완주 가능하다. 더 받을 비행자 없으면 지상 생존자는 지상 탈출, 봉 생존자는 담당 사망 뒤에도 쿠션 도전 가능. 필수 협동 전 단독 문제와 구분한다.

## Files / Dependency

- 예정 파일은 setup 예약 구역만, 현재 수정 권한 없음. main_stage.unity는 025 소유, 외줄 원본 수정 금지; 공용 부상·관전 읽기/재사용만.
- 공용 결과/런 종료 contract는 별도 소유 연결 Task 의존이다. Task 식별자·담당·계약·연결 근거를 PM이 확인해야 한다. 이번 Allowed로 공용 Systems 변경 불가.
- 살아 있는 1명 실제 목적지 도착 성공, 그전에 전원 사망 실패. 생존/도착 2명·종료 레버 요구 없음. 공용 최소 생존 2명 규칙 전역 삭제·임시 우회 금지; 별도 소유 Task가 인간 대포 예외를 연결한다.
- 미연결이면 통합 종료 검증 BLOCKED. 로컬 판정/fixture/계획은 실제 공용 종료·보상·전환 연결 검증 근거가 아니며 integrated로 표시하지 않는다.
- 지상 2명 규칙·중계 대포·호응/보상 수치·2~3인은 미정/후속이며 구현 목표에 넣지 않는다.

## Auto Verification

- 구역: 예약 — 미배정. PM 준비 문서·컴파일·기존 EditMode 결과는 handoff의 Verification 참조.
- 자동 테스트·실행 로그: 미실행. 활성화 후 `pwsh -File Scripts/check-work.ps1 -Mode PlayMode`로 검사하고 실제 결과를 기록한다. 테스트 부재는 NO_PROJECT_TESTS, 실제 플레이 PASS가 아니며 공동 플레이 대체 불가.
- PM 준비의 기존 EditMode 5/5 검사와 이 단계 PlayMode/실제 4인 검증은 별개다.
- 공용 연결 근거 미확인으로 통합 종료 검증 BLOCKED. 별도 소유 연결 완료 후 실제 검증 결과를 기록한다.

## 공동 테스트 항목

합의·실행 전 계획이다. 실제 4인 플레이가 필요하며 계획과 실제 근거를 분리한다.

1. 쿠션·최종 대포·부상 독립

- 씬: HumanCannon.unity (setup 예약 테스트 씬, 현재 040 소유; 이관 후 실행).
- 인원: 4인(호스트 1·참가자 3). 지상 담당을 호스트→참가자로 교환한 회차로 최종 구간에 진입한다.
- 재현: 마지막 협동→쿠션 진입→부상/사망자 상태 확인→각자 대포 1대 탑승→기존 F 유지와 새 F 입력 비교→순차 발사; 정상/다리 손실/외팔 조건 반복.
- 예상: 쿠션에서 종료·회복·부활·재시작 없음. 4대 같은 기본 힘/높이/사거리, 새 F로만 개별 발사, 부상 무관·동시 발사 강제 없음.
- 실제 기록 방법: 일시·4인 이름/역할·commit·쿠션 전후 생존/부상·대포별 입력/궤적·영상/로그·예상 대비 실제를 handoff에 남긴다. 현재 미실행.

2. 공유 톱 주기·후발 발사

- 씬: HumanCannon.unity (setup 예약 테스트 씬, 현재 040 소유; 이관 후 실행).
- 인원: 4인(호스트 1·참가자 3). 지상 담당 호스트/참가자 교환, 첫 진입자·후발 발사자도 바꾼다.
- 재현: 첫 생존자 진입→예고/주기 관찰→다른 3명 시간차 진입·발사→가로 왕복/수직 출현·직선·퇴장·다음 예고 관찰→플레이어 위치 변경.
- 예상: 첫 진입 이후 공유 주기 유지, 후발 발사 reset 없음. 가로 좌우 왕복, 수직 고정 직선/퇴장 후 다음 예고, 가속·추적 없음; 회피 시간·주기가 네 화면에서 일치한다.
- 실제 기록 방법: 일시·4인 이름/역할·commit·진입/발사/톱 예고·출현·퇴장 타임라인·궤적 영상/로그·실제 reset 유무를 handoff에 남긴다. 현재 미실행.

3. 협동 후 단독 완주·실제 공용 종료

- 씬: HumanCannon.unity (setup 예약 테스트 씬, 현재 040 소유; 이관 및 별도 공용 연결 후 실행).
- 인원: 4인(호스트 1·참가자 3). 지상 담당 호스트/참가자 교환 후 사망 회차를 만들며 시작 세션의 4인 참여를 기록한다.
- 재현: 마지막 필수 협동 완료→다른 3명 사망→지상 생존자의 받을 사람 없음/봉 생존자의 담당 사망을 별도 회차로 구성→탈출/쿠션/최종/목적지; 다른 회차는 도착 전에 전멸시킨다.
- 예상: 협동 후 1명도 완주하고 실제 목적지 도착에서 공용 성공 종료, 그전 전멸은 실패. 쿠션·1명 잔존만으로 성공/자동 실패 없음; 다른 묘기 2명 규칙은 보존. 미연결이면 통합 종료 검증 BLOCKED.
- 실제 기록 방법: 일시·4인 이름/역할·commit·연결 Task/계약/연결 commit·사망/실제 도착/공용 종료·전환 로그와 영상·예상 대비 실제를 handoff에 남긴다. 연결 부재는 BLOCKED로 기록, 현재 미실행.
