# 시점 체험과 다음 구현 순서

## 사용자 지시

- 첫 운반 1인 연습에서 기본 1인칭, 트램폴린 확정 운반 중 자유 3인칭, 놓으면 1인칭. 정지 중 둘러봐도 트램폴린 방향 유지.
- 추가: 기존 연속 코스의 모든 대포와 연습 대포에서 탑승 중 3인칭, 발사 순간 1인칭.
- 현재 구현 상태/순서를 기록하고 다음 구현도 진행. 이후 “전부 작업 진행하고 끝나면 이야기 해줘 테스트 해보게” 요청으로 043 전체 구현 뒤 사용자 테스트 순서로 변경했다.

## 구현 순서와 현재 상태

1. 공용 실패 기준 생존 1명 미만: 완료·회귀6/6 PASS.
2. 안전 쿠션·독립 최종 대포4대: 구현·자동 검증 완료, 실제4인 검증 별도.
3. 기존 코스 오른쪽 구간별 1인 연습: 10구간·몸 프리셋·보조·재시도/복귀 구현, PlayMode5/5 PASS.
4. 운반/대포 시점: 구현. 공용 카메라/프리셋은 수정하지 않고 콘텐츠 요청 API 사용.
5. 최종 톱: 첫 진입 예고→가로 왕복·수직 단일 직선 공유 주기, 후발 발사 초기화 없음. 원본·옆 연습 템플릿 저장 완료.
6. 실제 목적지·공용 성공/실패 종료: 실제 최종 착지판→PerformanceRewards 연결 구현. Waiting1인 연습은 별도 연습 결과·재시도만 제공. 최종 검증은 다음 History 참조.
7. 전체4인·외팔 완수/난도 검증·044 후속: 미실행.

## 시점 검증 진행

- 첫 실행11개 중10 PASS. 첫 운반 Grab/Drop·시선 유지·몸 표시·정지 몸/트램폴린 유지, 사망 관전, 중첩 메뉴 차단, 대포 발사 직후 눈 위치, 기존 연습 회귀 PASS.
- 원본10대 탑승 검사1실패: 순간이동 직후1프레임만 기다린 준비 단계에서 공중 상태 감지. 실제 접지 완료 대기로 수정, 해당 검사 재실행1/1 PASS.
- 신규 partial 스크립트 meta GUID 길이 오류로 초기 컴파일 실패, 유효 GUID로 정정/import 후 컴파일 PASS. 편집 중 공용 CameraViewDirector.PrepareView:210 오류도 재관찰했으며 공용 코드는 수정하지 않았다.
- 자동 시선 주입은 실제 마우스 조작감 검증과 구분한다. 사람 실입력·4인·commit/push/PR은 미실행.
