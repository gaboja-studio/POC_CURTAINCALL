# 추격자 외관 레이어

## 사용 순서
1. Unity의 대기실 씬에서 Tools → Curtain Call → Pursuit → Mannequin Designer를 연다.
2. 탑뷰 마네킹을 선택한다. 오른쪽 선택 / 순찰 → 마네킹 설정 → 외관 레이어로 이동한다.
3. 기본 조합에서 자동 다양화/프리팹 기본/기존5상태 중 하나를 고른다.
4. 때 정도·마모 정도·혈흔 정도(각0~1)를 원하는 조합으로 바꾼다. 하나를 바꾸면 다른 두 값은 유지된다.
5. 때·마모 무늬와 혈흔 무늬(각0~15)는 독립이다. 피를 바꿔도 때가 함께 움직이지 않는다.
6. 선택 외관 가까이 보기로 확인하고 위쪽 저장을 누른다. 씬 저장·재열기·Ctrl+Z/Redo를 지원한다.

## 아래에서 위로 쌓이는 층
| 층 | 표현 | 설정 |
|---|---|---|
| 피부 / 봉제 | 원래 마네킹 피부, 더 촘촘한 관절 교차 실밥과 바늘 자국, 꿰맨 천 조각 | 모델별 기본층 |
| 때 / 마모 | 큰 때 얼룩, 작은 긁힘·표면 마모·천의 바램 | 때 정도, 마모 정도, 때·마모 무늬 |
| 혈흔 | 개체별 국소 핏자국과 손자국, 포획 후 추가 피 | 혈흔 정도, 혈흔 무늬 |

예: 때0.9 + 마모0.8 + 혈흔0.2는 심하게 낡았지만 피는 적은 인형이다.
때0.1 + 마모0.1 + 혈흔0.9는 비교적 깨끗한 바탕에 피가 많이 묻은 인형이다.
피 표시를 끄면 혈흔층만 숨겨지고 피부·봉제·때·마모는 그대로다. 배치 에디터는 혈흔을 포함한 디자인을 보여준다.
포획 수 초기화는 선택한 기본층·오염 설정을 바꾸지 않는다.

## 기존 선택 보존
기존 외관/얼룩 무늬는 기본 조합으로 그대로 읽힌다. 슬라이더를 조절하기 전에는 씬 데이터를 자동 변경하지 않는다.
직접 조절 후 기본 조합으로 되돌리기를 누르면 해당 프리셋 값으로 돌아간다.
기본 조합을 새로 고르면 직접 조절 모드가 해제되며, 이후 다시 각 층을 조절할 수 있다.
현재 사용자 WaitingRoom 저장본은 자동으로 덮어쓰지 않는다.
