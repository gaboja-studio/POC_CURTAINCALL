로컬 준비 브랜치는 이미 생성하는 방식으로 승인되었다. 작업 공간 확정 후 인계 상태를 갱신하고 기존 브랜치에서 준비 변경을 받는다. assign-task.ps1은 기존 로컬 브랜치 생성과 충돌하므로 그대로 재실행하지 않는다. 준비 브랜치는 origin 공개 예정이며 작업 공간 확정 전 구현 금지는 유지한다.
