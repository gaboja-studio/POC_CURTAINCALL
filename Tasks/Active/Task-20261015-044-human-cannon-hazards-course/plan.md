# Plan

## Context

044는 043 다음 예약 단계다. 폴더·빈 씬(root 0)만 준비됐으며 인간 대포 기능은 구현되지 않았다. 아래는 실행 근거가 아닌 예정 계획이다.

## Activation

1. PM이 043 integrated·실제 4인 공동 테스트 근거(공용 종료 연결 포함)·소유권 반납·실제 JIRA URL을 확인한다.
2. 다음 1개인 044에만 Active Task/Allowed를 부여하고 승인된 준비 브랜치에 배정 문서를 Merge commit으로 sync한다.
3. 기존 feat 브랜치는 앞 단계 완료 후 최신 부모 이력을 받는다. 실제 전달 PM 확인 이후만 start-work한다.

## Approach

1. 일반 공중 왕복 가시추·회전 날개 절단과 공중/지상 송풍 수평 밀림을 배치한다. 지상 왕복/교차 톱은 PM과 합의한 둘 이상의 대응법이 가능한지 검증한다(톱 2종 고정 요구 아님). 공용 절단 순서 왼다리→오른다리→왼팔→오른팔/일반 1곳을 읽기/재사용한다.
2. 다리 1 손실은 운반 느림·몸 점프 낮음·공중 반응 둔화, 대포/트램폴린 반동 높이 유지. 다리 2는 기어가기·낮은 몸 점프·낮은 손잡이·높은 몸 점프 없는 탑승/쉼터 진입이며 다리 1보다 쉬워지지 않는다.
3. 부상 3 외팔은 두 다리 제약 유지·시간이 필요한 손잡이 잡기/탑승 지연, 반동·정지 정상(반동 자체 지연 없음)이다. 장치 이용을 금지하거나 완수를 막지 않는다. 공통 UI 조작은 부상 무관.
4. 일반 절단과 일반 바닥 추락 즉사·불꽃 접촉 사망 설계안을 구분한다. 난도 1~3 프리셋을 안내하고 실제 4인 약 5분·다인 연속 받기·필수 관문 우회 불가·외팔 완수를 측정한다.

## Files / Risks

- 예정 파일은 setup 예약 구역만, 현재 수정 권한 없음. main_stage.unity는 025 소유, 외줄 원본은 읽기/재사용만 허용.
- 공용 부상·관전·종료 수정은 별도 소유 Task. 043 공용 종료 계약 미연결이면 전체 통합 종료 검증 BLOCKED이며 임시 우회하지 않는다.
- 함정 거리/속도/판정·최종 밸런스값 미확정. 시험 프리셋 값·안내·측정 결과를 기록하되 원문 수치를 확정값으로 복사하지 않는다.
- 지상 2명 규칙·중계 대포·호응/보상 수치·2~3인은 미정/후속이며 구현 목표에 넣지 않는다.

## Auto Verification

- 구역: 예약 — 미배정. PM 준비 문서·컴파일·기존 EditMode 결과는 handoff의 Verification 참조.
- 이 단계 기능 자동 테스트·실행 로그·실제 4인 검증: 미실행.
- 활성화 후 `pwsh -File Scripts/check-work.ps1 -Mode PlayMode`로 검사하고 구역→문서→컴파일→PlayMode 테스트→실행 결과를 사실대로 기록한다. 테스트 부재는 NO_PROJECT_TESTS, 실제 플레이 PASS가 아니다; fixture는 4인 전체 플레이·시간·난도·외팔 완수 근거를 대체하지 않는다.
- PM 준비의 기존 EditMode 5/5 검사와 이 단계 PlayMode/실제 4인 검증은 별개다.

## 공동 테스트 항목

합의·실행 전 계획이다. 모든 묶음은 실제 4인 플레이로 수행하며 실제 결과는 handoff에 따로 기록한다.

1. 일반 함정·둘 이상의 대응

- 씬: HumanCannon.unity (setup 예약 테스트 씬, 현재 040 소유; 이관 후 실행).
- 인원: 4인(호스트 1·참가자 3). 지상 담당을 호스트→참가자로 교환하고 같은 순서를 반복한다.
- 재현: 공중 가시추/회전 날개 접촉→부상 순서 확인→공중/지상 송풍 밀림→왕복/교차 톱에 합의한 대응법 2개 이상 각각 시도→일반 추락/불꽃 접촉을 별도 회차로 비교한다.
- 예상: 일반 접촉은 공통 순서 한 곳 절단, 송풍은 수평 밀림; 지상 톱에 둘 이상 실현 가능한 대응 존재. 일반 절단과 추락/합의한 불꽃 사망 판정을 혼동하지 않으며 네 화면에서 일치한다.
- 실제 기록 방법: 일시·4인 이름/역할·commit·시험 프리셋/판정·함정별 재현/대응법·부상/사망/밀림 영상·로그·예상 대비 실제를 handoff에 남긴다. 현재 미실행.

2. 다리 1/2·외팔 제약과 완수 가능

- 씬: HumanCannon.unity (setup 예약 테스트 씬, 현재 040 소유; 이관 후 실행).
- 인원: 4인(호스트 1·참가자 3). 지상 담당 호스트/참가자 교환 후 부상자가 지상/비행 역할을 번갈아 맡는다.
- 재현: 정상 기준 측정→다리 1 손실 운반/몸 점프/공중 조작/반동→다리 2 기어가기·낮은 손잡이·탑승/쉼터→부상 3 외팔 잡기/탑승/정지/반동/다시 받기/인계→구간 완수한다.
- 예상: 다리 1 둔화에도 대포/반동 높이 유지, 다리 2는 더 불리하되 높은 몸 점프 없이 진입 가능. 외팔은 두 다리 제약·손잡이 잡기/탑승 지연을 유지하며 반동/정지 정상(반동 자체 지연 없음), 이용 금지·완수 차단 없음; 공통 UI는 부상 무관.
- 실제 기록 방법: 일시·4인 이름/역할·commit·부상 단계별 속도/몸 점프/반동 높이/잡기 시간·입력 순서·완수/막힘 영상·로그·실제 비교를 handoff에 남긴다. 현재 미실행.

3. 약 5분 전체 코스·협동/외팔·난도 안내

- 씬: HumanCannon.unity (setup 예약 테스트 씬, 현재 040 소유; 이관 및 043 공용 종료 연결 후 실행).
- 인원: 4인(호스트 1·참가자 3). 지상 담당 호스트/참가자 교환 회차와 외팔 지상/비행 회차를 모두 수행한다.
- 재현: 난도 1→2→3 프리셋/안내 확인→각 회차 분리 출발/첫 받기→필수 봉 협동·다인 연속 받기→쉼터/재출발→마지막 협동→쿠션/최종/실제 목적지; 별도 회차로 협동 우회 시도·외팔 완수한다.
- 예상: 4인 전체 코스가 약 5분 목표에 접근하며 필수 협동 우회 불가·연속 받기·외팔 완수 가능. 난도 안내와 실제 시험 설정 일치, 최종 밸런스는 미확정; 공용 미연결이면 통합 종료 검증 BLOCKED.
- 실제 기록 방법: 일시·4인 이름/역할·commit·공용 연결 근거·난도별 시험값/안내·시작/도착/종료/구간 시간·우회/외팔 결과·영상/로그·약 5분 대비 실제와 조정 요청을 handoff에 남긴다. 현재 미실행.
