# 044 전체 기능 구현 및 연속 코스 확장

이 문서는 최초 전체 구현 이력이다. 이후 봉 수/위치/동작·함정 밀도·관문 변경은 [후속 조정](20261016-strategic-poles-and-saw-walls.md)이 우선한다.

## 사용자 확정 범위

- 5단계 전체 기능을 이어서 구현. 별도 기능별/1인 코스는 삭제하고 기존 연속 코스가 기본이다.
- 목표 플레이 시간은 5분에서 10분으로 변경. 첫째/둘째 관문 뒤 각각30m 연장, 일반 봉 약6m 간격 시험안 승인.
- 추가 지시: 일반/관문 연결 봉 모두 고정된 천장 매달림 형태, 실제 천장 면은 만들지 않는다.
- 난도1/2/3 시험값: 일반 함정 속도1/1.25/1.5배·바람0.6/0.8/1.0m/s, 기본1. 지상 톱은 기다려 통과 또는 옆으로 회피한다.
- 10분은 실제4인 측정 후 조정할 목표다. 제한시간 실패나 최종 밸런스 확정이 아니다.

## 구현 결과

1. 부상 제약: 앞선 [기록](20261016-injuries-and-original-course.md) 유지. 다리1 이동/공중80%, 다리2 기존 기어가기/공중50%, 외팔 잡기/탑승0.6초 호스트 재검사. 반동·발사 높이/즉시 놓기·공통 점프 유지.
2. 일반 함정: 가시추2·회전 날개2·지상 교차 톱4. 공유 서버 시각으로 동일 궤도를 표시하고 호스트만 실제 몸 캡슐과 이동 구간을 검사한다. 공통 ServerCut으로 접촉당1부위, 동시에 여러 함정에 닿아도 한 프레임1부위다. 접촉을 벗어나 다시 들어가면 새 절단이다.
3. 송풍: 공중2·지상2. 플레이어 소유자 이동에 수평 속도만 더하고 입력 보정과 구분한다. 겹친 범위에서도 승인 세기를 넘지 않는다. 공중 변위는 필수 관문 제한 전에 합산하며, 지상 바람 후 접지 유지. 청록 화살표로 방향 안내.
4. 난도/시간: 호스트 선택값·함정 시작시각·첫 발사/결과시각을 공유한다. 정식 공연은 명부 시작 시 공용 보상에 같은 난도를 전달하고 이후 고정한다. 1인 연습은 첫 발사 뒤 고정·R 초기화 후 다시 선택한다. HUD에 목표10:00·경과·난도·대응법 표시.
5. 코스: 관문 뒤 각각30m, 총60m 연장. 기존 봉4개에 일반 봉12개를 추가하여 총16개. 추가 봉은 첫 구간z38~68/둘째z114~144에6m 간격. 기존 연결 봉 포함 모두 상부 빔·케이블·앵커로 고정하며 바닥 지지대와 실제 천장 면은 없다. 물리 진자/동적 봉으로 바꾸지 않았다.
6. 연속 경로: 첫 발사→첫 받기 간격과 관문 기능은 보존. 쉼터/두 번째 출발+30m, 최종 쿠션/대포/목적지+60m. 연장 바닥/측벽·옆 리프트 접근로·불꽃 경계·받는 영역을 함께 이동했다. 옆 연습 코스는 없다.
7. 재시작: 접촉 기록/시계 초기화. 원격 몸이 옛 함정 위치에 남아 있는 동안 다시 절단하지 않고 실제 출발 위치 도착 후 검사 재개. 클라이언트는 재시작 응답 토큰을 확인한 스냅샷부터 적용한다.

## 검증

- Unity6000.3.25f1 컴파일 PASS, EditMode HumanCannon338/338 PASS(순수 충돌·배치·연속 경로·봉16개·기존 회귀 포함).
- PlayMode HumanCannon9/9 PASS(25.06초). 기존5개와 새4개, 실제 LAN호스트1명 fixture다. 난도 잠금/공용 정산·실제 지상 바람·재시작 옛 위치 보호/재접촉 절단을 확인했다.
- 씬 빌더는 Unity Editor API로 기존 HumanCannon 씬에 순서대로 적용/저장. root15·봉16·일반 함정8·송풍4. Scene View 이미지에서 상부 매달림/천장 면 없음/두 연장 구간을 확인했다.
- verify-fast PASS(hard0, 범위 밖 기존 WARN6), diff --check PASS. check-work는 PM 위임 전환 문서8개를 scope FAIL로 보고하여 후속을 생략하므로 개별 검증을 병행한다.
- 실제4인 네트워크·실입력·10분 측정·외팔 전체 완수·필수 협동 우회 시도는 미실행이며 자동 검사를 대체 근거로 쓰지 않는다.
- 커밋/push/PR은 요청 전이므로 수행하지 않았다. 코드/씬은044 Allowed 안, 공용 Systems/Resources/Packages/ProjectSettings 변경 없음.

## 사용자 확인 순서

1. 기존 HumanCannon 씬 Play→LAN Host. 시작1인칭, 트램폴린 잡기3인칭/놓기1인칭, 대포 탑승3인칭/발사1인칭 확인. 난도1로 시작한다.
2. 첫 출발/받기→관문 연결 봉 협동을 확인하고, 연장 구간의 고정 봉을 타며 가시추·회전 날개·바람을 확인한다.
3. 지상 담당은 톱을 기다렸다 통과/옆으로 회피를 각각 시도한다. 일반 함정의 순차 절단과 바닥 추락·불꽃 사망을 비교한다.
4. 쉼터 리프트→두 번째 출발/관문→연장 구간→쿠션→독립 최종 대포→초록 FINISH 순서로 확인한다.
5. 다리1/다리2/외팔로 잡기·운반·탑승·공중 조작을 비교한다. 난도2/3은 별도 회차로 진행한다. 실제4인 전체 소요시간/막힌 위치를 기록해10분 목표와 비교한다.

## PM 지식 반영 제안

- 결정 갱신: 인간 대포 약5분→10분 목표, 기존 코스만 유지·각30m 연장, 모든 봉 고정 상부 매달림 형태, 승인 난도 시험값. Harness는 PM이 갱신한다.
- 함정 기록 제안: 공통 Restarted는 원격 Transform 순간이동보다 먼저 도착할 수 있으므로 새 피해 시스템은 출발 위치 수신까지 옛 위치 충돌을 보호해야 한다. 정산 난도는 명부 시작 전에 선택/고정해야 한다.
