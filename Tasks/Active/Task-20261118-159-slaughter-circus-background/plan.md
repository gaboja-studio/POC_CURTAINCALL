## Context
신규 에셋을 포함한 private 서브모듈 전체를 조사하고 공용 공연장을 어둡고 강압적인 살육의 서커스로 고도화한다. 첨부 실공연 사진은 어둠과 절제된 스폿 대비의 참고이며, 플레이어·공연 오브제 가독성을 우선한다. 현재 로그인 계정 @MoHoDu가 요청을 실행하며 공연장 기존 담당은 @RagSpirin이다.

## 계획
사용자가 지정한 순서를 유지한다.
1. 보유 에셋 전수 목록과 테마 적합 후보 확인.
2. 현재 공용 배경 및 외줄·인간 대포 화면/조명 코드 확인.
3. 실제 에셋으로 구현 가능한 배치·명암·색상·연출 기준 수립.
4. 예상 게임 화면 원화를 생성하고 사용자 피드백을 받는다.
5. 피드백 반영 후 Unity 에디터에서 실제 배치.
6. 공연 중심에서 멀수록 어두워지는 조명 조정.
7. 천장 곳곳의 실물 등기구에서 플레이어를 추적하고 색상을 조절하는 스폿 연결.
8. 실제 적용 결과 짧은 영상과 로컬 HTML 보고서 작성.
9. 사용자 피드백과 수정.

전체 에셋을 후보군으로 조사하되 모든 프리팹을 한 씬에 넣지는 않는다. 기존 게임 규칙과 코스 배치를 보존한다. GameSettings 규칙 우회가 필요하면 사용자에게 확인한다. commit/push는 요청 전 하지 않는다.

## 미정·주의
4단계 피드백 완료: 사용자가 원화 A 방향으로 진행 요청. 빛기둥의 번짐을 줄이고 조명받는 플레이어를 확실히 구별하며, 스폿·배경 감광·객석 조명 등을 에디터 설정과 한국어 툴팁으로 노출한다. 추가 피드백: 객석에 약한 조명을 넣어 어두워도 공연장 느낌이 유지되어야 한다.

공용 배경은 private PerformanceBackground 씬과 MainStage/PerformanceFinaleLighting, Systems/PerformanceBackground와 겹친다. 서브모듈 원본 에셋/GUID를 보존하며 새 재질은 파생본으로 만든다. URP 지원과 다인원 조명·성능은 실제 적용 후 검증한다.
