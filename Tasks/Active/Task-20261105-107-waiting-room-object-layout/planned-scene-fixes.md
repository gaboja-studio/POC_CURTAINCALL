# 대기실 보상 및 배치 수정 제안

대상: Assets/Scenes/InGame/WaitingRoom/WaitingRoom.unity

## 적용 준비된 보상 코드
- 머리핀 15%, 공연 토큰(자금 10원) 20%, 빈 상자 65% 중 하나만 선택한다.
- 호스트가 개방 시 한 번 추첨하고 진행 기록에 결과를 보관한다. 재시도/인벤토리/바닥 용량 문제로 재추첨하지 않는다.
- 토큰은 바닥 기물로 생성되며 F로 획득하면 기존 공동 자금 장부에 10원을 한 번 입금한다.
- 새 낡은 상자는 이 보상표를 기본값으로 사용한다.

## 아직 실행되지 않은 씬 변경
1. 현재 활성 낡은 상자 11개의 빈 보상 설정을 위 표로 변경한다. 아이템 번호는 기존 번호와 겹치지 않게 배정한다.
2. 폐기물 보관소 TrialPadlockedTrunk의 계단 열쇠를 기존 뒤쪽 1m 지점에서 트렁크 앞쪽 0.9m 바닥으로 이동한다. 해제 조건은 유지한다. 조건 연결과 원래 바닥 좌표는 유효했으며, 열쇠 미표시의 원인이 이 위치라고 확정된 것은 아니다.
3. 사진 근처 Bed_B의 통짜 BoxCollider를 끄고 활성 외형 메시별 정적 충돌체를 사용한다. 둥근 캡슐의 모서리 법선 때문에 잘못된 지면으로 판정하는 경우를 줄이는 PlayerMover 코드도 수정했다. 실제 플레이 재현 확인은 사용자 담당이다.
4. 변경 후 지정된 씬만 저장한다.

자동 승인 검토가 위 씬 수정/저장을 거절하여 실행하지 않았다. 사용자 승인 전에는 실행하거나 다른 경로로 우회하지 않는다.
- 최신 사용자 지시: 트렁크는 수정 대상에서 제외한다. 현재는 구현 여부 확인만 요청했으므로 본 계획의 씬 변경은 추가 실행하지 않는다.
- 2026-11-05 최신 명시 요청으로 상자11개 보상과 트렁크 열쇠 위치만 적용·저장 완료했다. 선반/벽 충돌을 피해 +forward 앞쪽으로 배치했다. 침대 수정은 실행하지 않았다.
