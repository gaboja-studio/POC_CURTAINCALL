# 빠른 확인용 치트

## 사용
- 기존 Dev 모드를 켜고 F9를 연다. 상단의 외줄/대포 1·2·3단계 버튼으로 해당 난이도의 새 테스트 런을 시작한다. 연결 중이면 호스트가 실행하며 팀원도 함께 이동한다.
- F8의 공연 시작 설정에서도 난이도 1~3을 선택할 수 있다. 일반 런의 난이도·해금·클리어 이력은 변경하지 않는다.
- F8의 `공연 클리어 이력 유지`를 켜면 공간 이동 후에도 외줄타기/인간 대포 최고 클리어 단계와 그에 따른 난이도 해금을 보존한다. 기본은 꺼짐이며 보상 결과 이력·크레딧과는 별개다.
- 탈출로에서 F9 상단의 `탈출로 체크포인트`를 사용한다. 후반 질주 시작, 후반 그네 앞/뒤, 마지막 화염 구간, 출구 절단기 앞, 마지막 문 앞 6곳이 나온다.
- 탈출로에서 F9 → `마지막 문 열기 (호스트)` → `탈출로 · 갈대밭 · 엔딩 도착` 순서로 엔딩을 확인한다. 문을 열면 갈대밭 이동 지점이 추가된다. F8로 직접 시작한 탈출로도 지원한다.
- 문 열기는 Dev 모드의 준비된 호스트만 실행한다. 출구 필수 배선 절단 상태를 기존 장치끼리 공유하고 네트워크에 발행한다. 문은 원래 개방 연출을 따르며 재시작하면 닫힌다.
- 직접 탈출 테스트에서 리타이어하면 기존 출발점 재시도가 유지된다. 엔딩 후에는 결과창의 로비 복귀 버튼을 사용한다.

## 검증
- 후속 검증: 실제 호스트 공연→F8 탈출로 전환에서 외줄2/대포1 유지 및 최고 선택 단계3/2, 후반6지점 이동, 문 개방→갈대밭→결과창, 로비 복귀 후 옵션 해제 시 두 이력 초기화 확인. F8/F9 화면은 `Previews/clear-history-panel.png`, `Previews/checkpoints-panel.png`.
- Unity 6000.3.25f1 일반 에디터, 별도 작업 프로젝트, 실제 LAN 1인 호스트.
- `DevStartPointTests` 28/28 PASS: 공연6조합, 잘못된 난이도 거부, 기존 진행/시작 규칙 포함.
- F9 호출 경로로 외줄/대포×1/2/3 실제 이동6회. 런 상태와 PerformanceRewards 난이도 일치, 치트/시작 창 닫힘 확인.
- 후반6지점 실제 플레이어 이동 후 바닥 존재·Normal·목표 거리0.05m 확인. 출구 개방 후 갈대밭 도착 Arrived→Ending 확인.
- 직접 시작 리타이어 후 Normal 복구, 같은 세대·Escape 유지 확인.
- 최초 갈대밭 검사는 절단 완료 상태를 주입했다. 문 열기 치트 추가 후에는 F9의 공개 호출 경로로 배선24/24·문 회전·갈대밭 Arrived/Ending·결과창 표시를 확인했다. Dev-off 거부·중복 호출 안정성·재시작 후 닫힘/재개방도 PASS (`Verification/door-cheat-play.json`). 절단 수동 완주·다중 클라이언트는 미검증.
- JSON 근거는 `Verification/cheat-*.json`, F9 화면은 `Previews/cheat-panel.png`. 실행 도구는 `Tools/cheat-probe.cs`이며 게임 Assets에 포함되지 않는다.
