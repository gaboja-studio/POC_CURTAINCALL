# Dev 체크포인트 편집기

- Unity에서 공연/탈출로 씬을 열고 `Tools > CurtainCall > Dev > 체크포인트 편집기`를 연다. 목록이 없는 씬에서도 만들 수 있다.
- 기본 지점 불러오기로 코스에 맞는 목록을 시작한다. `+`는 선택한 오브젝트나 Scene 뷰 중심에서 지점을 추가하고 주변 바닥에 맞춘다. 행을 선택해 위치와 방향을 잡고, 행 왼쪽 핸들을 드래그해 F9 순서를 정한다. 씬 저장으로 팀과 공유한다.
- F9 상단에서 지점으로 순간 이동한다. `마지막 체크포인트에서 모두 부활`은 호스트만 누를 수 있으며, 맨 아래 부활 가능 행에 팀을 모으고 부상을 회복한다. 일반 재시작 위치나 런 세대는 바뀌지 않는다.
- `순간 이동 전용`은 팀 부활 위치 계산에서 제외한다. 공연 도착선과 갈대밭에 적용한다. 갈대밭은 출구 개방 이후에만 표시한다.
- 기본 목록: 외줄 6개, 대포 11개, 탈출로 15개(최신 추격 구간·최종 전투 포함). 이전 기본 순간 이동은 F9 일반 위치 이동 목록에서 이용할 수 있다.
