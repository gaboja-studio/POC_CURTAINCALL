# 결과창 피드백과 부상자 2인 엔딩

- 검은 원은 개인 최고 호응 초상화의 바탕과 테두리다. 기록이 없으면 둘을 숨기고 —를 가운데 표시한다. 실측 0점은 그대로 0이다.
- 마스크 원의 반경 60/128이 테두리 안쪽 57.5/128보다 컸다. 표시 면을 95%로 줄이고 가운데를 유지했다. 토큰 행 중심은 구분선 468/556의 중간인 512.
- 기존 Canvas/PlayerRow를 Unity Prefab API로 수정하고 재생성 코드와 Task 소스를 맞췄다. 이전 전달용 v1 보관 파일은 별도.
- 첫 2인 실행에서 선두와 부상자 사이가 약 33m로 벌어졌다. 같은 갈대밭 경로의 뒤쪽 참가자와 간격이 벌어지면 선두 입력을 줄여 기존 플레이어 이동과 부상 표현을 유지한다.

## 캡처한 실게임 런

- Unity 6000.3.25f1 실제 LAN 호스트/클라이언트(보조 Unity 에디터). 단원 2 곰에 공용 순서 절단으로 왼쪽 다리 부상 적용. 외줄타기 1단계 클리어 1/1, 정산 획득 200/소모 0, 호응 0. 같은 세대에서 두 사람 모두 탈출, 양 화면 결과 동일.
- 이동 치트로 도착선을 통과하고 실제 공연·탈출 판정으로 정산했다. 대기실 집결 및 탈출 전환도 동일 세대에서 실행했다. 수동 코스 전체 완주 테스트는 아니다.
- 테스트 시작 시 클라이언트 공연 배치 진입점을 호출하고, 탈출에서 호스트 문 열기 뒤 양쪽을 갈대밭에 배치했다. 이 구성에서 클라이언트 문 상태 갱신은 확인되지 않아 그 화면은 실제 갈대밭 표식 좌표로 이동했다.
- Player 탭 초상화에는 부상 배지가 없다. 갈대밭의 곰은 왼쪽 다리 없는 게임 모델이며 호스트와 같이 움직인다. 양쪽 뷰포트 내부 확인, 이후 호스트에서 약 283m 더 이동한 후에도 두 명이 화면 안(가로 0.81/0.70).
- 캡처: `Previews/ending-two-player-{players,statistics,meadow}.png`. 배경은 캡처할 때만 결과 레이어를 숨겼다. `Verification/feedback-*.json`, `Tools/ending-feedback-probe.cs`.
