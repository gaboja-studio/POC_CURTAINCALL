# Plan

## Context

Start 진입부터 대기실, 외줄타기·인간 대포의 플랫폼까지 같은 달리기·앉기를 공용 조작으로 제공한다(2026-10-19 PM @MoHoDu 승인 계획).
키 → 입력 역할 → 조작 규칙 → 이동 부품 구조를 확장하며, 묘기 전용 조작(줄 위, 대포 탑승·비행)에서는 동작을 정의하지 않고 입력 진입 로그만 남긴다.

사용자 확정(2026-10-19):
- LShift 달리기·LCtrl 앉기는 WASD 조합과 무관한 홀드, 떼면 복귀. 기존 문서의 조합 토글 설명은 적용하지 않는다.
- 동시 홀드는 앉기 우선. Ctrl을 떼고 Shift가 남으면 기립 공간이 있을 때 달리기.
- 달리기 배율 1.5, 앉기 이동 배율 0.5, 앉기 높이 비율 0.6. 공통 GameSettings에서 각각 조정, 플레이 중 반영.
- 달리기 중 WASD·점프 가능(점프 관성 유지), 앉은 상태는 느린 이동·점프 금지.
- 앉기: 발 고정, 외형·충돌 높이 감소, 머리 위 장애물이 있으면 기립 차단(떼도 앉은 상태 유지), 온라인 자세 공유. 전용 애니메이션 없음.
- 1인칭 카메라는 낮아진 눈높이를 따른다. 3인칭 거리·줌은 유지.

## Approach

1. `setup.md`의 배정된 공용 파일 안에서만 구현.
2. 달리기·앉기 요청은 이동 입력처럼 매 프레임 유효하게 이동 부품에 넣는다. 조작 규칙 전환·대포 전용 이동·입력 차단 시 요청은 자동으로 사라진다.
3. 실제 앉기 상태는 이동 부품이 요청과 분리해 유지한다. 몸이 커질 때(기립·부상 회복)는 머리 위 공간을 검사한다.
4. 속도 = 기본 × 부상 × 자세 배율, 점프 = 기존 허용 AND 실제 앉기 아님. 앉기 높이 = min(정상 캡슐 × 비율, 부상 목표 높이).
5. 외형은 모델 슬롯 Y 스케일(발 기준)로 낮추고, 래그돌 분리·모델 교체 때는 중립 크기로 처리한다.
6. 기존 테스트 파일만 확장하고 새 테스트 어셈블리는 만들지 않는다.
7. 구현 완료 후 `check-work`(EditMode)와 PlayMode 검증을 한 번에 집중 실행한다.
