# 대기실 레이아웃 명세 (구조도 기준)

원본: [reference.webp](reference.webp) — 위에서 내려다본 대기실 구조도(2026-10-20 사용자 제공).
목적: 이 그림과 같은 장면을 Unity에서 다시 만들 수 있도록 공간·배치·분위기를 수치로 옮긴다.

## 좌표 규칙

- 단위 m, Y 위. **+X = 그림 오른쪽(동)**, **+Z = 그림 위쪽(북)**. 원점 = 로비 바닥 중심.
- 기존 그레이박스(`WaitingRoomGreyboxBuilder`)와 같은 축이다(로비 x ±10, 숙소 z 9~16).
- 그림 환산: 약 **27px = 1m**. `x = (px - 610) / 27`, `z = (485 - py) / 27`.
- 그림은 평면도라 높이 정보가 없다. 높이는 기존 결정(벽 10m, 문 3m)을 따른다.
- 좌표는 그림에서 잰 근사값(±0.5m)이다. "추정"은 그림에서 가려져 확정할 수 없는 값이다.
