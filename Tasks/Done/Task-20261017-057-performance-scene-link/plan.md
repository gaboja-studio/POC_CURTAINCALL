# Plan

## Context

시작·로비의 기존 게임 흐름에서 더미 대신 지정 줄타기와 인간 대포를 연다. 묘기 순서·규칙은 유지하며 직접 씬 실행도 보존한다.

## Approach

1. 세팅 기반 묘기별 씬 선택, 미등록 종류는 기존 더미 fallback.
2. 공간뿐 아니라 목적 씬을 구분하고 기존 NGO/오프라인 로드를 재사용.
3. 대포 기존 정산 재사용. 줄타기는 별도 연결 어댑터와 기본값 보존 lifecycle hook.
4. 연결 모드만 방 종료·자동 전원복구·재도전 차단. 부상·자금·세션 유지.
5. 결과 처리 완료 후 공연 식별자를 재확인하고 공용 정산 한 번. 기존 씬/프리팹 무수정 우선.

## Files

- 수정 예정: setup의 공용 파일, 관련 세팅/빌드 목록, 신규 회귀 테스트.
- 읽기 전용: Campaign/Reward/Network/StartLobby/HumanCannon 및 실제 두 공연 씬.

## Risks

- 늦게 발견한 Playing 세션, spawn 지연, 결과 이벤트 재진입, Additive 중복 관리자.
- 기존 소유 밖 씬/프리팹 변경이 필수면 멈추고 PM 공동 변경 요청.

## Auto Verification

- 구역 검사: check-work.
- 1 문서/규칙: verify-fast.
- 2 컴파일: 대상 Unity 에디터.
- 3 테스트: 라우팅·지연 시작·부상 보존·정산 중복·독립 회귀 EditMode/PlayMode.
- 4 실행 로그: 오류/예외 확인. 합성 테스트와 실제 입력을 구분.

## 공동 테스트 항목

1. Start→Lobby 준비/레버→기존 순서 줄타기→중간 진행→인간 대포. 호스트/참가자 같은 씬·출발 위치·조작 확인.
2. 공연 성공/실패 후 정산 한 번·다음 시간대·부상/자금/접속 보존·엔딩/로비 복귀.
3. 인간 대포와 줄타기 씬 직접 실행의 기존 연습·조작·종료·재시작 확인.

- 기능 완성 후 한 번에 확인. 2인 환경 미확보 시 미실행, 1인/자동 결과로 대체하지 않는다.
