# 대기실 화면 문구 (Task-086)
# 형식: 키 | 문구   (한 줄에 하나)
# - 키(| 왼쪽)는 바꾸지 마세요. 코드가 키로 문구를 찾습니다. 줄을 지우면 코드의 기본 문구를 씁니다.
# - #으로 시작하는 줄은 설명입니다. 줄바꿈은 \n 으로 씁니다.
# - {item}, {n} 같은 이름표는 게임이 실제 값으로 바꿉니다. 각 구역 설명에 뜻을 적어 두었습니다.
#   이름표를 지우는 것은 괜찮지만, 그 줄에 없던 새 이름표를 넣으면 채워지지 않습니다.
# - 조사 자동: {item:을} → 받침에 맞춰 을/를. {x:이}(이/가), {x:은}(은/는), {x:과}(과/와), {x:으로}(으로/로), {x:이다}(이다/다)
# - 고친 뒤 플레이를 다시 시작하면 반영됩니다.
# - 튜토리얼 안내 문구는 WaitingRoomTutorialTexts.txt, 안내 패널 수치는 WaitingRoomTutorialPanel.txt에 있습니다.
# - 단서·문·상자·벽 이름은 맨 아래 "탐색 대상 이름" 구역에서 고칩니다. 벽 표지판·CCTV·공연 이름은 Unity 인스펙터에서 고칩니다.
