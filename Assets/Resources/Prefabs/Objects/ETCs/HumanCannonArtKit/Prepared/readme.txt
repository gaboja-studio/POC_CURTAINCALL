공용·인간대포 오브젝트 적용 준비본
작업자: 주형락 / 2026-10-20
상태: 15종에 대한 프리팹 16개 구성·검사 완료. 씬에는 적용하지 않았습니다.
공용 봉은 중립 연결본과 인간대포 기능 연결본을 각각 제공합니다.

어떤 폴더를 쓰나요?
PerformanceArtKit/Prepared: 공용 바닥·계단·봉·로프·그네·발판·안전망 7개.
HumanCannonArtKit/Prepared: 인간대포 기능을 연결한 준비본 9개.
기존 폴더의 외형 전용 프리팹 대신 Prepared의 연결본을 검토합니다.
readiness.json에 기존 시트 ID별 프리팹 경로·판정·연결 항목을 기록했습니다.

맞춘 내용
• 바닥: 콘크리트 4×4m. BoxCollider 상면과 보이는 바닥 모두 y=0.
• 계단: 실제 계단 메시와 같은 MeshCollider. 진입 y=0, 위쪽 약1.83m.
  Top은 높은 단의 실제 표면, Bottom은 낮은 쪽 진입점입니다.
• 대포: 현행 탑승·좌석·포구와 같은 기준점. 대표 대포의 발사값을 복사했습니다.
• 원형 트램폴린: 천 지름4m·높이0.5m. 보이는 천에 맞춘 원형 반동 판정.
  프레임 최대 반경2.475341m와 손잡이(-2.8,0,0)를 함께 운송 검사합니다.
  기존 반동 속도12m/s·운반 및 공중 조절4.5m/s를 복사했습니다.
• 봉·그네: 봉 중심과 길이1m의 케이블 메시를 정규화했습니다.
  기존 진자 로직이 봉 위치·줄 길이를 바꿔도 외형 중심이 어긋나지 않습니다.
• 톱날: 날 끝 최대 반경과 현재 수학 판정 반경을 맞췄습니다.
• 철퇴: 실제 가시 끝까지의 최대 거리를 구 판정 반경에 맞췄습니다.
• 십자 칼날: 직교하는 기존 선분/캡슐 판정 안에 두 날을 정렬했습니다.
• 톱 관문: 기존 44×2.4×0.6m 차단 판정을 유지한 연결본입니다.
  기존 회전 날을 보존하고 새 지지 구조를 44m 규격으로 확장했습니다.
• 운송 발판: 금속 6×8m. 좌우 경첩마다 바닥 Collider를 연결했습니다.
  문이 열리면 충돌과 안전 착지가 함께 해제되고, 닫으면 복구됩니다.
• 쿠션: 보이는 상면·실제 Collider·안전 착지 면을 y=0에 맞췄습니다.
• 로프·협동 발판·안전망: 보이는 경계와 같은 크기의 Trigger를 준비했습니다.
  자동 탑승·발판 신호·구조는 각 코스의 기존 로직에 연결해야 합니다.

원형 반동 옵션
기존 씬의 트램폴린은 circularSurface=false 기본값으로 기존 사각 판정을 유지합니다.
RoundTrampolinePrepared만 원형 옵션을 켰습니다.
공중에서 받기와 지상 점프 반동 모두 같은 모양으로 접촉을 검증합니다.
호스트의 지연 허용 폭은 기존1m를 유지하면서 원형으로 검사합니다.
loadHalfSize가0인 기존 장치는 이전 반동 면 크기로 운송 검사합니다.

씬 적용 시 연결할 항목 — 현재는 연결하지 않았습니다
1. 대포는 기존 stations 배열에, 함정은 hazards 배열에 등록합니다.
2. 해제봉은 linkedGate 및 PoleSystem의 pole/gate 배열에 연결합니다.
3. 운송 발판은 RouteSystem의 transports 배열에 연결합니다.
4. 기존 위치·방향·코스별 속도·경로·봉 앵커 높이는 원래 배치 값을 유지합니다.
5. 공용 로프·발판·안전망 Trigger는 외줄 코스의 기존 선분/협동/구조 규칙에 연결합니다.
   Trigger만 놓아도 새 게임 규칙이 자동으로 생기지는 않습니다.
6. 기존 오브젝트와 새 오브젝트의 충돌체·기능 컴포넌트가 중복되지 않도록 교체합니다.
