외줄타기 에셋 — 씬 적용 및 외형 정리
작업자: 주형락
대상: Assets/Scenes/Tests/MainStage/Tightrope/Tightrope.unity

1. 적용 상태
기존 씬의 Course에 TightropeArtProfile이 연결되어 있습니다.
Saws에는 가로 톱·정면 톱·협동 톱·두 종류 발판이 연결되어 있습니다.
관리자를 추가하거나 준비 프리팹으로 중복 배치하지 마세요.

2. 로프와 바닥
WalkingRope: 둥근 갈색 줄을 최대 3m 단위로 반복합니다.
구간색은 사용하지 않습니다. 줄·구간 표지·진행 안내의 색 덧칠을 제거했습니다.
로프 두께 0.2m / 실제 지지 폭 0.4m. 반복 메시마다 충돌체를 만들지 않습니다.
바닥은 시멘트·금속 계열입니다. 하부 안전망과 충돌체는 제거했습니다.

3. 봉과 톱
봉은 공용 해제봉의 금속 부품과 로프를 재사용합니다.
봉 몸체는 금속, 매달림 케이블은 짙은 회색 원통입니다. 손잡이 띠로 작동 상태를 표시합니다.
기존 잡기 위치·길이·반동을 따라가며 외형에 별도 충돌체는 없습니다.
톱은 금속 재질입니다. 속도·접촉·동기화 계산은 기존 시스템을 사용합니다.
일반 톱: 외형 지름 1.2m / 접촉 지름 1.0m / 두께 0.1m.
협동 톱: 지름 2.1m / 두께 0.2m. 기존 별도 원판 Collider를 유지합니다.
발판: 일반 0.8×0.8m / 협동 0.8×1.6m / 두께 0.04m.

4. 사용 주의
Profile 변경 후 코스를 재시작합니다. 실행 도중 교체하지 마세요.
Prepared는 연결 예시, Showcase는 외형 모음이며 게임 진행 기능은 없습니다.
노란 위험 전조·연소 효과와 기존 게임 규칙은 유지합니다.
외부 모델·텍스처는 private 원본을 참조하며 공개 폴더에 복사하지 않았습니다.
변경·검증 기록: Docs/References/tightrope-art-cleanup-20261020.md.

5. 전기톱 경로 표시
가로 왕복·정면 진입 경로는 얇은 빨간 레이저 선으로 표시합니다.
정면 톱이 사라지면 경로도 꺼집니다. 레이저 선 자체에는 피해나 충돌 판정이 없습니다.

6. 줄 종류 구분
일반 줄: 갈색 원형 단면.
봉으로 연결하는 줄: 밝은 섬유색에 짙은 띠를 반복합니다.
봉 위 매달림 줄: 짙은 금속 케이블. 일반 줄보다 가늘고 세로로 이어집니다.
구간별 색은 다시 넣지 않았습니다. 외형만 바꾸고 지지 판정은 유지합니다.
