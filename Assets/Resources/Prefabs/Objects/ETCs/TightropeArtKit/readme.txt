외줄타기 에셋 적용 준비
작업자: 주형락
상태: 준비 완료 / 기존 씬 미적용

1. 어디에 무엇이 있나요?
• Prepared/TightropeCoursePrepared: 바닥·구간별 로프·안전망·봉·그네 외형 연결본
• Prepared/TightropeSawsPrepared: 가로 톱·정면 톱·협동 톱·해제 발판 연결본
• Showcase: 외형만 모아 보는 프리팹. 게임 진행 기능은 없습니다.
• TightropeArtProfile.asset: 코스가 실행 중 생성하는 오브젝트의 외형 목록

2. 나중에 적용하는 순서
테스트 씬 복사본에서 기존 Course와 Saws를 각각 준비본으로 교체합니다.
기존 Course의 위치·회전·씬별 설정·참조를 준비본에 옮깁니다.
Fire·Run·UI·네트워크 연결을 확인한 뒤 플레이합니다.
기존 오브젝트 옆에 준비본을 추가하면 코스와 톱 관리자가 중복됩니다.
이 작업에서는 씬 교체나 배치를 하지 않았습니다.

3. 유지한 판정과 수치
• 로프 외형 두께 0.2m / 실제 지지 폭 0.4m. 색 경계에 새 Collider를 만들지 않습니다.
• 일반 톱: 외형 지름 1.2m / 실제 접촉 지름 1.0m / 두께 0.1m
• 협동 톱: 지름 2.1m / 두께 0.2m. 기존 원판 Collider를 별도로 유지합니다.
• 일반 발판: 0.8×0.8m / 협동 발판: 0.8×1.6m / 외형 두께 0.04m
• 봉과 케이블: 기존 잡기 위치·길이·반동을 따라가며, 상태 색도 함께 바뀝니다.
• 줄 생성·소실·노란 전조·연소 시점·속도·점프·카메라는 변경하지 않았습니다.
현재 설정의 6줄·165m를 기준으로 확인했습니다. 과거 330m 기획을 덮어쓰지 않았습니다.

4. 외형 연결 기준
봉은 인간대포 공용 해제봉의 금속 봉·로프 부품을 재사용합니다.
독립된 외줄 생성봉 디자인을 추가하지 않았습니다.
barX는 X축 가로봉, barY·cableY는 Y축 길이 기준의 중심 원점 부품입니다.
코스가 실제 크기와 양 끝점을 정하므로 부품을 직접 움직일 필요가 없습니다.
일반·협동 톱 원본의 회전축은 +Y입니다. 정면 회전은 기존 코드가 처리합니다.
Profile은 실행 도중 교체하지 않습니다. 변경 후 코스를 다시 시작합니다.

5. 공용 에셋과 재질
바닥은 시멘트·금속 계열입니다. 나무 바닥은 사용하지 않습니다.
공용 FloorModule·RopeSegment·SafetyNetModule을 외형으로만 연결합니다.
PerformanceArtKit/Prepared의 Trigger 프리팹은 이 코스에 중복 배치하지 않습니다.
톱·발판·줄에 Collider나 물리 스크립트를 추가하지 않습니다.
에셋 원본은 private Assets/_ThirdParty를 참조합니다. 외부 파일을 공개 폴더에 복사하지 않았습니다.
원본 버전: b92b37a4db5ff840a82d26bf323c3b2831b2698a
세부 출처는 PerformanceArtKit/sources.json과 이 폴더의 readiness.json을 확인합니다.

6. 적용 후 함께 확인할 것
봉을 잡고 반동을 줄 때 손·케이블 끝점이 맞는지 확인합니다.
줄 생성·연소·재시작 시 외형과 지지면이 함께 갱신되는지 확인합니다.
정면·협동 톱과 발판을 두 명 이상으로 통과하며 외형과 접촉이 맞는지 확인합니다.
이번 검사는 준비본과 자동 검사 기준입니다. 실제 멀티플레이 체감 검증은 하지 않았습니다.
