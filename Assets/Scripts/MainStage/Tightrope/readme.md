# 외줄타기 고도화 이어서 작업하기

2026-10-19 기준. 작업 브랜치는 `feat/tightrope-enhancement`, 제출 대상은 `integration/main-stage`다.

## 다른 PC에서 준비

1. Unity를 종료한 상태에서 GitHub Desktop의 이 저장소를 연다.
2. `Fetch origin` → `feat/tightrope-enhancement` 선택 → `Pull origin`으로 최신 내용을 받는다.
3. 처음 받는 PC는 저장소 폴더에서 `git submodule update --init --recursive`를 실행한다. 외부 에셋 저장소 접근 권한이 필요하다.
4. Unity Hub에서 프로젝트를 **6000.3.25f1**로 열고 가져오기·컴파일 완료를 기다린다.
5. `Assets/Scenes/Tests/MainStage/Tightrope/Tightrope.unity`를 연다.
6. 혼자 협동 연습을 하려면 Play를 끈 상태에서 **CurtainCall → Tightrope → Build Local Practice Bot** 메뉴를 한 번 실행한다.
7. Play → **봇 추가 · 로컬 연습** → **외줄타기 시작**. 봇은 따라오기·봇이 위·봇이 아래를 선택한다.

봇 실행파일은 PC마다 빌드하며 Git에는 포함하지 않는다. 봇 코드가 바뀐 뒤에는 같은 메뉴로 다시 빌드한다.

## 현재 조작과 코스

- 플랫폼은 1인칭, 줄에 올라서면 자동 3인칭. 줄 위·점프·목마에서는 마우스로 시점을 회전한다. V 전환은 없다.
- 줄 위 W/S 앞뒤 이동, A/D 균형, Space 점프, Q/E + Space 옆줄 점프. 인간대포 WASD 공중 보정은 봉을 놓은 뒤 비행 중에만 적용한다. 일반 점프는 이륙 궤적을 유지하고, 옆줄 점프는 선택한 옆줄에 자동 착지한다. 봉 도약 뒤 착지하는 순간 비행 입력을 비우고 기존 줄 위 이동·균형·착지 규칙으로 복귀한다.
- 이동 속도·중력은 인간대포 공통 설정(현재 3m/s·9.81m/s²). 2026-10-19 추가 요청으로 외줄 점프 높이만 공통 0.8m의 1.25배인 1.0m로 올렸다. 인간대포 원본 점프 높이는 유지한다.
- F로 목마·동료 받기, F 길게 눌러 해제. 목마 최상층에서 W/S + Space 앞뒤 분리 점프.
- R은 두 플레이어를 포함해 외줄 코스 전체를 처음부터 다시 시작한다.
- 165m·6줄·5구간이다. 0~30m 균형과 점프, 30~75m 해제봉 교대, 75~100m 목마와 높은 봉 접근, 100~130m 공중그네, 130~165m 한 줄 최종 협동이다. 균형·동료 흔들림·받기·측면 톱은 공통으로 유지한다.
- 40~48m는 모든 줄이 끊긴 해제봉 교대 관문이다. 2·5번 줄의 출발 봉(37.5m) 중 하나를 F로 잡으면 3번 통로가 연결된다. 먼저 건넌 동료가 반대편 봉(51m)을 잡으면 2·5번 귀환 줄과 3번 통로가 함께 연결된다. 출발자는 F/Space로 놓고 합류하며 반대편 봉이 유지 중이면 길이 끊기지 않는다. 유지 30초, 해제 후 인간대포의 2초 예고. 첫 관문은 1명 유지이며 설정으로 각 편 2명을 요구할 수 있다. 중간 관문에 자동 솔로 우회는 없다.
- 100~116m는 모든 줄이 끊긴 2인 공중그네 구간이다. 3번 줄 방향에 높은 봉 두 개와 낮은 마지막 봉을 둔다. 목마 위 사람이 W+Space로 분리 점프하고 F로 첫 봉을 잡는다(혼자 점프 높이로는 닿지 않음). 아래 사람이 F로 매달린 동료 몸을 잡으면 상단은 W/S 반동, 하단은 Space로 다음 봉에 먼저 날아가 F로 잡는다. 처음 상단도 Space로 따라가 새 상단의 몸을 F로 잡아 교대한다. 마지막 낮은 봉은 두 번째 봉에서 혼자 도달할 수 있는 경로로 두어 동료가 먼저 줄에 착지해도 남은 사람이 따라갈 수 있다.
- 공중그네 각 봉은 상단 1명+하단 1명, 최대 유지 30초다. 하단이 붙어 있을 때 상단의 수동 놓기는 막고 아래 사람이 먼저 도약하도록 안내한다. 사망·시간 만료·재시작은 매달림을 정리한다. 줄 위에 실제 착지하면 공중 입력·옆줄 목표·이전 점프 상태를 비우고 기존 줄 이동·균형으로 복귀한다.
- 봉 반동·접선 속도·추가 상승 속도는 `HumanCannonPole` 그대로다(추가 상승 6m/s). 공중 보정은 `CannonAirControl`의 3m/s·다리 부상 배율 0.8/0.5를 사용하고 중력 적분은 공용 `BallisticMotion`을 호출한다. 해제봉은 놓으면 원래 지면으로 내려오며 공중 발사하지 않는다.
- 노란 균형 구간도 추락 게이지를 빨강의 1/3 속도로 누적한다. 노랑↔빨강 전환은 누적을 유지한다. 공중에서는 기존처럼 구간 체류 누적을 멈춘다. 현재 기준 추가 착지 없이 노랑만 유지하면 약 6초, 빨강만 유지하면 2초에 추락한다.
- 점프·옆줄 착지 충격은 현재 기울어진 쪽으로만 적용한다. 정확히 중앙이면 이륙 시 방향(옆줄은 Q/E 방향)을 사용하며 매 착지마다 랜덤 방향을 뽑지 않는다. 충격은 목마 배율을 받지만 착지 위험 시간은 기본 충격/100 × 추락 기준 시간으로 한 번만 더한다. 현재 혼자·받기 없이 제자리 착지는 0.2초, 옆줄 착지는 0.7초를 더한다. 연속 착지해도 위험을 중앙에서 즉시 초기화하지 않으며, 줄 위 초록 구간에서 1.5초 연속 안정시켜야 해소한다. 공중 시간은 안정 회복으로 세지 않는다. 동료 손잡기·받기의 50%/90% 완충은 충격과 추가 위험에 함께 적용한다.
- 균형에 느린 왕복과 작은 빠른 진동을 겹쳐 강약이 변하게 했다. 추가 힘은 정지 6·걷기 12/초, 큰 왕복 0.55Hz가 초기값이며 실제 바늘·몸 기울기·추락 판정이 같은 균형값을 사용한다.
- 같은 연결 줄 위 동료의 하중은 앞뒤 12m 안에서 가까울수록 커진다. 동료 한 명당 최대 25%, 총 75%까지 자연·동적 흔들림을 강화하고 진입·이탈은 부드럽게 반영한다. 기존 착지 파동은 유지한다. 다른 줄·끊긴 구간 너머·공중 인원은 제외하고 같은 목마의 하중은 중복 계산하지 않는다.
- 중앙 방향으로 A/D를 누르면 바깥으로 미는 흔들림·기울기·위층 전달이 보정 입력을 상쇄하지 못한다. 양끝에서도 입력 세기 × 기본 보정 속도(현재 85/초) 이상으로 즉시 복귀하고, 복귀를 돕는 흔들림은 그대로 더한다. 입력을 놓거나 바깥 방향으로 누를 때의 흔들림과 노랑·빨강 위험 누적 규칙은 유지한다.
- 4인 목마 코드 검토: 흔들림 배율은 2배이며 같은 목마의 하중은 별도 동료 하중에서 제외한다. 위층 전달은 바로 위 한 명을 재귀 가산하지 않고 실제 위층 값의 합 ×0.2를 한 번 적용해 1층 최대 60/초다. 건강한 4인 목마가 옆줄 착지 직후 걷는 이론상 흔들림 상한은 121.5/초(외부 동료 하중 제외)로 크지만, 중앙 방향 보정은 이 힘과 위층 전달을 합친 뒤 적용되어 입력이 역전되지 않는다. 체감 난이도가 검증됐다는 뜻은 아니다.
- 남은 줄이 연결되도록 양끝에서 무작위로 타며 최종 생존 줄은 달라진다.
- 정면 톱은 최후반 158m에 한 번만 등장한다. 지름 2.1m의 원형 톱이며 소각 후 남을 줄로 접근한다. 기존 중반 톱과 최후반 자동 개방은 사용하지 않는다.
- 마지막 출발선에서 실제 4인 목마를 호스트가 확인하고 당시 1~4층을 기억한다. 4층, 3층이 먼저 W+Space로 발판 너머로 이동하고, 원래 2층이 W+Space로 발판에 착지하여 1층의 길을 연다. 상층이 먼저 떠나도 2층의 도약 자격은 유지된다. 3·4층이 성급하게 발판을 밟아 톱을 튀기는 실수는 막지 않는다.
- 발판을 밟으면 톱이 1.2초 동안 기본 캡슐 높이의 1.5배(현재 2.25m)까지 튀며 시작점 쪽으로 6m 이동한다. 남은 목마를 보호하도록 높이를 자동으로 키우지 않는다. 착지 후에도 3m/s로 계속 회전·이동하고 닿으면 즉사한다. 공중 입력을 추가하지 않고, 출발 때 정해진 도약 궤적을 따른다.
- 측면 톱은 12/21/30/43.5/52.5/61.5/70.5/91.5/100.5/109.5/118.5/124.5/133.5/142.5/151/162m에 배치된다. 줄들을 가로질러 이동하며 후반일수록 빠르다. Space 점프로 피한다.
- 발판을 밟으면 주변 6m 안의 측면 톱이 6초 멈춘다. 마지막 1초는 재가동 전조다.
- 시작 10초 뒤 뒤쪽에서 불길이 0.35m/s로 추격한다. 불길 접촉은 사망 판정이다.
- 줄 소각 범위는 130~165m에 한정한다. 선두가 120m에 도달하면 앞쪽 소각을 예고하고, 한 줄당 1.5초 경고 후 양끝에서 순차 소각하여 무작위 한 줄만 남긴다. 1.5초는 초기 조정값이며 플레이 체감을 확인하지 않았다. 해제봉·공중그네 앞뒤 8m 보호도 유지한다. 실제 지지면·피격·노란 예고·붉은 불이 같은 범위를 사용한다. 뒤에서 오는 추격불과 제한시간은 별개로 유지한다.
- 동료 주변 청록색 범위에 착지하면 기존 손잡기 보조가 충격을 50% 줄인다. F로 3초 동안 받기를 준비하면 앞뒤 1.25m 범위에서 90% 줄인다. 준비 중 이동·점프는 취소하며 A/D 균형 조작은 가능하다.
- 받기 준비는 팔을 내밀고 범위·남은 시간을 표시한다. 마지막 1초는 주황색, 성공은 두 사람에게 초록색 표시와 팔을 드는 동작으로 알린다. 절단된 팔은 조작하지 않는다.
- 착지하면 0.2초 뒤 같은 줄의 앞뒤 6m에 파동이 10m/s로 퍼진다. 동료의 균형 충격은 최대 6에서 거리에 따라 줄어든다. 자기 자신·옆줄·공중·끊어진 줄 너머에는 적용하지 않으며 연속 충격에는 0.5초 간격을 둔다. 받기 준비·성공 직후에는 파동도 90% 완충한다.
- 측면 톱 접촉은 다리부터 팔 순서로 손실시킨다. 정면 톱은 일반 이동 중·관문·튕긴 이후 모두 접촉 즉사다. 사망한 목마 인원의 위쪽은 기존 연쇄 추락 규칙을 따른다.
- 마지막 4인 관문을 발판으로 해결하고 톱의 실제 도약(1.2초)이 끝난 뒤 165m에 한 명이라도 도착하면 성공한다. 상층이 결승선에서 기다려도 버튼 직후 바로 성공하여 도약 중 피격을 생략하지 않는다. 소각 전 다른 줄로 우회해 결승선만 넘는 것은 성공으로 처리하지 않는다. 전원 탈락 또는 제한 시간 300초가 먼저 끝나면 실패한다.
- 봉은 공연 대기 중에도 표시한다. 편집 중 Scene 뷰에서 Gizmos를 켜면 봉·케이블·이름과 끊어진 줄을 볼 수 있다. 미리보기 좌표와 런타임 봉 위치는 같은 코스 계산을 사용한다.
- 혼자 시작·외줄 시작·봇 추가/내보내기·역할 버튼은 Input System UI Button으로 클릭을 받는다. IMGUI 안내 카드의 같은 위치에 배치한다. 새 글자는 실행 중 전용 폰트에 생성하며 공용 Static 폰트 에셋은 수정하지 않는다.

## 확인과 조정

- 수치: `Assets/Resources/Settings/GameSettings/Tricks/TightropeSettings.asset`.
- 교대 관문: 코스의 `relayGapEnabled`, `relayRequiredHolders`(기본1, 심화2), `relayHoldSeconds`(30초). 위치는 `swingGapStart`/`swingGapLength`(40/8)를 사용한다. `relayGapEnabled`를 끄면 이전 2·5번 독립 회전봉 방식으로 돌아간다.
- 공중그네: `trapezeEnabled`, `trapezeStart`(100), `trapezeLength`(16), `trapezeLane`(봉 배치 줄 번호3). 지면 끊김은 모든 줄에 적용한다. 이 코스 값들은 기존 호스트 코스 모양 공유에 포함한다.
- 정면 톱: `cooperativeGateDistances=[158]`, `finaleFourStackRequired=true`, `finaleSoloAutoOpen=false`, `cooperativeGateHopHeightMultiplier=1.5`. 이전 `cooperativeGateHopHeight`는 호환용이며 실제 홉 높이에 사용하지 않는다.
- 동적 균형 조정: 줄 위 동작의 `dynamicIdleSway`, `dynamicMovingSway`, `dynamicSwayFrequency`, `sharedSwayRange`, `sharedSwayPerPlayer`. 새 필드는 저장 전에도 C# 기본값으로 동작한다. 외줄의 `TightropeRopeSway`가 공용 균형에 매 프레임 힘을 전달하고, 외줄 밖·공중·비활성 때 해제한다.
- 추가한 최후반 주기·착지 파동 수치는 초기 테스트값이다. 기존 설정 에셋에 새 필드가 저장되기 전에도 C# 기본값을 사용한다.
- 카메라: 공용 `FreeThirdPerson`을 런타임 복제해 사용한다. 공용 원본 프리셋은 변경하지 않는다.
- 봇은 실제 별도 LAN 클라이언트다. 화면 없는 실행에서 표시용 요소는 생략하지만 게임 판정은 실행한다.

- 별도 LAN 봇 검사 범위는 접속·F 목마·역할 교대·이동·R·종료다. 새 회전봉의 두 클라이언트 동기화와 사람의 다인 플레이는 아직 미검증이다. 위 세 가지 플레이 체감 항목은 사람이 확인해야 한다.
- 봇 빌드 중 Unity가 `Assets/Settings/`의 볼륨·URP 설정 3개와 `ProjectSettings/ProjectSettings.asset`, `ProjectSettings/UnityConnectSettings.asset`을 자동 갱신했다. 코드 변경과 구분하며 임의로 되돌리지 않았다.
