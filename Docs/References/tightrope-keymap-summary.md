# 외줄타기 키맵핑·입력 규칙 요약

- 원문: [외줄타기 키맵핑 및 입력 규칙](https://hrjoo122770.atlassian.net/wiki/spaces/UIUX/pages/4882437) (Confluence, 작성 이수)
- 요약: 2026-10-01, AI가 원문을 읽고 작업에 필요한 규칙만 추림. **원문이 기준**이며 어긋나면 원문을 따른다.
- **PM 결정(2026-10-01)이 반영된 부분은 [결정](../../Harness/Project/Decisions/tightrope-rules.md)이 우선**한다.
- 표기: SB = SpaceBar. 숫자 값(홀드 시간 등)은 원문에 없음 → 인스펙터 튜닝값으로 연다.

## 키 역할

| 입력 | 공통 역할 | 외줄타기 |
|---|---|---|
| W / S | 이동 | 전진 / 후진 (카메라가 아니라 **코스 진행 방향** 기준) |
| A / D | 자세 제어 | 균형 보정 **전용**. 좌우 이동·옆줄 이동에 쓰지 않음 |
| SB | 기본 액션 | 점프 (상태에 따라 결과가 다름) |
| Q / E | 좌우 보조 방향 | 옆줄 이동 방향 지정 (단독으로는 동작 없음) |
| Q/E **홀드** + SB | 방향 특수 이동 | 왼쪽 / 오른쪽 옆줄로 점프 이동 (Q/E를 누른 채 SB) |
| F 짧게 | 상호작용·협동 연결 | 목마 연결 시도 |
| F 길게 | 해제·놓기 | 목마 연결 해제 (점프 없이) |

## SB 점프 규칙

| 상태 | 결과 |
|---|---|
| 혼자 있음 | 개인 점프 |
| 목마 중, **내 위에 사람 있음** | 점프 불가 (아래층이 위층을 떨어뜨리는 것 방지) |
| 목마 중, **내 위에 사람 없음** | 분리 점프 (목마에서 빠지며 점프) |

## 옆줄 이동 (Q/E 홀드 + SB)

- 가능 조건(모두 만족): 옆줄 이동 가능 구간 / 내 위에 사람 없음 / 그 방향에 착지 가능한 줄 있음 / 그 줄이 불타지 않음. 하나라도 아니면 **입력 무시**.
- 목마 맨 위 플레이어가 옆줄 이동하면 목마 연결은 **자동 해제**된다.
- 착지 처리: 비어 있으면 그대로 착지 / 다른 유저와 겹치면 **코스 진행 방향 뒤쪽으로 보정** / 거기도 막히면 더 뒤로 / 공간이 전혀 없으면 착지 실패(튕겨남).
- 옆줄 이동 후 겹쳐도 **자동 목마 결합 없음**. 합류하려면 착지 후 F 짧게.

## 목마 연결·해제 (F)

- 연결은 **유지 입력이 아니다.** 목마 중에도 A/D로 균형을 잡아야 하므로 키를 계속 누르게 하지 않는다.
- F 짧게 = **누른 사람이 가까운 동료(목마면 맨 위) 위로 올라간다.** 올라가는 사람은 **단독이어야** 하며, 목마에 속해 있으면 해체 후 한 명씩 올라간다. (PM 결정)
- F 짧게: 단독이면 가까운 동료(목마면 맨 위) 위로 연결 시도 / 대상 없으면 무반응 또는 "연결 불가" 표시. (원문의 "목마 중이면 다음 동료와 연결 시도"는 PM 결정으로 대체: 목마에 속한 사람은 올라갈 수 없음)
- F 길게: 내 위에 사람 없으면 **본인만 분리** / 내 위에 사람 있으면 **해제 불가** / 목마가 아니면 무반응. → 해제는 **맨 위부터 순서대로**.
- 균형 붕괴·장애물 충돌·낙하·줄 이탈은 입력이 아니라 **시스템 판정**으로 해제.
- SB 분리 점프 = 점프하며 이탈(회피·패널 밟기) / F 길게 = 점프 없이 정리(잘못 연결 해제).

## 원문에 없는 것 (구현 시 열어 둘 값)

- F "길게"로 판정하는 시간, 연결 가능 거리, 옆줄 뒤쪽 보정 거리 → 인스펙터 값.
