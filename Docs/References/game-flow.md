# GAME_FLOW.md — 커튼콜 (Curtain Call) · 게임 흐름 개요 (2026-09-30)

AI 개발 에이전트용. 게임의 시작·루프·결말·엔딩 분기와 메커니즘을 설명한다.

- **확정** = 그대로 구현한다
- **※미정** = 임의로 확정하지 않는다. 인스펙터 값·인터페이스·확장 지점으로 열어 두고, 기본값이 필요하면 이 문서에 적힌 기본값을 쓴다
- **숫자는 전부 튜닝값** = `[SerializeField]`로 노출한다. 상수로 박지 않는다
- 묘기 세부 스펙은 `CONTEXT.md` 참조

## 1. 개요

- 장르: 최대 4인 코옵 프렌드 슬롭 (공연 + 방탈출 + 로그라이크)
- 플랫폼: PC · Unity 3D · 1인칭
- 한 줄: 가축처럼 갈아치워지는 서커스 단원이 되어 외계인 관객 앞에서 묘기를 수행하고, 그 대가로 산 기구로 시설을 탈출한다. 우리가 못 나가면 흔적만 남고, 다음 세대가 새로 섞인 시설에 다시 도전한다.
- 핵심 가치: 묘기가 재밌어야 한다
- 결정 지점은 하나: 자유시간 타이머. "지금 갈까, 한 판 더 벌까"

## 2. 게임의 시작

1. 메인 화면 → 로비(최대 4인) → 런 시작 (1세대, Day 1)
2. 대기실에서 눈을 뜬다. 긴 방, 깨진 거울, 쪽지 벽, 잠긴 뒷문
3. 첫 공연 호출 → 이하 하루 루프(§4)

- 시작 소지: 크레딧 0. 초기 기물 세트 ※미정 (수직 슬라이스는 외줄 하나로 시작)

## 3. 전체 상태 흐름

```
메인 화면
  → 런 시작 (세대 g, Day 1)
  → Day 루프: Day 1 … Day N
       공연 → 자유시간 → 공연 → 자유시간 … → 밤(정산·구매·세이브) → 다음 Day
  → 종료 조건 (먼저 오는 쪽)
       a. 제어실 도달                  → 엔딩 (탈출 엔딩 / 복수 엔딩, §7)
       b. 추격자에게 잡힘 (한 명이라도) → 전원 폐기 = 게임오버 → 세대 g+1, Day 1부터 (§5)
       c. 공연 중 전원 사망            → 전원 폐기 = 게임오버 → 세대 g+1, Day 1부터 (§5)
       d. Day N 소진                   → 전원 폐기 = 게임오버 → 세대 g+1, Day 1부터 (§5)
```

## 4. 하루 루프

### 4.1 공연 (공연장 씬)

- 보유 기물에 해당하는 묘기가 랜덤 순서로 호출된다 (※선택 방식 미정: 완전 랜덤 / 랜덤 후보 중 팀 선택 / 세트리스트 → 기본값: 완전 랜덤)
- 완벽 수행 채점 → 크레딧 적립
- 실수 → 부상(사지 절단). 사지가 잘린 채 공연하면 크레딧 배율↑ + 조작 페널티. 부상은 자산
- 공연 중 사망 → 사망 상태. 한 명이라도 살아서 공연이 끝나면 그 자유시간에 생존자가 살릴 수 있다 (§5)
- 공연 중 전원 사망 → 전원 폐기 = 게임오버 (§5)
- 하루 공연 수 M회 (튜닝값)
- ※예외 처리 미정: 묘기를 일부러 안 받았을 때 · 일부만 죽었을 때 · 팔이 필요한 묘기인데 팔이 없을 때 · 온 사지 절단이 패배인지

### 4.2 자유시간 (대기실 · 탈출로 씬)

- 공연 종료 시 타이머 시작 (길이 튜닝값)
- 할 수 있는 것: 대기실에서 쪽지·흔적 확인, **사망한 동료 부활**(§5), 뒷문 너머 정비층 정찰(갔다 돌아옴)
- 타이머 0 시점에
  - 무대에 있음 → 다음 공연 (마지막 공연이었으면 밤)
  - 무대에 없음 → 탈주자. 추격자 방출 (§6)
- 정찰 중 사망(추락 등) → 개인 사망 상태. 나머지가 제시간에 복귀하면 정상 진행. 부활은 §5와 같은 메커니즘
- 레벨 요구: 정찰(갔다 돌아옴)과 커밋(끝까지 감)이 자동으로 갈리도록 복도 길이를 잡는다
- ※팀 분할 미정: 일부 공연·일부 탈주 허용 / 전원 무대 필수 → 기본값: 개인별 판정. 분할을 허용하면 커밋한 한 명이 잡힐 때 무대에 남은 사람도 같이 폐기된다(§5)

### 4.3 밤 (대기실 씬)

- 정산: 그날 크레딧 확정 (배율 반영)
- 기물 구매: 상점 터미널 (※구매 시점 미정: 밤에만 / 자유시간마다 → 기본값: 밤에만)
- 세이브 → Day + 1
- 새 기물의 효과: 다음 날부터 새 묘기가 공연에 섞이고, 정비층 장애물의 해법이 된다

## 5. 사망 · 폐기 · 세대

**사망은 어디서, 어떻게 죽었는지가 결과를 정한다. 개인 사망은 자동 복귀가 아니라 생존자가 살리는 능동 메커니즘이다.**

| 상황                   | 결과                                                                                                                                                                               |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 공연장에서 사망        | 개인 사망 상태. 한 명이라도 살아서 공연이 끝나면, 그 자유시간 안에 생존자가 **부활 메커니즘**(※미정)으로 살릴 수 있다. 부활한 플레이어는 **패널티**(※미정)를 안고 다음 공연에 참가 |
| 정찰 중 사망 (추락 등) | 같은 메커니즘으로 살린다. 나머지가 제시간에 복귀하면 정상 진행                                                                                                                     |
| 공연 중 전원 사망      | 살릴 사람이 없음 → 전원 폐기 → 게임오버 → 다음 세대                                                                                                                                |
| 추격자에게 잡힘        | **한 명이라도** 잡히는 순간 전원 폐기 → 게임오버 → 다음 세대. 무대에 남아 있던 사람도 폐기                                                                                         |
| Day N 소진             | 전원 폐기 → 게임오버 → 다음 세대                                                                                                                                                   |

- 살리지 않으면 사망 상태로 남고, 이후 자유시간에도 살릴 수 있다 (기본값)
- 개인 사망은 세대·Day를 바꾸지 않는다
- 게임오버는 세 가지: 추격자에게 잡힘 / 공연 중 전원 사망 / Day N 소진
- ※부활 메커니즘·패널티 미정 (조합 가능). 기본값은 (b)
  - (a) 크레딧 지불 → 패널티 = 돈. 상점 터미널과 같은 UI
  - (b) 시체와 상호작용 → 부상 상태(배율↑ + 조작 페널티)로 복귀. 기존 부상 시스템 재사용
  - (c) 살리는 데 자유시간이 소모됨 → 패널티 = 정찰할 시간이 줄어듦
- 세대 간 전승: **흔적만** 넘어간다. 크레딧·기물·부상은 전부 리셋. 탈출 방법(장애물 조합·순서)은 재배치
  - ※흔적의 역할 미정: 감정 연출만 / 믿을 수 없는 힌트(이전 세대가 죽은 자리·방식) / 남는 물건(걸어둔 로프·부순 벽)
- 쪽지: 플레이어블이 아닌 이전 인원(NPC)들이 남긴 스토리 기록. **플레이어 로그로 자동 생성하지 않는다**. ※쪽지가 그 세대의 탈출 힌트도 주는지 미정

## 6. 탈출 파트 (탈출로 → 제어실)

- 동선: 대기실 뒷문 → 정비층(거대한 산업 공간: 캣워크·배관·사육장) → 제어실
- 장애물 3~4개(튜닝값)를 순서 배치. 세대마다 일부만, 랜덤 순서. 필요한 기물 세트가 매번 다르다
- 장애물은 기물로 푼다: 외줄=틈 건너기, 대포=벽 파괴·자기 발사, 그네=천장 통로, 칼판=원거리 스위치, 원통=압력판 (※묘기-기물 관계 미정: 1:1 / 3층)
- 안내 없음. 공연과 정찰에서 익힌 것을 총동원해 스스로 길을 찾는다 (레퍼런스: 포탈 1 마지막 스테이지). 탈출로에서 새 규칙을 가르치지 않는다
- 추격자: 타이머 0에 방출. 느리지만 절대 안 멈춘다. 한 명이라도 잡히면 전원 폐기 = 게임오버 (§5). ※장애물에 막히는지 미정(무시하고 벽 타고 옴 / 막힘) · ※정체 미정
- 전투 시스템 없음

## 7. 엔딩 분기

제어실 = 공통 관문. 도달 시 문이 닫히고 추격자가 차단된다 (안전지대).

| 결과                 | 조건                                                         | 내용                                                                                                                             |
| -------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| **탈출 엔딩 (일반)** | 제어실 도달                                                  | 출구로 나간다. 복수 없음. 전체 완성본(홀 케이크)의 기본 목표 엔딩                                                                |
| **복수 엔딩 (진)**   | 제어실 도달 + 조건 ※미정                                     | 창 너머 무대 → 무대 장치(전기톱 등)를 관객에게 → 갇힌 인간 해방 → 출구. 가둔 존재의 정체 공개(※정도 미정). 앞선 세대 전부의 복수 |
| **게임오버**         | 추격자에게 한 명이라도 잡힘 / 공연 중 전원 사망 / Day N 소진 | 전원 폐기 → 다음 세대 (§5)                                                                                                       |

- 구현 요구: 제어실 진입 시 `조건 검사` 인터페이스를 거친다. 조건이 정해지기 전에는 항상 탈출 엔딩
- ※엔딩 판정 인원 미정: 1명이라도 도달 / 생존자 전원 도달 → 기본값: 1명 도달

## 8. 씬 5개와 동선

| 씬        | 역할                                                                   |
| --------- | ---------------------------------------------------------------------- |
| 메인 화면 | 로비 · 런 시작                                                         |
| 대기실    | 허브. 상점 터미널 · 쪽지 벽 · 흔적 · 취침 · 정산. 무대와 뒷문으로 연결 |
| 공연장    | 묘기 수행 · 채점                                                       |
| 탈출로    | 정비층. 장애물 · 추격                                                  |
| 제어실    | 골인 · 안전지대 · 엔딩                                                 |

동선: 공연장 ↔ 대기실 ↔ 탈출로 → 제어실

## 9. 세계관 · 톤 (구현 참고)

- 인간은 가축, 시설은 사육장 겸 서커스장. 관객은 외계인. 가둔 존재의 정체는 엔딩에서 (※미정)
- 무대는 화려(빨강·금색·스포트라이트), 뒷공간은 차갑고 무기질. 이 대비가 기괴함
- 톤: 잔혹 동화. 어둡지만 잔인하진 않게. ※사지 절단 표현 수위 미정 · ※배경 미정(외계 사육 시설 / 지구 지하 / 추상)
- 비주얼: 1인칭(본인 손·발), 성인 비율 로우폴리 + 물리 랙돌. 동료가 항상 화면 안에

## 11. 미정 목록 (하드코딩 금지 · 정해지면 이 파일 갱신)

1. 묘기 선택 방식 (기본: 완전 랜덤)
2. 기물 구매 시점 (기본: 밤에만)
3. 팀 분할 허용 여부 (기본: 개인별 판정)
4. 부활 메커니즘 · 패널티 내용 (기본: (b) 시체 상호작용 → 부상 상태 복귀, §5)
5. 추격자와 장애물 (무시 / 막힘)
6. 추격자 · 가둔 존재의 정체
7. 흔적의 역할
8. 쪽지의 탈출 힌트 여부
9. 묘기-기물 관계 (1:1 / 3층)
10. 묘기 예외 처리 (§4.1)
11. 복수 엔딩 조건
12. 엔딩 판정 인원 (기본: 1명 도달)
13. 초기 기물 세트 (수직 슬라이스: 외줄 하나)
14. 사지 절단 표현 수위 · 배경
15. 멀티플레이 방식(넷코드) — 수직 슬라이스 단계에서 결정

## 12. 현재 단계 · 스코프

- 스프린트 "묘기 플레이 프로토타입 빌드" (9/29~10/13): 묘기 그레이박스
- 수직 슬라이스: 하루 분량 · 대기실 1 · 정비층 1 + 장애물 소수 · 기물 2종(외줄·대포). 이게 돌아가면 나머지는 복사
- 작업 순서: 묘기 종류 → 그레이박스 구현 → 재미 검증 → 씬별 작업
- 싱글로 먼저 만든다. 넷코드는 수직 슬라이스 단계에서 결정
- 출발점: 개인 미니 프로젝트의 그레이박스 묘기(외줄·원통·그네)
