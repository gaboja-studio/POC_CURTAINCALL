# 외줄타기 프로토타입 상세 규칙 요약

- 원문: `Docs/References/tightrope-prototype-rules.docx` (기획 "외줄타기 프로토타입 상세 규칙", 2026-10-03 PM 전달)
- 요약: 2026-10-03, AI가 원문을 읽고 작업에 필요한 규칙과 수치만 추림. **원문이 기준**이다.
- 이 원문이 **진행·판정·맵·캐릭터 크기·점프·톱날**의 최신 기준이다. 균형(게이지·흔들림·충격)·조작 키·목마는 원문에 없으므로 기존 문서를 따른다.
- PM 결정 반영: [코스·진행 결정](../../Harness/Project/Decisions/tightrope-course-rules.md). 그대로 따를 수 없거나 빈칸인 항목: [검토·권유서](../../Integrations/Active/Integration-tightrope-prototype/rules-review-20261003.md).
- 단위: 1 = 1m. 진행 위치 = 외줄 시작점 0m 기준 전진 거리.

## 1. 진행·판정

| 항목 | 값 |
|---|---|
| 인원 | 4명 고정(P1~P4, 프로토타입 한정) |
| 제한시간 | 5분, 게임 시작부터 측정 |
| 클리어 | 최소 1명 도착. 전원 도착 → 즉시 클리어. 일부 사망 후 나머지 전원 도착 → 즉시 클리어 |
| 진행 중인 플레이어가 없을 때 | 도착자 있으면 즉시 클리어, 없으면 즉시 실패 |
| 제한시간 종료 | 도착자가 한 명도 없으면 실패 |
| 사망 | 톱날 충돌 → 즉시 사망, 균형 실패로 추락 → 즉시 사망 |
| 도착 후 | 피격·탈락 판정 꺼짐 |
| 플레이어 상태 | 진행 중(도착·사망 전) / 도착 완료(도착선 통과) / 사망(톱날·추락) |

## 2. 맵

| 항목 | 값 |
|---|---|
| 외줄 구간 | 0 ~ 100m (도착 판정선 100m) |
| 구간 / 목표 시간 | 초반 20m·1분, 중반 50m·2분 30초, 후반 30m·1분 30초 (합계 5분, 테스트 후 조정) |
| 시작 대기 공간 / 세리머니 공간 | 외줄 시작점 앞 6m / 도착선 뒤 6m → 전체 세로 112m |
| 안전구간 | 시작 0~4m, 도착 95~100m (톱날 외형·판정이 들어오지 않음) |
| 외줄 | 4개, 중심 간격 3m (P1~P4 9m), 양쪽 끝 줄 중심에서 맵 경계까지 2m → 유효 맵 폭 13m |
| 톱날용 폭 | 가로 톱날 중심 왕복 = 맵 경계 밖 각 3m(범위 19m), 외형 포함 20.2m, 구현 폭 약 21m |
| 외줄 소멸 | 없음(나중 시스템). 원문에 4→1 합류 없음 |

## 3. 캐릭터·외줄

| 항목 | 값 |
|---|---|
| 이동 속도 | 0.5m/s, 전진·후진·점프·옆줄 이동 가능 |
| 외형 | 높이 1.6m, 폭 0.7m |
| 충돌체 | 캡슐 높이 1.5m, 지름 0.6m, 발밑 기준 |
| 외줄 | 지름 0.2m, 중심선을 따라 이동 |
| 균형 | 균형바를 보며 조작, 실패하면 추락·탈락 |
| 플레이어끼리 | 밀기 불가. 다른 플레이어의 줄로 이동 가능. 옆줄 착지가 겹치면 **상대 뒤쪽으로 착지** |
| 이동 시간 | 순수 이동 3분 20초(초반 40초·중반 100초·후반 60초), 대기·회피 여유 1분 40초 |

## 4. 점프·톱날 높이 (기준: 외줄 윗면)

| 항목 | 값 |
|---|---|
| 점프 높이 | 0.8m (외줄 윗면 → 최고점 발바닥) |
| 가로 톱날 | 눕혀 배치, 공격 판정 상단 0.2m → **점프로 회피 가능**하게 |
| 수직 톱날 | 세워 배치, 중심 0.6m, 외형 상단 1.2m, 충돌체 상단 1.1m → **점프 회피 불가, 옆 외줄 이동으로 회피** |

## 5. 가로 톱날

| 항목 | 값 |
|---|---|
| 크기 | 외형 지름 1.2m, 충돌체 지름 1.0m(수평 면) |
| 배치 | 미리 배치, 진행 위치마다 1개, 총 22개 (초반 5·중반 10·후반 7) |
| 위치(m) | 초반 5.6 / 8.8 / 12.0 / 15.2 / 18.4 · 중반 22.5 ~ 67.5 (5m 간격 10개) · 후반 71.8 / 75.4 / 78.9 / 82.5 / 86.1 / 89.6 / 93.2 |
| 움직임 | 게임 시작과 동시에 모두 작동, 제자리(진행 위치 고정)에서 좌우 왕복, 끝에서 즉시 반전, 계속 반복 |
| 처음 방향 | 좌측 톱날 좌→우, 우측 톱날 우→좌 |
| 속도 | 기본 0.8m/s, 후반 1.2m/s(1.5배) |
| 배치 조건 | 가로 톱날끼리 접촉 없음, 한 플레이어에게 양쪽 동시 접근 없음, 안전구간 침범 없음 |

## 6. 수직 톱날

| 항목 | 값 |
|---|---|
| 크기 | 외형 지름 1.2m, 충돌체 지름 1.0m(세운 원판) |
| 출현 | 시작 1분 후 첫 출현(초반 1분 없음), 맵 전체 최대 1개, 제거 후 20초 뒤 다음 출현 |
| 대상 | 진행 중인 플레이어가 있는 외줄 중 1개 랜덤 |
| 경로 | 93m에서 생성 → 그 줄을 따라 시작점 쪽으로 직선 이동 → 5m에서 제거 (왕복 없음) |
| 속도 | 0.8m/s 고정(가로 톱날 기본 속도), 후반 증가 없음 |
| 횟수 | 1회 88m·110초 → 1:00, 3:10 출현(5분에 2회). 추후 목표 5분에 최소 4회 |
| 추후 | 출현 경고 UI 검토, 외줄 소멸 도입 시 사라진 줄에서 생성 금지 |
| 가로 톱날과 동시 접근 | 허용, 회피 가능한지 테스트 |

## 7. 1차 테스트 확인 항목

이동 속도 0.5m/s가 답답하지 않은지 / 가로 톱날을 점프로 통과할 수 있고 타이밍이 적절한지 / 수직 톱날은 점프로 못 넘고 옆줄 이동으로 피할 수 있는지 / 가로·수직 톱날이 함께 와도 피할 수 있는지 / 균형·옆줄 착지가 자연스러운지 / 최소 1명이 5분 안에 도착할 수 있는지.
