# 멀티플레이 환경 구축

## 결정 사항 공유

- 호스트가 동기화 권한 보유
- 호스트가 종료 시 게임 종료
- 플레이어 위치, 사용하는 도구/인터렉션 가능한 오브젝트만 동기화
- 플레이어는 2-4명
- 도구의 수는 최대 인당 2개
- 동기화 물체는 추정 상 평균 2-4명 + 4~10개 오브젝트로 많아도 20개 내로 예상
- 세이브 포인트는 없음
- 사망 시 맨 첫째 날부터 시작
- 단, 세션 동안에는 런 데이터를 저장해 이후 이전 단원의 기록 등으로 표시
- 거리 기반 음성 있음
- 공간 음향 없음
- 일부 플레이어 음성 제한 없음
- 최대 사용 가능한 운영 자금: 10만원
- 유니티 버전은 6000.3.25f1로 픽스
- 개발 마감은 11월 말 (현재 약 2달 남음)
- 멀티플레이 솔루션은 현재 문서와 다르게 Photon과 NGO에서 고민 중. 개발 완료가 최우선 목표

## 연관 문서

- 유니티 버전 및 멀티플레이 솔루션 비교: https://docs.google.com/document/d/187V2H0zrJYpOjHTDPSylREHNlPN2iaLo7DRyxICaLtE/edit?tab=t.0#heading=h.3tadxcvsnde5

## 금주 목표

- 솔루션 도입
- 멀티 플레이 방 생성
- 4명이 들어오면 바로 게임 시작
- 플레이어 위치 동기화
- 플레이어 상태(죽음 등 향후 추가) 동기화
- 툴 및 상호작용 오브젝트 위치, 상태 동기화
- 플레이어 애니메이션 동기화
- 게임 상태 동기화

# 플레이어 기본 조작 및 외줄타기 묘기 구현

## 결정 사항 공유

- 공통 입력 역할:
  - W/S: 이동
  - A/D: 자세 제어
  - SPACE BAR: 기본 액션
  - Q/E: 좌우 보조 방향 입력
  - Q/E 홀드 + SPACE BAR: 방향이 있는 특수 이동
  - F 짧게 입력: 상호작용/협동 연결
  - F 길게 입력: 해제/놓기
- 외줄타기에서 매핑
  - W/S: 전진/후진
  - A/D: 줄타기 균형 보정
  - SPACE BAR: 점프
  - Q/E: 홀드 시에만 옆줄 이동 방향 지정
  - Q/E 홀드 + SPACE BAR: 왼쪽/오른쪽 옆줄 이동
  - F 짧게 입력: 목마 연결 시도
  - F 길게 입력: 목마 연결 해제
- 현재 프로토타입에서는 모델, 애니메이션, 연출을 제거하고 기능만 구현한다.
- 확인할 수 있게 디폴트 모델, 캐릭터 프리팹을 교체할 수 있게 한다.
- 그 외 확정 내용은 프로토타입 기획 문서, 외줄타기 키맵핑 및 입력 규칙 문서 참고
