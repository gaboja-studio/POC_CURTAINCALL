## 게임 개요

- 4인 협동. 맨몸(봉 없음)으로 외줄을 타며 목마로 균형을 맞춰 위협을 통과한다.
- 핵심 의도: **한 명이 혼자 앞서가서 끝낼 수 없게**, 동료의 행동이 전진·생존에 꼭 필요하게 만든다.
- 전체 흐름: 시작 플랫폼 → 맨몸 외줄 이동 → 협동 줄 변경 → 후방 화재 → 한 줄 합류 → 목마로 위협 돌파 → 목적지.

## 맨몸 외줄 이동 (이번 범위)

- 걷는 동안 좌우 흔들림이 생기고 A/D로 기울기를 보정한다. 점프 착지와 동료 움직임도 균형에 영향을 준다.
- **균형 한계를 넘으면 추락**한다. 균형은 캐릭터 기울기 + 간단한 게이지로 표시한다.
- 옆줄 이동: 동료 도움을 받는 **협동 이동**(안정적 출발·착지)이 기본, **단독 이동**도 가능하지만 착지 충격 + 일정 시간 균형 난도 상승. 줄에 못 닿거나 착지 후 균형 상실이면 추락.
- 협동/단독 판정(PM 결정): 목마 맨 위가 옆줄로 가거나 옆줄에서 목마 쪽으로 오면 협동, 출발·도착 모두 단독이면 단독. 협동 여부는 **점프 출발 시** 확정. 단독 이동 불안정 효과는 **강도가 쌓이지 않고 지속 시간만 갱신**(강도 상한).

## 목마와 균형 (이번 범위)

- 아래부터 1~4층. 층은 고정 번호가 아니라 **현재 위치**. 최대 4명.
- 맨 아래가 전체 이동(W/S) 담당. **모든 층이 A/D로 자기 균형**을 조절한다.
- **위층 기울기가 아래층으로 전달**된다. 높이 쌓을수록 협동 효과↑, 균형 유지 난도↑.
- 맨 아래 SB: 모든 연결이 유지돼 있으면 **목마 전체 점프**. 착지 충격이 각 층에 전달되고 착지 후에도 균형을 맞춰야 한다.
- 목마 효과는 실제 무게 시뮬레이션보다 **명확한 게임 규칙**으로 구현한다.

## 예외 처리 (이번 범위 관련만)

- 연결이 풀리면 짧은 재결합 여유를 두되 **자동으로 계속 유지하지 않음**.
- 위층이 크게 기울면 아래층에 흔들림 전달. **작은 실수 한 번으로 즉시 전멸하지 않게** 조정.
- 중간층이 먼저 점프하려 하면 제한하고 **이유를 표시**.
- 전체 점프 중 연결 해제 → 그 위치에서 분리. 착지 전 재연결 가능 여부는 연결 범위로 판정.
- 단독 줄 이동 반복 → 불안정 효과 지속 시간만 갱신, 강도 상한.
- 추락(PM 결정으로 원문 대체): **4명 모두 떨어지면** 묘기 실패 → 재시작(모든 요소를 초기 상태로). 1명이라도 줄 위에 남아 있으면 계속 진행. 전체 게임의 게임 오버(첫째 날부터)와는 별개.
