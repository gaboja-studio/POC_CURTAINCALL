## 균형 규칙

- A/D로 균형 보정. W/S는 코스 진행 방향 기준 전진·후진.
- 균형바: 빨강 30 | 초록 40 | 빨강 30. 바늘이 현재 균형을 가리킨다. 빨강에 **2초** 머물면 추락.
- 목마 난이도는 전체 인원 기준(혼자 < 2인 < 3인 < 4인). 같은 목마 안에서는 모든 층이 같은 난이도.
- 층 간 영향은 위층 → 아래층 한 방향. 위층이 빠지면 아래층은 쉬워지고 위에서 오던 흔들림도 사라진다.
- 연쇄 추락: 아래층이 떨어지면 그 위 전원 추락. 위층이 떨어지면 아래층은 남는다.
- 혼자 옆줄 점프 → 착지 때 크게 흔들리고 한동안 흔들림이 커진다. 옆줄 동료 근처 착지면 줄어든다.

## 점프·장애물 규칙

- 측면 전기톱: 혼자 점프로 피함. 정면 대형 전기톱: 혼자 점프로는 못 넘고, 2층 이상에서 점프하면 넘는다.
- 목마 전체 점프(1층 SB)로는 1층이 정면 톱을 못 넘는다.

## 수치 (제안값)

| 항목 | 값 |
|---|---|
| 균형값 범위 | −100 ~ +100 (0 중앙, ±100에서 멈춤) |
| 초록 / 빨강 | ±40 이내 / ±40 ~ ±100 |
| 추락 | 빨강 2초 체류 (확정) |
| 빨강 타이머 | 초록으로 돌아오면 0으로 초기화 (제안) |
| A/D 보정력 | 초당 60 |
| 자연 흔들림 | 이동 중 초당 15, 정지 중 초당 5. 방향은 1~2초마다 랜덤 |
| 기울기 가속 | 초당 (현재 균형값 × 0.5) |
| 목마 배율 | 혼자 1.0 · 2인 1.3 · 3인 1.6 · 4인 2.0 (자연 흔들림·충격에 곱함, 인원 바뀌면 즉시) |
| 위층 → 아래층 전달 | 초당 (위층 균형값 × 0.2), 위 층마다 합산. 맨 위는 받지 않음 (제안) |
| 점프 중 균형 | 공중에서는 정지, 착지 때 충격 (제안) |
| 착지 충격 | ±10 랜덤 방향. 개인·목마 전체 점프 공통(전체 점프는 각 층) |
| 단독 옆줄 점프 | 착지 시 ±35 + 3초간 자연 흔들림 ×2.5. 반복해도 쌓이지 않고 시간만 갱신 |
| 동료 근처 착지 | 옆줄 동료와 1.0m 이내면 위 충격·흔들림 50% 감소 (범위 제안) |
| 캐릭터 키 | 1.73m (어깨 ≈ 1.45m). 기본 캡슐 2m를 1.73m로 맞춤 |
| 개인 점프 높이 | 1.0m (초속 ≈ 4.43m/s, 중력 9.81) |
| 정면 톱 윗면 / 측면 톱 윗면 | 2.0m / 줄 위 0.5m |
| 줄 간격 | 1.5m (공중 약 0.9초 → 옆줄 수평 속도 약 1.7m/s) |

- 참고: 이 값이면 A/D로도 초록에 못 돌아오는 선이 혼자 ±90 · 2인 ±81 · 3인 ±72 · 4인 ±60.
- 높이 규칙: 개인 점프 1.0 < 정면 톱 2.0, 2층 1.45 + 1.0 = 2.45 > 2.0, 측면 톱 0.5 < 1.0. 이 부등식만 지키면 값이 바뀌어도 규칙 유지.
