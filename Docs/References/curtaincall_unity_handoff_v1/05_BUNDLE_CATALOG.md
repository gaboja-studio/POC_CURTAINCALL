## 자주 쓰는 가벼운 버전

- `curtaincall_title_unity_only_v1.zip` — 타이틀 현재 23개, 조립 코드·적용 문서 중심.
- `curtaincall_worldlabels_unity_only_v2.zip` — 월드 라벨은 v2 사용.
- `curtaincall_spectator_unity_only_v1.zip`.
- `curtaincall_curtain_unity_only_v1.zip`.

위 네 가벼운 버전도 이전 전달 기록/현재 파일에서 확인했다. 전체판과 가벼운 판을 중복 설치할 필요는 없다. 공용 경로의 같은 파일은 한 번만 둔다. 공용 버튼 전체판은 ZIP 손상 대응 후 제공된 `curtaincall_buttons_v1_fixed.zip` 이름을 사용한다.

다른 채팅에서 파일에 접근할 수 있으면 정확한 이름으로 찾아 읽는다. 접근이 안 되면 해당 씬에 필요한 ZIP을 사용자에게 요청한다. 문서에 과거 절대 경로가 있다고 파일이 실제 존재하는 것으로 간주하지 않는다.
