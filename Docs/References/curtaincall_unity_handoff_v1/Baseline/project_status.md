# CURTAIN CALL 제작 현황 — 타이틀 메뉴 묶음

기준일:2026-10-20 · C안 / 무대감독 계기판.

## 집계

- 이전 승인:C16까지15개 묶음, 고유 PNG137개.
- 이번 전달:신규8 + 승인15 재사용 =23 PNG.
- 누적 고유 PNG:**145개 = 승인137 + 이번 검토8**. 재사용은 중복 가산하지 않는다.
- 모든 실제 Unity 컴파일·임포트·Play 검증은 `not_run`이다. 그래픽 승인과 게임 연결 완료를 구분한다.
- 고유 PNG 개수로 전체 프로젝트 완료율을 계산하지 않는다.

## 이후 순서

이번 타이틀 묶음의 피드백을 받은 뒤 설정 전용 화면·남은 컨트롤을 제작한다. 수화기 구매/판매, 스케줄표, 공연 결과 패널도 남아 있다. 완성 리소스만 사용하는 최종 화면7개와 화면별 조립 설명은 단계5에 제공한다. 이번 타이틀 검토 목업은 단계5 최종7개 납품과 별개다.

- Q1 메뉴 입력
- Q2 방장 이탈
- Q3 소지 슬롯 수
- Q4 최초 가이드 범위
- Q5 C6/C15 표시 방식
- Q6 접속 이탈 후 호응 최대값
- Q7 C11 실제 관전 전환 키·관전 대상 선택·대상 없음·사망에서 관전으로 전환하는 게임 정책
- Q8 C16 실제 씬 로드·전원 준비 완료·연결 실패·전환 중 입력과 Canvas 수명 정책
- Q9 T1/T2/T3 실제 방 만들기·방 코드/주소 규칙·접속·설정·종료·입력 모듈 연결

월드 라벨은 물리 소품 표면3종(나무·천·종이)과 근접 정보2종(기물·선반)의 확정 용도를 유지한다. 타이틀 딤은 타이틀 루트 내부만 사용하며 플레이 중 ESC 메뉴에는 추가하지 않는다.
