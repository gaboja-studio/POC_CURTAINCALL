# CURTAIN CALL — 다른 채팅에서 Unity 씬 적용 시작하기

이 패키지는 지금까지의 확정 결정과 최신 리소스 상태를 전달하는 **인계본**이다. 전체 대화의 원문 기록은 아니며, 145개 전체 PNG 통합본도 아니다.

## 시작 방법

1. 새 채팅을 열어 이 `curtaincall_unity_handoff_v1.zip`을 첨부한다.
2. `01_START_NEW_CHAT.md`의 지시문을 첫 메시지로 전달한다.
3. 새 채팅은 인계 문서를 읽고, 동봉된 두 기존 ZIP으로 **공연 C1·C2·C3·P1**부터 적용한다.
4. 실제 프로젝트에 연결할 때 해당 채팅에 Unity 프로젝트나 필요한 코드/씬 정보도 제공한다. 프로젝트 접근 전에는 그 사실을 표시한 구성 가이드부터 시작한다.
5. 이 제작 채팅은 기존처럼 한 묶음씩 제작과 피드백을 계속한다. 이후 새 묶음은 ZIP과 적용 변경 요약을 새 채팅에 전달한다.

## 현재 기준

고유 PNG 145개 = 확정 137개 + 타이틀 신규 검토 중 8개. 실제 Unity 실행은 미실행. 다음 그림 제작은 설정 창·탭·슬라이더·토글이며, 적용 채팅은 이미 확정된 공연 HUD부터 시작한다.

기존 `style_contract_v1.json`의 제작 상태 문구는 초기 스냅숏이므로 현재 상태로 해석하지 않는다. 최신 누적 목록과 프로젝트 상태가 현재 전달·승인 상태의 기준이다.
