# 대시보드 v14

2026-10-21 사용자 디자인 요청 적용. 같은 Apps Script 본인 전용 배포 URL을 유지한다.

## 화면
- 상단 게임 버전 선택은 모든 통계·시간·자금·런 검색·도식/타임라인에 적용한다. 새 버전은 첫 로그를 가져온 뒤 자동 선택지에 추가된다. 최초 조회는 관측된 최신 숫자 버전(최소 0.1.0), 기존 무버전 기록은 ‘버전 미기록’으로 분리한다.
- 총 플레이·수집 이벤트·공연 플레이·공연 평균 성공률 카드.
- 묘기 통계: 외줄 타기/인간 대포 탭이 난이도 별 승률·사망 원인·상세 데이터에 함께 적용된다.
- 난이도 1~3 게이지는 고정 0~100% 축. 표본 없는 난이도는 미수집, 거리는 m.
- 사망 원인은 선택 묘기의 원인별 도넛과 범례. 원인이 없는 로그는 미확인으로 남긴다.
- 대기실 통계: 구역별 카드 이용 현황, 기물·서비스의 표/원형 그래프 전환.
- 실패·운반 기록: HOST 확정 거절 사유별 횟수, LOCAL 내려놓기/다시 줍기/인계/서비스 이탈을 구분한다. 미수령·의료 미이용은 종료가 관측된 항목만 표시하며 중도 이탈·취소와 정상 쉬는 시간 종료를 분리한다.
- 런 통계: 일차 별 공동 자금, 세션 ID·일차·활동·공연별 타임라인.
- 각 섹션의 설명 문단과 하단 설치 안내는 제거. 빈 값·갱신 오류 등 기능 상태만 표시.

## 자금
- 기본은 관측 런들의 일차별 평균 잔액이다. 호스트 transactionId를 중복 제거한다.
- 같은 런의 장부 번호 순서로 그 일차의 마지막 관측 잔액을 정한다. 시계 순서로 마지막 잔액을 덮지 않는다.
- 최초 잔액은 추정하지 않는다. 이후 도달이 확인된 일차에는 관측 잔액을 이어 쓴다.
- 일차별 표본 수는 해당 일차 잔액을 관측/이월할 수 있는 런 수다. 기록 공백은 완전한 회계 증명이 아니다.
- 런 ID 검색/선택 시 해당 런만 표시, 평균 버튼으로 복귀. 타임라인의 세션 선택과 독립이다.
- 선 그래프 점의 호버/키보드 포커스는 일차·잔액·리워드·지출·표본을 표시한다.

## 타임라인
- day: breakId/performanceId/payload.gameDay로 구분. 원천이 없으면 일차 미분류.
- 일차 아래 공연/아침·중간 쉬는 시간/밤 정비/기타 기록 탭.
- 같은 일차의 두 묘기는 하나의 n일차 공연 탭에 공연 선택 카드로 함께 표시한다.
- HOST의 최초 성공/실패가 결과이며, 사망 명부 역시 HOST만 집계한다.
- 공연은 출발 방향(좌)→도착 방향(우)의 공통 좌표 SVG로 표시한다. 현재 두 코스의 월드 +Z를 가로축으로, 외줄은 X(좌우), 대포는 Y(높이)를 세로축으로 사용한다.
- 축 범위는 선택 공연의 실제 관측 좌표 범위다. 최대 도달 좌표를 실제 코스 도착점이라고 표시하지 않으며 출발/도착 방향만 표시한다. 기록된 코스 전체 경계가 없는 과거 데이터에 경계값을 만들지 않는다.
- 플레이어 슬롯 0~3은 화면의 플레이어 1~4이며 파랑·금색·분홍·초록으로 고정한다. 이동(원), 부상(십자 마름모), 추락/사망(해골), 팀원(두 사람), 사물(육각 기물) 아이콘에 같은 색을 적용한다.
- 호버/키보드 포커스는 사건명·플레이어·시각·핵심 결과만 툴팁으로 표시하고 해당 플레이어의 시간순 사건 연결선을 같은 색으로 보여준다. 다른 플레이어 아이콘은 채도를 낮춘다.
- 클릭/Enter/Space는 아래 상세 패널을 고정하고 좌표·부위·장애물/기믹·상태 및 접힌 원본 JSON을 표시한다. 다른 점 클릭은 선택을 바꾸며 배경/외부 클릭·닫기·Escape는 해제한다.
- 겹치는 아이콘은 분산하고 정확한 관측 위치까지 가는 가는 보조선을 둔다. 동선은 분산 전 실제 좌표를 연결한다. 좌표 없는 사건은 ‘좌표 미수집’ 목록이며 그 사건을 가로지르는 동선을 연결하지 않는다.
- 공연의 기존 사건 목록/페이지 이동은 숨기고 대기실·기타 기록은 현재 목록을 유지한다. 도식은 최소 1120px, 사건 수에 따라 최대 4800px이며 좁은 화면에서는 도식 안에서 가로 스크롤한다.
- 사건 목록은 페이지당 200건, 도식은 중요한 사건 400건까지. 초과 시 표시 수/전체 수를 보인다.
