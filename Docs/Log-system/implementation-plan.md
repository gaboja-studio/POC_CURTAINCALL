# 구현 단계와 연결 범위

## 현재 Task-069의 기반
- 기존 외줄 GameplayRecorder는 보존. 새 TelemetryRuntime이 씬·앱·네트워크·런·부상을 관측한다.
- Start 계열 씬에서만 자동 bootstrap. 기존 씬/프리팹/설정 직렬화 파일 변경 없음.
- SharedRunId는 기존 PerformanceRewards.State.SessionId와 Generation을 사용한다.
- 공용 자금은 호스트 장부를 읽어 번호별 1회 기록한다. 놓친 페이지는 TELEMETRY_GAP.
- 디스크 outbox·내용 해시 ACK·재시도, Drive 원본·Sheets 중복 적재 방지.
- 대시보드 소스: 런 필터·타임라인·묘기·사망·공간·기물/서비스·자금, 수동/30분 갱신.
- 아직 미연결인 이벤트가 등록 계약에 존재한다는 것만으로 ‘수집 중’으로 보고하지 않는다.

## 후속 연결 순서
2026-10-21 사용자 후속 지시로 Task-069의 공개 API 어댑터를 먼저 연결했다. 상세 범위·실행 검증·남은 원천은 [coverage.md](coverage.md).
미커밋 기반은 현재 브랜치에서 보존한다. PM 승인 7개 파일에는 관측용 공개 API를 추가했다. 그 밖의 원천·씬 변경은 소유권 확인 후 진행한다.

| 연결 묶음 | 원천·할 일 | 확인 조건 |
|---|---|---|
| 네트워크·로비 | 실제 인증 playerId, CODE/LAN 공통 roomId, 서명 변경, 종료 사유 | 호스트·참가자 동일 방·런, 슬롯 0~3 |
| 공연 공통·외줄 | TightropeResults.AttemptId/ResultConfirmed, 기존 Telemetry의 입력·샘플·협동 사건 | 재시도별 새 ID, 호스트 결과 1회, 장애물/구간 매핑 |
| 인간 대포 | 발사/비행/종료 공개 사건, 기존 진행 Task-040~044 계약 | launchId로 발사·착지 결합, 마지막 구간 판정 보존 |
| 대기실 공간 | zone enter/exit 트리거·flowId, 경보·집결, 준비 완료 | 진입/이탈 짝, 공간 이동/퇴장으로 열린 체류 닫기 |
| 상점·운반 | 주문·배송·수령·보관의 실제 완료/실패 경계 | flowId로 주문 생애 결합, 부분 수령·이양 추적 |
| 의료 서비스 | 예약·입장·완료·복귀·이탈, 몸/이동 능력 | 비용·복구 원천 대조, 미이용/실패도 기록 |
| 입력·음성 | PlayerInputReader, 버튼 adapter, VoiceChat 발화 시간 | 키 이름·입력 방식만, 음성/입력 문자열 저장 안 함 |

## 선행 정리
- 시도 공유 UUID는 외줄 기존 Results의 N 형식을 D로 정규화해 재사용할 수 있다.
- 인간 대포 시도·발사 ID는 해당 공간 소유 Task와 합의해야 한다.
- 사망 원인·장애물/상호작용 영속 ID·구간/줄 번호는 각 공간의 의미를 확인해 연결한다.
- 신체 손상은 PlayerCondition.Changed 연결 완료. 같은 프레임 연속 손상 2건의 각각 기록을 PlayMode에서 확인.
- 대기실 방별 BoxCollider·실제 배치/준비/퇴장/경보/집결 시간·호스트 만료 위치·의료 실제 복귀를 연결했다. 통로 막힘/우회와 동일 경로 전후 실측은 coverage.md의 원천 필요 항목으로 남긴다.
- 키·uGUI 버튼·Vivox 발화와 공개 협동/손상·대포·구매·수령·보관·의료 단계는 연결했다. coverage.md의 제한 지표는 아직 미연결이다.

## 공동 검증
1. 같은 방의 호스트+참가자, 성공·실패·재시도 → JSON·시트·화면 숫자 대조.
2. 중간 네트워크 차단·강제 종료·재실행 → 이벤트 중복 0, 원본 보존, 결손 표시.
3. 구역 체류·구매/양도/보관·의료 예약/완료/실패 → flowId로 소요 시간 재구성.

## 비용
- Google Apps Script·Drive·Sheets 기존 무료 할당량만 사용. 결제 연결·유료 API 없음.
- 서버의 처리량·시간 한도는 운영 보호이며 영구 확장성을 보장하지 않는다.
- 초과 시 무료 범위 안에서 보관/집계 분할 방식을 먼저 검토하고 요금제 전환은 하지 않는다.
