# M2 이벤트 적용 대조표

[Confluence M2 초안](https://hrjoo122770.atlassian.net/wiki/spaces/bYmkRlnpusng/pages/35553283/M2+--) 버전 8과 11월 5일 피드백을 대조했다. 아래의 ‘적용’은 코드 연결을 뜻한다. 운영에서 직접 대조한 합성 런과 실플레이 검증 범위는 [공간 로그와 타임라인](m2-spatial-timeline.md)에 별도로 기록한다.

## 공통 연결 정보

| 기획 이벤트 | 적용 여부 | 기록 기준 |
|---|---|---|
| 런 시작(기존 항목 보완) | 적용 | 방 세션과 런 순번을 함께 저장. 런의 결과·자금은 개별 집계한다. |
| 플레이 기록 연결 코드 생성 | 적용 | 기존 세션 코드 유지. |

## 묘기 공통

| 기획 이벤트 | 적용 여부 | 기록 기준 |
|---|---|---|
| 묘기 시작 | 적용 | 일차·공연 번호·묘기명을 탭에 표시. |
| 묘기 성공 | 적용 | 호스트가 확정한 팀 성공 및 소요 시간. |
| 묘기 실패 | 적용 | 호스트가 확정한 팀 실패와 사유. |
| 플레이어 도착 | 적용 | 첫 도착에서 팀 클리어 시간 한 번. |
| 구간 진입 | 적용 | 각 플레이어의 실제 경계 통과 시각과 구간. |
| 구간 이탈 | 적용 | 실제 공연 구간에서 벗어난 시점·체류. |
| 플레이어 사망 | 적용 | 플레이어, 사망 판정 원인, 위치, 관련 장애물. |
| 사지 절단 발생 | 적용 | 절단 부위, 누적 결손 개수와 결과. |
| 묘기 진행 중 이탈 | 적용 | 호스트가 관측한 접속 이탈과 묘기 이탈을 구분. |
| 재도전 시작 | 제외 | 묘기 재도전 없음. 같은 방의 다음 런으로 확인. |
| 묘기 보상 확정 | 적용 | 최종 팀·개인 호응과 실제 지급 토큰. 환호·야유는 개별 사건. |

| 대포 준비 완료 | 적용 | 호스트가 다시 상호작용 가능해진 시점 한 번. |

| 대포 비행 결과 | 제외 | 별도 비행 결과 대신 실제 착지·반동·피격을 확인. |
| 장애물 접촉 | 적용 | 실제 접촉 위치·장애물·절단 개수와 결과. 발사 ID 불필요. |
| 협동 기믹 사용 시도 | 적용 | 트램펄린·봉에 실제 잡기 요청을 보낸 시점. 확정된 작동·해제와 분리한다. |
| 협동 기믹 작동 | 적용 | 트램펄린·봉·리프트·발판 작동과 캐릭터 상태. |
| 협동 기믹 해제 | 적용 | 플레이어가 놓거나 내렸을 때 상태 해제. |

## 탈출로

| 기획 이벤트 | 적용 여부 | 기록 기준 |
|---|---|---|
| 탈출 시작 | 적용 | 각 플레이어가 제한시간 시작을 관측. |
| 구간 진입 | 적용 | 플레이어별 각 구간 최초 진입 시각. |
| 구간 이탈 | 제외 | 다음 구간 진입으로 해석. |
| 기믹 사용 시도 | 통합 | 별도 시도 건수 대신 실제 작동. |
| 기믹 작동 | 적용 | 대포·그네·봉·버튼·레버·목마·트램펄린·컨베이어·권상교. 개인과 공용 상태 구분. |
| 기믹 해제 | 적용 | 확정된 해제/이탈 시점. 일회성 기믹의 가짜 해제 없음. |
| 대포·그네 이동 결과 | 통합 | 플레이어별 착지와 낙하 관측. 별도 비행 결과 없음. |
| 위험 요소 상태 변경 | 적용 | 소실 외줄 각각 및 권상교 상태 변화는 호스트 기록. |
| 피격 | 적용 | 피격자, 장애물, 접촉 위치와 결과. |
| 사지 절단 발생 | 적용 | 개별 결손 개수와 신체 상태. |
| 플레이어 사망 | 적용 | 각 플레이어의 확정 사망/원인/위치. |
| 절단기 획득 | 적용 | 집은 직후 플레이어와 획득 위치. |
| 절단기 발사 | 적용 | 발사 직후 사수와 위치·방향. |
| 절단기 명중 결과 | 제외 | 실제 배선 절단으로 확인. |
| 배선 절단 | 적용 | 플레이어·선 식별자·절단 수와 남은 수. |
| 문 개방 | 적용 | 실제 문 열림은 호스트가 한 번 기록. |
| 플레이어 도착 | 적용 | 갈대밭 진입 즉시 도착자 기록 및 전송. 팀 결과와 구분. |
| 제한 시간 만료 | 적용 | 제한시간 만료 시 호스트 1회. |
| 탈출 진행 중 이탈 | 적용 | 호스트에서 확인된 이탈자 기록. |
| 탈출 종료 | 적용 | 게임이 실제로 종료되는 시점에 결과를 확정하고 남은 데이터를 제출. |

## 직접 요청한 대기실·공연·탈출로 사건

| 기획 이벤트 | 적용 기준 |
|---|---|
| 대기실 탐색·상호작용·기물 획득/드랍 | 탐색 대상·성공 여부·시도 횟수, 기물 번호, 실제 소모 전후 내구도와 위치 |
| 추격·도망·잡힘 | 호스트의 추격자별 위치·대상·상태와 플레이어 본인의 추격·대상 해제·잡힘/사망. 대상 해제를 무조건 도망 성공으로 세지 않는다. |
| 리허설·오브제 발견·공연 해금·스케줄 변경 | 실제 단계와 완료, 발견 기물과 해금된 묘기, 실제 변경된 일차·편성·난도 |
| 공연 환호·야유·피격·기믹·사망 | 반응과 호응 변화, 접촉·상호작용 대상·사망 원인의 위치를 표시 |
| 동선과 물체 | 대기실·탈출로 1초/0.5m, 공연 위치·장애물 5초와 특별 사건. 층별/모든 층, 탈출로 전체/14구간 |
| 런 포기·패배 | 런 종료 사유로 구분. 한 사람의 접속 이탈을 팀 패배로 세지 않는다. |

대기실·리허설 확대 항목과 집계하지 않는 항목은 [대기실·리허설 관찰 기준](waiting-room-observations.md)에 별도로 정리했다.
