## 실제 플레이로 확인할 항목

1. **CODE 방 2인 이상:** 호스트·참가자가 로비→공연→대기실→종료. 같은 roomId/runId/attemptId, 서로 다른 슬롯, 재접속·인계 로그를 대조한다.
2. **정상 플레이:** 외줄/대포 성공·실패·절단·협동, 구매/배송/수령/보관, 의료/시설 예약. 눈으로 본 결과·위치·순서와 기록이 일치하는지 확인한다. 키보드·마이크 실제 입력도 포함한다.
3. **전송·대시보드:** 오프라인 종료→재실행, 강제 종료 후 복구, 수동/30분 갱신. 누적·미전송 복구와 중복 없는 적재를 확인한다.

단일 PC 최소 전송 검증은 완료: 격리 큐 저장/재생성, 전송 실패 후 원본 보존, 실제 Google ACK 후 pending 제거, 같은 배치 2회 전송/가져오기 후 Drive 원본 1개·Events 1행. 실제 프로세스 강제 종료·PC 전체 오프라인·두 PC 플레이는 위 공동 검증에 남는다.

기존 전체 EditMode의 목마 점프 기대 0.9/실제 1.35 불일치는 별도 담당 구역이다. 이번 검사 통과를 전체 프로젝트 통과로 해석하지 않는다.
