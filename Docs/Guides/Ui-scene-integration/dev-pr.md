## 변경 내용
기존 임시 UI를 Assets의 완성 프리팹으로 교체하고 Start → Lobby → 대기실 → 외줄/인간대포 실제 진행 흐름에 연결한다. 공통 UI는 별도 additive 씬에서 관리한다.

- Start 로고·참가/LAN 팝업, 로비 준비·시작·방 정보와 상호작용 안내.
- 대기실 상점·서비스·장부, 일정 항목 편집·확정·준비, 이름표·시간·자금 HUD. 4일차 공연 편성 제거.
- 두 공연 호응·불 이동 타이머·위치·피드백 HUD, 불 시작 기준 완료 시간·개인 최대 거리·결과창. 성공/실패 모두 참가 인원×10 기본 자금을 기존 보상에 가산.
- 사망 알림, 결과 대기·커튼 전환, 공통 ESC 메뉴·설정·음성 설정·마이크 상태.
- 상호작용 커서/외곽선, 상점·일정 hover 툴팁, 1920×1080 Expand Canvas 및 대체 임시 UI 정리.
- 외줄 조작 안내는 상황별 상단 배너. 한글 글리프가 포함된 폰트 사용.
- 공통 C5 슬롯과 숫자1~5 선택, 같은 번호/빈 슬롯으로 집어넣기, 호스트 상태 동기화, 선택 기물 내려놓기·선반 연결. 기존 팔/배낭 소지 한도 유지.
- Dev 시작 시점 도구 및 적용 가이드. 리소스 공급 브랜치에서 받은 완성 에셋/프리팹 변경도 포함.
