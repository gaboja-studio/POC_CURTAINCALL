# 공연 호응·시간·위치 연결

2026-10-20 사용자 요청: UI 화면 HTML 4-1 임시 호응 규칙을 두 공연의 공통 로직으로 구현한다. 이전의 표시 전용 범위와 C3 1인 미지원 결정을 이 항목에 한해 대체한다.

## 구성과 데이터
- CommonPerformanceUI: 기존 Assets 정본 C1/C2/C3 인스턴스를 유지. SoloPerformanceProgress가 동일 인스턴스의 실제 첫 단원 마커를 표시한다. 2~4인은 기존 SetProgress를 사용한다.
- Tightrope/HumanCannon 공간 씬: 루트 PerformanceAudience가 호스트의 플레이 상태를 관찰한다. UI 표시를 꺼도 점수는 갱신된다. 클라이언트는 기존 PerformanceRewards 스냅샷으로 같은 호응을 표시한다.
- 원본 프리팹·PNG·폰트·파일명·9-slice는 수정하지 않았다. package 리소스는 사용하지 않았다.
- C2 외줄: 불의 지연 + 안전 경계까지 거리/속도 - 경과시간. 인간대포: 활성·armed 불벽의 안전 경계 도달까지 가장 짧은 시간. 종료된 벽만 남으면 0:00, 아직 armed 벽이 없으면 —.
- C3: 코스 축으로 투영한 나/팀원 위치와 실제 불 전방. 외줄은 경고 대기 중 시작 위치도 표시한다. 인간대포는 활성 armed 불벽 중 가장 앞선 전방이다.
- 타이머는 표시만 한다. 기존 불 접촉·추락·공연 종료 판정은 변경하지 않았다.

## 설정과 미확정 세부 기준
- 설정 에셋: `Assets/Resources/Settings/GameSettings/Tricks/Rewards/temporary-audience.asset`.
- 두 공연은 문서대로 개인 상한100, 절단30. 다른 묘기와 테스트의 보상표는 유지한다. 명시적인 기존 RulesOverride는 계속 우선한다.
- 문서에 수치가 없는 근접 회피는 여유0.3m, 불 직전 도착은3m, 접근8m/통과2m로 구현했다. 플레이 테스트 후 설정에서 조정한다.
- 인간대포 아래층은 기존 구간 설정의 RaisedMinY 미만, FirstStartZ 이후에 서 있는 단원이다. 출발 대기·좌석·비행·봉 매달림은 제외한다. 아래층 지속 중 인원이 바뀌면 해당 시점의 아래층 단원에게 지급한다.
- C10 환호/야유 팝업, C8 추락 알림, C12 결과 화면의 새 그래픽 적용은 이번 범위가 아니다. 호응 데이터와 정산 연결은 완료했다.

## Unity 사용자 확인 순서
1. Start부터 기존 흐름으로 외줄 공연 진입. 혼자여도 우상단 내 위치와 불, 남은 거리가 보여야 한다. 불 이동이 시작되면 좌상단 시간이 줄어야 한다.
2. 장애물을 앞에서 접근해 지나간 뒤 개인 호응 +5/+15를 확인한다. 같은 장애물을 왕복해도 중복 지급되면 안 된다. 절단 +30, 야유 감소, 추락한 단원0 고정을 확인한다.
3. 두 명 이상에서 수직 톱 목마 통과 +50 / 줄 변경 통과 −30, 각 단원의 색·위치와 로컬 큰 마커를 비교한다.
4. 인간대포에서 반동 +15, 봉 연속3초 −15(같은 잡기에서 반복 없음), 아래층2명 연속10초마다 −15를 확인한다. 출발 대기는 제외된다.
5. 정상 도착과 불 직전 도착의 환호가 정산에 포함되는지 확인한다. C2 0 자체는 실패를 발생시키면 안 된다.
