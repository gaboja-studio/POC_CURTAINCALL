# GitHub 연결 (처음 한 번만)

AI가 PR·이슈를 대신 올리려면 내 PC에 GitHub 도구(`gh`)가 연결되어 있어야 합니다.
연결이 안 되어도 **웹페이지 방식으로 똑같이 제출할 수 있으니** 걱정하지 않아도 됩니다.

1. AI에게 **"GitHub 연결해줘"**라고 말합니다. 설치는 AI가 시도합니다.
2. 로그인 차례가 되면 Claude Code 입력창에 아래를 입력합니다.
   ```
   ! gh auth login --web --git-protocol https
   ```
3. 브라우저가 열리면 화면에 나온 코드를 입력하고 **Authorize**를 누릅니다.
4. AI는 최대 2번까지 시도합니다. 그래도 안 되면 다음 중 하나를 고르라고 물어봅니다.
   - ① 내용이 채워진 웹페이지 열기 → 확인 후 버튼만 누르기
   - ② 한 번 더 연결 시도 → 성공하면 AI가 등록
5. "저장소 권한이 없다"고 나오면 PM에게 GitHub 저장소 초대를 요청합니다.

비밀번호나 토큰을 AI에게 알려 줄 필요는 없습니다. 로그인은 항상 브라우저에서 직접 합니다.
