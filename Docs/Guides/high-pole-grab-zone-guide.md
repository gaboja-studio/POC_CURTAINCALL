# 높은 그네(목마 전용) 잡기 판정 조절 가이드

높은 위치의 그네·스위치 그네를 **목마로만** 잡게 하거나, 그 판정 범위를 직접 늘리고 줄일 때 읽습니다.
(2026-11-26 Task-204. 일반 그네의 판정·공중에서 잡는 느낌은 바뀌지 않습니다.)

## 1. 한눈에 보기

- 그네마다 **"목마 전용 높은 봉"** 체크가 있습니다. 켜면 그 그네를 **바닥·발판·외줄·목마 위에서** 잡을 때만 아래 규칙을 씁니다.
  - **목마 조건**: 목마 맨 위 사람(또는 목마에서 막 W+Space로 뛰어오른 사람)만 잡을 수 있습니다. 혼자 점프·2단 점프로는 높이와 상관없이 안 잡힙니다.
  - **판정 상자**: 몸 중심이 노란 상자 안에 있어야 잡힙니다. 상자는 흔들리는 봉을 따라 움직입니다.
- 그대로인 것: 대포·그네 비행 중 공중에서 잡기(기존 반경 3m), 매달린 동료 잡기(기존 3.5m), 체크하지 않은 모든 그네.
- 상자는 **물리 충돌체가 아닙니다**. 사람·카메라를 막지 않는 "잡기 판정 전용 영역"입니다.

## 2. 지금 켜져 있는 곳

| 위치 | 그네 | 상태 |
|---|---|---|
| 공연 외줄 · 공중그네 | 높은 첫 봉(줄 위 5m) | 자동으로 켜짐(코드가 생성) |
| 대기실 리허설 · 공중그네 수업 | 높은 첫 봉(0.5m 낮춤) | 자동으로 켜짐 |
| 연습용 낮은 봉·복귀 봉 | — | 꺼짐(일반 봉) |
| 탈출로·인간대포·연습실 씬 그네 | 씬에 놓인 봉 전부 | 꺼짐. 필요하면 아래 3번으로 켬 |

2026-11-26 측정: 탈출로 그네 36개는 모두 옆 발판에서 서거나 점프해 잡는 배치였고, 인간대포 불 스위치 봉은 바닥에서 7.3m라 대포로만 닿습니다. 그래서 씬 봉은 기본으로 켜지 않았습니다.

## 3. 씬에 놓인 그네를 목마 전용으로 만들기

1. 하이어라키에서 그네 오브젝트(`HumanCannonPole` 컴포넌트)를 선택합니다.
2. 인스펙터 **"목마 전용 높은 봉 — 바닥에서 잡는 판정"** 칸에서 **목마 전용 높은 봉**을 켭니다.
3. 씬 뷰에 노란 상자가 보입니다. 기본 크기는 GameSettings 공통 값입니다.
4. 이 그네만 다르게 하려면 **개별 판정 상자 사용**을 켜거나 **[기본 영역을 개별 상자로 복사]** 버튼을 누릅니다.
5. 씬 뷰의 상자 면에 있는 점(핸들)을 끌어 크기를 바꿉니다. 콜라이더 편집과 같은 방식이며 Ctrl+Z가 됩니다.
6. 씬을 저장합니다.

상자 숫자(봉 중심 기준, m): **X=봉 길이 방향, Y=위(음수면 봉 아래), Z=앞뒤 흔들림 방향.**

## 4. 닿는지 확인하는 법 (씬 뷰 기준선)

봉을 선택하면 봉 바로 아래 발판에서 계산한 기준선이 보입니다. 인스펙터 안내 칸에도 같은 결과가 글로 나옵니다.

| 선 | 의미(몸 중심 높이, 발판 기준) | 목마 전용이면 |
|---|---|---|
| 혼자 점프 | 0.75m + 점프 0.8m = 1.55m | 상자 밖(빨강)이 안전 |
| 2단 점프 | 약 2.35m(신발 등) | 목마 조건이 켜져 있으면 상자 안이어도 안 잡힘 |
| 목마 위 | 1.5m + 0.75m = 2.25m | 상자 안(초록)이면 서서 F로 잡힘 |
| 목마 점프 | 2.25m + 1.2m = 3.45m | 상자 안이어야 함 |

외줄 공중그네 첫 봉은 씬에 오브젝트가 없어서, **외줄 코스(`TightropeCourse`)를 선택**하면 첫 봉 자리에 같은 상자와 기준선이 보입니다.
이 상자는 **GameSettings › 봉 설정 › 기본 바닥 잡기 영역**으로 조절합니다.

## 5. GameSettings › 봉 설정(PoleSettings) 항목

`Assets/Resources/Settings/GameSettings/Tricks/PoleSettings.asset`

| 항목 | 기본값 | 설명 |
|---|---|---|
| 기본 바닥 잡기 영역 | 중심 (0, -1.1, 0) · 크기 (3, 4.2, 4.6) | 개별 상자를 쓰지 않는 모든 목마 전용 봉. 봉 아래 3.2m~위 1m |
| 목마 탑승자만 바닥에서 잡기 | 켬 | 끄면 상자만 봅니다(아래 6번 주의) |
| 높은 봉 안내 거리 | 6m | 이 수평 거리 안에서 아직 못 잡으면 화면 왼쪽 아래에 사용법 안내. 0이면 끔 |
| 안내 문구 6개 | 혼자/목마 위/목마 아래 | F·Space·W/S는 현재 키 설정으로 바뀌어 보입니다 |

## 6. 자주 하는 조절

- **목마 위에서 꼭 점프해야 잡게**: 상자 아래쪽을 올립니다. 예) 중심 Y -0.5, 크기 Y 3.0 → 봉 아래 2.0m부터. 목마 위에 서기(2.25)는 밖, 목마 점프(3.45)는 안.
- **목마 조건을 끄고 높이로만 막기**: 2단 점프(2.35)가 상자 밖이 되도록 상자 바닥을 봉 아래 약 (봉 높이 - 2.6)m 위로 올립니다. 신발·발판 위 점프 같은 변수가 있어 **목마 조건 켜기를 권장**합니다.
- **앞뒤로 더 넓게 잡게**: 크기 Z를 늘립니다. 흔들림이 큰 봉은 5~6m가 편합니다.

## 7. 바꾼 뒤 확인

1. Play → 혼자 봉 아래에서 Space(2단 점프 포함)+F: 안 잡히고 안내가 뜨는지.
2. 동료와 F로 목마 → 위 사람이 봉 아래에서 F(또는 W+Space 후 공중 F): 잡히는지, 목마가 풀리는지.
3. 아래 사람이 매달린 동료 가까이에서 F: "매달린 동료 잡기"로 함께 매달리는지.
4. 대포·그네 비행 중 F로 공중 잡기: 전과 같은지.

문제가 있으면 봉 이름·씬·인스펙터 안내 칸 내용을 함께 알려 주세요.
