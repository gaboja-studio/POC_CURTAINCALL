# AI에게 하는 말

PM과 작업자 모두 같은 흐름을 사용합니다.

| 말 | 하는 일 |
|---|---|
| “○○ Task 만들어줘, 담당은 A” | 목적·담당·작업 브랜치를 적은 3문서 생성 |
| “Task-○○○ 시작해줘” | 작업 브랜치 열기, plan·todo 확인 |
| “○○를 고쳐줘” | 관련 기능을 조사·수정하고 계획·할 일 갱신 |
| “검사해줘” | 변경에 필요한 검사만 실행·log 기록 |
| “저장해줘” | 변경 확인·가벼운 검사 후 commit/push |
| “제출해줘” | 선택 대상으로 PR 생성 |
| “이 변경 받아줘” | 선택 출발 브랜치에서 현재 작업으로 직접 받기 |
| “인계 메모 써줘” | log에 문제·남은 일·다음 행동 정리 |

작업 구역·PM 인계 승인은 필요 없습니다. dev 반영은 PR과 지정 팀원 검토를 거칩니다.
