# 공연 배치 창

Unity 메뉴 **Tools → CurtainCall → 공연 → 공연 배치**. 상단에서 외줄타기/인간 대포와 난이도 1~3을 고른 뒤 **공연 씬 열기**를 누른다.

## 지도 조작

- 우클릭 드래그: 회전. 휠: 확대/축소. 가운데 버튼: 화면 이동.
- 목록 또는 지도 표식을 클릭해 선택한다. 지도에서 드래그하거나 오른쪽 위치·회전을 입력한다.
- **선택 대상 확대**, **전체 배치 보기**, **Scene 뷰에서 이동·회전**을 사용할 수 있다. Undo/Redo를 지원한다.
- **배치 저장**은 현재 공연 씬과 관련 설정을 저장한다. 미리보기 모델·카메라는 씬에 저장되지 않는다.

## 환호 포인트

**환호 포인트** 탭에서 클릭 배치 높이를 정하고 ‘클릭해서 추가’를 켜거나 뷰 중심에 추가한다. 복제·현재 난이도에서 삭제·표시할 난이도 변경을 지원한다.

**링 크기 배율**에서 고리를 줄이거나 키운다(1 = 기본 크기). 불꽃과 통과 판정도 같이 바뀌며, 바로 아래에 실제 통과 지름이 표시된다. 복제·난이도 분리 시 크기도 유지된다.

기존 고리는 세 난이도가 공유한다. 한 난이도만 옮기려면 **현재 난이도 전용으로 분리**를 먼저 누른다. **획득 연출 재생**으로 아래로 내려갔다 위로 회수되는 모습을 확인한다.

공통 **환호 포인트 사용**은 기본 ON이며 OFF이면 표시와 통과 보상을 함께 중단한다. 외형은 불/금빛/가면으로 전환할 수 있다. 줄은 보유 로프·매듭 모델을 사용하며 꼬임을 늘리지 않고 반복한다. 줄 길이·두께·하강 거리/시간·상승 가속도/속도·최소 숨김 높이는 같은 GameSettings에서 조절한다. 화면 안에서는 축소·투명화하지 않는다.

## 인간 대포의 장치

**공연 장치 · 장애물 · 착지 지점** 탭에서 대포, 톱날/함정, 봉, 착지판, 트램폴린, 운반 장치, 불 등을 선택한다. 위치·회전·크기·사용 여부는 선택한 난이도에만 적용된다.

기존 장치를 복제하거나 ‘새 장치 원본’에 지원 컴포넌트가 있는 프리팹/씬 오브젝트를 넣어 추가한다. 대포·톱날·봉·운반 장치·불의 실제 동작 목록에도 등록한다. 다른 장치와 연결된 복합 장치는 연결된 자식이 포함된 원본을 사용하고 플레이로 확인한다.

삭제는 해당 난이도에서 제외하는 방식이다. 목록의 **[제외]** 장치를 선택해 ‘이 난이도에서 사용’을 켜면 복원된다. 다른 장치가 참조하는 객체와 네트워크 목록 순서는 유지한다. ‘원본 동작 설정 (공통)’에서 바꾸는 속도·연결 등은 난이도별 위치와 달리 공통 설정이다.

## 외줄타기의 장애물과 도착 지점

외줄은 설정을 읽어 코스를 생성한다. **이 난이도 배치 편집 시작**을 누르면 현재 코스와 난이도 추가 톱날을 복사해 독립시킨다. 다른 난이도는 그대로다.

톱날 추가·제외·거리 이동, 도착 지점·공중 봉 구간·봉 교대 관문 이동을 지도에서 편집한다. 오른쪽 ‘줄 · 도착대 · 봉 구간’에서 구간 사용 여부와 길이, ‘톱날 배치 · 작동 순서’에서 나오는 조건을 조절한다. 톱날 삭제는 번호를 보존하는 제외 처리이며 해당 항목의 ‘Excluded’를 끄면 복구한다.

외줄 지도는 배치 확인용 도형이다. 시간에 따른 장치 동작, 협동 규칙과 최종 외형은 실제 플레이에서 확인한다.

## 예상 경로와 플레이

초록 선은 외줄 경로 또는 대포의 현재 발사 속도와 공통 중력으로 계산한 탄도다. 입력·바람·충돌은 반영하지 않는다. 대포 선택 시 그 대포의 탄도만 표시한다.

**이 공연·난이도로 플레이**는 저장 확인 후 실제 캠페인 테스트를 시작한다. Play를 종료하면 편집으로 돌아오고 임시 Dev 모드를 복원한다. 최종 통과 가능 여부와 재미는 팀 플레이로 확인한다.
