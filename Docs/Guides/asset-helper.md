# 에셋 도우미 사용법

프로젝트 폴더의 `asset-helper.vbs`를 더블클릭하면 브라우저에 도우미가 열립니다(Windows). 명령어를 입력하지 않습니다. 이미 열려 있으면 기존 창을 다시 엽니다.
Mac은 프로젝트 폴더의 `asset-helper-mac.zip`을 더블클릭해 한 번 풀고, 같은 폴더에 생긴 `asset-helper.app`을 더블클릭합니다. Terminal 입력 없이 실행하도록 구성했으며 Mac 실행은 아직 실기기 검증 전입니다. 처음 열기 제한이 나오면 Finder에서 우클릭 → 열기를 사용합니다.

## 에셋 추가·수정·삭제 후

1. **Unity에서 먼저 작업**합니다. Package Manager 등으로 임포트하고, Unity Project 창에서 `_ThirdParty` 안으로 옮깁니다. 수정·삭제도 Unity에서 합니다.
2. Unity 저장, Console 오류와 실제 기능 사용을 확인합니다.
3. 도우미에서 **변경 확인하고 공유**를 누릅니다.
4. 변경 목록을 보고 바뀐 내용을 한 줄로 적습니다. 기능 확인 체크 후 **에셋 변경 저장·공유**를 누릅니다.
5. 비공개 에셋을 먼저 저장·업로드하고, 게임에는 에셋 연결 표시만 저장·업로드합니다. 다른 게임 파일의 변경·저장 준비 상태는 보존합니다.
6. 도우미가 다른 코드가 섞이지 않는 **에셋 전용 dev PR**을 자동으로 준비합니다. 현재 작업 브랜치에 에셋 연결 변경만 있으면 그대로 사용하고, 다른 코드도 있으면 공유용 임시 브랜치를 만듭니다. 검토·병합 화면에서 지정 팀원이 확인합니다.
7. 병합 후 도우미의 **다시 확인**을 누릅니다. 실제 `origin/dev`의 에셋 연결을 확인한 뒤에만 **팀 공유 완료**로 표시하고, 완료된 도우미 임시 항목을 정리합니다.

**별도 브랜치 업로드만으로 팀 공유가 끝난 것은 아닙니다.** 화면은 비공개 에셋 업로드 → 게임 작업 브랜치 업로드 → 팀 공용 origin/dev 반영을 따로 보여 줍니다. 통합·검토 대기나 네트워크 오류는 공유 완료로 표시하지 않습니다.

작업 브랜치에서 사용합니다. dev에 직접 저장하지 않으며, dev 반영은 기존 PR 검토로 합니다. 게임 브랜치에 아직 올리지 않은 다른 커밋이 있으면 Desktop/Fork에서 먼저 공유합니다.

## 임시 브랜치·작업 폴더 정리

- 공유 준비에 쓴 임시 작업 폴더는 준비 직후 지웁니다.
- 병합 후 **다시 확인**하면 도우미가 만든 공유 브랜치와 업로드용 에셋 브랜치를 PC와 원격에서 정리합니다. 실제 dev·비공개 main에 통합된 저장 기록을 먼저 확인합니다.
- 내 게임 작업 브랜치, 복구용 보관 기록, 다른 도구의 작업 폴더는 유지합니다.
- 추가 수정·잠금·연결 오류로 정리하지 못하면 **임시 항목 정리 보류**와 이유를 표시합니다. 변경을 보존하며 다음 확인 때 재시도합니다.

## GitHub Desktop·Fork에서 브랜치를 이동한 뒤

1. Unity를 닫습니다. 에디터가 파일을 다시 저장하는 동안 버전을 바꾸지 않기 위해서입니다.
2. 도우미에서 **에셋 버전 맞추기**를 누릅니다.
3. 확인 후 **현재 브랜치에 맞추기**를 누릅니다. 최신 main이 아니라 게임 브랜치가 기록한 버전으로 받습니다.
4. 내 수정이 있으면 **내 변경을 보관하고 맞추기**를 선택할 수 있습니다. 따로 저장한 에셋 커밋도 로컬 보관 브랜치로 남깁니다.
5. 이전 미저장 작업은 화면 아래 보관 목록의 **작업 복구**를 눌러 이어갑니다. 게임 브랜치는 이동하지 않습니다.

`Detached HEAD`는 서브모듈이 특정 버전을 사용하는 정상 상태일 수 있습니다. 기획자가 직접 main으로 바꿀 필요는 없습니다.

## 처음 준비할 것

- PowerShell 7, Git와 Git LFS, GitHub CLI가 필요합니다. 설치돼 있지 않으면 설치 화면에서 설치합니다. GitHub CLI 설치: https://cli.github.com/
- **GitHub 연결** 버튼으로 브라우저 로그인을 합니다. 도우미에 나오는 일회용 코드를 GitHub 로그인 화면에 입력합니다. 터미널 명령어 입력은 없습니다.
- 비공개 에셋 저장소 쓰기 권한이 필요합니다. GitHub 연결에서 로그인한 계정을 도우미의 Git 인증에도 사용하며, 기존 전역 Git 설정은 바꾸지 않습니다.
- 브라우저 화면은 이 PC의 주소에서만 열립니다. 로컬 도우미가 종료됐다면 아이콘을 다시 더블클릭합니다.

## 처리 중 문제가 생기면

- **업로드 중 끊김:** 상태를 다시 확인하고 같은 저장·공유 버튼으로 이어갑니다. 이미 만든 커밋을 중복 생성하지 않습니다.
- **다른 사람이 먼저 에셋을 올림:** 내 에셋을 별도 원격 브랜치에 업로드하고 비공개 main PR을 준비합니다. 검토 화면에서 **Merge commit** 방식으로 통합한 뒤 같은 버튼으로 게임 dev PR까지 이어갑니다. GitHub 권한 문제로 PR 자동 생성이 안 되면 비교 화면에서 직접 PR을 만듭니다. 이때도 팀 공유 미완료입니다.
- **dev 검토 요청 준비 실패:** 작업 브랜치 업로드는 보존하고 팀 공유 미완료로 표시합니다. 같은 버튼을 다시 누르면 dev 검토 요청 준비를 이어갑니다. dev에 직접 push하거나 자동 병합하지 않습니다.
- **해결되지 않은 충돌:** Fork의 충돌 화면에서 담당자와 해결합니다. 도우미가 씬·프리팹 충돌을 자동 해결하지 않습니다.
- **보관 뒤 다운로드 실패:** 보관 목록에서 내 작업을 복구할 수 있습니다. 잠금·미저장 파일을 자동 삭제하지 않습니다.
- **진행 중 파일·브랜치가 바뀜:** 새 상태를 확인하고 다시 누릅니다. 도우미 작업 중에는 Desktop/Fork나 Unity에서 같은 저장소를 바꾸지 않습니다.

도우미는 에셋 임포트·이동·편집, 게임 브랜치 전환, 실제 기능·재미 판단을 대신하지 않습니다.
