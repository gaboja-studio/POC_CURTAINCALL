# 게임 세팅 파일 사용법 (기획자용)

마지막 갱신: 2026-10-03 (Task-20261003-013 기준) · 결정 근거: `Harness/Project/Decisions/game-settings.md`
컨플루언스에 공유할 때는 이 문서를 최신으로 고친 뒤 그대로 옮긴다(맨 아래 "문서 관리" 참고).

## 한눈에

- 게임 수치(속도·균형·코스 모양·시간·인원 등)는 **Unity의 세팅 파일에서만** 바꾼다. 캐릭터·코스 프리팹에는 더 이상 숫자 칸이 없다.
- 세팅 파일은 `Assets/Resources/GameSettings/` 한 폴더에 있다.
- 칸 위에 마우스를 올리면 한글 설명과 단위, 기획 기준값이 나온다.

## 파일 구성

| 파일 | 담는 것 |
|---|---|
| `GameSettings` | 시작점. 아래 파일들을 연결만 한다. **고치지 않는다** |
| `BaseGameSettings` | 묘기와 상관없는 게임 기본값: 세션·캐릭터·입력·균형 공통·연출·동기화 |
| `Tricks/TightropeSettings` | 외줄 묘기 값: 코스·진행·줄 위 동작·목마·보상 연결 |
| `Tricks/Rewards/` | 보상 규칙 파일(보상 작업 이후). 묘기 세팅의 "보상" 칸에 끼워서 바꾼다 |

묘기가 늘어나면 `Tricks/` 아래에 묘기별 파일이 하나씩 생긴다.

## 값 바꾸는 법

1. Unity의 Project 창에서 `Assets/Resources/GameSettings/` 폴더를 연다.
2. 파일을 클릭하면 Inspector에 묶음(굵은 제목)별 칸이 보인다.
3. 숫자를 바꾼다. 따로 저장 버튼은 없다. Unity에서 저장(Cmd+S / Ctrl+S)한다.
4. 바꾼 값을 팀에 올리려면 AI에게 "저장해줘"라고 한다. 세팅 파일도 작업 구역에 있어야 저장된다(담당 Task의 `setup.md`).

## 언제 반영되나

| 값 | 반영 시점 |
|---|---|
| 대부분(속도·균형·충격·시간·연출 등) | 플레이 중에 바꿔도 **바로** |
| 코스 모양(줄 수·간격·길이·플랫폼 등) | 대기 중에는 바로 코스를 다시 만든다. 게임 진행 중에 바꾸면 다음 대기 때 |
| 방 정원 | 다음에 방을 만들 때 |
| 모델 맞춤 키 | 다음에 캐릭터 모델을 끼울 때 |

## 꼭 알아둘 점

- **플레이 중에 바꾼 값은 플레이를 멈춰도 남는다.** 프리팹과 다르게 세팅 파일 자체가 바뀐다. 시험으로 바꿨다면 직접 원래 값으로 되돌린다. 기본값은 아래 "항목 목록"에 있다.
- **온라인에서는 호스트 기준이다.** 코스 모양은 대기 중 호스트의 값이 모든 사람에게 맞춰진다. 클라이언트에서 바꿔도 적용되지 않는다. 나머지 값은 "모두 같은 빌드 = 같은 세팅"이라고 본다. 따로 바꾼 빌드끼리 같이 플레이하지 않는다.
- 설명에 **"기획 미정"·"테스트 값"**이라고 적힌 칸은 임시값이다. 기획이 정해지면 바꾸고 설명도 고쳐 달라고 요청한다.
- 칸을 새로 만들거나 없애는 것은 코드 작업이다. 필요한 칸은 PM에게 요청한다.

## 문서 관리 (PM)

세팅 칸이 추가·변경된 Task가 병합되면, 컨플루언스에 공유하기 전에 이 문서를 고친다.

1. 세팅 클래스(`Assets/Scripts/Settings/`)와 에셋을 비교해 "항목 목록"에 새 묶음·항목·기본값·단위를 넣는다.
2. 반영 시점이 다른 칸(예: 시작할 때만 읽는 값)이면 "언제 반영되나"에 추가한다.
3. 새 묘기 파일이 생기면 "파일 구성"에 추가한다.
4. "앞으로 추가될 칸"에서 끝난 항목을 지운다. 맨 위 "마지막 갱신"의 날짜와 Task를 바꾼다.
5. 컨플루언스에는 이 문서 내용을 그대로 붙인다. 파일 경로 표기는 유지한다.
