# 공연 보상·공동 자금 설정 가이드 (기획자용)

마지막 갱신: 2026-11-04 (Task-105). 규칙: [reward-rules.md](../../Harness/Project/Decisions/reward-rules.md) · 전체 세팅: [game-settings-guide.md](game-settings-guide.md)

## 바꾸는 곳

Unity Project 창에서 `Assets/Resources/Settings/GameSettings/Tricks/Rewards/`를 연다.

- `temporary-audience.asset`: 완주 인정 비율, 상황별 환호·야유·관심 감소·회피 거리.
- `temporary-reward.asset`: 난이도별 호응 상한·완주 보너스, 절단 보너스.

Inspector에서 수정하면 다음 판정부터 읽는다. 온라인 판정·정산은 호스트 값 기준이다. 파일을 수정한 값은 Play 종료 뒤에도 남으므로 시험 조정은 원래 값으로 복원한다.
두 설정의 항목 이름은 한글로 표시되며, 항목에 마우스를 올리면 단위·지급 조건·반복 제한을 한글 툴팁으로 볼 수 있다.

## 단계별 환호 배율 (`temporary-audience`)

`1단계 환호 배율`=2, `2단계 환호 배율`=1.5, `3단계 환호 배율`=1이다. 아래 표의 기본 환호량에 현재 공연 단계의 배율을 한 번 곱한다. 소수점은 반올림한다(7.5→8, 22.5→23).

| 단계 | 배율 | 기본 +5 행동 | 기본 +10 행동 | 개인 호응 상한 | 완주 보너스 |
|---|---|---|---|---|---|
| 1단계 | 2배 | +10 | +20 | 100 | 100토큰 |
| 2단계 | 1.5배 | +8 | +15 | 150 | 150토큰 |
| 3단계 | 1배 | +5 | +10 | 200 | 200토큰 |

장애물 회피·구조·기물·대포 플랫폼·그네·환호 포인트·기본 환호에 적용한다. 야유·관심 감소·팔다리 절단 보너스에는 적용하지 않으며, 상한·완주 보너스도 바꾸지 않는다. 높은 단계의 더 큰 최대 수입은 유지한다.

## 정산 (`temporary-reward`)

| Inspector 칸 | 기본값 |
|---|---|
| 기본 환호 증가량 / 기본 야유 감점량 | 10 / 5 (상황별 자동 환호·야유는 `temporary-audience`에서 조정) |
| 1 / 2 / 3단계 호응도 상한 | 100 / 150 / 200 |
| 1 / 2 / 3단계 완주 보너스 (토큰) | 100 / 150 / 200토큰 |
| 팔다리 절단 환호량 (부위당) | 절단 1개당 호응 +10, 같은 부위 중복 없음 |

생존자는 호응×2 + 완주 보너스, 사망자는 사망 전 호응만 지급, 이탈자는 0이다. 완주 보너스는 호응 상한 밖에 더한다. 실패해도 호응 보상은 지급하며, 별도 기본 자금·전원 생존 보너스는 없다.

예: 1단계에서 A는 호응 40·진행 100%, B는 호응 30·진행 80%, C는 호응 20·진행 79%로 살아 있다면 A 180 + B 160 + C 40 = 공동 자금 380토큰이다. 위치를 도착점으로 옮기지 않고 마지막 위치에서 결과와 시간을 고정한다.

## 직접 확인

1. 외줄·대포 공연에서 한 명이 실제 도착할 때 80% 이상 동료도 완주 보너스를 받는지 확인한다.
2. 일반 장애물 회피 뒤 되돌아 재통과하거나 같은 플랫폼·그네를 반복해도 추가 환호가 없는지 확인한다.
3. 동료를 실제로 두 번 구조하면 두 번 모두 환호가 오르는지 확인한다.
4. 재미·호응 빈도·2~4인 온라인 최종 플레이 경험은 사람이 확인한다.
