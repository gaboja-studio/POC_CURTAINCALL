# 쉬는 시간·상점·캐시 설정을 바꾸는 법

2026-11-05 · Task-110. **Unity 위쪽 `CurtainCall → 게임 조정` 메뉴부터 열면 됩니다.**

## 구매 시간과 복구 가격

1. Play를 멈춥니다.
2. `CurtainCall → 게임 조정 → 구매 시간·신체 복구 가격`을 누릅니다.
3. 오른쪽 Inspector에서 아래 칸만 바꿉니다.

| 바꿀 것 | 칸 이름 | 이번 적용값 |
|---|---|---|
| 쉬는 시간에도 기물 구매 | 쉬는 시간에도 기물 구매 | 체크 |
| 첫 복구 가격 | 최초 부위당 가격 | 50 |
| 다음 이용부터 오를 금액 | 이용 1회당 단가 상승 | 25 |

체크를 끄면 기물 구매는 밤 정비에만 가능합니다. 신체 복구 서비스는 쉬는 시간에도 가능합니다.
복구 단가는 **50 → 75 → 100 → 125…**입니다. 한 번에 두 부위를 고치면 첫 이용은 100이고, 다음 부위당 단가는 75입니다. 여러 부위를 한 번에 고쳐도 단가 상승은 한 번입니다. 새 런에서는 50으로 돌아갑니다.

실제 파일은 `Assets/Resources/Settings/GameSettings/WaitingRoomSettings.asset`입니다.

## 쉬는 시간

1. `CurtainCall → 게임 조정 → 쉬는 시간`을 누릅니다.
2. Inspector의 **런 진행(Run)**을 펼칩니다.
3. **아침 쉬는 시간 / 낮 쉬는 시간 / 첫날 가이드 쉬는 시간**을 각각 펼칩니다.
4. **제한 없음**은 끄고 **제한시간(초)**에 `300`을 넣으면 5분입니다. 3분은 `180`, 10분은 `600`입니다.

새 시간은 **다음 쉬는 시간이 시작할 때** 적용됩니다. 첫날 가이드의 기존 타이머 시작 조건은 유지됩니다. 밤 정비는 이번 변경에서 건드리지 않았으며, 별도의 **밤 정비** 항목으로 조정합니다.

실제 파일은 `Assets/Resources/Settings/GameSettings/BaseGameSettings.asset`입니다.

## 변경한 설정으로 배포하기

Inspector 수정 후 `Ctrl+S`로 저장하고 새 빌드를 만듭니다. 이미 배포한 실행 파일은 바뀌지 않습니다. 온라인 테스트 참가자는 같은 새 빌드를 사용합니다.

## 배포된 게임에서 캐시 초기화

**설정 → 기타 → 캐시 초기화 → 캐시 초기화** 순서로 누릅니다. 시작 화면에서도 사용할 수 있습니다.

- 지우는 것: 현재 PC 사용자의 설문 열림 기록, 대기실 안내를 본 이력.
- 유지하는 것: 조작·음량·화면 설정, 안내 표시 켜기/끄기, 플레이 로그, 이미 제출한 Google 설문 응답.
- 대상 버전의 설문 기능이 켜져 있어야 해당 시점에 설문이 다시 열립니다. 초기화가 설문 기능 자체를 켜지는 않습니다.
- MPPM에서는 버튼을 누른 가상 플레이어의 기록만 초기화합니다. 모든 가상 플레이어의 설문 기록은 기존 에디터 메뉴 `CurtainCall → 설문 캐시 초기화 → MPPM 보조 플레이어 포함`을 사용합니다.

## 성공과 사망 정산

공연 성공 시 연결된 **모든 생존자**가 완주 보너스를 받습니다. 출발점에 남아 있던 사람도 포함하며, 사망자·접속 종료자는 제외합니다. 실제 이동 거리와 마지막 위치는 도착점으로 바꾸지 않습니다. 종전의 80% 진행률 설정은 사용하지 않습니다.

보너스 금액은 `Assets/Resources/Settings/GameSettings/Tricks/Rewards/temporary-reward.asset`의 **1/2/3단계 완주 보너스**로 바꿉니다. 현재는 100/150/200입니다. 사망 안내는 개인 호응도가 절반으로 줄어든다고 표시합니다.
