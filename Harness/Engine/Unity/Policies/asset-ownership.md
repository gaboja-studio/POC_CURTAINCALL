# Asset Collaboration

- 작업 목적에 필요한 씬·프리팹·세팅을 수정할 수 있다. setup 작업 구역·공용 파일 독점 배정은 없다.
- 새 에셋 추가·활용·배치와 새 머티리얼 생성은 자유롭다. 외부 에셋 원문은 반드시 `_ThirdParty` private 저장소에 둔다.
- 기존 에셋의 큰 수정·삭제는 PM·에셋 관리자가 관리한다. 원본 교체, 대량 이동·삭제, 여러 씬의 참조를 바꾸는 수정 등이 해당한다.
- 작은 연결·값 조정은 직접 하고 변경 이유를 기록한다. 미정인 게임 의도는 사람에게 확인한다.
- 동시에 수정하는 씬·프리팹은 담당자끼리 조율한다. AI가 외부 메시지를 보내는 것은 사용자 요청이 있을 때만이다.
- 에디터가 연결돼 있으면 raw YAML 대신 에디터를 쓴다. 전후 컴포넌트와 참조를 확인하고 필요한 에셋만 저장한다.
- 저장 여부는 git 상태로 확인한다. `.meta`/GUID·다른 사람의 미저장 변경을 보존한다.
- 씬·프리팹 YAML 충돌은 AI가 임의로 해결하지 않고 담당자와 확인한다.
- 결과·주의점·미검증 내용은 Task log에 남긴다.
