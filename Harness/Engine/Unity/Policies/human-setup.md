# Unity Setup

- 사용자가 요청한 목적에 맞는 씬·프리팹·UI·아트 배치를 AI가 수정할 수 있다. meta의 AI Setup Allowed나 PM 사전 준비 표시는 요구하지 않는다.
- 기존 구조·공개 기능을 재사용하고 불필요하게 재설계하지 않는다.
- 미정인 게임 의도는 human-decision에 따라 사람에게 확인한다. 이미 요청한 배치나 일반 구현에 다시 허락을 묻지 않는다.
- 큰 에셋 수정·삭제는 PM·에셋 관리자가 관리한다. 참조·meta·다른 사람 미저장 변경을 보존한다.
- 실제 변경·검사·미검증 내용은 Task log에 남긴다.
