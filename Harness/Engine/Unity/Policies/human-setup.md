# Human Setup Required

기본적으로 다음은 사람이 준비한다.

- 씬 하이어라키
- 프리팹 구조
- UI 배치
- 아트/그래픽 배치
- 시각적 위치·크기

## AI Setup Allowed

Task `meta.md`의 `AI Setup Allowed`에 적힌 항목은 AI가 직접 만들거나 수정할 수 있다. 이 경우에도:

- 기존 구조를 최대한 재사용한다.
- 기획 미결정 사항은 `Harness/Core/Policies/human-decision.md`를 따른다.
- 불필요하게 재설계하지 않는다.
- 만들거나 수정한 씬/프리팹/UI를 handoff에 명확히 적는다.

위임 표시가 없는데 AI가 디자인·배치 판단까지 대신해야 한다면, 작업을 멈추고 사람에게 준비를 요청한다(Human Setup Required).
