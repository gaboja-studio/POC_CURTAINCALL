# 씬에 배치했는데 저장되지 않음

## 언제 읽나

에디터 명령으로 씬·프리팹을 수정했거나, "이미 배치되어 있다"는 보고를 근거로 다음 작업을 할 때.

## 증상

에디터 안에서는 오브젝트가 보였지만, 다시 열거나 다른 worktree/커밋에서는 사라져 있다.

## 원인

- 수정 후 저장 명령을 실행하지 않았거나 저장이 실패했다.
- 에디터 메모리 상태만 보고 "완료"로 판단했다.

## 대처

1. 수정 후 저장 명령을 명시적으로 실행한다.
2. 열린 씬의 dirty 여부를 확인한다(`verify-unity.ps1`은 dirty 씬이 있으면 실패).
3. **최종 판단은 `git status`로 한다.** 해당 `.unity`/`.prefab`이 변경 목록에 있어야 저장된 것이다.

## 확인 방법

```
git status --short -- Assets/
```
