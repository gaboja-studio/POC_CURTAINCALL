# 재질 색 값이 소수점만 바뀜

## 언제 읽나

`git status`에 `*.mat`이 수정으로 잡혔는데 재질을 고친 적이 없을 때. 저장 전 변경 목록을 정리할 때.

## 증상

- diff가 한두 줄: `_Color: {r: 0.15, g: 0.2, ...}` → `{r: 0.14999998, g: 0.19999996, ...}`. 보이는 색은 같다.
- 그 재질을 쓰는 프리팹을 코드(PrefabUtility 저장)로 저장하거나, 플레이·재컴파일 뒤에 다시 생긴다.

## 원인

URP 재질의 `_BaseColor`와 옛 `_Color`를 맞추는 과정에서 Unity가 색을 다시 계산해 저장한다(실수 반올림 차이). 사람의 편집이 아니다.

## 대처

- 재질을 직접 바꾼 게 아니면 **커밋하지 않고 되돌린다**: `git checkout -- "<.mat 경로>"`.
- 다른 Task 소유 재질이면 되돌리지 않으면 구역 검사가 막는다.

## 확인 방법

`git diff -- "*.mat"`이 소수점 차이뿐인지 본 뒤 되돌리고 저장한다.
