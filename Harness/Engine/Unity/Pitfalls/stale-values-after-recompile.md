# 재컴파일 후 옛 값이 남음

## 언제 읽나

코드 수정 → 재컴파일 직후 Inspector 값, 직렬화 필드, Play Mode 결과로 수정 효과를 판단할 때.

## 증상

코드를 고쳤는데 동작이 그대로이거나, 조회한 값이 수정 전 기본값과 같다.

## 원인

- 컴파일/도메인 리로드가 끝나기 전에 조회했다.
- 직렬화된 필드는 코드의 기본값을 바꿔도 이미 저장된 씬/프리팹 값이 유지된다.
- Play Mode를 재진입하지 않아 이전 세션 상태를 봤다.

## 대처

1. `verify-unity.ps1 -Compile`처럼 재컴파일 완료(`completed`/`up_to_date`)까지 기다린 뒤 조회한다.
2. 직렬화 값이 의도대로 바뀌어야 하면 코드 기본값이 아니라 에셋 값 변경이 필요한지 판단한다(에셋 소유권 필요).
3. Play Mode 결과는 종료 후 재진입해서 다시 확인한다.

## 확인 방법

조회 결과에 컴파일 완료 시각 이후의 로그가 있는지, `git diff`에 에셋 값 변경이 있는지 확인한다.
