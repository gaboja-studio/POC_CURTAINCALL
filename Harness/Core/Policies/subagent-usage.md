# Subagent Usage

보조 AI(서브 에이전트)는 비용과 요청 제한을 소모한다. 메인 AI가 좁게 직접 조사하는 것이 기본이다.

## 규칙

- 기본은 **0~1명**. 동시에 띄우는 것은 **최대 2명**.
- 같은 질문을 여러 보조 AI에게 동시에 맡기지 않는다.
- 보조 AI에게는 "처음부터 조사해 줘"가 아니라 **좁은 질문**을 준다.
  - 나쁨: "보상 시스템 전체를 조사해 줘"
  - 좋음: "`A.cs`, `B.cs`, `C.cs`에서 `Grant()`가 호출되는 순서만 알려 줘"
- 이미 알아낸 파일 경로, 심볼 이름, 현재 결론을 프롬프트에 넘긴다. 보조 AI가 `AGENTS.md`·정책을 다시 읽지 않게 필요한 규칙만 요약해 넘긴다.
- 결과는 요약본만 받아 Task 문서에 반영한다.

## 요청 제한(429 등) 대응

1. 잠시 기다렸다가 **1회만** 재시도한다.
2. 그래도 실패하면 보조 AI를 포기하고 메인 AI가 범위를 좁혀 직접 조사한다.
3. 실패 사실을 `log.md`에 1줄 남긴다.
