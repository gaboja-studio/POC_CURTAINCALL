# Human Decision

AI는 사용자가 요청한 목적과 이미 합의된 게임 의도 안에서 구현·계획 수정을 진행한다.

- 게임 규칙·밸런스·보상·조작·UX·아트·문구의 **미정인 의도**를 새로 정해야 하면 근거와 추천안을 짧게 묻는다.
- 사람이 이미 요청한 변경, 기존 패턴 재사용, 작은 버그 수정·에러 처리·기술 구현에 허락을 반복해서 묻지 않는다.
- 작업 도중 요구가 바뀌면 같은 Task의 plan·todo를 갱신한다. 별도 Task는 목적·담당을 나누는 편이 유용할 때만 만든다.
- 에셋의 큰 수정·삭제, 되돌리기 어려운 데이터 변경은 영향과 구체적인 변경을 먼저 보여 준다.
- 답이 필요한 부분만 기다리고 독립적인 작업은 계속한다. 침묵을 승인으로 보지 않는다.
- 미정 사항과 확정된 결정은 plan에, 특별한 사건·확인 결과는 log에 기록한다. 오래 유효한 결정은 지식 폴더에 남긴다.
- 재미·감정·방향성·최종 플레이 경험 판단은 사람이 한다.
