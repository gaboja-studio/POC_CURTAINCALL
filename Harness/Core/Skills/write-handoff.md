# Write Handoff

## 언제

"오늘 여기까지"라고 할 때, 대화를 새로 열기 전, 제출 전, 큰 단계를 끝냈을 때.

## 순서

1. `handoff.md`를 템플릿의 칸대로 **덮어쓴다**(이어 붙이지 않는다).
   - 지금 상태: 동작하는 것, 막힌 것, PR 링크
   - 다음 할 일: 바로 실행할 1~3개 행동
   - PM이 확인할 것: 확인 요청, 대기 중인 결정, 공용 파일 요청
2. Verification 칸은 마지막 검사 결과를 유지한다. 새로 검사했다면 `check-work`로 갱신한다.
3. `log.md`에 오늘의 결론을 1~3줄 추가한다.
4. 알게 된 함정·결정이 있으면 `record-knowledge`(작업자는 handoff의 "PM이 확인할 것"에 적어 PM에게 전달).
5. `save-work`로 저장한다. 문서 크기가 넘으면 `compact-docs`로 줄인 뒤 저장한다.
6. 사용자에게 알린다: "다음엔 새 대화에서 'Task-○○○ 이어서 해줘'라고 하시면 돼요."
