# write-handoff

1. plan·todo가 현재 목적과 남은 일을 보여 주도록 갱신한다.
2. log에 현재 결과·문제·미검증·다음 행동·PR 링크를 짧게 남긴다.
3. 기획자가 알아야 할 핵심만 채팅에 보고한다. 인계 여부·PM 전달 체크는 없다.
4. 오래된 기록은 History로 옮기고 링크한다. 중요한 미해결 사항은 현재 문서에도 남긴다.
5. “오늘 여기까지”에 저장 의도가 포함되면 save-work를 따른다.
