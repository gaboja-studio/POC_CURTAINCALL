# Investigate Bug

1. **실제 로그를 먼저 확보한다.** Console / `Editor.log` / 테스트 결과에서 실패 이유를 그대로 기록한다.
   - macOS Editor.log: `~/Library/Logs/Unity/Editor.log`
2. **한 번 실패인지, 매번 실패인지** 확인한다. 같은 조작을 2~3회 반복해 재현 조건을 적는다.
3. 입력/상태 → 기대 결과 → 실제 결과를 적는다.
4. 관련 지식 폴더의 `Pitfalls/index.md`를 보고 알려진 함정인지 확인한다(옛 값, 씬 미저장 등).
5. 원인을 코드 결함 / 직렬화 데이터 결함 / 기획 모호함 / 환경·도구 문제로 구분한다.
6. 가장 작은 가설부터 검증한다. 버린 가설은 `log.md`에 1줄로 남긴다.
7. 첫 원인을 고친 뒤에도 원래 시나리오를 **처음부터 끝까지** 다시 돌려 두 번째 원인이 없는지 확인한다.
8. 가능하면 회귀 테스트를 추가하고 최소 범위로 수정한다.
9. 기대 동작이 불분명하거나 플레이어가 체감하는 부분이면 `request-human-decision`.
10. 새로 알게 된 함정은 `record-knowledge`로 남긴다.
