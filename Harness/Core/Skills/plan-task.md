# plan-task

1. 현재 Task plan·todo와 관련 지도 1개, 필요한 실제 파일을 읽는다.
2. 근거·가정·사람이 정할 게임 의도를 구분한다. 이미 요청한 변경은 반복 승인받지 않는다.
3. plan에 Context·현재 접근·주의점을 짧게 적고 todo에 다음 행동을 적는다.
4. 경로는 참고 정보이며 수정 허가 구역이 아니다. 기능 연결도 목적 안에서 함께 진행한다.
5. “먼저 보고” 요청이면 구현 전에 계획을 보고한다. 그 외에는 승인된 목적 안에서 진행한다.
