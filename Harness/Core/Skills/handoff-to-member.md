# handoff-to-member

1. plan·todo와 필요한 log를 읽고 담당·작업 브랜치·남은 일을 확인한다.
2. 다음 사람이 바로 이어 갈 수 있게 현재 목적과 막힌 점을 갱신한다.
3. 전달할 안내를 짧게 만든다. AI가 다른 사람에게 메시지를 보내는 것은 명시적 발송 요청 때만 한다.
4. assigned·실제 인계 체크·공동 테스트 통과·작업 구역 반납 절차는 없다.
