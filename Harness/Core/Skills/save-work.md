# save-work

1. 현재 변경을 확인한다. 관련 없는 기존 변경은 섞지 않는다. 작성자는 gh 로그인 계정만 사용한다.
2. 현재 파일과 일치하는 검사 결과는 재사용한다. Unity 변경이 없으면 에디터를 요구하지 않는다.
3. `pwsh -File Scripts/save-work.ps1 -Message "<종류>: <요약>" [-DryRun]`.
4. 도구는 현재 변경 전체를 저장하므로 다른 작업이 섞였다면 명시 경로만 stage해 같은 검사를 거쳐 저장한다.
5. 저장 요청에 따라 작업 브랜치에 commit/push한다. dev 반영은 별도 PR 검토다.
6. 자동 테스트·공동 플레이는 매 저장마다 반복하지 않는다. 결과와 제약을 정확히 알린다.
