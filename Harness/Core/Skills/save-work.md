# Save Work

1. Unity에서 저장(Cmd+S / Ctrl+S)했는지 사용자에게 확인한다.
2. 이번 변경을 한 줄로 요약해 커밋 메시지를 만든다: `<종류>: <요약>` (예: `feat: 커튼 3초 열림 연출`).
3. 먼저 미리보기: `pwsh -File Scripts/save-work.ps1 -Message "<메시지>" -DryRun`
   - 스크립트가 하는 일: 구역 검사(`verify-scope`) → 문서 크기 검사(`verify-context`) → 변경 파일 목록 출력.
4. `[위반]`이 나오면 **저장하지 않는다.** 원인별로 쉬운 말로 알린다.
   - 구역 밖 파일: "○○는 이 Task 구역이 아니에요. 되돌릴까요, PM에게 요청할까요?"
   - `.meta` 없음: "Unity에서 해당 폴더를 한 번 열면 생겨요."
   - 문서 크기 초과: `compact-docs` 절차로 줄인 뒤 다시 시도한다.
   - 사용자 동의 없이 파일을 되돌리거나 지우지 않는다.
5. 문제가 없으면 `-DryRun`을 빼고 실행한다(커밋 → push).
6. 무엇을 저장했는지 1~2줄로 보고한다.

`tests/*` 브랜치에서는 구역 검사를 하지 않는다. `dev`, `integration/*`, `builds/*`에는 이 Skill로 저장하지 않는다.
