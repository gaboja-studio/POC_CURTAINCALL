# Setup GitHub CLI

PR·이슈 등록 전에 `submit-work`, `report-issue`가 호출한다. "GitHub 연결해줘"로 직접 불러도 된다.

1. 상태 확인: `pwsh -File Scripts/setup-gh.ps1`
   - exit 0 → 준비 완료. 원래 하던 일로 돌아간다.
2. 실패 원인에 따라 **시도 1회**:
   - 10 미설치 → `pwsh -File Scripts/setup-gh.ps1 -Install` (brew/winget 자동 설치)
   - 11 로그인 필요 → 사용자에게 입력창에 `! gh auth login --web --git-protocol https`를 입력해 달라고 한다. 브라우저가 열리면 화면의 코드를 넣고 승인하면 된다고 쉬운 말로 안내한다. AI가 대신 로그인하지 않는다.
   - 12 저장소 권한 없음 → 재시도로 해결되지 않는다. PM에게 저장소 초대를 요청하라고 안내하고 5번으로 간다.
   - 13 설치 실패 → 출력된 원인을 쉬운 말로 전한다.
3. 다시 1번을 실행한다. 여전히 실패하면 **한 번 더**(총 2회) 2번을 시도한다.
4. 2회 모두 실패하면 실패 원인을 1줄로 Task `log.md`에 남긴다. 처음 보는 원인이면 `record-knowledge`로 함정 파일에 기록한다.
5. 사용자에게 묻는다 (둘 중 하나를 고르게 하고, 답을 받기 전에는 진행하지 않는다):
   > "GitHub 연결이 계속 안 돼요. 이번에는 직접 등록해도 괜찮을까요?
   > ① 내용이 채워진 GitHub 페이지를 열어 드릴게요. 확인 후 버튼만 누르시면 돼요.
   > ② 연결을 한 번 더 시도하고, 되면 제가 등록할게요."
   - ① → 호출한 스크립트를 `-Browser`로 실행한다.
   - ② → 2~3번을 1회 더 한 뒤, 또 실패하면 5번 질문으로 돌아온다.

주의: 토큰·비밀번호를 사용자에게 묻거나 출력하지 않는다.
