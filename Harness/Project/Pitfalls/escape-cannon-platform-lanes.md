# 탈출로 대포대와 착지줄 판정

## 언제 읽나
대포 주변 정상 바닥에서 죽거나, 대포 착지용 3줄 사이에 점프할 수 없을 때.

## 원인과 보수
- A의 두 번째 대포대는 가장 가까운 외줄보다 6m, 코어 끝 대포대는 8m 낮다. `TightropeRun.Running`만으로 일반 이동에도 줄 기준 1m 낙사를 적용하면 정상 발판에서 죽는다. 복합 씬의 줄 깊이 검사는 실제 외줄 조작에만 적용한다.
- 11월 12일 공통 규칙 적용 시 저장 씬과 캠페인 배치 높이를 모두 25m로 맞췄다. 씬 루트만 옮기면 캠페인 진입 때 `PlaceCampaign`이 이전 높이를 복원한다. 기존 개별 낙사 영역 대신 `GameSettings`의 월드 Y -15 즉사와 일반 낙하 피해를 적용한다. 위험물 경로와 입장 앵커도 함께 옮긴다.
- `PlayerMover` 옆줄 점프는 `LaneSpacing` 고정 거리다. A05의 실제 1.65m와 설정 2m, A06의 비평행 줄은 `FindSceneLandingLane`에서 거절됐다. 양옆 줄과 중앙 줄의 시작점도 달라 진행 거리 변환이 어긋나므로 간격·방향뿐 아니라 시작/끝을 맞춘다. 중앙 줄을 연장해 기존 착지 선택 길이를 유지했다.
- `sceneRopes` 15개에 `laneEndDistances`가 11개만 있었고 A04A 상부 줄도 실제 15.108m와 설정 12m가 달랐다. 실제 지지 충돌체 길이로 맞춰 끝부분을 규칙상 없는 줄로 취급하지 않게 했다.
- 중앙 시각선은 형제의 배칭 메시(67·71·72)에 있고, 추가 줄은 케이블 자식 회전에도 이전 기울기가 남는다. Collider와 기존 배칭 Transform·케이블 축·양끝 고정부를 함께 맞춘다. 공유 메시 자체는 변경하지 않았다.

## 검증과 한계
- `TightropeSurfaceControlTests` 55/55, `FallVoidTests` 13/13. 양방향 및 앞뒤 이동 중 점프와 실제 도착 좌표를 검사했다.
- 기존 검사에서 A 착지 구역 52곳·468점의 낙사 영역 침범 0, 정상/부상 점프 캡슐 경로 264점의 벽/기물 겹침 0. 새 높이에서 착지 구역 52곳의 최저 높이는 월드 Y 3m다.
- 실제 호스트·참가자의 플레이와 통신 조건 확인은 사용자 테스트로 남는다.
