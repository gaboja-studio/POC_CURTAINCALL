# 탐색 경로·F 검증

## 언제 읽나
구조 A의 경로가 닫혔다고 나오거나, 층/벽 너머 조사·획득이 가능한 경우.

- 편집기에 저장된 NightDoorLock 철창은 닫힌 모습이다. 낮 동선 검사에는 shutter 충돌 소스만 제외한다. 실제 밤 폐쇄를 맵 결함으로 수정하지 않는다.
- Collider NavMesh에는 카메라/구역 트리거를 넣지 않는다. 반경/높이/단차는 실제 몸통과 맞춘다. 임시 데이터는 씬에 저장하지 않는다.
- 수평 거리만 검사하면 다른 층의 대상도 닿는다. ExplorationReach로 층·거리·가림을 검사하고 대상 자신의 충돌체/플레이어/트리거는 제외한다.
- FloorPropsView는 겹친 기물을 Spread로 옮겨 그린다. 호스트 획득 검사는 같은 표시 위치·범위를 사용해야 정상 F와 서버 판정이 갈리지 않는다.
- NavMesh 연결, 내부 메서드 호출, 합성 InputSystem 입력, 사람 직접 플레이는 별개 근거다. 입력 도보 검사에서 시작 뒤 위치를 보정하지 않는다.
- 실제2인 성공은 두 클라이언트로 따로 검사하며 한 호스트의 입력/상태 모의로 대체하지 않는다.

- 회전된 방 아래에 문을 만들 때 충돌체의 로컬 크기를 월드 출입구 폭으로 착각하지 않는다. 막음 면을 월드 문 축에 맞추고 좌우 가장자리를 가로지르는 Ray와 개방 후 충돌 해제를 검사한다.
