# 외줄 결승 목마 순서 변경

결승 관문은 실제 목마의 아래층 순서와 승인 명부를 대조한다. 아래 두 사람이 살아 있어도 기존 연결을 풀고 역할을 바꿀 수 있다. 유효한 새 편성이 실제 출발선에 왔고 승인된 사람이 도약 중이거나 관문 너머에 있지 않으면 새 순서를 승인한다. 정상적인 상층 이탈로 아래 두 명의 연결이 남은 경우에는 기존 명부를 유지한다. EditMode의 FinaleStackRetry 회귀는 역할 교체와 이미 건넌 사람의 승인 보존을 확인한다.
