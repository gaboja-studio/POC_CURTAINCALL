# 탈출로 입장 확인 대기

## 언제 읽나

로비가 담긴 대기실에서 탈출로로 전환할 때 커튼을 열지 못하거나 참가자가 합류실에 고정될 때.

## 원인과 대처

- 호스트는 출발 위치 확인을 받은 뒤 장면을 붙이고, 도착 배치를 확인한 뒤 대기실을 정리한다. 연결 종료자는 확인 대상에서 제외한다.
- 참가자가 아직 연결돼 있는 상태로 확인이 안 오면 무한 대기는 전환 중 플래그를 유지해 EscapeSceneTransfer의 재시도를 막는다.
- 출발·도착 확인은 각각 NGO 장면 로드 시간 이상 기다린 뒤 기존 실패·재시도 경로로 돌아간다. 로스터·기수신 확인·이미 붙인 장면은 유지한다.
- 시간 초과를 도착 성공으로 처리하면 카메라·위치를 옮기지 못한 참가자를 대기실에 남기게 된다. 확인이 실제로 도착하거나 해당 참가자의 연결이 해제되면 진행한다.
- NGO가 로드 실패를 보고한 뒤 호스트 씬만 남아 있을 수 있다. 배치 승인은 모든 연결 참가자의 로드 성공을 확인한 뒤 공유한다. 승인 전 재시도는 부분 씬을 닫고 새 로드 이벤트를 전송한다. 승인 이후 배치 확인 대기와는 별개다.
- 탈출 단계가 확정된 뒤에만 전환 패킷을 적용한다. 캠페인과 전환 메시지의 도착 순서가 바뀔 수 있으므로 호스트는 확인 대기 중 전환 상태를 재전송한다.
- 도착 확인은 실제 지지면에 아바타를 배치했을 때 보낸다. 카메라가 먼저 준비되면 도착과 함께 인계하고, 늦으면 아바타를 다시 움직이지 않고 카메라만 인계한다. 카메라 초기화가 팀 입장을 막지 않도록 한다.
