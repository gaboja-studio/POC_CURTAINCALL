# 명령 시간 초과·거부

## 언제 읽나

긴 파이프라인 명령이나 여러 명령을 한 줄로 이은 검증 명령이 실행 전 거부되거나 시간 초과로 끊길 때.

## 증상

검증 명령이 결과 없이 거부/중단되어, 공식 검증 대신 수동 확인으로 우회하게 된다.

## 원인

도구의 안전 검사기가 복잡한 한 줄 명령을 분석하다 시간 초과되거나, 명령 자체가 기본 타임아웃을 넘는다.

## 대처

- 복잡한 한 줄 명령 대신 `Scripts/`의 스크립트를 호출한다(짧고 검사하기 쉬운 명령).
- 오래 걸리는 명령은 단계별로 나눠 실행하거나 타임아웃을 늘려 실행한다.
- 검증을 못 돌렸다면 PASS로 적지 말고 `ENV_BLOCKED(timeout)`로 handoff에 적는다.

## 확인 방법

handoff의 Verification에 각 단계가 실제로 실행되었는지(`PASS`/`FAIL`) 기록되어 있는지 본다.
