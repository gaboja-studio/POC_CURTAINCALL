# 탈출로 배선 공유와 발사기 재활성화

발사기 하나가 같은 네트워크 방에서 꺼졌다 켜질 때는 오래된 소유권만 무효화한다. 장치별 갱신 번호와 코스 번호를 함께 올리면 공용 출구가 다른 발사기의 유효한 절단 기록까지 무시한다. 재활성화 시 같은 배선을 공유하는 장치에서 비활성 중 발생한 절단을 다시 가져온다. 코스가 실제로 재시작된 경우에는 최신 코스의 절단만 사용한다.
