# 아바타 교체와 지연된 기물 상태

인간대포의 발판 이동 승인에는 탑승 시점의 부활 번호가 필요하다. 부활 알림을 먼저 받고 처음 도착한 이전 발판 상태는 현재 아바타에 적용하지 않는다. 새 발판 상태가 부활 번호보다 먼저 도착하면 번호가 일치할 때까지 탑승과 도착 적용을 기다린다.

탈출로 입장 확정은 참가자에 대한 결정이다. 배치 재사용은 실제 아바타가 같을 때만 가능하다. 같은 소유자의 새 아바타는 확보한 입구 좌표와 지지면을 다시 검증한 뒤 배치한다. 이전과 같은 아바타면 이동을 반복하지 않는다.

외줄 구조 완료 메시지는 장부에서 본 아바타의 네트워크 객체 번호, 재시작 번호, 부활 번호가 현재와 같은 경우에만 적용한다. 탈출로 하층 초과 인원 복귀 응답도 보낸 로컬 아바타와 부활 번호에만 적용한다. 회차가 같아도 아바타 교체와 부활이 발생할 수 있다.

트램펄린 첫 반동에서 접촉 메시지와 소유자 좌표는 다른 순서로 올 수 있다. 같은 플레이어·회차·순번의 접촉을 재시도하고, 이미 받아들인 요청의 응답은 원래 접촉을 사용한다. 승강기가 반동을 구별할 때는 대포 좌석 번호 대신 현재 비행 구간을 시작시킨 기물을 본다. 탈출로 화염은 배치 대기를 실제 참가 슬롯으로 확인하며, 리스폰 좌표 샘플이 건너뛰어도 배치 유예 후에는 기존 위험 판정으로 돌아간다.
