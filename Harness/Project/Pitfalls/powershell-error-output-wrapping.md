# PowerShell 오류 출력 줄바꿈

## 언제 읽나

로컬에서는 통과한 격리 PowerShell 회귀가 Ubuntu CI에서 오류 문구 불일치로 실패할 때.

## 증상

workspace-flow의 `Update.*금지` 검사가 실패했다. 실제 명령은 금지 대상을 정상적으로 거부했지만, 출력에서 Update와 금지 사이가 줄바꿈됐다.

## 원인

PowerShell 오류 표시는 환경에 따라 줄을 나누고 ANSI 색상 코드를 포함한다. 캡처 배열을 줄바꿈으로 합친 문자열에서 정규식 `.`은 기본적으로 줄바꿈과 일치하지 않는다.

## 대처

예상 오류 정규식을 전체 캡처와 비교할 때 `(?s)`로 줄바꿈을 허용한다. 실패 종료 코드 조건과 실제 쓰기 없음 검사는 유지한다. 운영 금지 규칙이나 CI workflow를 완화하지 않는다.

## 확인 방법

- workspace-flow 격리 회귀에서 강제 줄바꿈·ANSI 예상 오류를 인정한다.
- 다른 오류 및 예상 문구를 출력한 정상 종료는 인정하지 않는다.
- 수정 제거 복사본에서 새 회귀가 실패하는지 확인한다. fixture 결과는 실제 공동 테스트나 Ubuntu CI 통과를 대신하지 않는다.
