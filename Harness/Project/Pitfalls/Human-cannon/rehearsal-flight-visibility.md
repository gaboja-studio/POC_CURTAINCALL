대기실 플레이 씬 두 개가 같은 구워진 오클루전 데이터를 쓴다. 인간대포 연습에서는 원래 링 장식이 숨겨지고 카메라가 지상 시야 구역 밖까지 올라간다. 연습 비행 중에만 로컬 카메라의 구워진 가림을 끄고, 비행 종료나 코스 정리 시 카메라의 원래 값을 복원한다.

연습실 벽의 WhiteFlickerLamps는 의도적인 조명 깜빡임이다. 인간대포 연습 중에는 깜빡임만 잠시 끄고 연습이 끝나면 복원한다. 실제 플레이 화면은 사용자 확인이 필요하다.
