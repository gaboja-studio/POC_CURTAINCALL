# 트램펄린 외형과 접촉 판정

## 언제 읽나
트램펄린 프레임·손잡이·별 장식을 교체하거나 반동 시작 높이/코너 판정이 달라졌을 때.

## 확인한 동작
HumanCannonTrampoline.ContactBounds는 활성 Renderer.localBounds를 장치 좌표로 합친다. 구형 더미는 TrampolineContact의 전체 AABB 판정을 유지한다. Task-083에서 사용자가 원형 본체와 손잡이의 실제 외곽을 선택하여 새 CC 모델은 usePropOutline=true와 TrampolineOutline을 쓴다. 원통 본체와 손잡이/연결봉 세 개에 몸통 swept contact를 검사하며 운반 회전도 따라간다. 빈 사각 코너는 반동하지 않는다. 플레이어 반경이 있어 중심점만 원 밖이라고 무조건 빗나가는 것은 아니다.

## 대처와 확인
Task-082 기준 Surface 상대 min=(-2.875,-.5,-2.4753408), max=(2.4753408,.15,2.4753408). 반동 높이는 Surface+max.y, 속도는 기존 설정을 유지한다. 새 모델 적용 도구는 외곽 판정을 활성화한다. 잡기 거리는 실제 손잡이 중심을 기준으로, 표시 손바닥은 손잡이 위쪽 .65m에 정렬한다. 별도 PhysX Collider 대신 이 커스텀 접촉이 실제 반동을 처리한다. 본체/손잡이 규격 변경 시 TrampolineOutline의 형상도 함께 갱신하고 중앙·테두리·손잡이·빈 코너·옆/아래 접근·빠른 이동/회전을 검사한다.
