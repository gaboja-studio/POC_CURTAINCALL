# 실제 모델의 절단 생성과 운반 충돌

`HumanCannonCarry`는 모든 레이어를 OverlapBox로 검사한다. `Ignore Raycast` 레이어만 지정한 사지는 운반 검사에서 제외되지 않는다. 평면 이동이 거절되면 단차 넘기기나 운반자 위치 복귀가 실행되어 트램펄린이 사지 위로 올라가거나 끼는 것처럼 보인다.

Legacy `LimbDismemberment.Launch`는 `DismemberedLimb`를 붙였지만 `HumanoidModel.BakePiece`는 이 표식을 빠뜨렸다. 완성한 두 관절 충돌체 계층의 루트에 활성화 전에 표식을 붙여야 한다. 활성화 시 사지 레이어, 공용 운반/지지면 제외, 나중에 생성·재활성화된 플레이어의 충돌 제외가 연결된다. 프로젝트 충돌 행렬의 트램펄린-사지 제외와 사지-일반 바닥 충돌은 그대로 사용한다.

표식이 이미 붙은 임의 상자로만 검사하면 실제 생성 누락을 놓친다. `HumanoidLimbCarryTests`는 저장된 Rabbit 모델의 실제 BakePiece 경로에서 양팔·양다리를 생성해 운반 스윕, 놓기 지지면, 후발 플레이어, 재활성화 및 분리 물리 씬에서 트램펄린 통과/일반 바닥 착지를 확인한다. 사용자 씬 물리 시뮬레이션이나 PlayMode는 실행하지 않는다.
