# 인간대포 재시작 응답 누락

이동 발판·일반 장애물·결승 톱은 재시작 뒤 현재 토큰이 포함된 응답까지 이전 상태를 거부한다. 최초 요청 당시 호스트가 씬 채널을 등록하기 전이면 이후 주기 스냅샷에 토큰이 없어 영구 대기할 수 있다. 대기 중 같은 토큰으로 다시 요청하고 현재 토큰 응답이나 연결 종료 뒤에는 반복을 멈춘다. EditMode의 `RestartSyncRetry` 검사는 누락, 연속 재시작, 연결 종료 조건을 다룬다.
