# 공연 종료 후 부활자의 재사망

## 언제 읽나

공연 종료 후 부활 로그가 있는데 대기실에서 계속 사망·관전 상태일 때.

## 원인

CampaignRun의 단계 변경은 InjuryRevival을 통해 즉시 사망자를 부활시킨다. SpaceLinkDirector의 씬 전환·대기실 배치는 그 뒤다. 부활은 위치를 옮기지 않으므로 옛 낙하 위치·불벽 접촉이 남아 있으면 옛 씬의 피해 판정이 다시 사망시킬 수 있다.

## 대처

관리형 인간대포의 CampaignPerformanceEntry 서버 가드는 출발점 확인뿐 아니라 현재 해당 공연 진행 중인지도 확인한다. 씬이 해제될 때까지 가드를 유지하고 기존 가드를 복원한다. 카메라만 강제로 정상화하거나 단독 연습의 피해 판정을 끄지 않는다.

## 확인 방법

PerformanceEntryJudgeTests의 부활 직후 피해·옛 씬 유지 회귀와 PerformanceLinkPlayTests의 실제 대기실 전환 회귀를 실행한다. 수정 제외 비교에서는 대기실 전환 뒤 Normal 대신 Fallen으로 실패하고, 수정 적용 시 같은 검사가 통과했다. 실제 LAN 호스트 1명에 상태·위치를 합성한 회귀이며 실제 참가자 공동 플레이 증거가 아니다.
