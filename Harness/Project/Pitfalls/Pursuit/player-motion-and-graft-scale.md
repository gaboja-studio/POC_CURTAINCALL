# 플레이어 동작과 표면 봉합

## 언제 읽나
`PursuitLocomotionImporter`, `PursuitSuturedLimbs` 또는 마네킹 크기를 바꿀 때.

## 대처
- 휴머노이드 동작은 실제 Avatar에서 평가하고 상완·전완·허벅지·정강이의 자식 방향으로 마네킹 리그에 옮긴다. 관절의 로컬 축은 서로 다르다.
- Legacy 변환은 휴머노이드 루트 이동을 자동 적용하지 않는다. BakeMesh로 최저 표면을 확인해 발과 사망 후 몸통을 바닥에 둔다.
- 원본 앉기 동작을 그대로 옮겼을 때 높이는 약 1.27m였다. 공통 앉기 높이와 중형 1.16배를 고려해 골반을 낮추고 다리 IK로 발을 유지한다. 애니메이션 전체 주기의 실제 메시 높이를 검사한다.
- 2026-11-16 사용자 피드백으로 실제 팔다리 이식 방식을 폐기했다. `sharedMesh`·정점·스키닝·재질 참조를 변경하지 않고 `PursuitGraftProjection`의 UV 전사 텍스처를 property block으로 적용한다. 선택 해제는 표면 레이어만 끈다.
- 원본 팔다리의 서로 떨어진 UV 섬 사이를 보간하면 손에 잘못된 색 띠가 생긴다. 임시 2D 베이크 데이터만 세분화하고 작은 영역마다 같은 원본 삼각형에서 샘플링한다. BVH로 근접 면을 찾는다. 캐릭터에 생성 메시·실 오브젝트를 붙이지 않는다.
- 봉합 실과 바늘 구멍은 미터 단위의 표면 색/높이로 표현한다. 텍스처 여백을 늘릴 때 봉합선 주변을 보호해야 실이 굵어지지 않는다. FBX 100배 스케일은 표면 거리 계산에 반영한다.
- 합성 순서는 원본 피부 → 선택 표면·봉합 → 때·마모 → 혈흔이다. 피 표시를 꺼도 봉합과 오염은 남아야 한다. `RefreshSurface`는 기존 property block을 읽고 수정해야 한다.
- 미리보기에서 같은 Editor tick에 여러 애니메이션을 렌더하면 GPU 스키닝 버퍼가 갱신되지 않을 수 있다. 검증 캡처는 `SampleAnimation` 후 `BakeMesh`로 평가된 포즈를 고정한다. 이는 캡처 전용이며 실제 캐릭터 메시를 바꾸지 않는다.
- 피격은 import된 renderer bounds 대신 현재 뼈 위치의 작은 범위들을 검사한다. 앉은 몸 위를 지나가는 톱날은 맞지 않아야 한다.

## 확인 방법
`PursuitUpgradeTests`, `PursuitGraftSurfaceTests`, 정면·측면·손 근접 렌더. 표면 테스트는 4개 캐릭터, 다른 부위로 전사, 메시 불변, 오염 보존, 피 숨김, 선택 해제를 검사한다. `PursuitUpgradeRuntimeTests`는 1.2m 통로, 자세별 피격, 오르기 중 낙하, 3/5회 사망, 10초 초기 위치 복귀를 검사한다.
