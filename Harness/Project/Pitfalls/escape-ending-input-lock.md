# 탈출 엔딩 입력 잠금

## 언제 읽나

호스트 연결 종료나 씬 전환 뒤 성공 엔딩 카메라·결과가 남고 캐릭터 입력이 돌아오지 않을 때.

## 원인과 대처

- 탈출 콘텐츠와 성공 엔딩 컴포넌트는 별도 오브젝트다. 콘텐츠가 먼저 비활성화되거나 캠페인이 초기화되면 엔딩 컴포넌트가 계속 살아 있을 수 있다.
- 씬 해제 전에 성공 상태나 콘텐츠 활성 조건이 사라지면 기존 정리 경로로 입력 잠금, 카메라, 결과를 해제한다. 확인 버튼을 눌러도 성공 상태와 콘텐츠가 계속 유효하면 전환 대기를 유지한다.

- 성공 엔딩 코루틴과 화면은 같은 콘텐츠 활성 조건으로 수명을 정한다. 명부가 비어도 결과 화면을 열어 로비 복귀를 제공한다. 게스트가 캠페인 전환보다 먼저 받거나 다른 일차의 결과를 받으면 그대로 고정하지 않고 현재 엔딩에서 재요청한다.
