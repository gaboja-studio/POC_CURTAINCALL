# 로비 복귀 시 환경 활성화와 출발 위치 경합

## 언제 읽나

SpaceLink 추가 로드 공간에서 허브로 돌아왔을 때 캐릭터가 지정된 출발 위치가 아닌 원점 옆이나 가구 위에 나타날 때.

## 증상

Task-052에서 첫 로비 진입은 정상이나 엔딩 복귀 후 0번 캐릭터가 (-4.5, 0, 0)에 놓였다. 지정된 출발 위치는 (-1.8, 0.05, 1.4)였다.

## 원인

- 로비 환경과 그 안의 PlayerSpawnPoints는 SpaceLinkHub의 hubUi에 포함되어 공간 전환 중 비활성화된다.
- LobbyRoom.Update가 SpaceLinkHub.Update보다 먼저 복귀를 감지하면 환경이 아직 꺼져 있다.
- PlayerSpawnPoints.GetPose는 활성 출발 위치가 없을 때 줄 간격 기반 기본 위치를 반환한다.

## 대처

복귀 감지 시 이동 예약만 하고 LateUpdate에서 위치를 적용한다. 현재 SpaceLinkHub는 Update에서 환경을 켜므로 이후에는 출발 위치를 찾을 수 있다. 활성화 단계를 바꿀 때에는 이 순서 보장을 다시 확인한다.

## 확인 방법

1. Start에서 LAN 방 생성 → 로비 출발 위치 확인.
2. 게임 시작 → 공간 진입 → 엔딩 로비 복귀 후 같은 출발 위치인지 확인.
3. 첫 진입뿐 아니라 같은 방 재시작·복귀까지 반복한다. 2026-10-16 도구 기반 1인 실행에서 수정 후 지정 위치·Normal 상태 확인, 실제 2인 검증은 별도.
