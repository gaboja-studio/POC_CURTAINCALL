# 행동 전환과 입력 초기화

목마 상태로 연습을 종료하거나, 메뉴 뒤 F가 누락되거나, 사지 조각 때문에 기립·운반이 막힐 때 읽는다.

- 대포 연습 종료는 살아 있는 참가자의 기물·목마 연결도 해제한다. 클라이언트가 종료 상태를 먼저 받았다면 연결 해제까지 기다린 뒤 Follow/Pilot의 임시 이동 소유권을 반환하고 복귀 잠금을 저장한다. Simulated=false를 그대로 복원값에 저장하거나 링크 해제보다 먼저 순간이동하면 복귀가 다시 동료 머리 위로 덮인다.
- CommonInteractionSelection.Forget은 Held·대상·목마 하차 대상을 함께 지운다. 현재 프레임은 소비된 것으로 유지하고 다음 새 제스처는 선택을 다시 한다. 메뉴 중에는 Selected가 호출되지 않을 수 있으므로 중립 프레임에 의존하지 않는다.
- InputAction.canceled는 물리 키 해제 외에 장치 초기화에서도 발생한다. 눌렀던 장치의 reset/disable/disconnect/remove 알림에서 대기 중 탭·홀드를 폐기한다. 실제 키 해제의 경과 시간은 기존 GameSettings 기준을 사용한다.
- PlayerMover.HasHeadroom은 DismemberedLimb를 제외한다. 이동에서 무시하는 사지 조각을 천장으로 처리하면 앉기·점프가 잠긴다. 실제 벽·천장 차단은 유지한다.
- 트램펄린 운반 sweep에서 사지를 제외하는 것만으로 실제 물리 접촉은 없어지지 않는다. 활성화와 매 FixedUpdate에서 본체·자식 충돌체에 IgnoreCollision을 적용한다. 내려놓음·새 조각·충돌체 재활성화도 포함하고 일반 바닥 충돌은 유지한다.
- 대포 Space 발사는 공통 Action 입력을 사용한다. ActionHeld까지 중립 확인에 포함해야 탑승 전부터 누른 키가 즉시 발사로 재사용되지 않는다. F 탭 발사·F 홀드 하차를 유지하고 동시 입력에서는 하차를 우선한다.

자동 검사는 임시 객체와 실제 코드 경로를 사용한다. 다른 PC 2·3·4인 플레이 통과를 의미하지 않는다. 검사 결과와 기존 전체 검사 실패는 Task-114의 Inventory/remaining-test-failures.md에 구분해 기록한다.

## 치료와 다른 이동의 동시 인계 — 수정 후 검사 기준

- 2026-11-13 DEV 1764a21c에서 치료 Working 중 대포 연습 시작 조건이 허용됨을 확인했다. 리허설 이동 뒤에도 의료 입력 잠금이 남고, 치료 종료가 위치를 승강기 앞으로 덮는다. placed 목록은 유지되어 연습 시작 위치를 다시 복구하지 않는다. 치료 내부가 리허설 returnPose로 저장되는 점도 확인했다.
- 의료 입장 요청 시 트램펄린 운반 소유가 있으면 Enter는 수락하며 목마만 해제한다. 운반 추적이 순간이동 경로의 벽을 만나면 이전 안전 위치로 밀어내고 의료 잠금은 유지한다. 공통 실제 Mesh+임시 측벽에서 재현했으며 실제 지연 패킷 타이밍/작성된 씬 전체 재현은 미검증이다.
- 기능별 치료19개·리허설70개 검사는 통과했다. 새 이동을 추가하거나 입력 잠금을 수정할 때 두 기능이 동시에 점유하는 상태를 검사해야 하며, 단독 검사 통과를 동시 전환 보장으로 해석하지 않는다. 재현 근거는 Task-114의 Inventory/post353-transition-audit.md.
- 수정 후 치료 Working/Exiting 동안 양쪽 리허설 시작을 막고, 리허설/투표 뒤 늦은 의료 입장도 거부한다. 참가자는 의료 상태가 끝난 뒤 복귀점 저장·배치·종료 이동을 한다. 예약만 해둔 상태는 이동을 막지 않는다.
- 의료 입장은 호스트의 운반·목마 해제 후 진행하고 참가자는 소유 해제 수신을 기다린다. 신규 운반/목마 요청은 의료 점유를 확인한다. 의료를 PiggybackSystem.UsingDevice에 넣으면 Follow가 원래 이동 소유권을 복원하지 않으므로 새 연결의 자격 판정에만 적용한다.
- 새17사례 포함 치료36/36·공통618/618 통과. 서로 다른 PC의 실기 결과로 해석하지 않는다.

## PR355 이후 리허설 입장 인계 — 수정 후 기준

- 대포 재연습 배치 전 트램펄린 Grab을 수락하면 LocalTick은 Held 해제를 기다리고, placementBlock은 Drop 입력까지 막는다. 실제 공통 Mesh와 임시 코스에서 정상3회·2/3/4인 목록×절단0~3개 대표12조합 재현. 좌석의 IsPracticeReady 검사가 트램펄린에는 없다. 실제 패킷 지연 빈도·작성된 맵 위치는 미검증.
- 밤의 수면 중 외줄 재연습 제안이 허용된다. ActivateLocal/Relocate는 수면 준비를 해제하지 않아 BedRestView 입력 잠금·시점과 NetworkBedPose의 침대 위치/누운 외형이 남는다(3회 재현). F/Esc 기상으로 풀릴 수 있다. 대포 EnsureCourse에는 SetReady(false)가 있으므로 동일하게 취급하지 않는다.
- 수정 후 트램펄린 CanGrab도 기존 대포 IsPracticeReady(actor)를 확인한다. 배치 전과 종료 중에는 호스트 요청을 거부하고 정상 배치 후에는 잡기·놓기를 허용한다. 수치·씬별 예외는 추가하지 않는다.
- 외줄/대포 시작은 BedRestView.EndForRehearsal로 준비·시점·입력·침대 선택을 정리한다. NetworkBedPose는 리허설 중 늦은 침대 상태를 적용하지 않는다. 침대와 호스트의 늦은 Ready 요청은 CampaignRun.CanSleep을 공유하고 종료 후 정상 수면을 허용한다.
- NightBed에서 Ready 승인 뒤 시점을 만들 때 마지막 수면자가 즉시 Dawn으로 넘어가 localReady=false가 되는 경우도 처리해야 한다. 기존 밤→아침 시점을 누락시키지 않는다.
- 관련 기존237개 통과와 새 결함 재현은 양립한다. 신규68검사는 2/3/4인×생존 사지 마스크15종과 양쪽 리허설/수면/원격 외형/밤 전환을 포함한다. 실제 다른 PC 플레이 보장은 아니다.
