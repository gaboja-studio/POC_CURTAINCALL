# 이동·부활 모션 인계

## 언제 읽나
- 발판 위 제자리 걷기, 목마 윗사람 점프 중 대기 자세, 복귀 후 이전 착지 자세가 남을 때.
- 원격 지상 캐릭터가 낙하 자세이거나, Animator 재바인딩 후 운반 자세가 사라질 때.

## 확인한 원인과 처리
- PlayerMover의 외부 이동·배치 인계에서는 IsMoving도 정리한다.
- 대포 착지 모션은 표시용이다. 새로운 일반 점프·이동·앉기가 시작되면 공통 이동 모션으로 넘긴다.
- 목마 윗사람 제자리 점프는 PiggybackFollow가 움직인다. 그 상태도 표현에 전달해야 한다.
- 원격 목마의 두 Transform은 같은 시점으로 보간되지 않는다. 위 사람 위치에서 아래 사람 머리 높이를 뺀 값을 점프 높이로 쓰면 정지 상태에도 계속 뛰는 것처럼 보인다. 소유자의 실제 hopHeight를 공유하고, 연결 중에는 그 값과 맨 아래 사람의 공유 점프 상태를 사용한다.
- 대포·봉 비행을 호스트에서만 제거하면 원격 CircusMotion에 비행이 남는다. 바닥 아래 사망 경로에서도 LandingMessage를 보내고 Revived에서도 양쪽 비행 레지스트리를 비운다.
- 소구간 완료/재연습 종료는 살아 있는 플레이어도 순간이동시킨다. 소유자 pilot만 비우면 호스트·관전자 비행이 남으므로 배치 전에 공유 봉/대포/목마/매달림을 기존 해제 경로로 정리한다.
- 낮은 바닥을 줄 기준 추락 깊이만으로 판정하면 접지 후에도 자연 추락을 다시 요청하고 원격에 낙하 자세가 반복된다. 실제 지지면에서는 재요청하지 않는다. 초기 교육의 바닥 복귀는 착지 이벤트를 놓친 경우에도 기존 GameSettings 설정/배치 승인에 따라 재확인한다.
- 월드 Y 즉사는 소유자의 현재 좌표와 재시작/부활 번호로 요청한다. 원격 부활 직후 호스트에 남아 있는 옛 아래쪽 Transform만 보고 다시 죽이지 않는다.
- 같은 목마의 위 사람은 균형 기울기로 아래 사람의 몸 높이 안에 들어온다. 앞뒤 플레이어 충돌에서 같은 사슬을 제외하지 않으면 한쪽 방향만 막힐 수 있다. 일반 바닥/외줄 모두 같은 판별을 쓴다.
- 원격 플레이어의 비시뮬레이션 PlayerMover에는 옛 공중 상태가 남을 수 있다. 소유자가 전송한 CurrentJump를 사용한다.
- Restarted뿐 아니라 Revived에서도 모션·정렬·샘플을 초기화한다. 낮은 지연에서는 Fallen 프레임이 생략될 수 있다.
- 운반 레이어 캐시와 실제 Animator 상태를 함께 확인한다. Rebind는 상태만 초기화한다.
- 치료 승강기처럼 목마 소유자를 순간이동시키기 전에는 호스트 연결과 승객의 분리 순간 위치를 먼저 공유한다. 링크만 지우면 늦게 실행되는 Follow가 이미 옮겨진 운반자 앞으로 승객을 재배치할 수 있다. 서비스 상태가 먼저 와도 연결 해제까지 입장을 기다리고, 로컬 Follow를 정리한 뒤 이동한다.
- 두 다리 손실 시 정지 Crawl을 공중까지 재사용하지 않는다. 기존 Cut2/3 상승·낙하·착지 모션을 연결한다.
- 외줄 구조에 서 있는 ItemPull을 쓰면 팔 길이 밖의 낮은 접점에 도달하지 못한다. 기존 RopePull/부상별 변형과 양손 보정을 사용한다. 구조 시간·거리는 GameSettings 그대로다.
- 이동 속도는 BaseGameSettings의 표현용 기준 속도로 나누어 기본 레이어의 LocomotionRate에 전달한다. Animator 전체 속도를 바꾸면 상체 상호작용까지 느려진다.
- 목마 연결 해제 정보가 늦어도 추락·로컬 분리 점프는 위 사람 자신의 점프 상태를 표시한다. 연결을 유지하는 점프만 아래 사람과 제자리 점프 높이를 따른다.
- 위치를 즉시 옮길 때 기존 공중·착지·정렬 상태도 비운다. 추락 후 복귀를 새 위치에서 일어난 착지로 표시하지 않는다.
- 정지한 Crawl/ItemCrawl은 기본 레이어 속도만 0으로 둔다. 상체 상호작용 레이어의 시간은 계속 흐른다.
- 침대는 현재 슬롯의 Animator만 정지·복구한다. 모델 교체 뒤 새 Animator를 추적하고, 분리된 래그돌의 Animator는 깨우지 않는다.
- 도구의 이동 잠금으로 바닥과 목마 위 Space를 판정한다. 다음 상호작용 잠금은 F 탭을 막는다. 운반·장치 인계와 체크포인트 이동에서는 이전 도구 동작·지연 타격을 취소한다.
- 운반 장치를 놓는 F 홀드는 일반 바닥과 외줄 조작에서 같은 Pilot으로 전달한다. 지연된 트램펄린 잡기는 장치 이동·줄 매달림·목마 위층 상태를 다시 확인한다. 추락 후 복귀 전 운반을 해제하고 기존 사망 드롭 경로를 사용한다.
- 손을 맡은 기물이 바뀌면 손 도구와 UV 발광을 함께 중지한다. 인벤토리 소지와 자동 발동 장비는 기존 장부에서 유지한다.
- 목마 추락 후 실제 착지는 분리된 사람의 지지면을 본다. 해제 스냅샷이나 착지 ACK가 늦어도 아래 사람의 표면·균형·F 해제를 적용하지 않는다. 잠깐의 바닥 조작을 거쳐 외줄에 착지하면 추락 전 방향을 되돌린다. 속도가 없는 진입에서 눌린 S만으로 방향을 뒤집지 않는다.
- 목마 링크가 남아 있어도 사망·추락·기물 인계가 확인된 층 위로는 위치를 맞추지 않는다. 아래층 전체가 유효해야 착지 제외·목마 입력·자세를 적용한다. 생존 부상은 연결을 유지하고 점프 허용과 높이를 공통 부상 설정으로 계산한다.
- 순간이동과 복귀에서는 이전 외줄 그립, 대포 좌석, 발판 탑승 기록을 정리한다. 비워진 이동 발판은 기존 이동 일정대로 움직인다.
- 운송 발판의 대기 인원은 발판 위의 유효한 목마 연결을 따라 센다. 위층 제자리 점프는 링크를 유지하므로 높이 범위를 잠시 벗어나도 인원은 그대로다. 대포·치료 승강기는 실제 진입 조건을 충족한 대상에 짧은 F를 주고, 호스트가 수락할 때 연결을 풀며 남은 사람의 위치를 보존한다.

## 봉·외줄 진입과 추락 순서 (11/11 녹화 후속)
- 플랫폼은 S로 걸어도 모델이 실제 이동 쪽으로 돌아본다. 그 방향을 외줄의 W 기준으로 다시 잡으면 진입 즉시 S가 반전된다. 마지막 지상 속도와 입력 부호로 기준을 잡고, 모델 회전 중간값에 의존하지 않는다. 줄 위에서는 T만 명시적으로 기준을 뒤집는다.
- 목마 연쇄 추락은 모든 부모 연결을 끊은 뒤 매달림/낙하 콜백을 호출한다. 소유자 낙하 RPC가 해제 스냅샷보다 먼저 올 수 있으므로 Follow도 해제 수신 전까지 재부착을 억제한다. 중복 자연 추락 요청으로 수직 속도를 다시0으로 만들지 않는다.
- 호스트가 착지를 처리해도 참가자 PC의 임시 추락 표시는 자동으로 지워지지 않는다. 대기 중인 착지와 번호가 맞는 ACK에서만 임시 표시를 해제한다. 다음 점프 최고점은 유지하고 재전송된 옛 ACK는 무시한다. 착지 후 같은 행동을 한 번 더 해야 이 잔류를 잡을 수 있다.
- 착지한 줄의 실제 지지가 확인되면 지연된 호스트 추락 플래그만으로 외줄 조작을 차단하지 않는다. 줄의 좁은 윗모서리 접촉은 공통 착지 검사도 받아야 한다.
- 공통 긴 F는 초기 속도0으로 손을 놓는다. Space만 모은 반동으로 도약한다. 호스트가 위치/속도를 기존 Release 패킷에 싣고 모든 참가자가 같은 값을 사용한다.
- 외줄 지지 폭은 GameSettings의 MatchVisualSupportWidth를 통해 보이는 굵기를 사용한다. 자동 생성 줄은 RopeThickness, 배치된 줄은 자체 메시 폭(없으면 원본 콜라이더 폭). 길이·막힌 구간은 유지한다.

## 검증 범위
- 발판·리프트의 복귀 응답 대기는 그 장치의 입력만 막아야 한다. 확정된 대포 비행의 WASD까지 먼저 차단하면 공통 공중 조작 수치가 정상이어도 보정이0이 된다. HumanCannonPilot은 봉 입력 뒤 비행 입력을 우선 처리하고, 바닥/운반 입력만 RouteResetBarrier를 거친다.
- 11/11 오후 추가 수정은 코드 경로·컴파일 확인이다. 사용자가 테스트를 맡기로 했으므로 앞선 플레이 통과 기록을 이 수정의 4인 검증으로 확대하지 않는다.
- 최초 6개 재현 검사는 수정 전 실패·수정 후 통과. 원격 잔류 상태는 합성 수신 경계 검사다.
- 네 캐릭터 × 생존 부상 4단계의 실제 걷기·일반 점프·착지와 부상 유지 검사. 새 전용 애니메이션 제작이나 모든 접촉 품질 보증과 구분한다.
- 구조하는 쪽/받는 쪽 손 간격은 부상0~3단계에서 검사한다. 외팔은 공통 잡기 거리가 짧으므로 검사 준비 위치도 그 거리 안에 둔다.

- 목마 탑승자의 지상 자세 갱신은 꺼진다. 공통 기립 공간을 확인해 앉은 상태의 점프를 차단한다. 트램펄린을 든 상태에서는 외줄 조작을 켜지 않는다. 실제 줄 지지나 그립이 확인되면 호스트가 장치를 놓고 소유 상태를 공유한다.
- 파괴된 UI 요청자는 공통 입력 잠금에서 제거하고 마지막 잠금이면 기존 키 놓기 대기를 거친다. 구조 동작은 새 장치의 소유가 확정되면 중단한다.
