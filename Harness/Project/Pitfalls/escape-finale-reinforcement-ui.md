# 탈출 결승 추격자 안내

선두를 복제하면 붙어 있던 런타임 경고 오브젝트도 복제된다. 각 증원은 기존 경고를 정리한 뒤 자기 상태에서 바닥 경고를 생성한다.

출구는 배선과 전체 추격자 제압을 함께 요구한다. 예정된 증원은 문 잠금에 포함되지만, 첫 상태를 받기 전에는 조준 대상으로 안내하지 않는다. 목표 카드는 문이 닫힌 상태에서도 현재 전투와 배선 완료에 맞춰 갱신한다.

증원은 선두의 현재 리그 포즈나 절단 렌더러를 그대로 쓰지 않는다. 기본 포즈와 온전한 부위 상태로 복구한 뒤 활성화한다. 도약 예고·도약 중에는 톱날이 맞지 않으므로 착지 대기를 표시하고, 사망 상태가 소유권 해제보다 먼저 도착하면 조준점을 즉시 숨긴다.

결승의 잘린 고렘 파편은 별도 표식이 있으므로 절단기 지지면 검사에서 제외한다. 발사형 절단기 내려놓기는 운반자의 접지와 장치 위치의 지지를 따로 확인한다. 아바타 초기화 중 컨트롤러 참조가 없으면 상호작용을 보류한다.
