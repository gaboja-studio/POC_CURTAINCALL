# 탈출로 협동 구간 상태

추격 시계는 슬롯을 받고 배치가 끝난 참가자만 시작한다. 새 캠페인 세대에서 이전 시작 시각은 추격에 쓰지 않는다.

반출교 활성화는 전개를 다시 시작하는 이벤트가 아니다. 마지막 상태와 서버 시각으로 현재 전개도를 계산한다.

협동 도착은 캡슐이 정상 발판 가장자리에 실제로 지지되는 경우도 센다. 하층 담당자 선택과 게이트는 잘린 추격자 파편을 바닥으로 처리하지 않는다.

- 외줄 모서리에서 몸통이 지지되는 착지와 중심점이 상판 사각형 안에 있는지를 따로 판정하면, 착지 성공 뒤 추격 동선만 활성화되지 않는다. 대포에서 첫 외줄이나 상단 외줄로 넘어갈 때 같은 물리 지지 콜라이더를 사용한다.
- 일반 바닥, 외줄, 기립 검사는 실제 몸통 크기와 충돌 무시 관계를 반영한다. 합류실은 현재 씬의 가까운 바닥만, 트램펄린 복구는 생존자가 손을 뻗을 높이의 지지면만 사용한다.
