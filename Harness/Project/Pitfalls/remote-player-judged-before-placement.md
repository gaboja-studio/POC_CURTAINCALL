# 원격 플레이어 배치 전 호스트 판정

## 언제 읽나

게임 흐름으로 공연 씬에 들어갔을 때 호스트는 살아 있고 참가자만 시작부터 사망·실격일 때. 새 공연 씬에 위치 기반 호스트 판정(낙하선·영역 사망 등)을 추가할 때.

## 증상

2026-10-17 실제 2인: 줄타기 → 대기실 → 백스테이지 → 인간 대포에서 P2만 시작부터 Fallen, 맵 아래로 계속 낙하. 1인 LAN 자동 검사에서는 재현되지 않았다.

## 원인

- 중간 공간(더미)에는 바닥이 없어 몸이 계속 떨어진다.
- 출발점 이동은 소유자가 한다. 호스트 자신은 같은 프레임에 배치되지만 원격 소유자의 순간이동은 네트워크로 늦게 온다.
- 그 사이 HumanCannonRouteSystem이 호스트에 남은 원격의 옛 위치(-10m 아래)를 보고 ServerKill했다.

## 대처

연결 공연 Entry가 호스트에서 출발점 확인 전 사망을 거절한다(CampaignPerformanceEntry, 줄타기는 CampaignTightropeAdapter의 출발점 확인 후 시작). 새 공연을 연결할 때도 같은 대기 경계를 유지하고, 판정 코드에서 "씬 로드 = 모두 배치됨"으로 가정하지 않는다.

## 확인 방법

1. `RevivalTests/PerformanceEntryJudgeTests` PlayMode 실행(1인 LAN 합성).
2. 실제 2인으로 중간 공간을 거쳐 해당 공연에 들어가 참가자 생존·출발점을 확인한다. 1인 검사로 대체하지 않는다.
