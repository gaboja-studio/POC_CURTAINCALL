# 거대 화염 재사용

탈출로의 FX_Flame_Thrower_01을 확대하거나 새 피해 범위에 맞출 때 읽는다.

- 원본 ShapeModule의 randomDirectionAmount=1과 활성 limitVelocityOverLifetime은 분사 방향/도달 거리를 바꾼다. 시작 속도×수명만 바꾸면 실제 불꽃이 반대편까지 닿지 않는다. A 거대 화염 인스턴스는 무작위/구면 방향0,속도 제한·중력0으로 정규화한다.
- 전체 구역이 점화와 동시에 위험하면 최초 한 수명을 미리 시뮬레이션한 뒤 재생해 반대편에 불이 보이기 전 피격되는 문제를 막는다. 비활성 상태는 emission=false/playOnAwake=false로 저장한다.
- 원본 트램폴린을 두 개 만들면 singleton/반동이 충돌한다. A 휴대 톱은 별도 장치로 만들고 IHumanCannonCarry의 조작/카메라/자세만 공유한다. 손잡이 수평 오프셋과 실제 배선 앞 운반 충돌 여유를 확인한다.
- 발사 톱날은 날 평면 안으로 날아가야 한다. 구체 근접만으로 절단하면 옆 전선도 잘리므로 얇은 원판의 연속 궤적과 배선 곡선을 교차 검사한다. 배선의 절단 상태/절단점은 운반자 소유권과 별개 코스 세대로 유지해 놓기/다시 잡기로 복구되지 않게 한다.
- 현재 배치/설정은 [화염 추격과 출구](../../../Tasks/Active/Task-20261027-073-exit-route-space-design/a-fire-pursuit-and-exit.md). 실제 다인 속도·VFX 비용은 정적 검사로 확정하지 않는다.
