# 착지대와 장식 받침의 중복 면

## 언제 읽나
탈출로 바닥 자글거림, 장식 받침 삭제, 정적 메시 최적화를 수정할 때.

- `HumanCannonLandingZone`이 붙은 바닥도 정적 렌더 표면이다. 수정 가능 대상을 좁히는 필터를 읽기 전용 검사 대상 필터로 재사용하면 실제 겹침을 놓친다.
- 이번 사례는 `03 conveyor eastern decision apron`과 장식 받침의 상단 4.8㎡ 중복이었다. 같은 이름이 아닌 발판/계단/설비 덮개에도 같은 문제가 있었다.
- 이미 가려진 면을 제거한 씬에서 장식을 지우면 이웃 벽에 구멍이 생길 수 있다. 삭제 부피에 해당하는 원래 벽면을 복원하고 실제 메시/앞뒤 시야를 검사한다.
- 움직이거나 사라지는 기물을 영구 차폐물로 사용하지 않는다. Renderer 메시만 수정해도 Collider나 동적 참조, 정적 검사의 렌더 경계에 영향이 없는지 비교한다.
- 읽기 비활성 메시도 `UnityEditor.MeshUtility.AcquireReadOnlyMeshData`로 검사한다. 검사 목적으로 import 설정을 바꾸지 않는다. LOD 대체 모델과 내부 접합 후보는 시각 오류 확정과 구분한다.
- `EscapeLandingSurfaceAudit`와 `LandingSurfaceRegressionTests`는 실제 착지대의 중복 상단 면을 이름과 관계없이 검사한다. 이 검사는 사선 전체 표면/모든 카메라/실제 플레이 검증을 대신하지 않는다.
