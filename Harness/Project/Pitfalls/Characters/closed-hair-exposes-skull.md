# 닫힌 머리인데 피부가 구멍처럼 보일 때

## 언제 읽나
캐릭터의 정면은 괜찮지만 측면/정수리/후방에서 머리카락·머리띠·모자가 떠 있거나 피부가 관통할 때.

## 관찰
분홍 소녀는 머리카락 연결성분1·열린 경계0이었지만 앞머리 밑면이 피부에서 떨어져 있었고 머리띠가 가로질렀다. 모자 조각과 리본의 닫힌 판 메시도 깊이/연결이 부족해 측면에서 떠 보였다. 연속 형상으로 교체한 뒤에도 실제 Unity 후면에서 피부가 머리카락보다 약7mm 바깥으로 나와 작은 흰 틈이 남았다.

## 대처
- 편집본/라이브 세션을 보존하고 Unity 실제 카메라의 상부 정면·정측면·정수리·상부 후면·정후면을 동일 각도로 전후 비교한다.
- 앞머리 밑면과 모자 안쪽을 실제 머리/두피 표면에 맞춘다. 머리띠는 앞머리 앞을 직선으로 가로지르게 두지 않는다.
- 정수리/후두부는 머리와 머리카락의 광선 교차 좌표를 비교한다. 닫힌 경계 검사만으로 덮임을 보장할 수 없다. 수정 후35개 후방 표본은 최소9.63mm 덮임이었다.
- 머리카락 뒤쪽을 옮길 때 모자/리본의 접촉 부위도 같은 변형으로 유지한다. 작은 리본도 매듭·접힌 옆면·뒷면을 갖는 닫힌 볼륨으로 만든다.
- 제작본의 종이 면 법선이 내보내기의 높이별 음영 규칙에 덮이지 않도록 보닛/리본 ART 태그를 별도로 처리한다.
- 사선 렌더 확인 후 기존9절단 메시를 재생성하고 본/재질/기능 회귀를 확인한다. 자동 검사는 사람의 최종 미술 승인을 대신하지 않는다.
