# 겹치마가 절단 후 뒤집히거나 혈흔이 조각날 때

## 증상과 원인
- 기존 토끼 코트의 높이 반전 접기를 겹치마에 재사용하면 층이 뒤집힌다. 사라진 허벅지 본에 옷을 고정하면 해당 본의 킥에 자락이 수평으로 들린다. 절단 단면 gap0과 유한 좌표 검사는 통과한다.
- 메시 루프 번호로 UV를 임의 배치하면 CLEAN에서는 변화가 약하지만 LIGHT/HEAVY의 혈흔 무늬가 삼각형마다 끊겨 찢어진 표면처럼 보인다.

## 대처와 확인
- 초기 단조 높이 압축도 사용자가 치마까지 잘리는 것으로 지적해 제거했다. 현재는 **다리만 절단하고 치마/프릴은 원래 위치·길이·면 수를 유지**한다. 절단된 쪽의 Hips 고정은 유지해 사라진 허벅지의 킥을 차단한다.
- 각 치마 패널 안에서 국소 방향과 높이에 따른 연속 UV를 부여한다. 봉제 패치 경계의 별도 UV와 임의 삼각형 경계는 구분한다.
- 실제 프레임이 진행하는0/1/3부상 렌더를 확인한다. CLEAN만 보거나 Blender의 양면 표시에만 의존하지 않는다.
- 확인 파일: private PinkGirl/Source~의 export.py, verify-intact-skirt.py, skirt-continuous-uv.py, skirt-intact-geometry-report.json. 모든 몸체의 치마5,788정점/10,608삼각형과 원래 좌표, 분리사지의 치마0점을 검증한다.300포즈/16단면 검사와 실제 외형 검토는 별개다.
