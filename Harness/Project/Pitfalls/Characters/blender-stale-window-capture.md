# Blender 창 캡처가 갱신되지 않을 때

## 언제 읽나
Windows Blender에서 MCP의 실제 데이터/뷰와 Computer Use 창 캡처가 서로 다른 모델을 보여줄 때.

## 관찰
Blender5.2.3/addon1.8에서 새 분홍 소녀 씬이 활성인데 창 캡처는 이전 삐에로 또는 흰 화면을 반환했다. 제목/포커스는 갱신됐으며 새 창, 복원/최대화, redraw, 파일 재열기로도 GPU 화면 회복은 확인하지 못했다. 드라이버 원인은 확정하지 않았다.

2026-10-30 후속 사선 수정에서는 현재 분홍 모델, 선택 정점, 편집/이동 모달이 실제로 갱신됐다. 관찰된 창을 최대화하고 native G Y 6mm로 머리띠294정점을 조정했다. 이전 문제의 일반 해결책으로 단정하지 않고 매번 현재 모델·모달과 일치하는지 확인한다.

## 대처
- 오래된 캡처 좌표를 현재 메시 위치로 간주해 드래그하지 않는다.
- MCP로 실제 활성 씬/객체/편집 정점 선택을 확인한 뒤, Computer Use에서 관찰된 Blender 포커스에 키보드 조작을 한 단계씩 적용할 수 있다.
- G 모달의 존재, 축 제한 후 수치 입력, 확인 전후 실제 bmesh 정점 좌표를 MCP로 대조한다. 이 작업에서는 꼭대기 Z+25mm와 비례 편집 양갈래 X+25mm가 실제 적용됐다.
- 외형 확인에는 정상 갱신되는 MCP look과 Unity 카메라를 쓰고, Computer Use 캡처가 복구됐다고 보고하지 않는다. 앱 상태/선택을 확인할 수 없으면 입력하지 않는다.
- 분홍 소녀 `Source~/manual-refinements.json`에 실제 before/after를 보관했다. 전후 이미지/수치 증거와 최종 미술 승인은 별개다.
