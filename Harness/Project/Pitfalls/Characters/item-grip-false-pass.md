## 기물 쥐기 검사의 거짓 합격 (Task-088)
- 손잡이 기준점을 Palm()에 붙이고 두 점의 거리가 0인지 검사하면 배치 코드 자체만 재확인한다. 실제 손바닥 관통과 손가락 감싸기는 검사하지 못한다. 사용자 플레이 화면에서 관통이 발견되었다.
- Blender FBX 프리팹 루트의 축 변환을 Attach의 SetPositionAndRotation으로 덮어쓰면 모델의 실제 손잡이 축과 코드의 가정이 달라진다. Identity 루트 아래에 원본 FBX를 자식으로 넣어 변환을 보존한다. UV 손잡이의 Unity 좌표는 (-.125,.14,0)이다.
- 아이템 실측 두께, 스키닝된 손 메시의 손바닥/손가락과 실제 손잡이 축의 간격, 두 방향 확대 이미지와 실제 Player를 함께 확인한다. 원통 표면의 삼각형 표본 검사는 연속 면 전체의 무충돌 보장이 아니다. 단일 머리핀/열쇠는 손잡이 부분만 원통 검사하며 장식부의 무충돌까지 보장하지 않는다.
- 부상별 몸체와 네 캐릭터의 손가락 길이·두께가 달라 고정 굴곡각만으로 같은 손잡이를 감싸지 못한다. 기물 소지 중 손가락 길이에 맞춰 접촉 포즈를 보정하고, 해제 시 Animator 포즈로 돌아가야 한다.

- 정지 전신 포즈와 이동 중 오른팔 레이어가 같은 이름이어도 캐시 키에 레이어를 포함해야 한다. 다리 없는 이동에는 오른팔을 고정하는 Hold 레이어 대신 오른팔 추진 전신 클립을 쓴다.
- 에디터 비포커스 상태의 가상 입력은 IgnoreFocus와 AllDeviceInputAlwaysGoesToGameView 임시 설정이 필요하다. InputSystem 설정 setter는 기존 설정의 flags가 HideAndDontSave이면 즉시 파괴한다(InputManager.cs). 복제 전에 기존 flags를 보관하고 DontSave로 바꾼 후, 종료 때 기존 설정과 flags를 복구한다. 결과는 정리 코드보다 먼저 저장한다.
