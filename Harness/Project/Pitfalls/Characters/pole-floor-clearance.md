# 낮은 유지봉의 발 여유

- HumanCannonPole.HangingPosition은 실제 메시의 발바닥이 아니다. HumanoidPlayerPresentation.ApplyHangPose가 손바닥을 봉에 맞추면서 모델을 내려 실제 발이 논리 발보다 약 .46m 낮아졌다.
- 바닥과 논리 발 높이가 같다는 검사만으로 합격시키지 않는다. 실제 Rabbit Hanging의 여러 위상에서 BakeMesh한 발 정점과 바닥 높이, 손바닥 접점 오차를 함께 측정한다.
- 사용자 최종 선택은 A06 바닥-.2m/봉+.45m다. 천장 고정점은 유지하고 케이블을 다시 맞춘다. 공통 캐릭터 자세/부상 규칙 변경은 하지 않았다.
- 수정 후 발 메시 여유 .193~.203m, 손 접점 오차 .0014m 이하. 부상0~3단계의 낮은 몸통 중심/점프 높이·손 거리 감소·벽 가림도 확인한다. 에디터 표본은 실제 Play/다인 검증과 구분한다.
