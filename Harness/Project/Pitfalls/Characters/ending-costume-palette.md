# 엔딩 소품의 플레이어 바리에이션 보존

## 언제 읽나

플레이어 메시를 정적인 엔딩 머리·의상 소품으로 만들거나 기존 캐릭터에 오염 재질을 추가할 때.

## 원인과 처리

- `RabbitSurfaceStates.SetVariant`는 캐릭터별 Paper 셰이더 재질과 `_VariantColor`, `_VariantPattern`을 적용한다. 곰·삐에로·소녀는 UV 영역별 머리카락·모자·얼굴 색도 셰이더에서 바꾼다. 원본 텍스처를 일반 Lit에 붙이는 것만으로 실제 플레이어 모습이 복원되지 않는다.
- `HumanoidModel.SetColor`의 `PlayerTintMaterialSlots`와 카탈로그 의상 팔레트는 별개다. 둘 다 원본과 동일하게 적용한다.
- 실패 엔딩 빌더는 원본 셰이더의 색·무늬 코드를 보존한 파생 셰이더에 `FailureCostumeWear.hlsl`을 덧붙인다. 원본 메시/아틀라스/캐릭터 재질은 변경하지 않는다.
- 빌더의 예상 삽입 지점이 없어지면 예외로 중단한다. 원본 셰이더가 바뀌면 새 코드를 확인하고 다시 생성한다.

## 확인

`verify-ending-appearance.cs`는 원본 프리팹의 실제 SetVariant/SetColor와 엔딩 소품을 비교한다. 모델 4종 × 의상 4개, 머리·팔다리 160개 재질 표면의 아틀라스·색·무늬 일치 및 셰이더 오류를 확인했다. 4종 배치 캡처는 합성 명부 미술 검증이며 실제 4인 접속 검증과 구분한다.

필라멘트의 `_EmissionColor` 값만으로 실제 발광을 판단하지 않는다. Task-130의 URP Lit 재질은 발광 키워드가 꺼져 주변 조명에 의존했다. 전용 발광 셰이더로 변경하고 필라멘트·유리·실제 Light 밝기를 같은 Flicker 값으로 구동했다. 광원의 위치/아래 방향과 20초간 밝기 동기화를 실제 Play에서 별도로 검사한다.
