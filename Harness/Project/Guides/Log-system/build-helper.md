# 빌드 도우미로 Windows 게임 파일 만들기

Unity 메뉴를 여러 번 오가지 않고, 창 하나에서 버전·로그·설문·개발자/라이브를 골라 Windows 빌드를 만듭니다.
프로젝트 폴더의 **`build-helper.vbs`를 더블클릭**하면 열립니다. PowerShell 7이 없으면 설치 안내가 나옵니다.

## 순서

1. **게임 버전**: 현재 프로젝트 버전이 미리 적혀 있습니다. 필요하면 `0.2.2`처럼 바꿉니다.
2. **빌드 종류**
   - **라이브(LIVE)**: 일반 플레이어 배포용입니다. Development Build와 Dev Mode가 모두 꺼집니다.
   - **개발자(TEST)**: 검증용입니다. Development Build가 켜지고, 실행만 하면 **Dev Mode가 항상 켜집니다**. `-devmode` 바로가기는 필요 없습니다.
3. **로그 수집**, **설문 사용**을 각각 체크합니다. 로그의 TEST/LIVE 구분은 빌드 종류에 따라 정해집니다.
4. 설문을 쓰면 **[설문 등록...]**을 누릅니다. Unity의 **CurtainCall → 로그·설문 설정**과 같은 항목이 나옵니다.
   - 밤 정비 설문: 몇 일차 밤에 열지 정합니다. 게임 종료 설문: 런을 플레이한 뒤 나가기·방장 종료·연결 끊김 때 열립니다.
   - **대상 버전**에는 `0.2.2`(한 버전), `0.2.x`(패치 전체), `*`(전체) 중 하나를 씁니다.
   - Google Forms에서 연결 코드 질문에 `CC_LINK_SAMPLE`을 넣은 미리 채워진 링크를 붙여넣고 **[가져오기]**를 누르면 주소와 질문 ID가 채워집니다.
   - 창 아래쪽에 "이번 빌드에 열릴 설문"이 표시됩니다. 비어 있으면 빌드가 시작되지 않습니다.
5. **저장 위치**는 `Builds/<버전>-Windows-<LIVE|DEV>-<로그설문|로그|설문|기본>/`로 자동으로 정해집니다. 필요하면 [찾아보기]로 바꿉니다.
6. **[빌드 시작]**을 누르면 Unity가 창 없이 실행되어 빌드합니다. 진행 상황은 창 아래에 표시되고, 자세한 기록은 [로그 열기]로 봅니다.
7. 빌드가 끝나면 [빌드 폴더 열기]를 누릅니다. 폴더 안 `빌드정보.txt`에 버전·종류·로그/설문 설정이 적혀 있습니다. **폴더 전체를 압축해서** 전달하세요.

## Unity 에디터가 열려 있을 때

같은 프로젝트를 Unity 에디터로 열고 있으면(에디터에서 빌드 중일 때 포함) 도우미는 **아무 파일도 바꾸지 않고 기다립니다.**
에디터 작업이 끝나면 Unity를 직접 닫아 주세요. 닫히는 즉시 자동으로 빌드를 시작합니다. 기다리는 동안 [취소]를 누르면 아무것도 바뀌지 않습니다.

## 빌드할 때 바뀌는 것

- `ProjectSettings`의 게임 버전을 입력한 값으로 저장합니다. 버전을 올렸다면 이 변경을 커밋할지 정하세요.
- 로그·설문 체크는 Unity 메뉴 **CurtainCall → 테스트 빌드 태그**와 같은 PC 설정에 저장됩니다.
- 설문 등록 내용은 빌드를 시작할 때 `Scripts/Telemetry/playtest-settings.json`에 저장됩니다. 바뀐 내용이 없으면 파일을 다시 쓰지 않습니다.
- 빌드 기록은 `Builds/_logs/`에 남습니다. `Builds/` 폴더는 Git에 올라가지 않습니다.

## 막혔을 때

| 메시지 | 할 일 |
|---|---|
| 로그 전송 설정이 없습니다 | [최초 전송 설정](local-test.md)을 마친 뒤 도우미를 다시 엽니다. |
| 이 버전에 열릴 설문이 없습니다 | [설문 등록]에서 대상 버전을 맞추거나 설문 사용을 끕니다. |
| Unity.exe를 찾지 못했습니다 | [변경]을 눌러 `ProjectVersion.txt`와 같은 버전의 `Unity.exe`를 선택합니다. 이 선택은 PC에 기억됩니다. |
| 컴파일 오류 / PlaytestBuildRunner가 없습니다 | 최신 dev를 받은 프로젝트인지 확인하고, Unity로 한 번 열어 오류가 없는지 봅니다. |

Mac 빌드는 이 도우미가 지원하지 않습니다. Mac에서는 [빌드 만들기](pc-build.md)의 Mac 순서를 따르세요.
