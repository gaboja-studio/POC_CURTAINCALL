# 대시보드로 플레이 문제 찾기

Windows·Mac 모두 화면과 읽는 방법은 같습니다. 먼저 **환경·게임 버전**을 맞추고 **지금 갱신**을 누르세요.
TEST는 기능 확인용입니다. 실제 난이도 판단에는 같은 조건으로 진행한 플레이 기록을 사용합니다.

## 1. 맨 위 숫자 읽기

| 표시 | 뜻 | 혼동하기 쉬운 점 |
|---|---|---|
| 총 플레이 | 기록에서 확인한 런 수 | 게임 실행 횟수·사람 수가 아님. 진행 중 런도 포함 |
| 수집 이벤트 | 분석 대상 사건 수 | 키·버튼·마이크 입력 제외. 원본 시트의 전체 행 수와는 다름 |
| 공연 플레이 | 성공·실패 결과가 확정된 공연 수 | 시작만 하고 결과가 없으면 제외 |
| 공연 평균 성공률 | 확정된 공연 중 성공 비율 | 10회 중 3회 성공이면 30% |

**미수집·기록 없음·—는 ‘판단할 자료가 없음’**입니다. 0초·실패 0회와 구분하세요.
표본은 ‘계산에 실제 사용한 횟수’입니다. 1회뿐인 100%와 100회 중 100%는 근거의 양이 다릅니다.

## 2. 묘기 통계: 어디가 어려운가?

외줄 타기 / 인간 대포 탭 → 난이도별 승률 → 사망 원인 → 상세 데이터 순서로 봅니다.
난이도 2·3은 기록이 없더라도 자리를 유지합니다. 미수집을 0% 실패로 해석하지 않습니다.
사망 원인 도넛의 추락 60%는 **사망 기록끼리 비교한 비중**입니다. 모든 참가자의 60%가 추락했다는 뜻은 아닙니다.
평균 최대 거리는 플레이어·시도마다 도달한 최대 거리의 평균(m)입니다. 이동한 길 전체의 합이 아닙니다.
협동·사물 상호작용은 확인된 작동 횟수입니다. 키를 누른 횟수나 손잡기를 유지한 시간과 다릅니다.

분석 예: ‘외줄 승률이 낮다 → 추락이 많다 → 해당 런 도식에서 같은 지점에 사망이 몰리는지 확인 → 실제 플레이로 원인 확인’.

## 3. 대기실: 어디서 시간이 드는가?

이용 현황의 각 구역은 큰 숫자로 진입 횟수를 보여 주고, 아래 네 줄을 함께 봅니다.

| 항목 | 뜻 | 볼 때 생각할 것 |
|---|---|---|
| 이용자(런별) | 그 런에서 구역에 들어온 플레이어 수 | 같은 사람이 다른 런에 참여하면 별도 표본 |
| 평균 체류 | 들어왔다가 나온 기록의 평균 시간 | 오래 머무는 것이 필요한 행동인지, 길을 찾는 중인지 확인 |
| 완료 표본 | 체류 시작·끝이 모두 기록된 횟수 | 끝나지 않은 방문은 평균에 빠짐 |
| 첫 도착 평균 | 실제 스폰 이후 그 구역에 처음 도착하기까지 걸린 평균 | 반복 방문 시간은 아님. 목적지를 찾기 쉬운지 살펴볼 후보 |

진입 횟수는 재방문을 포함합니다. 이용자가 2명인데 진입 8회라면 여러 번 오갔을 수 있습니다.
**기물 · 서비스 이용** 표의 이용률은 관측된 런별 플레이어 중 실제 이용자의 비율입니다. 원형 그래프는 이용 횟수의 구성비입니다.
**평균 소요 시간**은 상점·운반 / 편성·준비 / 의료 / 시설을 골라 봅니다. 시작·끝이 모두 있는 건만 평균에 포함합니다.
미수령·의료 미이용은 쉬는 시간 종료 시점에 확정한 건입니다. 중도 이탈은 별도 사유로 봅니다.

분석 예: ‘의료 예약은 많은데 완료가 적다 → 미이용·실패 사유 확인 → 예약 후 의료실 이동/입장 대기 시간 확인’.
치료 전후 같은 길의 실측 속도 비교는 아직 없습니다. 현재는 팔다리·이동·점프·소지 한도의 설정 복원 여부를 기록합니다.

## 4. 세션 찾기: 날짜 → ID 검색 → 목록

1. **달력 · 모든 날짜**를 누릅니다. 세션이 있는 날짜만 선택할 수 있습니다.
2. 날짜를 고르면 해당 날짜의 세션만 드롭다운에 남습니다. 자금 평균·설문 통계도 그 날짜 범위입니다.
3. 원래대로 보려면 달력의 **모든 날짜 보기**. 날짜를 고르지 않아도 됩니다.
4. 특정 ID를 안다면 검색칸에 일부를 입력 → **세션 드롭다운에서 선택**합니다. 검색칸은 목록을 좁히며, 입력만으로 본문을 바꾸지는 않습니다.
5. ID 검색을 비우면 선택 날짜의 전체 목록이 나옵니다. 세션은 한 판을 구분하는 긴 번호입니다.

달력은 **한국 시간의 최초 플레이 기록 날짜**입니다. 게임 속 일차와 다릅니다.
설문만 있는 세션은 플레이 시작을 알 수 없어 **최초 설문 열림 날짜**를 사용하고 목록에도 ‘설문 열림’을 표시합니다.
자금·타임라인·설문은 각자 선택합니다. 같은 판을 비교하려면 세 곳의 ID를 맞추세요. 맨 위 전체 요약 숫자는 개별 세션 선택으로 바뀌지 않습니다.

## 5. 공동 자금 변동

- **일차 별**: 게임 속 각 일차의 마지막 관측 잔액. 기존 방식입니다.
- **구간 별**: 실제 쉬는 시간 기준 **n일차 아침 / 오후 / 밤**의 마지막 관측 잔액. 아직 진행 중이면 현재까지 기록된 값입니다.
- 기본은 여러 런의 **평균 잔액**입니다. 한 세션을 선택하면 그 런만 표시합니다. **평균** 버튼으로 선택 날짜의 전체 평균으로 돌아갑니다.
- 점에 마우스를 올리면 잔액·리워드·지출·표본 수를 봅니다. 구간이 많으면 좌우로 스크롤합니다.

공연 수입은 다음 관측된 쉬는 시간 잔액에 반영될 수 있습니다. 구간을 확인할 기록이 없으면 임의로 아침·오후·밤을 만들지 않습니다.
이전 관측 잔액이 있고 다음 도달 구간에서 변동이 없으면 같은 잔액을 이어 보여 줍니다. 그래프가 평평하다고 미수집으로 단정하지 마세요.
뒤쪽 일차는 도달한 런만 남으므로 평균의 대상이 달라질 수 있습니다. 갑작스러운 변화는 같은 ID의 개별 런으로 다시 봅니다.
비교 예: ‘공연 직후 수입은 충분한가 → 밤의 서비스·구매 뒤 잔액이 급감하는가 → 다음 날까지 필요한 자금이 남는가’.

## 6. 공연 도식으로 원인 확인

1. 세션 → 일차 → 공연 → 외줄 타기 또는 인간 대포를 선택합니다.
2. 왼쪽은 출발 방향, 오른쪽은 도착 방향입니다. 번호·색으로 플레이어를 구분합니다.
3. 아이콘에 마우스를 올리면 사건 핵심과 같은 플레이어의 사건 순서가 연결됩니다. 다른 플레이어는 흐려집니다.
4. **휠 또는 ＋/−**로 간격을 넓히고 좁힙니다. 아이콘 자체 크기는 유지됩니다.
5. **클릭한 채 좌우로 드래그**해서 이동합니다. Mac 트랙패드의 가로 스크롤이나 하단 가로 스크롤도 사용할 수 있습니다.
6. 아이콘을 클릭하면 아래 상세가 고정됩니다. 다른 아이콘은 선택 변경, 빈 곳 클릭이나 Escape는 해제합니다.

그림은 중요한 사건 좌표를 이은 것입니다. 매 순간의 이동 촬영이나 완전한 지도는 아닙니다.
오른쪽 마지막 점이 실제 도착점이라고 단정하지 않습니다. 좌표가 없으면 ‘좌표 미수집’에 별도로 표시합니다.
대기실·기타 타임라인은 표/목록을 유지합니다. 키 입력 같은 분석 잡음은 타임라인에 표시하지 않습니다.

## 7. 설문과 행동 함께 보기

**설문 통계 → 첫날 밤 / 게임 종료 → 세션·플레이어 선택**으로 좁혀 봅니다.
문항 비율은 그 질문에 답한 사람 수가 기준입니다. 복수 선택 합계는 100%를 넘을 수 있습니다.
**응답 보기**를 누르면 답변과 설문을 열 때까지의 호스트 확정 사망·절단·협동 기록이 함께 나옵니다.
‘플레이 로그 없음’은 설문만 켠 빌드이거나 아직 기록이 안 들어온 상황일 수 있습니다. 플레이하지 않았다는 뜻으로 단정하지 않습니다.
예: ‘조작이 어렵다는 답변 → 해당 플레이어의 반복 부상·추락 구간 확인 → 조작 설명 부족인지 장애물 난이도인지 재플레이로 구분’.

## 분석 메모는 이렇게 남기세요

‘버전·환경 / 관측 횟수 / 의심 구간 / 함께 본 세션 ID / 확인할 가설 / 다음 플레이에서 볼 행동’으로 적습니다.
예: ‘0.1.0 LIVE / 외줄 12회 / 3구간 추락 집중 / 세션 … / 점프 거리 안내 부족 가설 / 안내 후 재확인’.
한 번의 0%·100%나 긴 체류 시간만으로 규칙을 바꾸지 않습니다. 숫자 → 해당 판 → 실제 플레이 순서로 확인하세요.

## 공연 참가 인원이 달라 보일 때

공연 도식의 **시작 인원**은 게임이 그 공연을 시작할 때 남긴 값입니다. **기록 확인**은 해당 공연의 기록에서 실제로 구분된 사람 수입니다. 시작 4명·기록 확인 2명이라면 2명만 플레이했다는 뜻이 아닙니다. 아직 기록이 도착하지 않았을 수 있으므로 상단 처리 대기를 먼저 확인하세요. 각 일차·공연은 별도로 집계하며, 다른 세션의 사람을 임의로 합치지 않습니다.
