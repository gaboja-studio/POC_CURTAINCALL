# 개발자 모드와 서비스용 빌드: Windows·Mac

여기서 **서비스용 빌드**는 일반 플레이어에게 전달할 게임 파일입니다.
**Development Build를 끄고**, 필요한 로그·설문을 선택한 뒤 새로 빌드합니다.

## 이름이 비슷한 두 설정

| 구분 | 게임의 개발자 모드(Dev Mode) | Unity의 Development Build |
|---|---|---|
| 하는 일 | 혼자 시작하기·원하는 일차에서 시작하기 등 테스트 편의 기능 | 개발 중 확인하기 위한 실행 파일 만들기 |
| Unity에서 설정하는 곳 | Tools → CurtainCall → Dev Mode (1인 테스트) | File → Build Profiles → Development Build |
| 설정이 적용되는 곳 | Tools 체크는 이 PC의 Unity 재생에만 적용 | 새로 만드는 게임 파일에 적용 |
| 완성된 게임에서 켜는 방법 | 실행할 때 `-devmode`라는 추가 옵션을 붙인 경우만 켜짐 | 빌드할 때 체크한 값으로 고정 |
| 대시보드 TEST/LIVE 구분 | 이 설정으로 구분하지 않음 | 체크하면 TEST, 해제하면 LIVE |

**Tools의 Dev Mode만 끄고 빌드했다고 서비스용 빌드가 되는 것은 아닙니다.**
반대로 Tools에서 켜져 있어도 완성된 게임을 일반적으로 실행하면 Dev Mode는 기본 꺼짐입니다.
Unity에서 재생한 기록은 Development Build 체크와 관계없이 TEST입니다.

## 서비스용 빌드 만들기

Windows·Mac 모두 아래 순서입니다. 빌드는 최신 프로젝트를 준비한 담당 PC에서 진행합니다.

1. Unity 재생을 멈춥니다. **Edit → Project Settings → Player → Version**이 배포할 버전인지 확인합니다. 현재 설문은 **0.1.0 전용**입니다.
2. **CurtainCall → 테스트 빌드 태그**에서 로그 수집과 0.1.0 설문을 각각 선택합니다. 둘 다 기본은 꺼짐입니다. **현재 설정 확인**으로 다시 확인합니다.
3. **File → Build Profiles**를 엽니다. Windows 배포는 **Windows**, Mac 배포는 **macOS**를 선택합니다.
4. **Development Build 체크를 해제**합니다. Tools의 Dev Mode 체크를 대신 끄는 것이 아닙니다.
5. 씬 목록은 팀 설정을 유지하고 시작 씬이 Start인지 확인합니다. **Build**를 눌러 새 폴더에 만듭니다. 이름 예: `Builds/0.1.0-Windows-LIVE` 또는 `Builds/0.1.0-Mac-LIVE`.
6. Windows는 완성된 `.exe`, Mac은 `.app`을 일반적으로 실행합니다. `-devmode`가 붙은 테스트용 바로가기나 실행 명령은 사용하지 않습니다.
7. 로그를 켰다면 플레이 후 대시보드에서 **환경: 실제 플레이 / 게임 버전: 0.1.0**을 선택하고 **지금 갱신**으로 확인합니다.
8. Windows는 `.exe`와 같은 폴더의 **모든 파일·폴더**, Mac은 완성된 **`.app`**을 압축해 전달합니다.

Windows·Mac별 설치·빌드 화면의 자세한 순서는 [빌드 만들기](pc-build.md)를 따릅니다.
로그를 켜는 빌드 담당 PC는 [최초 전송 설정](local-test.md)이 필요합니다. 받는 플레이어는 게임만 실행하면 됩니다.

## 배포 목적에 따라 고르기

| 목적 | Development Build | 로그 수집 | 0.1.0 설문 |
|---|---|---|---|
| 내부 기능 검증 | 켬 → TEST | 필요하면 켬 | 필요하면 켬 |
| 일반 플레이와 설문을 함께 분석 | 끔 → LIVE | 켬 | 켬 |
| 일반 플레이 행동만 분석 | 끔 → LIVE | 켬 | 끔 |
| 행동 기록 없이 설문만 받기 | 끔 → LIVE | 끔 | 켬 |
| 로그·설문 없이 배포 | 끔 | 끔 | 끔 |

설정만 바꿔도 기존 게임 파일은 바뀌지 않습니다. 반드시 **새로 빌드한 파일**을 전달하세요.
같은 PC에서 이미 열린 설문은 서비스용 빌드에서도 다시 열리지 않습니다. 다시 확인하려면 [설문 캐시 삭제](pc-files.md)를 따르세요.
현재 확인을 마친 실행 파일은 Windows **Development Build(TEST)**입니다. 서비스용(LIVE) 빌드와 Mac 실행은 별도 확인이 필요합니다.
