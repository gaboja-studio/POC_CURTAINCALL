# 게임 버전 올리기 — M2부터

현재 개발 버전은 **0.2.0(M2)**입니다. 이전 M1 기록은 **0.1.0**으로 남습니다.

## 숫자는 언제 바꾸나요?

우리 팀의 테스트 배포 기준으로 아래처럼 사용합니다. 모든 게임이 따르는 강제 규칙은 아닙니다.

| 변경 내용 | 버전 예시 |
|---|---|
| 단순 오류 수정·작은 안내/수치 조정 후 새 테스트 배포 | 0.2.0 → 0.2.1 → 0.2.2 |
| 새로운 기능·콘텐츠 묶음 또는 플레이 경험이 크게 달라지는 변경 | 0.2.2 → 0.3.0 |
| M1에서 빠졌던 기능·콘텐츠를 구현하는 M2 시작 | 0.1.0 → **0.2.0** |
| 팀에서 정식 출시 기준을 달성했다고 결정 | **1.0.0** |

파일을 고칠 때마다 바꿀 필요는 없습니다. **서로 다른 테스트 결과를 구분할 새 배포본**을 만들 때 올리세요. 같은 버전으로 계속 배포하면 수정 전후 통계가 합쳐집니다. M2 안의 작은 수정 배포는 0.2.1부터 사용하면 됩니다.

## Windows·Mac에서 설정하기

두 운영체제 모두 Unity 안의 메뉴는 같습니다.

1. 재생을 멈추고 **Edit → Project Settings → Player → Version**에 `0.2.0`을 입력합니다.
2. **CurtainCall → 테스트 빌드 태그 → 로그 수집**을 켭니다.
3. 현재 M2는 **설문 사용**을 끕니다. M1 설문은 `0.1.x` 대상이므로 0.2.0에서는 실행되지 않습니다. 대상 설문 없이 태그만 켜면 실수를 막기 위해 빌드가 중단됩니다.
4. **현재 설정 확인**을 누릅니다. 태그는 PC별 설정이므로 다른 PC에서도 확인해야 합니다.
5. 에디터에서 검증하거나 [PC 빌드](pc-build.md)를 새로 만듭니다. 이미 만들어 둔 실행 파일의 버전은 바뀌지 않습니다.

## 대시보드에서 확인하기

- 에디터 또는 Development Build: **검증용 데이터(TEST) / 0.2.0**.
- Development Build를 끈 배포본: **실제 플레이(LIVE) / 0.2.0**.
- 새 로그가 서버에 도착해 갱신된 뒤 버전 목록에 나타납니다. 이전에 저장된 0.1.0 로그를 재전송해도 0.1.0으로 유지됩니다.
- 0.1.0의 설문과 통계는 그대로 남습니다. M2 설문은 새로 연결하기 전까지 없습니다. 현재 설정에서는 캐시를 지워도 0.2.0에서 M1 설문이 열리지 않습니다.
- 2026-10-26 새 타임라인·설문 계약을 Google 수신v35/대시보드v36에 반영했습니다. M2 Windows 테스트 빌드는 `Builds/Telemetry-0.2.0-Windows-TEST`의 **개발자 모드로 실행.lnk**를 사용합니다.

## 패치 버전을 묶어서 로그·설문 대상 정하기

Windows·Mac 공통으로 **CurtainCall → 로그·설문 설정**을 엽니다.

| 입력 | 의미 |
|---|---|
| `0.2.0` | 정확히 이 버전만 |
| `0.2.x` | 0.2.0, 0.2.1, 0.2.2 등 모두 |
| `*` | 모든 버전 |

- 로그 대상과 각 설문 대상을 따로 정합니다. 현재 로그는 모든 버전, M1 두 설문은 0.1.x입니다.
- 이 범위는 **수집·실행 대상**입니다. 로그·응답에는 실제 버전이 남으며 대시보드에서도 실제 버전별로 봅니다. 패치를 묶어 통계를 합산하는 기능과는 다릅니다.
- 설정 저장 후 새 빌드를 만듭니다. 설정 파일은 프로젝트에 함께 저장되지만 **로그 수집 / 설문 사용 태그는 PC별**로 확인합니다. 이미 배포한 실행 파일은 바뀌지 않습니다.

## 원하는 설문으로 바꾸거나 다시 받기

현재 자동 실행 시점은 **지정 일차의 밤 정비 / 런 퇴장** 두 종류입니다. 밤 정비는 ‘몇 일차 밤’도 바꿀 수 있습니다. 그 밖의 게임 시점은 추가 연결이 필요합니다.

1. 설문 관리자에서 새 폼을 직접 준비합니다. 기존처럼 필수 단답형 **플레이 기록 연결 코드 (자동 입력)** 질문을 넣습니다.
2. 이 질문에 `CC_LINK_SAMPLE`을 넣은 **미리 채워진 링크**를 가져옵니다. 응답 제출은 필요 없습니다.
3. 설정 화면에 링크를 붙이고 **주소·질문 가져오기**를 누릅니다. 이름과 대상 버전(예: `0.2.x`)을 정합니다.
4. 새 설문이면 **설문 ID**를 예: `M2_NIGHT`로 정합니다. 영문·숫자·밑줄·하이픈만 씁니다. 회차는 1부터 시작합니다.
5. 같은 설문을 다시 받고 싶으면 **회차를 1 → 2**로 올립니다. 새 빌드에서 해당 시점에 도달하면 기존 참여자에게도 한 번 더 열립니다.
6. **설정 저장**, **설문 사용** 태그 켜기, 새 빌드 순서로 적용합니다.

같은 ID·회차에서는 0.2.0 → 0.2.1로 바꿔도 다시 열리지 않습니다. M1의 예전 캐시도 유지합니다. ‘최초 1회’는 응답 제출 여부가 아니라 **브라우저 창을 연 횟수**입니다. 로그나 기존 응답은 삭제하지 않습니다.

새 폼의 응답을 대시보드에도 넣으려면 **응답 시트 URL과 탭 이름을 담당자에게 전달**하세요. 폼 주소만 바꿔서는 새 응답 시트를 자동으로 알 수 없습니다. 질문 제목은 `1. 재미`처럼 번호를 붙이고, 복수 선택은 제목에 `복수 선택`, 긴 의견은 `자유 응답`을 적습니다. 복수 선택 보기에는 쉼표를 넣지 않습니다.

대시보드의 **설문 회차**에서 ID·회차를 골라 봅니다. 버전·환경뿐 아니라 설문 회차도 나눠 집계하므로 서로 다른 질문 결과를 섞지 않습니다.
