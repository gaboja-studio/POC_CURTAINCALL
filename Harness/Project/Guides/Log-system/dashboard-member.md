# 팀원용: PC를 켠 뒤 대시보드 보기

대시보드는 인터넷으로 여는 통계 화면입니다. **Unity·게임·Codex를 켜지 않아도 기존 기록을 볼 수 있습니다.**
준비물은 인터넷, 브라우저, 관리자가 등록한 이메일입니다. Drive 폴더나 원본 시트 공유는 필요 없습니다.

## Windows

1. Chrome을 엽니다.
2. [CURTAINCALL 대시보드](https://script.google.com/macros/s/AKfycby1UfzhOaNl9ycjKYATPF-b32AkSskzupKQ--Zxj3Z_eIKraOqy9Aw1PYYLkqKewJ_wqw/exec)를 클릭합니다.
3. 다음부터 쉽게 찾으려면 **Ctrl+D**로 즐겨찾기에 저장합니다.
4. 아래 ‘접속과 조회’를 따릅니다. 재부팅 후에는 이 즐겨찾기만 열면 됩니다.

## Mac

1. Chrome을 엽니다.
2. [CURTAINCALL 대시보드](https://script.google.com/macros/s/AKfycby1UfzhOaNl9ycjKYATPF-b32AkSskzupKQ--Zxj3Z_eIKraOqy9Aw1PYYLkqKewJ_wqw/exec)를 클릭합니다.
3. 다음부터 쉽게 찾으려면 **⌘+D**로 북마크에 저장합니다.
4. 아래 ‘접속과 조회’를 따릅니다. 재부팅 후에도 같은 북마크를 사용합니다.

## 접속과 조회

1. 이메일 입력창이 나오면 **관리자에게 등록받은 이메일**을 입력 → **인증 메일 받기**.
2. 본인 메일함에서 8자리 번호를 확인해 입력 → **접속**. 안 오면 스팸함도 확인합니다.
3. 오른쪽 위에서 **내 이름 + 님 안녕하세요**를 확인합니다.
4. 상단에서 **환경 → 게임 버전 → 지금 갱신** 순서로 선택합니다.
5. [통계 읽는 법](dashboard-reading.md)에 따라 보고 싶은 섹션으로 내려갑니다.

번호는 10분 동안 사용할 수 있고, 접속은 최대 6시간 유지됩니다. 다시 인증을 요구하면 새 번호를 받으세요.
계정이 없거나 번호가 오지 않으면 관리자에게 **사용할 이메일과 표시 이름**을 전달하세요.
인증번호는 다른 사람에게 전달하지 않습니다. 관리자 계정을 함께 쓰지 않습니다.

## 기록이 안 보이면

- Unity·개발용 빌드 기록은 **검증용 데이터**, 일반 빌드 기록은 **실제 플레이**에서 찾습니다.
- 버전이 다르면 다른 게임 파일의 기록입니다. 먼저 버전을 맞춥니다.
- 세션 목록이 적으면 **달력 → 모든 날짜 보기**, 검색칸을 비우고 목록을 다시 엽니다.
- Windows 새로고침은 **Ctrl+R**, Mac은 **⌘+R**입니다. 브라우저 새로고침 후에도 필요하면 **지금 갱신**을 누릅니다.
- 계속 로딩 중이면 여러 번 연속 클릭하지 말고 잠시 후 다시 시도합니다. 담당자에게 화면과 시간을 알려 주세요.

**지금 갱신**은 Google에 도착한 기록을 가져옵니다. 게임이 꺼진 PC에 남은 기록까지 가져오는 버튼은 아닙니다.
이미 도착한 기록은 30분마다 자동으로 집계됩니다. PC나 브라우저를 계속 켜 둘 필요는 없습니다.
팀원은 조회만 합니다. 멤버 추가·원본 보관·삭제는 관리자에게 요청하세요.
