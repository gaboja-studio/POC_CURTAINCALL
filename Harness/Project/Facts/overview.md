# 게임 개요

## 언제 읽나

목적·범위·현재 상태 또는 규칙·UX·씬 Task를 파악할 때. 상세는 [게임 흐름](game-flow.md)·[런 상태](run-state.md)·[부상](../Decisions/injury-rules.md)·[인간 대포](../Decisions/Human-cannon/index.md).

## 기획 기준 — 아직 구현 완료 아님

- **커튼콜 (Curtain Call)** / `POC_CURTAINCALL`, PC Unity 3D·2~4인 코옵 프렌드 슬롭. NGO + Multiplayer Services(Host)([결정](../Decisions/multiplayer-stack.md)). 인간 대포는 4인 검증부터, 2·3인 검증은 후속.
- 서커스 단원이 묘기로 공동 자금을 벌어 기물·서비스를 구매하고 4일차 아침까지 탈출한다. 실패하면 흔적과 가판대(옛 이름: 물려줄 선반) 기물을 남기고 새 세대가 1일차부터 시작한다.
- 의도: “욕심과 공포”, “친구 사이의 사고와 원망도 재미”, “숨 막히는 시간 뒤 숨 돌릴 곳”. 인원수 증가로 필수 역할을 추가하지 않는다.
- **하루 시계**(M2): 아침 쉬는 시간(8~10시) → 오전 공연 → 낮 쉬는 시간 → 오후 공연 → 밤 정비(16~20시, 타이머 없음, 전력 차단·철창으로 탐색 제한) → 모두 침대에 누우면 수면 연출 뒤 다음 날. 서비스는 신체 복구 하나(시설 서비스 삭제)로 공연 중 외 언제든, 기물 구매는 밤 정비에만. 신체 복구는 부위당 기본 100토큰, 팀 이용 1회마다 다음 가격 +25(여러 부위도 1회, 런마다 초기화). 보상은 [확정 규칙](../Decisions/reward-rules.md): 생존 호응×2, 사망 호응½×2(중간 버림 없음), 도착자만 100/150/200토큰 추가. 전원 사망 실패에도 호응 보상 지급, 전원 생존 보너스 삭제.
- 공연장 ← 무대 입구 통로 ← 대기실(런마다 랜덤 방, 탈출 단계) → 탈출로 입구 → 탈출로 → 하역장. M2에서 대기실·백스테이지를 **대기실** 하나로 통합해 준비·서비스·탐색·탈출 시도가 대기실에서 일어난다. 한 공연장 씬에서 묘기 프리팹 교체, 탈출로는 구 공연장·하역장 복합 코스.

## 구현 근거 — 조사 날짜를 구분

- 2026-10-13 조사 당시: 외줄 프로토타입·세션/플레이어/손상 등 공통 기반, 공간 맵은 둘러보기 수준이었다. 이 당시의 “런·자금 없음”을 현재 구현 사실로 쓰지 않는다.
- 2026-10-15 확인: 공용 시스템 중간 반영 PR #64, 패널 수정 PR #65가 dev에 병합됨. 전체 공간 연결·인간 대포 구현 또는 4인 검증 완료를 뜻하지 않는다.
- 기능별 근거·진입점과 M2와 다른 현재 구현은 [공통 시스템 지도](../../../Docs/Domains/common-game-systems.md), 에셋 현황은 [Unity 프로젝트](unity-project.md)의 각 조사 날짜를 확인한다.

## 아직 정하지 않은 것

쉬는 시간 A/B안은 M2에서 삭제(안전지대 없음, 무대 입구 통로 진입으로 복귀). 가이드 쉬는 시간 길이·트루 엔딩·환호 포인트 위치 배치 방식·묘기별 환호 판정은 미정. 보상 수치는 [보상 규칙](../Decisions/reward-rules.md)(27459631) 확정. 1인 최대 3,000토큰은 목표, 현 규칙 계산은 2,700토큰으로 조정 미정. 기물 7종 새제품 가격은 [보상 규칙](../Decisions/reward-rules.md)에서 확정(구조장갑100·끈끈이장갑100·광대벌룬바지125·스프링신발175·머리핀50·말뚝뽑개75·UV등75토큰). 2026-10-28 [새제품 내구도·차감·소진 처리](../Decisions/item-durability.md)도 확정. 효과 수치·접두사·쿨타임·발견품 내구도의 기존 초안·미정은 유지, 변경 시 기물·보상 문서를 함께 수정한다. 서비스 연출은 대기실 담당이 A안 선택([대기실](../Decisions/Waiting-room/index.md)), 인간 대포의 지상 2명 규칙·중계 대포는 미정이다. 공통 보상 규칙은 인간 대포에도 적용한다. 준비 문서를 구현 완료나 확정 밸런스로 읽지 않는다.
