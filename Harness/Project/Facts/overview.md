# 게임 개요

## 언제 읽나

게임의 목적·범위·현재 상태를 파악하거나 게임 규칙·UX·씬 Task를 계획할 때. 상세는 [게임 흐름](game-flow.md), [런 상태·장소 전환](run-state.md), [부상 규칙](../Decisions/injury-rules.md).

## 기획 기준 — 아직 구현 완료 아님

- 프로젝트: **커튼콜 (Curtain Call)** / `POC_CURTAINCALL`. PC용 Unity 3D, 2~4인 코옵 프렌드 슬롭(공연 + 탐색·탈출 + 세대 교체). 넷코드는 NGO + Multiplayer Services(Host)([결정](../Decisions/multiplayer-stack.md)).
- 콘셉트: 서커스 단원이 관객 앞에서 묘기로 크레딧(공동 자금)을 벌고 기물·서비스를 사서 4일차 아침까지 탈출한다. 실패하면 흔적만 남기고 다음 세대가 1일차부터 다시 한다.
- 기획 의도: "욕심과 공포"(성공하면 보상↑, 죽으면 말짱 꽝), "친구 사이의 사고와 원망도 재미", "숨 막히는 시간 뒤 숨 돌릴 곳(대기실·밤)". 인원수별 예외 규칙을 두지 않는다.
- 핵심 루프: **공연 → 쉬는 시간(탐색·탈출 판단) 반복 → 밤 정비(복구·구매·세트리스트)**. 공간: 공연장 ← 무대 입구 통로 ← 복도 → 백스테이지 → 탈출로 → 하역장(대기실은 복도에 연결).
- 공간 담당은 [space-workspaces.md](../Decisions/space-workspaces.md), 시스템(런 상태·장소 전환)은 @MoHoDu.

## 저장소에서 확인한 구현 상태 (2026-10-13)

- 구현된 것은 외줄 묘기 프로토타입(공연장)과 공통 기반(세션·플레이어 동기화·조작·신체 손상·세팅·기록)이다. 공간 맵 씬은 둘러보기 수준이고, 런·하루 진행·쉬는 시간·밤·공동 자금·장소 전환은 없다. 기능별 재사용 판단은 [공통 게임 시스템 지도](../../../Docs/Domains/common-game-systems.md), 씬·입력 현황은 [Unity 프로젝트 구성](unity-project.md).

## 아직 정하지 않은 것

쉬는 시간 타이머 A/B안, 가이드 쉬는 시간 길이, 트루 엔딩, 보상·가격 수치(보상 시스템 문서 예정)는 [게임 흐름](game-flow.md)의 미정을 따른다. 기본값을 확정 밸런스로 쓰지 않는다.
