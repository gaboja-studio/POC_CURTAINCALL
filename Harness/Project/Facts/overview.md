# 게임 개요

## 언제 읽나

목적·범위·현재 상태 또는 규칙·UX·씬 Task를 파악할 때. 상세는 [게임 흐름](game-flow.md)·[런 상태](run-state.md)·[부상](../Decisions/injury-rules.md)·[인간 대포](../Decisions/Human-cannon/index.md).

## 기획 기준 — 아직 구현 완료 아님

- **커튼콜 (Curtain Call)** / `POC_CURTAINCALL`, PC Unity 3D·2~4인 코옵 프렌드 슬롭. NGO + Multiplayer Services(Host)([결정](../Decisions/multiplayer-stack.md)). 인간 대포는 4인 검증부터, 2·3인 검증은 후속.
- 서커스 단원이 묘기로 공동 자금을 벌어 기물·서비스를 구매하고 4일차 아침까지 탈출한다. 실패하면 흔적을 남기고 새 세대가 1일차부터 시작한다.
- 의도: “욕심과 공포”, “친구 사이의 사고와 원망도 재미”, “숨 막히는 시간 뒤 숨 돌릴 곳”. 인원수 증가로 필수 역할을 추가하지 않는다.
- **공연 → 쉬는 시간(탐색·탈출 판단) 반복 → 밤(복구·구매·세트리스트)**. 공연장 ← 무대 입구 통로 ← 복도 → 백스테이지 → 탈출로 → 하역장, 대기실은 복도에 연결.
- 한 공연장 씬에서 묘기 프리팹 교체. 대기실은 준비/안전, 백스테이지는 탐색·탈출 갈림길, 탈출로는 구 공연장·하역장 복합 코스.
- 공연장·탈출로 @RagSpirin, 대기실·백스테이지 @gyumin9048-ctrl, 총괄 시스템 @MoHoDu([작업 공간](../Decisions/space-workspaces.md)).

## 구현 근거 — 조사 날짜를 구분

- 2026-10-13 조사 당시: 외줄 프로토타입·세션/플레이어/손상 등 공통 기반, 공간 맵은 둘러보기 수준이었다. 이 당시의 “런·자금 없음”을 현재 구현 사실로 쓰지 않는다.
- 2026-10-15 확인: 공용 시스템 중간 반영 PR #64, 패널 수정 PR #65가 dev에 병합됨. 전체 공간 연결·인간 대포 구현 또는 4인 검증 완료를 뜻하지 않는다.
- 기능별 근거·진입점은 [공통 시스템 지도](../../../Docs/Domains/common-game-systems.md), 에셋 현황은 [Unity 프로젝트](unity-project.md)의 각 조사 날짜를 확인한다.

## 아직 정하지 않은 것

가이드 쉬는 시간 길이·트루 엔딩·보상/가격 수치는 미정. 쉬는 시간은 B 기본/A-B 세팅 전환이 확정이다. 서비스 연출 A/B는 대기실 담당 선택, 인간 대포의 지상 2명 규칙·중계 대포·상세 보상은 미정이다. 준비 문서를 구현 완료나 확정 밸런스로 읽지 않는다.
