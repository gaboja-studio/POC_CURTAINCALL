## 확인 방법

- Tools/CurtainCall/탈출로의 A 구조 씬 열기 / B 구조 씬 열기 / C 구조 씬 열기 → **Play만 누르면 혼자 시작**. 세 씬은 같은 EscapeDevelopmentSession을 사용한다. A는 첫 대포 접근부(13.5,0.05,64), B·C는 기존 무대 하부 입구에서 출발한다.
- 방 생성/참가 UI·시간제한·게임 오버·관전 대기를 넣지 않는다. 원본 피격/추락/리타이어 후 1초 뒤 온전한 몸으로 출발점 복구하며 R도 같은 복구를 사용한다. 기물 점유/카메라 복구는 공용 Restarted 이벤트를 쓴다.
- 원본 NetworkPlayer/묘기 시스템 실행을 위한 내부 연결은 loopback·빈 로컬 포트만 사용한다. 온라인 서비스/Relay·방 코드·외부 참가 없이 실행하며 씬 종료 시 정리한다. 기존 제작용 멀티플레이 시스템은 수정하지 않는다.
- 인간대포가 기본 조작, 외줄 위에서만 외줄 조작.1키는 실제 플레이어와 함께 자유비행하고 현재 위치/시선에서 복귀한다. R은 원래 출발점 재시작.
- 상시 조작 안내 박스는 없다. 사용할 수 있는 기물 가까이의 F 안내/테두리만 유지한다. 혼자 검토할 때 협동 구간의 동료 역할은 대체하지 않으며 1키로 공간을 살펴볼 수 있다.
- A 융합은 편집 상태에서 원본 탄도·연결·외줄 보행/매달림·그네 이동 범위를 확인했다. AuditCurrentFlow와 이전 제작 검사의 옛 기물 수/계단 가정은 새 A 완료 기준으로 쓰지 않는다. 이전 EditMode10/10·1인 시작 결과도 현행 플레이 검증을 뜻하지 않는다.
- AI는 이동/발사 입력·불필요한1인 실행을 수행하지 않는다. 실제 손맛·다인 협동·성능/밝기는 사람이 확인한다. 런타임 선택·대기실·추격/탈출 판정은 별도 범위다.
