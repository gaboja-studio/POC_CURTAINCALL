# 공용 UI 효과음

## 언제 읽나

UI 효과음을 추가하거나 재생 조건과 시트 ID를 확인할 때.

## 사실

- `Tools/CurtainCall/사운드 설정`의 사운드 탭에서 시트 ID의 클립, 구간, 음량을 설정한다. 적용 상황 탭에서 실제 이벤트의 큐를 바꿀 수 있다. 클립 대기 큐는 클립 배열이 비어 있고 비활성이다.
- 경고 배너(UI-102)는 공용 HUD에서 배너마다 요청한다. 개인 사망 카드는 UI-701을 재생한다. 추격 단계 상승은 전용 클립을 등록하면 UI-1401을 쓴다.
- 로비·대기실의 수락된 F 조작은 UI-302를 재생한다. 공용 메뉴 버튼 클릭은 UI-1002에 연결한다.
- 외줄 매달림(UI-502)은 로컬 남은 초가 줄 때 단발 비프를 재생한다. 구조 중에는 남은 시간과 비프가 멈춘다. 균형 경고(UI-901)는 주의·위험 구간에서만 루프를 유지한다.
- 휴식·정비 타이머 끝(UI-907)은 캠페인 스냅샷의 실제 만료 횟수가 증가할 때 요청한다. 탈출로 시계는 경과 시간을 측정한다.
- 지정 클립과 미배정 목록은 작업 기록에 둔다. [사운드 리소스 데이터](https://docs.google.com/spreadsheets/d/1hy9U_T6LEUIH_TC7Yb20Vw7FcfMkYVV_fXpCo0thyek/edit?gid=1461497593#gid=1461497593)
