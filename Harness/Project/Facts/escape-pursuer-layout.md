# 탈출로 A 추격자 배치

- 좌표는 EscapeCampaignFrame 로컬이다. 5m 거구는 A에서만 사용한다.
- 첫 벽은 `EscapeBackground/17_BrutalistRoute/01_Understage`의 **첫** `타설 콘크리트 벽`, 중심(15,1,-1)이다. 대기실에서 +X로 진입하므로 오른쪽은 -Z. 같은 이름의 (25,7,23) 벽이나 첫 대포 옆 끝막이(15,14,83.52)와 혼동하지 않는다.
- 파괴 모듈은(15,0,-1), Y180°다. +Z로 나온 후 플레이어를 향해 돌아서 첫6m는 걷고 이후 달린다. 원래 벽은 삭제하지 않고 비활성 보존한다.
- 단일 추격자가 74개 앵커를 따라 실제 이동한다. 전용 정비로는 불투명 지붕/외벽으로 가리고, `EscapePursuerScreens`가 복제된 추격자 pose와 참가자 위치를 받아 근처 패널을 연다. 포획 판정은 기존 호스트의 물리 시야/접촉을 사용한다.
- 46~48,70~71 합류 구간은 플레이어 길을 막지 않도록 출입 셔터 이후 밖으로 나오는 연출이다. 머리핀 통로의 통과 셔터는 몸이 닿기 전에 열린다. F6 연습에는 가림 연출을 중지한다.
- 각 패널의 앞/뒤 면 모두 공격 시야에 사용한다. 한쪽만 검사하면 다른 구간에서 반대편으로 조준할 때 닫힌 패널이 공격을 막는다. 경계에서는 팔 반경을 고려해 인접 면도 연다.
- 복귀 대포는 새 지붕과 실제 탄도가 교차할 수 있다. 18번 연결부는 높이5.3m, 나머지는6.7m. 플레이어 경로 앵커의 직선 보간은 대포 비행이 아니므로 실제 LaunchVelocity/공통 Gravity 탄도와 따로 검사한다.
- 같은 면의 겹침은 `EscapeCoplanarPolish`로 공유 렌더 영역만 잘라낸다. 원본 메시와 콜라이더를 보존하고 파생 메시를 `_ThirdParty/Task100/SurfaceReview`에 저장한다. 서로 다른 LOD 단계의 동일 표면은 동시 표시 중복으로 취급하지 않는다.
- A와 `UnderstagePursuerPlaytest.unity`를 함께 저장한다. 맵 변경 후 위치·통과 공간·카메라 시야·공격선·기물 비행을 재검사한다. 전 구간 다인 플레이와 공포감/압박감 판단은 사용자 확인이다.
- 카운트다운은 없다. [내부 연출 시계](escape-route-timer.md)는 유지하며, 출구는 필수 배선 절단으로만 열린다.
