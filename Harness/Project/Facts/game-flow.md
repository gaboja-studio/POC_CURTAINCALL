# 게임 흐름

## 언제 읽나

런·하루 진행, 공연 정산, 쉬는 시간·밤, 실패·세대 교체를 계획할 때. 상세는 [런 상태](run-state.md)·[부상](../Decisions/injury-rules.md)·[인간 대포](../Decisions/Human-cannon/index.md). **기획 기준이며 구현 상태가 아니다**(현재 코드와 다른 점은 [공통 시스템 지도](../../../Docs/Domains/common-game-systems.md)의 M2 미반영 구현). 수치는 잠정값으로 세팅에서 조정한다.

## 기획된 흐름

- **런**(약 60~85분): 1~3일차 + 4일차 아침 쉬는 시간 끝까지 탈출. 기한 초과·탈출로 전원 리타이어 → 실패 → 세대 교체 → 1일차 줄타기부터.
- **하루 시계**(원형 시계): 8~10시 아침 쉬는 시간, 10~12시 오전 공연, 12~14시 낮 쉬는 시간, 14~16시 오후 공연, 16~20시 밤 정비(이때만 타이머 없음), 그 외 수면. 쉬는 시간이 시작되면 바로 시계가 흐르고 남은 시간도 표시한다. 1일차: 도입 컷씬 → 오전 줄타기(고정) → 낮 가이드 쉬는 시간 → 오후 인간 대포(고정) → 밤 정비(아침 쉬는 시간 없음). 4일차는 아침 쉬는 시간만(마지막 탈출 기회). 공연 6회(각 약 5분), 쉬는 시간 6회(각 5분 잠정) = 탈출 기회 6회. 2일차부터 세트리스트 선택.
- **장소**: 공연장 ← 무대 입구 통로 ← 대기실(랜덤 방, 탈출 단계) → 탈출로 입구 → 탈출로 → 하역장. 대기실·백스테이지를 대기실 하나로 통합해 탐색·장애물·단서·탈출 4단계·추격이 대기실 안에서 일어난다. 방은 **런마다** 섞고, 탈출 진행도(탐색으로 열고 해금한 방·문 등)는 그 런 동안 유지한다.
- **쉬는 시간**: 탐색·탈출 시도·서비스 이용·직전 사망자 외팔 부활. A/B안 삭제(M2). **안전지대 없음**, 복귀는 시간 안에 **무대 입구 통로**에 들어가는 것 하나. 시간이 끝나면 추격자가 대기실에 풀리고, 잡히면 팔 하나만 남기고 무대로 끌려감(이미 외팔이면 사망). 경보 1분(소집 경보: 종소리·방송)·30초·10초(방송), 늦은 인원 정리까지 공연 대기, 전원 무대 입구 통로 진입 시 조기 시작. 제한 시간 용어는 **탐색 제한 시간**([결정](../Decisions/Waiting-room/exploration-time-limit.md)). 가이드 쉬는 시간은 대기실 기능 안내와 서비스·상점 화면 안내(기물 구매는 밤 정비).
- **밤 정비**: 타이머 없음. 추격자 없는 안전한 시간. 전력이 차단되고 대기실 로비와 이어진 탐색 방 입구에 철창이 내려와 탐색은 일부 영역만. 기물 구매·스케줄·세트리스트·난이도 단계 선택. **종료**: 구매·상의를 마친 뒤 각자 침실의 자기 침대에 상호작용해 눕는다 → 모두 누우면 눈이 감기며 검은 화면에 다음 날로 넘어가는 연출(= 수면) → 눈을 뜨고 일어나며 다음 날 시작.
- **공연**: 생존 규칙은 [run-rules.md](../Decisions/run-rules.md) #2·#10 — 2026-10-16부터 모든 묘기 공통으로 생존 1명까지 계속, 남은 생존자 도착 시 성공, 전원 사망 시 실패. 묘기 재시작 없음. 2026-10-27 [보상 규칙](../Decisions/reward-rules.md): 생존 호응×2토큰, 사망 전 호응×½×2토큰(중간 버림 없음), 도착자만 단계별 100/150/200토큰 완주 보너스. 전원 사망 실패에도 각자의 사망 전 호응 보상 지급, 별도 전원 생존 보너스 삭제.
- **호응/공동 자금**: 개인 색 구간을 잇는 팀 게이지, 호응도는 0~단계별 100/150/200. 사망 시 전부 지우지 않고 절반 인정 표시. 완주·사망 시 본인 호응도를 고정하고 공연 종료 후 정산해 **토큰 공동 자금**에 합산(개인 지갑 없음). 잔액 표시·장부 열람, 고의 탕진도 막지 않음. 환호는 협동 양쪽 각10/오브제 최초5/근접 회피5/절단 개당10/포인트15. 추락−15(같은 추락 중복 없음), 시간 끌기 15초마다−10(정상 대기 제외). 개인별 마지막 환호·공연 시작부터 20초 뒤 초당−1, 시간 끌기 야유 때도 20초 타이머 초기화. **환호 포인트**는 선택 위험 구간의 공용 획득물로 먼저 닿은 1명 +15 후 소멸, 팀 개수는 인원×2/3/4, 위치 배치 방식 미정. 중복·판정·표현 상세는 [보상 규칙](../Decisions/reward-rules.md).
- **난이도 단계**: 묘기마다 1~3단계. 세트리스트를 정할 때 묘기별로 클리어한 단계의 다음 단계까지 고른다(1단계 클리어 → 1·2, 2단계 클리어 → 1~3, 클리어 못 하면 열리지 않음). 1일차는 1단계 고정. 단계가 높을수록 팀 호응 게이지의 1인 상한이 오른다. 위험·보상 함께 증가, 1·2·3축 설명 유지.
- **추락**: 인간 대포 추락은 즉사가 아니라 절단 순서대로 **2곳 절단**("한 번에 1곳"의 예외), 잃은 팔다리가 4개가 되면 사망. 압박 불길 등 다른 즉사는 유지. 외줄은 추락 게이지가 넘치면 줄을 잡고 매달려 버틴다(기본 7초, 세팅). 스스로는 못 올라오고 근처 동료가 F로 2초 끌어올리면 줄 위로 복귀(그동안 버티는 시간 정지, 도와주는 동료가 죽거나 피해를 받으면 끊기고 남은 시간이 다시 흐름), 시간이 다 지나면 낙사. 목마 중 낙하는 떨어진 사람들이 근처 줄을 한 줄에 한 명씩 먼저 떨어진 순서대로 잡고, 줄이 모자라면 남은 사람은 낙사. 사망 조건: 팔다리 4곳 모두 잃음, 묘기 규칙의 즉사 추락, 외팔로 쉬는 시간 대기실에서 잡힘.
- **기물**: 수화기 구매는 **밤 정비에만**, 배송구 수령, 소품실 무제한 보관(M1 기물 판매 제외). 소품실 **가판대**(옛 이름: 물려줄 선반) 4칸에 올린 기물만 다음 세대로. 팔 개수와 관계없이 기본 2칸, 배낭과 외팔 슬롯 감소 삭제(2026-10-28, [부상](../Decisions/injury-rules.md)). 공연 사망·잡힘에는 유지, 탈출로 리타이어 때 소실, 세대 교체는 가판대 4칸만 계승(런 실패 뒤 누적 성장). 옛 3/+3 예시는 적용하지 않음.
- **탈출**: 대기실 탈출 4단계 진행은 런 동안 유지, 다른 시간대 결과물 1개 이상·런마다 새 조건 1개 이상. 새 방에는 단서/보상 1개 이상. 전 해금 후 대기실↔최종 단계 왕복 5분 이내. 살아 있는 전원 탈출로 입구 집결·상호작용 → 탈출로(약 10분), 한 명 이상 하역장 도착 성공. 전원 탈출/희생 탈출, 트루 엔딩 미정.
- **세대 교체**: 이름·사진·흔적과 가판대 기물 유지. 대기실 방 배치를 새로 섞음. 탈출 진행·자금·묘기별 클리어 단계·신체 복구 가격·세트리스트/스케줄·인벤토리·부상 초기화.

## 서비스 (M2)

- 전문가 스케줄 삭제. 서비스는 **신체 복구 하나**(시설 서비스·장애물 강화/약화·VIP 등은 삭제), 모든 쉬는 시간과 밤 정비에 언제든 이용(공연 중 제외). 전화부스 팝업 구매.
- 연출은 **대기실 담당이 A안 선택**(대기실 2차 기획 2026-10-15, [밤 정비](../Decisions/Waiting-room/night-maintenance.md)): A 구매자만 캡슐/방 입구 F → 문 닫힘·쇠 소리·상태/외형 변화 → 퇴실. B 팝업 닫힘 → 거대 인형 집게가 구매자만 들어 올림 → 쇠 소리·변화 → 내려놓고 사라짐.
- **신체 복구**: 한 번에 1~3개 부위, 절단 역순(왼팔 → 오른다리 → 왼다리), 온전한 몸은 이용 불가. 공동 자금에서 부위당 기본 **100토큰**, 팀 전체 이용 1회마다 다음 부위당 가격 **+25**(여러 부위도 1번만), 런마다 100으로 초기화. 예: 첫 이용 2부위 200 → 두 번째 1부위 125 → 다음부터 150. 절단 호응 +10은 복구 비용과 연동하지 않으며 복구 비용보다 낮아야 한다는 별도 제한은 삭제(2026-10-27 보상 규칙이 옛 M2 10/+5 대체).

## 미정과 확인

가이드 쉬는 시간 길이·트루 엔딩·난도 3축 공통 적용 여부는 담당 협의. 보상 수치는 [확정 규칙](../Decisions/reward-rules.md)(Confluence 27459631), 포인트 위치 배치 방식·묘기별 성공/회피 판정·실제 수입은 후속 확인. 1인 최대 3,000토큰은 경제 목표이며 현 규칙 상한 완주 계산은 2,700토큰으로 차이 조정 미정. 기물 7종 새제품 가격은 확정(토큰): 구조장갑100·끈끈이장갑100·광대벌룬바지125·스프링신발175·머리핀50·말뚝뽑개75·UV등75. 2026-10-28 [새제품 내구도·차감·소진 처리](../Decisions/item-durability.md)도 확정. 효과 수치·접두사·쿨타임·발견품 내구도의 기존 초안·미정은 유지하고, 변경 시 기물·보상 문서를 함께 수정한다. 인간 대포의 지상 2명 규칙·중계 대포는 [전용 결정](../Decisions/Human-cannon/index.md). 출처는 위 Confluence 페이지와 M2 변경점(27721807), `Docs/References/game-flow.md`(2026-09-30)는 이전 판이다.
