# 게임 흐름

## 언제 읽나

런·하루 진행, 공연 정산, 쉬는 시간·밤, 실패·세대 교체를 계획할 때. 상세는 [런 상태](run-state.md)·[부상](../Decisions/injury-rules.md)·[인간 대포](../Decisions/Human-cannon/index.md). **기획 기준이며 구현 상태가 아니다.** 수치는 잠정값으로 세팅에서 조정한다.

## 기획된 흐름

- **런**(약 60~85분): 1~3일차 + 4일차 아침 쉬는 시간 끝까지 탈출. 기한 초과·탈출로 전원 리타이어 → 실패 → 세대 교체 → 1일차 줄타기부터.
- **하루**: 1일차 도입 → 줄타기(고정) → 가이드 쉬는 시간 → 인간 대포(고정) → 밤. 2·3일차 아침 쉬는 시간 → 공연 → 쉬는 시간 → 공연 → 밤. 공연 총 6회(각 약 5분), 쉬는 시간 6회(각 5분). 2일차부터 세트리스트 선택.
- **쉬는 시간**: 탐색·탈출 시도·기물 구매·직전 사망자 외팔 부활. **B안 기본**(첫 사람이 대기실에서 백스테이지로 나오면 팀 타이머 시작, 무대 입구 통로만 복귀 인정), A안은 세팅 전환([run-rules.md](../Decisions/run-rules.md)). 경보 1분(소집 경보: 종소리·방송)·30초·10초(방송), 전원 무대 입구 통로 진입 시 조기 시작. 늦으면 추격, 안전 도착·잡힘 정리까지 공연 대기. B안에서는 대기실 복귀를 합류로 인정하지 않는다. 이 제한 시간의 용어는 **탐색 제한 시간**(2026-10-15), 무대 입구 통로부터 백스테이지이며 한 번 나간 캐릭터는 쉬는 시간 종료까지 대기실 재진입 불가([탐색 제한 시간](../Decisions/Waiting-room/exploration-time-limit.md)). 대기실 기획서 4.1의 다른 수치는 적용하지 않는다.
- **밤**: 대기실 문 잠김·안전, 위협은 문 밖/백스테이지. 타이머 없이 전원 준비 완료로 종료. 의료 1·3일차 밤, 시설 2일차 밤, 구매·스케줄·세트리스트 준비.
- **공연**: 생존 규칙은 [run-rules.md](../Decisions/run-rules.md) #2·#10 — 2026-10-16부터 모든 묘기 공통으로 생존 1명까지 계속, 남은 생존자 도착 시 성공, 전원 사망 시 실패. 묘기 재시작 없음, 성공 생존자 보상·사망자 박탈, 실패 전원 박탈, 전원 생존 보너스.
- **호응/공동 자금**: 개인 색 구간을 잇는 팀 게이지, 환호↑·야유↓(0 하한), 죽은 사람 구간 삭제. 성공 시 남은 게이지를 공동 자금으로, 실패 시 0. 잔액 표시·장부 열람, 고의 탕진도 막지 않음. 관객 반응은 실제 게이지와 일치.
- **난도**: 묘기 반복 1·2·3+번째 = 단계 1·2·3(상한). 위험·최대 보상 함께 증가, 구체 수치는 미정.
- **기물**: 수화기 구매·배송구 수령, 소품실 무제한 보관(M1 기물 판매 제외). 대기실 기획의 소품실 4단 선반 = 아래 세대 계승 선반 4칸. 팔 2개 기본 2/외팔 기본 1/배낭 +2([부상](../Decisions/injury-rules.md)). 공연 사망·잡힘에는 유지, 탈출로 리타이어 때 소실, 세대 교체는 선반 4칸만 계승. 옛 3/+3 예시는 적용하지 않음.
- **탈출**: 백스테이지 4단계 진행은 런 동안 유지, 다른 시간대 결과물 1개 이상·런마다 새 조건 1개 이상. 새 방에는 단서/보상 1개 이상. 전 해금 후 대기실↔최종 단계 왕복 5분 이내. 살아 있는 전원 입구 집결·상호작용 → 탈출로(약 10분), 한 명 이상 하역장 도착 성공. 전원 탈출/희생 탈출, 트루 엔딩 미정.
- **세대 교체**: 이름·사진·흔적과 선반 기물 유지. 탈출 진행·자금·반복 횟수·세트리스트/스케줄·인벤토리·부상 초기화.

## 서비스 구매 (최신 흐름 5-3-1)

- 전화부스 팝업 구매. 스케줄 부재 시 비활성 + **“담당자 부재 중”**. 옛 고정 전문가 대화/즉시 효과 문구보다 이 절이 우선.
- 연출은 **대기실 담당이 A안 선택**(대기실 2차 기획 2026-10-15, [밤 정비](../Decisions/Waiting-room/night-maintenance.md)): A 구매자만 캡슐/방 입구 F → 문 닫힘·쇠 소리·상태/외형 변화 → 퇴실. B 팝업 닫힘 → 거대 인형 집게가 구매자만 들어 올림 → 쇠 소리·변화 → 내려놓고 사라짐.
- 후속 공연/탈출 서비스 효과는 적용 공간 UI로 표시. 비용·효과 수치는 미정.

## 미정과 확인

가이드 쉬는 시간 길이·트루 엔딩·보상/가격·난도 3축 공통 적용 여부는 담당 협의. 인간 대포의 지상 2명 규칙·중계 대포·상세 보상은 [전용 결정](../Decisions/Human-cannon/index.md). 출처는 위 Confluence 페이지, `Docs/References/game-flow.md`(2026-09-30)는 이전 판이다.
