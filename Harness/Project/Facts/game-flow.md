# 게임 흐름

## 언제 읽나

런·하루 진행, 공연 정산, 쉬는 시간·밤, 런 실패·세대 교체를 계획할 때. 장소 전환·런 상태 데이터는 [run-state.md](run-state.md), 부상은 [부상 규칙](../Decisions/injury-rules.md). 아래는 **기획 기준**이며 구현 상태가 아니다. 수치는 모두 잠정값(세팅 파일로 조정).

## 기획된 흐름

- **런**(약 60~85분) = 1~3일차 공연 + **4일차 아침 쉬는 시간 끝까지 탈출**. 기한 초과 또는 탈출로 전원 리타이어 → 런 실패 → 세대 교체 → 1일차 줄타기부터.
- **하루**: 1일차 = 도입 컷씬 → 공연(줄타기, 고정) → 쉬는 시간(가이드) → 공연(인간 대포, 고정) → 밤 정비. 2·3일차 = 아침 쉬는 시간 → 공연 → 쉬는 시간 → 공연 → 밤 정비. 공연 런 전체 6회(1회 약 5분), 쉬는 시간 6회(1회 5분).
- **쉬는 시간**: 대기실 문 열림, 탐색·탈출 시도·기물 구매·직전 사망자 부활. 종료 1분 전 소집 경보. 늦으면 추격자 방출, 안전지대(대기실·무대 입구 통로) 도착 시 합류. 늦은 사람이 정리될 때까지 공연 대기. 전원이 무대 입구 통로에 들어가면 조기 시작. 타이머 시작점 A/B안(A: 쉬는 시간 시작부터·대기실도 복귀 지점 / B: 대기실에서 나온 뒤부터·무대 입구 통로만 복귀) — 2026-10-14 PM: **B안 기본, 세팅으로 A/B 전환**([run-rules.md](../Decisions/run-rules.md)).
- **밤 정비**: 문 잠김, 타이머 없음, 전원 준비 완료로 종료. 스케줄표·세트리스트, 서비스(의료 1·3일차 밤, 시설 담당자 2일차 밤), 기물 구매.
- **공연**: 팀 단위 진행(2인 이상 생존 시만 클리어 가능 — 2026-10-14 PM: 생존 2명 미만이면 묘기 공통으로 실패, [run-rules.md](../Decisions/run-rules.md) #2), 정산은 개인 단위. 한 명이라도 도착 = 성공(생존자 각자 보상, 사망자 박탈) / 전원 사망·제한 시간 초과 = 실패(전원 박탈) / 전원 생존 성공 = 생존 보너스. 묘기는 재시작하지 않는다.
- **팀 호응 게이지**: 플레이어별 구간을 이어 붙인 막대 하나. 환호 +, 야유 −(0 하한), 사망하면 그 구간 제거. 성공 시 남은 게이지 → **공동 자금**, 실패 시 0.
- **난이도 단계**: 묘기별 반복 횟수 1·2·3+번째 = 1·2·3단계(상한). 위험과 최대 보상이 함께 오른다.
- **공동 자금**: 팀 공용 크레딧, 잔액 항상 표시, 사용 내역(장부)은 나중에 열람. 고의 탕진도 막지 않는다.
- **기물**: 수화기로 구매·배송구 수령, 소품실 무제한 보관. 소지 개수는 [부상 규칙](../Decisions/injury-rules.md)의 팔 개수 규칙을 따른다. 리타이어·런 실패 시 사라짐(물려줄 선반 4칸만 다음 세대로).
- **탈출**: 백스테이지 4단계(진행도 런 동안 유지, 1개 이상은 다른 시간대 결과물 필요). 살아 있는 전원이 입구에 모여 개시 → 탈출로(약 10분). 한 명 이상 하역장 도착 = 성공. 엔딩은 전원 탈출 / 희생 탈출(트루 엔딩 미정).
- **세대 교체**: 남는 것 = 이전 세대 이름·사진·흔적 위치, 물려줄 선반 기물. 초기화 = 탈출 진행도, 공동 자금, 묘기 반복 횟수, 스케줄, 기물, 부상.

## 미정

가이드 쉬는 시간 길이, 트루 엔딩, 난이도 3축의 묘기 공통 적용 여부(공연장 협의), 보상·가격 수치(보상 시스템 문서 예정).
