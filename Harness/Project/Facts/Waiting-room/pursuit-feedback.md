# 4인 피드백 후속 구현

## 언제 읽나
추격자의 외형/바닥 신호/네트워크 위치 튐/포획 후 관전을 수정할 때.

- `PursuitFeedback`의 근접 외곽선은 제거. 화면 테두리는 유지한다. 바닥 신호는 `PursuitAppearance`, 활성화 전 숨김, 순찰/복귀 흰색·청각 조사/수색 노란색·발견 준비/추격/포획 빨간색. 실제 FOV와 동일한 forward 축을 쓰지만 표시 크기는 탐지 범위와 별도다.
- 기본1.75m/밝기.32/흐림.65. 표시 각도는 CurrentStageRules.FieldOfView를 자동으로 따른다. 낮은 채도의 회백색·황토색·적갈색을 쓰며 길이·밝기·흐림·상태색은 배치 창 단계/연출에서 조절한다. 화면 근처30m에서10Hz 지면/벽 검사, NonAlloc 버퍼 재사용. 실제 층 바닥 없는 점은 투명 처리한다.
- 바닥 신호 테두리는 UV 기반 픽셀별 smoothstep·sin 감쇠로 곡선 처리한다. 메시는 층/벽 검사만 맡는다. 표시 각도 독립값 DirectionCueAngle은 호환 데이터로만 숨겨 두고 사용하지 않는다. AlwaysNearest는 실제 탐지에서 시야각을 무시한다.
- 원화는 `_ThirdParty/curtaincall/Pursuit/Concepts/Reclaimed/`. `Reclaimed/`에 새 파생 메시·재질·목 장식·보강판·강화20클립. `PursuitAppearanceBuilder`가 기존10개 프리팹의 리그/기존모션을 유지하며 연결한다.
- FBX 원본 bind mesh는 Z-up, 스킨 적용 후 renderer 좌표는 Y-up이며100배 변환이 섞인다. 원본 메시 기준 정규화 좌표를 UV3에 저장하고 셰이더가 이를 읽어 봉합선/혈흔의 흔들림·고주파 깨짐을 막는다.
- Placement.Size는 소형1/중형1.16. 외형만 변경, 순찰/포획/속도 규칙 공유. AdvancedAppearanceStage 기본3부터 목 장식·걷기/달리기 교체. BloodPerCapture 기본.28이며 호스트 포획 완료 횟수를 전달하고 기존 유혈 설정을 따른다. ResetStep에서0으로 초기화.
- 현재 통신 v4: 상태는 바이너리 신뢰성 전달4Hz+행동 전환(전등 이벤트·치트·포획 누적·poseEpoch 포함), 위치는 기존20Hz 비신뢰성16체/540byte 이내 분할. 두 경로 모두 준비 알림을 보낸 클라이언트에게만 전송한다. 생성/초기화 epoch와 캠페인 단계를 확인하고 호스트 시간 역순 샘플은 버린다. 150ms 여유,100ms 제한 예측을 유지한다. 구버전 빌드와 혼용 불가. 원격 포획은 [피해자 접촉 보고/호스트 확정](pursuit-capture-contact.md)을 따른다.
- 관전은 포획된 대상을 제외한다. `CameraViewDirector`가 관전 중 사망자 방의 시점 요청을 제외하고 생존자 중심의 마우스 시점/벽충돌을 적용한다. 대상이 없으면 마지막 사망 카메라 위치에서 시선만 회전한다. 메뉴 InputGate는 유지한다.
- 최종 검증과 원격4인 미검증 범위는 Task log를 따른다.
- F9 대기실 치트: DebugSetInvulnerable은 새 포획만 막고 탐지/추격/생존 인원에는 영향 없음. DebugSetRecognition(false)는 시야·발소리·AlwaysNearest 및 기억한 조사/추격을 해제하되 현재 위치·순찰 순서는 유지한다. 이미 잡힌 인원은 두 옵션으로 구출하지 않으며 기존 타이머 초기화로 해제한다.
- 위 치트는 호스트/Dev/RestTime에서만 변경 가능, 전원 적용·Snapshot으로 상태 전달. 타이머 조정/철회는 옵션 유지, 다른 캠페인 단계·새 런·Dev 해제에는 기본값(무적OFF/인식ON). 저장 에셋에는 기록하지 않는다.
- Placement.ActivationStage는 마네킹별 활동 시작1~4단계(기본1). 기존 배치/배치 없는 방 스폰은1단계를 유지한다. Actor.IsActivated는 현재 단계와 배치 값을 비교하고, 진행 중 포획은 완료까지 유지한다. 도달 전 시야/청각/포획·방향 표시·강화 외형은 숨긴다.
- 각성 시간은 전역 추격 경과시간이 아니라 각 마네킹의 활동 시작부터 센다. 늦게 활동하는 마네킹도 AwakeningSeconds를 거친다. 치트 단계 하향은 현재 위치/순찰 순서에서 정지, 다시 도달하면 재각성. 타이머 철회는 기존 ResetActor로 배치 위치 복귀. 클라이언트는 공유된 단계/모션과 씬의 동일 배치 값으로 대기/외형을 표시한다.
