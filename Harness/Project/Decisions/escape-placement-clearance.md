# 탈출로 배치 간섭 금지

탈출로 씬의 벽·발판·줄·그네·조명·설비를 추가/이동/수정할 때 읽는다.

- 에셋끼리 불필요하게 겹치거나 관통하는 배치를 만들지 않는다. 플레이어가 벽/설비를 통과하는 배치도 금지한다.
- 접이교처럼 눈에 보이는 구조물은 전개/회수 중에도 실제 충돌을 유지한다. 회전 갱신을 플레이어 이동보다 먼저 적용하고 물리와 동기화한다.
- 착지 보완용 벽/받침을 만드는 경우 외줄과 겹치지 않게 한다. 외줄 위에 넓은 착지 발판을 덧대 난이도를 낮추지 않는다.
- 2026-11-01 추가 수신면5개와 현수 지지는 철회한다. 외줄 색의 시인성과 착지 지지 폭을 소폭 보완한다.
- 그네는 봉/줄 정지 위치뿐 아니라 허용 반동 각도·탑승 자리 전체의 몸통 공간과 화염 범위를 확인한다. 이동하면 첫 잡기 접근도 유지한다.
- 조명/배관의 의도된 벽면 부착·구조물 접합은 관통 장식과 구별한다. 기능·참조가 없는 중첩 줄/전선·조명은 정리한다.
- 검사는 실제 형상·충돌체/피해 범위와 참조를 기준으로 한다. 일부 구간의 정적 검사를 맵 전체/실제 멀티플레이 검증으로 주장하지 않는다.
