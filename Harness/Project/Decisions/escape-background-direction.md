# 탈출로 배경 방향

## 언제 읽나

탈출로 공통 배경을 수정하거나 이후 B/C 공간 변형을 제작할 때.

- 공연장에 이어지는 압도적인 규모, 긴 콘크리트 공간과 꺾이는 일방향 진행을 유지한다.
- 2026-10-27 후속: 사용자는 “규모는 큰데 압도감이 부족함”으로 확인하고 03 첫 진입 개선을 승인했다. 낮은 진입부에서 공동이 드러나고, 전경·중경·후경의 겹침과 사람 크기 점검 구조, 암부·도착점의 빛으로 규모를 체감하게 한다. 전체 크기를 더 키우는 작업은 이번 승인에 포함하지 않는다.
- 영화 `Curve` 배경처럼 콘크리트 자체가 분명히 느껴지는 공간을 원한다. 강한 주황빛·갈색보다 중성 회색의 큰 면을 우선한다.
- 내부는 먹구름 낀 아침·낮처럼 칙칙하고 어둡되, 이동할 공간이 보이지 않을 정도로 어둡게 하지 않는다.
- 갈대밭 탈출구는 햇빛이 강한 밝은 외부다. 내부와 대비되는 해방감·안정감을 준다.
- 별도 추격자 전용 통로는 필요하지 않으며 주 진행 공간을 더 넓힌다. 구체적인 확장 배율과 제작 치수는 Task의 구현값으로 관리한다.
- 사람 크기는 현재 플레이어블 캐릭터 모델을 기준으로 한다. 기본 눈높이는 유지한다. 2026-10-28 사용자 요청으로 탈출로 배경 검토용 자유 비행을 추가하며, 이전의 미리보기 기능 금지 중 이 요청만 대체한다. HUD·순간이동·자동 복귀는 추가하지 않는다.
- 현재 범위는 배경 맵이다. 묘기·AI·탈출 규칙 구현 완료와 구분한다.
- 플레이 테스트는 사용자가 직접 한다. AI는 별도 플레이 테스트를 수행하지 않는다.
- 2026-10-28 취침 전 사용자는 현재 분위기를 유지하며 설비의 사용 흔적·반복 배치·시선 유도를 보완하고 B/C 구조 제작까지 진행하도록 요청했다. 큰 제작 라벨은 Play에서 숨기고 편집 화면에 보존한다. B/C의 상세 배치·치수는 Task의 구조 제작안으로 관리한다.
