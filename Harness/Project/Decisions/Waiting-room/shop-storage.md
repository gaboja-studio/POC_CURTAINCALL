# 상점과 기물 보관

## 언제 읽나

상점 구매·배송, 소품실 가판대 보관을 만들 때. 소지 개수는 [부상 규칙](../injury-rules.md) #8, 기물 유지/소실은 [게임 흐름](../../Facts/game-flow.md).

## 결정

- 상점(기획서 예시 배치 3번 공간)은 비대면이다.
  - 수화기: 벽면 상단. 전화를 걸어 구매한다.
  - 배송구: 수화기 하단. 구매한 물건이 배송되어 바닥에 떨어지고, 상호작용으로 옮길 수 있다.
- 판매 범주: 신체 복구 서비스(M2에서 서비스는 이것 하나), 공연에 필요한 도구, 탈출을 위한 도구.
- **이용 시간**(M2): 기물 구매는 **밤 정비에만** 할 수 있고 쉬는 시간에는 구매할 수 없다. 서비스(신체 복구)는 모든 쉬는 시간과 밤 정비에 언제든(공연 중 제외, [밤 정비와 서비스](night-maintenance.md)). 현재 구현(M2 미반영): 상점 구매·수령은 공연 중만 막는다(`WaitingRoomShop.InPerformance`).
- 보관(M2에서도 그대로): 직접 소지하거나 소품실(4번) **가판대**(옛 이름: 물려줄 선반, 4칸)에 놓는다. 가판대에 놓은 물건은 초기화되지 않고 다음 세대까지 보관된다([게임 흐름](../../Facts/game-flow.md)의 세대 교체 계승 4칸, 2026-10-15 PM). 가판대 밖 소품실 보관은 게임 흐름대로 무제한이며 세대 교체 때 초기화된다. 코드 이름(`HandoverShelf*`)은 그대로.

## 이유

비대면 구조로 주최측과 공연자 사이의 위계를 간접 체험시키고, 비도덕적인 환경에서 벗어나야 한다는 탈출 동기로 잇는다.

## 화폐와 새제품 가격 (2026-10-27 확정)

- 화폐는 개인 지갑이 아닌 팀 공동 자금 **토큰**([보상 규칙](../reward-rules.md)).
- 새제품 가격(토큰): **구조장갑100 / 끈끈이장갑100 / 광대벌룬바지125 / 스프링신발175 / 머리핀50 / 말뚝뽑개75 / UV등75**.
- 2026-10-28 새제품 내구도 확정: 구조장갑5·끈끈이장갑3·광대벌룬바지4·스프링신발3·머리핀5·말뚝뽑개4·UV등3회. 실제 효과 성공 시1 차감, 마지막 효과 완료 후 파괴·슬롯 제거. 상세는 [기물 내구도](../item-durability.md).
- 효과 수치·접두사·쿨타임·발견품 내구도의 기존 초안·미정 상태는 유지한다. 변경 시 기물·보상 원문 함께 갱신. 구현·UI 연결은 이번에 확인하지 않았다.

## 아직 정하지 않은 것

상점 외형·구매/배송 상세 규칙·중고/판매 규칙·가판대 보관물 삭제 조건. M1 이후 상점 기획서에서 정한다(원문 5.1 #3). 위 7종 새제품 가격과 토큰 명칭은 미정 목록에서 제외한다.

## 바꾸려면

대기실 담당이 상점 기획서를 쓰면 PM이 이 파일을 갱신한다. 공동 자금·가격 체계는 시스템과 함께 정한다.
