# 대기실 미정·보류

## 언제 읽나

대기실 Task 범위를 정하거나, 구현 중 기획에 없는 규칙을 만났을 때. 미정 항목을 AI가 임의로 확정하지 않는다.

## 보류: 플레이어 상태·조작 (2026-10-13)

- 대기실 상태(대기·이동·달리기·점프·앉기·상호작용·모션)와 전이표는 **제안 단계**. M1 이후 탈출로 @RagSpirin·조작법 @MoHoDu·백스테이지 @gyumin9048-ctrl이 협의한다. 수치를 구현 기준으로 쓰지 않는다.
- 지금은 [공통 조작키](../control-keys.md)를 따른다. 제안 요약(참고만): 앉기 L Ctrl 토글·이동 50%·머리 위 장애물 시 일어서기 불가, 이동 종료 0.3초 후 대기, 달리기 해제 1초 감속, 점프 입력 지연 0.1초·체공 0.7초, 공중 앉기 무시, 앉기에서 상호작용하면 앉기로 복귀, 모션 미확정.

## 별도 기획서 (원문 5.1)

탐색 공간(백스테이지·탈출로 연결 오브젝트·동선), 전문가 서비스 상세, 상점(M1 이후), 대기실 상세(배치·시간대별 오브젝트·SFX/VFX/BGM/앰비언스), 모션(가리키기·환호·인사·앉기·눕기, M1 이후).

## 미확정 규칙 (원문 5.2)

1~3. 제한 시간 적용 범위·추격자·미도착 처리 → 게임 흐름 기준으로 정리됨([탐색 제한 시간](exploration-time-limit.md)). 추격 세부 수치는 시스템·백스테이지 협의.
4. 공연 종료 후 정확한 스폰 위치
5. 밤 정비 종료·다음 날 전환·세트리스트 미작성 처리
6. 세트리스트 중복 선택·확정 권한·동시 수정
7. 4일차 추격자 시점·탈출 가능 시간·런 실패 판정
8. 호스트 이탈·공연 중 합류·사망자 복귀(재접속은 [런 규칙](../run-rules.md) #3로 비허용)
9. 맵 2개 구분과 공간별 접근 조건

## 확정·보류 (원문 5.3)

확정 유지: 전문가 서비스 밤 이용. 보류: 플레이어 상태·조작(M1 이후), 시간대별 오브젝트(상세 기획서). 원문의 "0초 자동 공연 시작"·"전원 7번 도착 조기 시작"은 게임 흐름과 충돌해 적용하지 않는다([탐색 제한 시간](exploration-time-limit.md)).
