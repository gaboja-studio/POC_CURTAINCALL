# 이전 단원 전시

## 언제 읽나

폐기물 보관소의 유해·코스튬·인형탈 배치를 만들거나 수정할 때.

## 결정

- 이전 세대 코스튬과 인형탈을 쓴 단원은 4명. 서로 다른 자세이며 팔·다리·머리의 결손이 있다.
- 사용자 후속 정정: 공간 여기저기 흩어 놓지 않고 **전시물·마네킹처럼 캐비닛 옆 빈 벽면에 일렬로 진열**한다. 기존 기획의 자세는 유지한다.
- 주변은 방치된 연구실과 로커룸 창고. 격벽으로 정렬된 구역, 만재 선반과 캐비닛, 컴퓨터·대형 모니터·깨진 액자·스파크·책상 위 이전 단원의 기록책이 있다.
- 자세는 관절 단위로 고정하고 바꾸는 것은 인물 전체 방향뿐이다. 누운 인물은 벽과 나란히 둘 수 있다.
- 구체적 전시대 치수·번호판·4명 순서는 구현 선택이며 사용자 확정 치수가 아니다.
