# 탐색 제한 시간

## 현재 우선 규칙 (2026-11-10 사용자, Task-115)

- 모든 쉬는 시간·밤 정비는 기본 300초. 제한시간 만료 뒤 추격을 시작한다.
- 실제 런은 각 휴식/정비 시작 시 전원의 카메라 가이드 완료 ACK를 기다린다. 마지막 복귀 블렌드·잠금 안내 대기열까지 끝나야 완료다. 안내 OFF도 전환 차폐/남은 카메라 복귀가 끝난 뒤 ACK한다. ACK는 세대·일차·시간대·휴식 종류·공연 칸을 검증하고 나간 인원은 집계에서 뺀다.
- `WaitingRoomSettings`의 쉬는 시간/정비 시간 문구 설정에 60·30·10초 알림 제목/본문, 추격 단계별 알림과 팀 임무 제목/본문을 따로 둔다. 팀 임무의 `{stage}`, `{escape}`, `{sleep}`는 가능한 조건의 안내로 치환된다. 정비 치트도 타이머/추격 조작을 지원한다.
- 방/구역별 제한시간 안전지대를 편집할 수 있다. 생존한 비수면 플레이어 전원이 안전지대에 있으면 타이머가 멈추고, 한 명이라도 비안전 구역에 있으면 남은 시간부터 다시 흐른다. 마지막 아침도 편집 설정을 따른다.
- 안전지대는 제한시간 정지 구역이다. 이미 시작한 추격을 취소하거나 공격을 막지는 않는다. 수면자 공격 제외는 [밤 정비](night-maintenance.md)의 별도 규칙이다.
- 편집 메뉴: `Tools > Curtain Call > Waiting Room > Safety Zones`. 실제 `ExplorationTimerZones` 방 콜라이더를 층별 평면도에서 선택·다중 선택·더블클릭 전환할 수 있다.
- 선택 구역/현재 층/전체의 안전 지정·해제, 구역 밖 안전 여부, Undo, 씬 저장을 제공한다. 전체 지정/해제는 구역 밖 설정도 함께 바꾼다. 플레이 중에는 조회만 한다.
- 안전·비안전 영역이 겹치면 기존처럼 안전 구역을 우선한다. 여러 층에 걸친 연결 구역은 동일 구역 설정을 공유한다.

아래의 안전지대 없음·밤 추격 없음은 이전 기획 기록이며 위 규칙이 우선한다.

## 언제 읽나

쉬는 시간의 제한 시간·시계·경보·추격·공연 시작을 만들거나, 대기실 기획서 4.1과 대조할 때. 공통 결정은 [런 규칙](../run-rules.md) #1·#6.

## 결정

- 2026-10-27 M2(쉬는 시간 A안/B안을 모두 삭제하고 하나로 정함):
  - **시작**: 쉬는 시간이 시작되면 **바로 시계가 흐른다**. 팀 공용, 1회 실제 길이 5분(300초, 잠정·세팅 값). 시각 구성은 [스케줄표](schedule-board.md)의 하루 시계.
  - **안전지대 없음**: 쉬는 시간에는 대기실도 안전하지 않다. 추격자가 없는 안전한 시간은 밤 정비다.
  - **복귀**: 시간 안에 **무대 입구 통로**에 들어가는 것 하나뿐이다. 들어가면 살아서 공연에 합류한다.
  - **종료**: 시간이 끝나면 추격자가 대기실에 풀린다. 잡히면 잡힘 규칙(팔 하나만 남기고 무대로 끌려감, 이미 외팔이면 사망, [부상 규칙](../injury-rules.md) #5).
  - **유지**: 종료 60초 전 **소집 경보**(종소리·방송), 30초·10초 전 방송(방송은 위험 알림에만, 게임 흐름 7-2). 늦은 사람이 정리될 때까지 공연 시작 대기, 전원이 무대 입구 통로에 들어가면 조기 시작.
  - 적용: 아침·낮 쉬는 시간. 밤 정비에는 없다([밤 정비](night-maintenance.md)). 1일차 낮은 가이드 쉬는 시간: 대기실 기능 안내, 서비스·상점 화면 안내(기물 구매는 밤 정비).
  - 표시: 흘러가는 모습은 원형 시계로 보여 주고 남은 시간도 표시한다(화면 우측 하단, UI 세부는 대기실 담당).
  - 삭제: A안/B안, "대기실에 있기"로 복귀, 대기실 재진입 불가, 첫 사람이 대기실을 나가면 300초 시작, 가이드의 대기실/백스테이지 분리 안내.
- 용어 "탐색 제한 시간"(2026-10-15)은 유지한다. M2에서 바뀜: 이전 "무대 입구 통로부터 백스테이지"(백스테이지는 대기실로 통합).
- **적용하지 않는 대기실 기획서 4.1 내용**(2026-10-15 PM 원문 오류 판정): 무대 입구 진입 시 시작, 잔여 180초 통로 추격자 등장, 11초 알림, 0초 단장 컷씬 강제 시작과 난이도↑·호응 0 패널티, 7번 공연 스테이지 입구 도착 조기 시작, 5.3의 "0초 자동 공연 시작".
- **현재 구현(M2 미반영)**: 공통 세팅 `restTimerMode` A/B(기본 B). B안은 `WaitingRoomExitWatch`가 대기실을 나간 첫 사람을 보고 `NotifyLeftWaitingRoom`으로 시작하며, 더미 안전 조건(`DummyExploration.IsSafe`)은 무대 입구(A안은 대기실 포함)다.

## 이유

M2에서 대기실과 백스테이지를 합쳐 대기실 안에서 탐색·탈출을 시도하므로, 쉬는 시간 전체가 시간 압박을 받는 위험한 시간이 된다.
