# 탐색 조작과 숨은 길 벽

## 언제 읽나

대기실 탐색 상호작용(벽 파괴·잠금·덮개·단서)과 탐색 도구 배치를 만들 때. 도구 사용 횟수는 [기물 내구도](../item-durability.md).

## 결정

- **조작**: 모든 탐색은 공연에서 쓰던 상호작용 키 **F**로 한다.
- **숨은 길 벽**: 도구는 **빠루**(= 천막 말뚝 뽑개). 손에 들고 F를 연타하면 한 번에 한 번 내려친다. **6번**이면 무너지고, 칠 때마다 벽이 더 낡고 금이 간다.
- **진행 유지**: 손을 떼도 쌓인 타격은 그대로 남고 팀 모두에게 같다(런 동안, 세대 교체 때 초기화). 여럿이 이어 쳐도 된다.
- **사용 횟수**: 벽이 무너지는 그때에만 연 사람의 빠루가 1 준다.
- **첫 벽**: 화장실 무너진 벽(화장실 → 배관 기어가기 통로). 무너지기 전에는 막혀 있다.
- **외관**(2026-10-29 사용자): 무너지기 전에는 옆 벽과 똑같아 보여야 한다(타일·콘크리트·철제 띠가 이어지고 문틀·깨진 가장자리 없음). 알아볼 단서는 가까이 가면 나타나는 공통 상호작용 외곽선뿐이다. 깨진 가장자리는 무너진 뒤 드러난다.
- **금**(2026-10-29 사용자): 부서질 때의 금은 거미줄처럼(방사형 금 + 고리 금) 같은 충격점에서 칠 때마다 커진다.
- **시험용 빠루**: 세대마다 작업실 바닥에 하나(발견품 — 기물 목록의 발견품 내구도, 초안 1회). 상점 정식 품목은 Task-076 상점 담당.

## 구현 위치

`WaitingRoom/Exploration/`의 `BreakableWall`·`ExplorationState`(호스트 판정·공유)·`FoundItemSpot`, 생성 `WaitingRoomLayoutA.M2.cs`(`BuildRestroomBreach`·`PlaceWorkshopCrowbar`·`EnsureExplorationState`).

## 아직 정하지 않은 것

머리핀 자물쇠·말뚝 뽑개 판자/덮개·UV 등 숨은 표식의 구조 A 위치, 실제 효과음, 타격 중 피격·추격(보류).
