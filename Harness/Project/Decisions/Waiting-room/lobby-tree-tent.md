# 로비 트리 천막

## 언제 읽나

대기실 로비의 중앙 장식·컨셉아트 천막을 만들거나 고칠 때.

## 결정

- 컨셉아트의 큰 중앙 천막 대신, **크리스마스트리 느낌의 작은 찌그러진 원뿔형 서커스 천막**(1인용 크기)을 둔다. 초라해야 하고 너무 크면 안 된다.
- 천막 아래에 서커스 도구와 상자가 선물처럼 널브러져 있다.
- 기존 휴게 공간과 로비 공간 구조는 그대로 둔다.
- 크기(지름 2.3m·높이 2.75m)·전구·소품 구성은 구현 선택이다.
