# 대기실 추격 시스템

## 언제 읽나
탐색 시간 만료, 추격·포획·관전, 집결 인원, 다음 장소 부활 또는 4일차 종료를 수정할 때.

## 결정
- M2 데모의 탐색 제한시간(현재 5분) 만료 후 전시 마네킹이 움직이며 추격한다. 만료만으로 즉시 공연에 보내거나 전원을 일괄 포획하지 않는다.
- 추격 활성화 후에는 타이머 정지/안전 구역도 추격 가능하다.
- 남은 생존자 전원이 공연장 입장 구역 또는 탈출로 입장 구역에 모여 실제 장소 전환하면 추격을 종료한다. 잡힌 플레이어는 관전하며 집결 인원에서 제외하고 선택한 목적지로 외팔 상태로 함께 이동한다.
- 1~3일차 전원 포획은 연출 완료 후 전원 외팔 상태로 다음 공연에 이동한다.
- 4일차 아침도 탐색 및 만료 후 추격·탈출이 가능하다. 기존 데모 조기 종료 예외보다 이 결정이 우선한다. 4일차에 전원 포획되면 즉시 런 실패한다.
- 추격 시작 후 1분 시야 확대, 2분 벽 투시, 3분 최인접 플레이어를 항상 추격한다. 단계 변화는 시스템 알림으로 전달한다.
- 포획 시 넘어뜨림·순차 절단·잡힌 방만 조명 점멸·외팔 후 사라짐/관전 연출이 다른 플레이어에게도 보인다.
- 방별 마네킹 배치/인원/순찰/담당은 씬 컴포넌트 또는 에디터 도구로 쉽게 바꾼다. 상체는 이동 전방 ±90도 안에서 시선을 따르고 하체는 이동을 따른다.
- 작업 씬은 WaitingRoomBase 전체 복제본을 임시 연결하여 사용한다. 지정 Synty 마네킹 10종을 사용하며 제작·파생 에셋은 _ThirdParty에 보관한다.
- M2에서는 포획 후 동료 구출이 없다. 초기값은 탐색 방마다 1체, 방 간 이동 허용, 시야 10m→20m, 달리기는 온전한 플레이어 최대 달리기 속도의 1.2배. 단계별 시작 시간·탐지·이동 수치는 설정에서 조절한다(2026-11-02 사용자 답변).

## 포획 범위·오르기 (2026-11-12 사용자 결정, Task-20261112-117)
- 추격 중인 추격자는 쫓는 대상이 아니어도 포획 범위에 닿고 가로막히지 않은 플레이어를 잡는다.
- 포획 범위는 수평 `CaptureRadius` + 높이 범위 `CaptureBelow/Above`(GameSettings). 트램펄린 표면·낮은 소품 위는 잡고, 높은 반동·점프 공중은 잡지 않는다.
- `ClimbFromStage`부터 `ClimbMaxHeight` 이하 단차·소품 윗면을 오른다. 2026-11-12 사용자 재결정: 1~4단계 언제든 오른다(ClimbFromStage=1). 드럼통 1.94m 등 실제 소품을 위해 최대 높이 2.5m. 대기실 씬·오브젝트·NavMesh 에셋은 수정하지 않는다(다른 작업자가 배치 고도화 중). NavMesh 윗면은 실행 중 링크, NavMesh 없는 좁은 윗면은 충돌체 검사 직접 오르기. 오르내리는 동안은 잡지 않는다.
- 2026-11-12 사용자 재결정: 높이 제한 없이 오른다. `ClimbMaxHeight` 0 = 제한 없음(기본), 양수면 그 높이까지. 2.5m 이하는 기존 한 동작, 초과분은 같은 속도(1.5m/`ClimbSeconds`)의 벽 타기. 높은 곳 뛰어내리기는 2.5m 넘으면 높이 제곱근 비례.

## 앉아 숨기 (2026-11-12 사용자 요청, Task-20261112-117)
- 앉은 플레이어의 몸(현재 앉은 캡슐)이 추격자 눈에서 장애물에 `CrouchHiddenCoverage`(GameSettings, 기본 0.8) 이상 가려지면 시야에 보이지 않는다. 0이면 끈다. 서 있는 플레이어는 기존 몸 중심 한 점 판정.
- 시야 판정만 바꾼다(발소리·포획 접촉은 기존 규칙). 벽 너머 탐지·위치 무관 추격 단계는 그 단계 규칙이 우선한다(현재 설정 3·4단계).

## 인식 상태 눈 표시 (2026-11-04 사용자 시안 컨펌·실제 적용 승인)
- 자기 조작 플레이어 기준으로만 마네킹 머리 위에 표시하며 네트워크 동기화 요소가 아니다. 아이콘은 머리보다 조금 작다.
- 인식 범위 진입 시 감은 흰 눈이 0.5초 페이드인, 반응 범위 이탈 시 0.5초 페이드아웃 후 숨김.
- 일반→경계: 0.5초간 눈을 뜨며 노랑, 경계 중 유지. 일반 복귀: 반대로 감으며 흰색.
- 발견/추격: 혈색 빨강과 약한 발광. 종료하면 경계색으로 돌아가거나 0.5초간 감으며 일반 복귀.
- 2026-11-05 사용자 요청: 흰 눈 또는 숨긴 상태에서 곧바로 추격하면 전환 시간을 두지 않고 빨간 뜬 눈으로 즉시 표시한다. 복귀 중 가까운 플레이어를 잡지 못하는 동작도 버그로 수정한다.
- 같은 날 후속 재현: 로비→공연장 통로에서도 복귀 중 시야 안의 플레이어에게 반응해야 한다. 눈의 노랑→빨강은 바닥 표시와 타이밍을 맞춘다(자기 대상 공격 준비부터 즉시 빨강 적용).
- 원본 스프라이트는 모두 흰색, 별도 아웃라인 없음. 색상은 Unity 에디터에서 적용한다. 실제 적용은 이미지·애니메이션 시안을 사용자가 컨펌한 뒤 진행한다.
