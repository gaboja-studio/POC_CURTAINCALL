# 스케줄표와 세트리스트

## 언제 읽나

스케줄표 상호작용·UI, 세트리스트·난이도 단계 작성·저장, 일차별 공연 적용, 하루 시계를 만들 때.

## 결정

- **하루 시계**(M2, 원형 시계): 오전 8~10시 아침 쉬는 시간 → 10~12시 오전 공연 → 오후 12~2시 낮 쉬는 시간 → 2~4시 오후 공연 → 4~8시 밤 정비(이때만 타이머 없음) → 그 외 수면(모두 침대에 누운 뒤 다음 날로 넘어가는 연출, [밤 정비](night-maintenance.md)). 쉬는 시간 1회 실제 길이는 5분(잠정, [탐색 제한 시간](exploration-time-limit.md)).
- 1일차: 도입 컷씬 → 오전 공연(줄타기) → 낮 쉬는 시간(가이드) → 오후 공연(인간 대포) → 밤 정비. 아침 쉬는 시간 없음. 4일차는 아침 쉬는 시간만(마지막 탈출 기회). 쉬는 시간 6회 = 탈출 기회 6회.

| 일차 | 공연 1 | 공연 2 | 구분 |
|---|---|---|---|
| 1 | 줄타기 | 인간대포 | 고정(학습), 1단계 |
| 2 | 선택 | 선택 | 1일차 밤 작성 |
| 3 | 선택 | 선택 | 2일차 밤 작성 |
| 4 | 없음 | 없음 | 3일차 밤 작성 가능, 실행 안 함 |

- 4일차 아침 쉬는 시간에 탈출하지 못하면 추격자 등장 → 런 실패. 세트리스트는 밤 정비 시간에만 작성하며 **저장 전까지 수정 가능, 저장 후 수정 불가**.
- **난이도 단계 선택**(M2, 반복 횟수 자동 상승을 대체): 묘기마다 1~3단계. 세트리스트를 정할 때 묘기별로 그 묘기에서 **클리어한 단계의 다음 단계까지** 고른다(1단계 클리어 → 1·2, 2단계 클리어 → 1~3, 못 하면 안 열림). 단계가 높을수록 팀 호응 게이지의 1인 상한이 오른다. 런 상태는 "묘기별 클리어한 최고 단계"를 기록한다.
- 상호작용: 로비 스케줄표로 이동 → F → 카메라 클로즈업 → 플래너 노트 UI → 일정 확인 → (밤) 세트리스트 작성. UI: 이전 세대가 쓰던 낡은 플래너 노트(누렇게 변색, 찢긴 페이지·헤진 가장자리·끼워진 낱장, 얼룩·먼지). 시간대별 공연·쉬는 시간 표시. 전문가 열·일차별 전문가 표시는 삭제(M2).
- **현재 구현(M2 미반영)**: `ScheduleBook.Difficulty`가 1일차부터 같은 묘기가 나온 횟수로 단계를 자동 계산(최대 3)한다.

## 이유

다음 날 공연과 난이도를 직접 골라 위험과 보상 사이의 전략적 선택을 주고, 자원 계획을 세우게 한다. 4일차 일정을 쓸 수 있게 해 공연이 계속될 것처럼 보이지만 실제로는 탈출해야 하는 상황을 연출한다.

## 아직 정하지 않은 것 (원문 제안, 미확정)

- 같은 공연 하루 2회 허용 여부(원문의 "반복 시 난이도 상승"은 M2 단계 선택으로 대체). 확정: 확정 버튼으로 저장 / 미작성: 작성 전까지 다음 날 진행 안 함 / 권한: 모두 보고 호스트가 최종 확정 / 멀티 동시 수정 처리.
- 4일차 추격자: 아침 쉬는 시간 종료 시 등장, UI는 이전과 같게 작성하되 실행 단계에서 차단.

## 바꾸려면

대기실 담당이 원문을 고치고 PM이 갱신한다. 일차별 고정 공연·난이도 단계 규칙은 게임 흐름(시스템) 결정이다.
