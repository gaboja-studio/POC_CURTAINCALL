# 스케줄표와 세트리스트

## 언제 읽나

스케줄표 상호작용·UI, 세트리스트 작성·저장, 일차별 공연 적용을 만들 때.

## 결정

- 하루: 아침 쉬는 시간(당일 일정 확인) → 공연 1 → 낮 쉬는 시간(다음 공연 확인) → 공연 2 → 밤 재정비(다음 날 세트리스트 작성·수정).
- 일차별 일정:

| 일차 | 공연 1 | 공연 2 | 전문가 | 구분 |
|---|---|---|---|---|
| 1 | 줄타기 | 인간대포 | 의료 | 고정(학습) |
| 2 | 선택 | 선택 | 시설 담당자 | 1일차 밤 작성 |
| 3 | 선택 | 선택 | 의료 | 2일차 밤 작성 |
| 4 | 없음 | 없음 | 없음 | 3일차 밤 작성 가능, 실행 안 함 |

- 4일차 아침 쉬는 시간에 탈출하지 못하면 추격자 등장 → 런 실패.
- 세트리스트는 밤 재정비 시간에만 작성하며 **저장 전까지 수정 가능, 저장 후 수정 불가**.
- 상호작용: 로비 스케줄표로 이동 → F → 카메라 클로즈업 → 플래너 노트 UI → 일정·전문가 확인 → (밤) 세트리스트 작성.
- UI: 이전 세대가 쓰던 낡은 플래너 노트(누렇게 변색, 찢긴 페이지·헤진 가장자리·끼워진 낱장, 얼룩·먼지). 시간대별 공연·쉬는 시간, 일차별 전문가 표시.

## 이유

다음 날 공연을 직접 골라 전략적 선택을 주고, 전문가 일정과 함께 보며 자원 계획을 세우게 한다. 4일차 일정을 쓸 수 있게 해 공연이 계속될 것처럼 보이지만 실제로는 탈출해야 하는 상황을 연출한다.

## 아직 정하지 않은 것 (원문 제안, 미확정)

- 같은 공연 하루 2회: 허용하고 반복 시 난이도 상승 제안([게임 흐름](../../Facts/game-flow.md) 난도 단계와 연결 확인).
- 확정: 확정 버튼으로 저장 / 미작성: 작성 전까지 다음 날 진행 안 함 / 권한: 모두 보고 호스트가 최종 확정 / 멀티 동시 수정 처리.
- 4일차 추격자: 아침 쉬는 시간 종료 시 등장, UI는 이전과 같게 작성하되 실행 단계에서 차단.

## 바꾸려면

대기실 담당이 원문을 고치고 PM이 갱신한다. 일차별 고정 공연·전문가 배치는 게임 흐름(시스템) 결정이다.
