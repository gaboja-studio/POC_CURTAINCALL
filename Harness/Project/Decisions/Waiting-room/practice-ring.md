# 연습실 공연 링

## 언제 읽나

연습실 링·연습 장치·관중석 배치를 만들거나 고칠 때.

## 결정

- 링은 연습실 크기에 맞게 2.5배(16m → 40m). 사용자 선택: **바닥 평면만 키우고 높이(데크 0.6m)·장비 크기는 유지**하며, 외줄은 링에 맞게 2.5배로 늘린다.
- 외줄타기 옆에 트램펄린과 인간 대포가 있다. 현재 구현은 외줄(링 중심 동서) 남쪽에 대포 레인(동쪽 발사·착지 매트·안전망), 북쪽에 트램펄린.
- 링 둘레에 관중석을 둔다. 출입구·링 계단·조명탑 자리는 비운다.
- 기존 사다리 충돌 보정·계단은 링과 함께 옮겨 유지한다. 중앙 천막은 돔과의 간섭 때문에 크기를 유지했다(구현 선택).
- 연습 기능(발사·반동·판정) 연결은 별도 범위다.
