# 최초 리허설과 첫날 연결

## 언제 읽나
첫날 캠페인·대기실 출입 제한·안내 완료·임시 퀘스트를 수정할 때.

## 확정 결정
- 서명 → 연습실 리허설 → 완료 후 무대 입구 전원 집결 → 첫 외줄 공연 → 대기실 튜토리얼 → **1일차 두 번째 공연** → 밤 정비 튜토리얼 순서다.
- 리허설 제작본과 공연과 같은 조작을 유지한다. 추락하면 해당 소구간 출발 위치로 복귀한다.
- 기능 연결을 먼저 마치고 검증과 대기실 버그 수정을 한다.
- 리허설 중 연습실 입구는 닫힌다. 완료하면 열고 전원이 나온 뒤 다시 잠근다. 첫 공연 전 다른 구역·상호작용 제한은 첫 공연 뒤 대기실 튜토리얼 때 해제한다.
- 전원이 대기실 연계 안내를 마치기 전 탐색 타이머와 집결에 의한 다음 공연 전환을 막는다. 임의의 120초 자동 완료는 제거한다.
- 최초 리허설 포기 투표는 제거한다(과반수 카운트다운은 인간 대포 리허설 규칙).
- 이번 기능 연결 범위에 임시 퀘스트 패널을 허용한다. 패널·퀘스트·내용은 사용자가 나중에 편집할 수 있어야 한다.

## 편집 위치
- `Assets/Resources/Settings/WaitingRoom/WaitingRoomTexts.txt`: 리허설 `rehearsal.*`, 첫날 연결 `first-day.quest.*`, 우측 패널 수치 `first-day.panel.*`.
- 좌측 대기실 튜토리얼은 기존 `WaitingRoomTutorialTexts.txt`와 `WaitingRoomTutorialPanel.txt`를 쓴다.
- 수치는 플레이를 다시 시작할 때 읽는다. 임시 퀘스트는 실제 상태를 표시하며 별도 완료 버튼·보상 규칙은 추가하지 않는다.
