# 열쇠 소지 규칙

- 열쇠는 구매 불가 기물이며 탐색 중 드랍된 것을 획득하는 도구다.
- 다른 도구처럼 슬롯에 들어가고, 지니기·선택·사용할 수 있다.
- 팀 공유 획득 이력만 남기고 슬롯을 차지하지 않던 Task-088의 이전 해석은 폐기한다.
- 열쇠 획득, 슬롯 표시, 구매 목록, 문 사용을 수정할 때 이 결정을 확인한다.
