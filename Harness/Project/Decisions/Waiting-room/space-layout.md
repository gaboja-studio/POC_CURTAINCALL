# 대기실 공간 구성

## 언제 읽나

대기실 맵 배치·스폰 위치·장소 전환을 만들 때. 공간 경로는 [작업 공간](../space-workspaces.md), 전환 데이터는 [런 상태](../../Facts/run-state.md).

## 결정

- **통합**(M2): 대기실과 백스테이지를 **대기실** 하나로 통합한다. 기존 백스테이지가 하던 일(탐색, 장애물·단서, 탈출 4단계, 추격)은 대기실 안에서 일어난다. 담당 @gyumin9048-ctrl(MG seo) 그대로. 구현 구조(씬·폴더·브랜치)는 아직 백스테이지 분리([작업 공간](../space-workspaces.md)). **역할**: 공연 전후 거점, 재정비(상점·부상 치료·휴식), 자유 활동, 세계관 탐색(스토리 단서), 탐색과 탈출 시도. 상점·탐색·스토리·탈출 상세는 별도 기획서.
- **방 구조**(M2): 대기실의 방 구조는 **랜덤으로 구성**하고 **런마다** 섞는다. 탈출 진행도(탐색으로 열고 해금한 방·문 등)는 그 런 동안 유지한다. 런이 실패해 다시 시작하면 [가판대](shop-storage.md)(옛 이름: 물려줄 선반)의 기물만 남는다. **연결**(M2): 공연장 ← 무대 입구 통로 ← 대기실(랜덤 방들, 탈출 단계) → 탈출로 입구 → 탈출로 → 하역장. 공연 종료 후 자동으로 대기실 복귀, 모든 공연 전에 반드시 거친다.
- **진입**: 세션과 이를 유지하는 호스트가 있어야 한다. 최초 1회 도입 컷씬 + 외줄 클리어 뒤 진입. 세션 유지·공연 중이 아니면 대기실에서 시작, 공연 진행 중이면 대기실에서 자동으로 공연 스테이지로 이동. 복귀 시 대기 상태.
- **퇴장**: 쉬는 시간에는 시간 안에 무대 입구 통로에 들어가야 공연에 합류한다([탐색 제한 시간](exploration-time-limit.md)). 공연 시작 조건 충족 시 공연 구간으로 전환. M2에서 바뀜: 이전 "대기실 문을 나서면 백스테이지, 나간 캐릭터 재진입 불가".
- **기획서 예시 배치**(20348931의 고정 8곳, 맵 2개 구성안). M2 랜덤 방 구조에서 각 방의 쓰임을 참고하는 자료이며 고정 배치가 아니다. 숙소/화장실·분장실/소품실은 개발 규모에 따라 축소·제거 가능, 오브젝트 상세 배치는 대기실 상세 기획서로 분리:

| 번호 | 공간 | 핵심 |
|---|---|---|
| 1 | 대기실 로비 | 중앙. 원형 서커스 천막·안내판·스케줄표. 대기실 이동 시 스폰 |
| 2 | 숙소(+화장실) | 낡은 침대(밤 정비 종료 때 자기 침대에 누움)·사물함·옷장·화장실. 이전 세대 벽 낙서 |
| 3 | 상점 | 수화기(구매)·배송구(수령), [상점](shop-storage.md) |
| 4 | 소품실(+분장실) | 가판대(놓은 물건 초기화 안 됨)·낡은 인형/인형탈·분장 거울 |
| 5 | 폐기물 보관소 | 아카이브: 공연 기록 노트·이전 세대 코스튬·탈출 힌트 노트 낱장·망가진 기물 |
| 6 | 무대 입구 통로 | 긴 터널. 붉은 커튼 방들: 열림 = 출입 가능, 닫힘 = 불가 |
| 7 | 공연 스테이지 입구 | 거대한 붉은 커튼. 다음 공연 대기 장소 |
| 8 | 전문가 대기실 | 낡은 소파·탁자. 서비스 연출(A안) 방, 커튼 열림·황금빛 연출. 날짜별 전문가 등장은 삭제(M2) |

- **부활**: [부상 규칙](../injury-rules.md)대로 사망자는 다음 시간대 시작 때 대기실에서 **외팔 상태로 부활**(사망 전 몸과 무관). 원문 3.4.1의 "마지막 신체 결손 상태 유지"는 적용하지 않는다(2026-10-15 PM).
- **시간대**: 공연이 끝날 때마다 전원 대기실로 이동. 아침·낮·밤에 재정비·탐색·휴식. 일부 오브젝트는 시간대 전환에 맞춰 위치·상태와 조명이 바뀐다(상세 기획서). M1은 최소 기능만.
