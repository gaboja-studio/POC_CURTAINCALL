# 대기실 공간 구성

## 언제 읽나

대기실 맵 배치·스폰 위치·장소 전환을 만들 때. 공간 경로는 [작업 공간](../space-workspaces.md), 전환 데이터는 [런 상태](../../Facts/run-state.md).

## 결정

- **역할**: 공연 전후 거점, 재정비(상점·부상 치료·휴식), 자유 활동, 세계관 탐색(스토리 단서), 탈출 준비. 상점·탐색·스토리·탈출 상세는 별도 기획서.
- **연결**: 대기실 → 무대 입구 → 공연 스테이지 → (공연 종료 후 자동) 대기실 복귀 반복. 모든 공연 전에 반드시 거친다.
- **진입**: 세션과 이를 유지하는 호스트가 있어야 한다. 최초 1회 도입 컷씬 + 외줄 클리어 뒤 진입. 세션 유지·공연 중이 아니면 대기실에서 시작, 공연 진행 중이면 대기실에서 자동으로 공연 스테이지로 이동. 복귀 시 대기 상태.
- **퇴장**: 대기실 문을 나서면 백스테이지(무대 입구 통로부터)이며 [탐색 제한 시간](exploration-time-limit.md)이 시작된다. 나간 캐릭터는 쉬는 시간 종료까지 재진입 불가. 공연 시작 조건 충족 시 공연 구간으로 전환.
- **기획서 공간 8곳**(맵 2개로 구성, 구분은 미정). 6·7번은 대기실 문 밖 백스테이지 쪽이다(2026-10-15 PM):

| 번호 | 공간 | 핵심 |
|---|---|---|
| 1 | 대기실 로비 | 중앙. 원형 서커스 천막·안내판·스케줄표. 대기실 이동 시 스폰 |
| 2 | 숙소(+화장실) | 낡은 침대·사물함·옷장·화장실. 이전 세대 벽 낙서 |
| 3 | 상점 | 수화기(구매)·배송구(수령), [상점](shop-storage.md) |
| 4 | 소품실(+분장실) | 4단 선반(놓은 물건 초기화 안 됨)·낡은 인형/인형탈·분장 거울 |
| 5 | 폐기물 보관소 | 아카이브: 공연 기록 노트·이전 세대 코스튬·탈출 힌트 노트 낱장·망가진 기물 |
| 6 | 무대 입구 통로(백스테이지) | 긴 터널. 붉은 커튼 방들: 열림 = 출입 가능, 닫힘 = 불가 |
| 7 | 공연 스테이지 입구(백스테이지) | 거대한 붉은 커튼. 다음 공연 대기 장소 |
| 8 | 전문가 대기실 | 낡은 소파·탁자. 날짜별 전문가 등장, 커튼 열림·황금빛 연출 |

- 대기실에도 탐색 가능한 백스테이지가 있다. 숙소/화장실·분장실/소품실은 개발 규모에 따라 축소·제거 가능. 오브젝트 상세 배치는 대기실 상세 기획서로 분리.
- **부활**: [부상 규칙](../injury-rules.md)대로 사망자는 다음 시간대 시작 때 대기실에서 **외팔 상태로 부활**(사망 전 몸과 무관). 원문 3.4.1의 "마지막 신체 결손 상태 유지"는 적용하지 않는다(2026-10-15 PM).
- **시간대**: 공연이 끝날 때마다 전원 대기실로 이동. 아침·낮·밤에 재정비·탐색·휴식. 일부 오브젝트는 시간대 전환에 맞춰 위치·상태와 조명이 바뀐다(상세 기획서). M1은 최소 기능만.

## 확인 필요

장소 기획(10454669)의 하위 구역 "단원 대기실·소품실·복도"와 1~5·8번 공간의 대응은 담당 확인 필요.
