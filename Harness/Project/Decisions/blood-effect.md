# 부상 혈흔 연출

## 언제 읽나
부상(절단) 연출·혈흔 설정·그래픽 설정 항목을 바꾸거나 다른 부상 연출을 붙일 때.

## 현재 결정
- 팔·다리를 새로 잃는 순간 절단 부위에서 혈흔 파티클이 튄다. 판정과 무관한 겉모습이다.
- 내 시점: 3인칭이면 내 캐릭터의 부상 위치에서 자연스럽게 튀고, 1인칭이면 화면에 보이도록(카메라 앞 잘린 쪽) 튄다.
- 팀원 시점: 내가 다칠 때 내 캐릭터의 부상 위치에서 튀는 모습이 보인다.
- 게임 설정(`Resources/Settings/GameSettings/BaseGameSettings` 신체 손상 · 혈흔 연출)으로 게임 전체에서 켜고 끈다.
  끄면 게임 설정 화면에 혈흔 항목을 표시하지 않고, 개인 설정과 상관없이 모든 플레이어에게 꺼진다.
- 게임 설정이 켜져 있으면 플레이어가 설정 → 그래픽 '혈흔 연출 표시'로 자기 화면 표시를 켜고 끈다(이 PC에 저장, 기본 켜짐).

## 구현 위치
- `Assets/Scripts/Systems/Damage/InjuryBloodEffects.cs`, `BloodSpurt.cs`, 기본 에셋 메뉴 `Tools/CurtainCall/Effects/혈흔 파티클 기본 에셋 만들기`.
- 모양: `Assets/Resources/Effects/Blood/BloodSpurt.prefab`(아트에서 교체 가능). 양·뿜는 시간은 게임 설정.
