# 음성 채팅

## 언제 읽나

음성 채팅 기능·채널 규칙·음량 값을 만들거나 바꿀 때, 사망/부활 상태를 추가해 음성 무리가 달라질 수 있을 때.

## 결정

- 2026-10-20 / PM(@MoHoDu):
  1. 솔루션: **Unity Vivox**(`com.unity.services.vivox`). 세션 접속에 쓰는 UGS 익명 로그인을 그대로 쓴다. 패키지는 PM이 통합 브랜치에 먼저 설치([multiplayer-stack.md](multiplayer-stack.md)의 "거리 기반 음성 제외"를 이 결정으로 해제).
  2. 사용 범위(같은 날 정정): **Start에서 시작해 이어지는 흐름의 확정 씬에서만** 쓴다 — `Start`·`Lobby`·`WaitingRoomBase`(대기실)·`Tightrope`(줄타기)·`HumanCannon`(인간 대포). 씬 안에서는 제한 없이 같은 규칙. 백스테이지·탈출로는 씬이 확정되면 세팅 `사용 씬`에 추가(M2 기획은 백스테이지를 대기실로 통합, 씬 구조는 아직 분리). 테스트 씬을 직접 열면 동작하지 않는다.
  3. 생존자: 생존자끼리만, **거리에 따라 크기가 달라진다**. 기본 2m 안 최대 음량, 20m 밖 무음(세팅에서 조정).
  4. 사망자: 사망자끼리만, **거리와 무관하게 같은 크기**.
  5. **완전 분리**: 생존자는 사망자를, 사망자는 생존자를 듣지 못한다.
  6. 사망 판정은 호스트 확정 상태 `Fallen`(추락·사망)·`Retired`(리타이어). 관전 규칙과 같다. `Normal`·`Arrived`는 생존. 부활·재시작으로 생존이 되면 다시 생존자 무리로 돌아간다.
  7. 말하기: **상시 마이크**(목소리 감지) + **음소거 키**로 내 마이크 끄기/켜기. 키 기본값은 임시(control-keys 목록 밖, 합의 필요).
  8. 접속 방식(2026-10-20 추가): Services 방과 **LAN 접속 모두** 기본으로 음성을 쓴다. 출시 빌드에 LAN 메뉴가 남을 수 있어 접속 방식에 따라 음성이 달라지지 않게 한다. LAN도 Vivox 서버를 쓰므로 인터넷이 필요하다.

## 이유

같은 UGS 프로젝트·로그인을 쓰는 공식 경로라 서버를 따로 두지 않는다. 공포·협동 분위기에서 근처 사람 목소리만 들리게 하고, 죽은 사람이 산 사람에게 정보를 주지 못하게 무리를 나눈다.

## 바꾸려면

규칙·음량 체감은 사람 결정(`Harness/Core/Policies/human-decision.md`). 수치만 바꿀 때는 공통 세팅 `음성 채팅` 값만 고친다.
