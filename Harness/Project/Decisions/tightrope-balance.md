# 외줄 균형 규칙

## 언제 읽나

균형 값·게이지 UI·흔들림·무너짐 판정을 구현하거나 튜닝할 때. 화면 예시: `Docs/References/ref_001.png`.

## 결정

- 2026-10-01 / PM(@MoHoDu):
  1. **게이지**: 화면 하단 가로 막대. 가운데 초록, 양쪽으로 노랑, 끝은 빨강. 바늘이 현재 균형(왼쪽 -1 ~ 0 중앙 ~ +1 오른쪽)을 가리킨다.
  2. **보정**: A는 바늘을 왼쪽, D는 오른쪽으로 민다(게이지 아래 `◀ A`, `D ▶`). 플레이어는 흔들림을 A/D로 상쇄해 중앙을 유지한다.
  3. **흔들림**: 기본 흔들림 위에 동작별 추가 흔들림이 더해진다 — 걷기, 점프, 옆줄 이동, 목마 인원 수. 동작이 많을수록 제어가 어렵다.
  4. **관성**: 노랑 쪽 끝으로 기울수록 바깥으로 미는 힘이 커져 점점 빨리 무너진다. 중앙 유지가 유리하다.
  5. **무너짐**: 빨강 구간에 **3초 이상** 머물면 무너져 떨어진다.
  6. **튜닝**: 구간 폭, 보정 속도, 각 흔들림 크기, 관성 세기, 무너짐 시간 등 **모든 수치는 인스펙터에서 조절**한다.
  7. **구현 위치**: 균형 계산·게이지·무너짐 신호는 플레이어 조작(004). 실제 낙하·대기·재시작은 외줄 코어(005)가 무너짐 신호를 받아 처리한다.

## 열린 점 (구현은 아래 가정, 테스트 후 확정)

- 빨강을 벗어나면 3초 타이머가 초기화된다(누적 아님).
- 점프·옆줄 흔들림은 동작 순간 한 번 크게 흔들리고 서서히 줄어든다. 걷기·목마 인원은 지속되는 흔들림이다.

## 이유

협동 동작이 늘수록 균형 부담이 커지게 해 긴장감을 만들고, 한 번의 실수가 아니라 방치(빨강 3초)가 실패로 이어지게 하기 위함.
