# 모든 씬의 봉 공통 규칙

봉·스위치 봉·연습 봉·운반 봉의 동작을 만들거나 바꿀 때 읽는다.

## 사용자 확정

- 모든 봉은 일반 그네봉과 스위치 봉 두 종류다. 조작·반동·관성·점프·도약 규칙은 모든 씬에서 같다.
- 기본값은 최대2인 위아래 연결·위 사람만 반동 조작이다. 2026-11-10 후속 요청으로 인원·조작 주체 같은 고정 규칙도 GameSettings Inspector에서 조정 가능하게 한다. 항목에는 효과·단위·적용 시점의 한글 Tooltip을 둔다.
- 모든 봉의 매달리기 제한은 30초다. 연습실도 동일하다.
- 공통 반동 기준은 외줄 공중그네의 최대 80°, 최대 180°/초다.
- 스위치 봉의 직접 잡은 사람이 손을 놓으면 장치가 꺼진다.
- 운반 속도는 도약에 영향을 주지 않으며 자동 하차하지 않는다.
- 일반 외형은 기존 탈출로/인간대포 봉, 스위치 외형은 인간대포 스위치 봉을 재사용한다.
- 2026-11-10 후속 승인: 일반 봉과 스위치 봉은 각각 같은 외형·크기를 사용한다. 스위치 봉도 기존 4.4m에서 1.8m로 축소한다. 종류별 너비는 기존 PoleSettings에서 조정한다.
- 사용자 승인 1~6단계에 따라 인원·운동·잡기/입력·비행/착지·스위치·씬 연결을 모두 공통화한다.

## 구현 위치

- `Assets/Resources/Settings/GameSettings/Tricks/PoleSettings.asset` — 공통 물리·외형 설정.
- `HumanCannonPoleSystem` — 호스트 점유·반동·1~4인·시간·네트워크. 인원은 봉 생성 시 적용한다.
- `HumanCannonSystem` / `HumanCannonPilot` — 공통 비행·착지.
- `TightropeTrapeze` / `TightropeRelayGate` / `TightropeSwingPole` — 외줄 배치·기물 연결 어댑터.
- 씬의 옛 봉 필드로 공통 설정을 덮어쓰지 않는다. 세부 값과 검사는 Task-114 `full-change-list.md` 참고.

## 조정·검증 경계

- Inspector에서 상단 단독/탑승자 평균 반동과 아래 사람을 둔 놓기 제한을 선택한다. 기본값은 기존 규칙을 유지한다. 3~4인도 바로 위 사람을 붙잡고 지지자가 없어지면 아래부터 낙하한다.
- 2026-11-11 마지막 후속 승인: 낙하거리5m 이상15m 미만 부상,15m 이상 사망(이전4m/8m 대체). 부상 절단 개수는 BaseGameSettings에서 조정하며 기본2개다. 실제 외줄 착지는 높이 피해를 면제한다. 별도로 플레이어 절대 월드 Y <= -15는 착지 전 사망하며 기존 복귀 정책을 따른다.
- 2026-11-11 봉 모션 속도 요청: PoleSettings의 앞뒤 모션 속도 배율1.6. 진자 시계와 원격 예측만 같은 배율로 진행하며 도약 각속도·추가 상승·수평상한 계산은 배율을 곱하지 않는다. 동일 각도/반동의 도약 성능을 유지하고 놓는 타이밍은 빨라진다.
- 기존 실패14개 수정은 사용자 지시로 보류한다. 실제 두 PC 동시 플레이는 별도 확인한다.
