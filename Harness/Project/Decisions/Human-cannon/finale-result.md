# 인간 대포 최종 구간과 결과

## 언제 읽나

4단계 쿠션·최종 대포·톱·목적지와 공연 종료를 연결할 때. [협동 경로](cooperative-route.md)·[런 공통 규칙](../run-rules.md)와 대조한다.

## 결정

- 마지막 필수 협동 → 마지막 봉 또는 지상 탈출로 → 쿠션 → 최종 대포 4대 → 가로/수직 톱 → **실제 목적지**.
- 쿠션은 안전 준비 구간일 뿐 **성공·회복·부활·재시작이 아니다**. 별도 불꽃/타이머 없음.
- 최종 대포는 각 1인, 4대 같은 기본 높이·사거리. 개별 F 탑승/새 F 발사, 전원 동시 출발 강제 없음. 발사 힘·조작은 부상 무관.
- 톱은 외줄의 **외형·기본 이동만 재사용**한다. 거리/출현 시간/부위 피해는 그대로 복사하지 않는다. 가로 수평 원판은 좌우 왕복, 수직은 정해진 출현점→대포 방향 직선 이동 후 제거(왕복·가속·추적 없음).
- 첫 생존자가 최종 구간 진입하면 예고 후 **공유 주기** 시작. 후발자의 발사로 reset하지 않는다. 수직 톱 하나 퇴장→예고→다음 출현, 빈 공간·회피 시간 확보.
- **살아 있는 1명이 실제 목적지에 도착하면 성공**. 생존 2명/도착 2명/종료 레버 요구 없음. 도착 전에 전원 사망하면 실패.
- 마지막 필수 협동 뒤 혼자 남아도 쿠션→최종→목적지 완수 가능. 필수 협동 전 혼자 남아 막히는 문제와 구분한다.
- 더 받을 비행자가 없으면 지상 생존자는 기다리지 않고 지상 탈출, 봉 생존자는 담당이 죽어도 쿠션 도전 가능.
- **공용 종료 의존성**: 기존 공통 생존 2명 자동 실패와 충돌한다. 인간 대포별 예외를 공용 결과/런 종료 계약에 연결할 소유 Task·담당 협의가 필요하다. 이번 준비는 문서화만 하며 `Systems/` 코드·다른 묘기 규칙을 전역 수정하지 않는다.

## 이유

협동을 마친 뒤의 단독 생존 가능성을 남기고, 도착/보상/시간대 전환의 확정 시점을 하나로 맞춘다.

## 바꾸려면

공연장 담당·총괄 시스템 PM이 합의하고 원문·run-rules·공용 연결 Task를 함께 갱신한다. 실제 공동 검증 전 연결 완료로 표시하지 않는다.
