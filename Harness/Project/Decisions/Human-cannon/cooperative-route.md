# 인간 대포 협동 경로

## 언제 읽나

2단계 봉·관문·사망 인계, 3단계 출발 이동장치·쉼터·불꽃 경로를 만들 때. [기본 조작](basic-control.md)·[최종 구간](finale-result.md)과 연결한다.

## 결정

- 경로: **분리 출발 → 공중/지상 협동 → 높은 쉼터 → 마지막 필수 협동 → 마지막 봉/지상 탈출로 → 쿠션 → 최종 대포 → 실제 목적지**.
- 지상 담당은 시작 장치에 트램폴린을 싣고 먼 분리 코스로 간다. 대포 무대에서 코스로 걸어가는 길은 없다.
- 봉 F 잡기, W/S 반동, F hold 취소·손 놓기 도약. 정지 봉은 **잡고 있는 동안** 연결 톱 세트를 자동 수납(별도 hold 유지 불필요).
- 봉 제한 시간, 놓기/시간 끝/사망 시 **예고 후** 톱 재동작. 일반 봉 밝은 금속, 연결 봉 노랑/검정·케이블로 연결 대상을 보인다.
- 필수 관문은 **비행자가 위 봉으로 열기 → 담당이 아래를 통과 → 너머에서 다시 받기**. 지상 점프·옆 우회·연속 봉·중계·정지 장치 반복으로 협동을 건너뛰지 못한다. 외팔을 다시 받을 시간·공간 확보.
- 담당 사망 시 장치는 제자리, 반동 계속. 살아 있는 봉 이용자가 중앙 반동을 거쳐 **반동 중 외곽 F 잡기**로 새 담당이 된다. 놓치면 중앙 재반동으로 재시도. 부활이 아니며 함정·불꽃도 계속한다.
- 쉼터 F 스위치는 해제 상태 유지, 해제만으로 출발하지 않음. **모든 생존 비행자가 합류한 뒤** 담당이 장치를 싣고 F로 상승. 낮은 손잡이·문턱 없는 진입, 교대는 선택.
- 불꽃벽은 예고 후 마지막 사람의 출발 여부와 무관하게 전진, 공중/지상 모두 압박. 접촉 사망 설계안·속도/판정은 플레이테스트로 조정한다.
- 쉼터 경계에서 앞 불꽃 종료·생존 합류 후 다음 구간 준비. 쿠션 경계에서 불꽃 종료, **쿠션/최종 대포에는 별도 불꽃·타이머 없음**.

## 이유

장치 담당과 비행자의 순서 협동을 필수로 만들되 사망 인계·외팔로도 다음 행동을 할 수 있게 한다.

## 바꾸려면

공연장 담당·PM 합의 후 원문·Task 계획 갱신. 지상 2명 제한/중계 대포는 [미정 목록](injury-hazards.md)을 따르며 여기의 필수 구현에 포함하지 않는다.
