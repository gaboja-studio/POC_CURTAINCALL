# 인간 대포 부상과 함정

## 언제 읽나

부상 패널티·일반 함정·5단계 코스/난도 검증을 할 때. 공통 상태는 [injury-rules.md](../injury-rules.md), 조작/결과는 [기본](basic-control.md)·[최종](finale-result.md).

## 결정

- 다리 1개 손실: 운반 이동 느림·몸 점프 낮음·공중 반응 둔화. **대포/트램폴린 반동 높이는 유지**.
- 다리 2개 손실: 기어가기·낮은 몸 점프, 낮은 손잡이와 높은 점프 없는 탑승/쉼터 진입. 1개 손실 때보다 쉬워지지 않는다.
- 외팔: 두 다리 제약 유지, 시간이 필요한 잡기/탑승 느림. 반동·정지 정상, 장치 이용 금지 없음. 공통 UI 조작은 부상 무관.
- 일반 공중 함정: 왕복 가시추·회전 날개 절단, 송풍 수평 밀림. 지상 왕복/교차 톱에는 둘 이상의 대응법을 둔다.
- 절단은 공통 순서 왼다리→오른다리→왼팔→오른팔, 일반 1곳. **추락은 예외로 2곳**(M2, 즉사 대신): 잃은 팔다리가 4가 되면 사망(두 다리를 잃은 상태나 외팔 상태에서 추락하면 사망). 불꽃 접촉(압박 불길 등) 즉사 설계안은 그대로이며 절단과 구분한다.
- 난이도 단계 1~3(M2: 세트리스트에서 묘기별로 클리어한 단계의 다음 단계까지 선택, 1일차 1단계 고정, [스케줄표](../Waiting-room/schedule-board.md)). 현재 구현(M2 미반영): 테스트 HUD에서 호스트가 난도 1~3을 직접 고름(`HumanCannonHazardCourse.SetDifficulty`). 4인 약 5분·외팔 완수·다인 연속 받기·필수 관문 우회 불가를 **실제 공동 플레이**로 검증하고 수치를 조정한다. 준비/자동 fixture 검증으로 대체하지 않는다.

## 아직 정하지 않은 것

- **지상 2명 제한**: 추가 톱 vs 호응 감소 검토 중. 원문 옛 톱안은 비교 자료이며 확정 구현 목표 아님.
- **중계 대포**: 미정 선택. 필수 역할/우회 경로로 먼저 추가하지 않는다.
- 공통 호응·보상은 [보상 규칙](../reward-rules.md)(Confluence 27459631) 확정. **환호 포인트**는 공용 선착 획득자 +15 후 소멸, 팀 개수 인원×2/3/4, 위치 배치 방식 미정. 인간 대포별 성공/회피 판정·함정 거리/속도/판정 수치·2/3인 검증은 후속. 옛 원문 수치로 최신 보상 규칙을 대체하지 않는다.

## 이유와 바꾸려면

더 다칠수록 불리하지만 완수가 막히지 않아야 한다. 공연장 담당·PM 합의 후 원문과 해당 단계 Task 계획·세팅 값을 함께 갱신한다.
