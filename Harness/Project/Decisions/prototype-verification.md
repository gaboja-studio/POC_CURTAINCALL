# 프로토타입 검증

- 개발·수정 묶음 완료 시 또는 사용자 요청 시 한 번 검사한다.
- Unity 변경은 컴파일, 문서·도구 변경은 관련 가벼운 검사만 한다.
- 자동 테스트는 재발 방지에 도움이 될 때 기존 것을 선택해서 쓴다. 매 수정마다 테스트 구조를 만들지 않는다.
- 재미·조작감·방향·최종 플레이 경험은 사람이 판단한다. 미실행은 통과로 쓰지 않는다.
- 결과·실패·생략은 log에 남긴다. 테스트가 없으면 NO_PROJECT_TESTS.
