# 프로토타입 검증 방식

## 언제 읽나

프로토타입 Task를 검사·저장·제출하거나, 테스트 결과를 handoff에 적을 때.

## 결정

- 2026-09-30 / PM(@MoHoDu):
  - AI는 **Unity/C# 컴파일 오류만** 검사한다. asmdef와 테스트 어셈블리는 만들지 않는다(테스트 결과는 `NO_PROJECT_TESTS`).
  - **플레이 테스트는 AI가 대신하지 않는다.** 확인할 항목을 작업자에게 넘기고, 작업자가 직접 해 본 결과(통과/실패, 본 현상)를 받아 handoff에 적는다.
  - 작업자의 답을 받기 전에는 플레이 테스트를 통과했다고 쓰지 않는다.

## 이유

5일 일정에서 자동 테스트 구조를 만드는 시간을 아끼고, 조작감처럼 사람만 판단할 수 있는 부분은 사람이 확인한다.

## 바꾸려면

테스트 어셈블리 도입은 별도 Task로 진행한다. 검증 단계 기준은 `Harness/Core/Policies/verification-ladder.md`.
