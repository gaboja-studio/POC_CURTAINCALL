# 탈출 결과 확정 시점

## 언제 읽나

실제 탈출로의 참가자 집계·출구 도착·성공/실패와 엔딩 전환을 연결할 때.

## 결정

- 참가자 전원이 도착하거나 리타이어할 때까지 결과 확정을 기다린다.
- 모두의 결과가 정해졌을 때 도착자가 한 명 이상이면 탈출 성공이다.
- 도착자 없이 전원 리타이어하면 실패다. 첫 도착만으로 즉시 종료하지 않는다.
- 예: 4명 중 1명 도착·2명 리타이어·1명 진행 중이면 계속 진행한다. 마지막 사람까지 도착/리타이어하면 성공을 확정한다.

## 적용 상태

연결 계획에 반영했으며 실제 A의 집계·종료 구현은 아직 없다. [계획](../../../Tasks/Active/Task-20261027-073-exit-route-space-design/a-waiting-room-link-plan.md), [현재 구현 사실](../Facts/escape-waiting-transition.md).
