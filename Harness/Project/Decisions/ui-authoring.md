# UI 편집 방식

## 언제 읽나
UI 프리팹·씬을 만들거나 고칠 때, UI 문구·아이콘·배치를 코드에서 바꾸고 싶을 때.

## 결정
- 디자이너가 씬 뷰·프리팹 화면에서 바로 보며 고칠 수 있어야 한다. UI는 **켜지고 보이는 상태(활성·CanvasGroup alpha 1)로 저장**한다.
  - 게임 중 처음 숨김·상황별 표시는 스크립트가 시작할 때(Awake 등) 처리한다. 저장된 상태에 의존해 숨기지 않는다.
  - 비어 있으면 모양을 알 수 없는 칸(목록 줄·설명·이름 칸)은 실제 형식의 예시 내용을 넣어 저장한다. 게임에서는 열 때 실제 내용으로 바뀐다.
- 위치·크기 등 배치, 고정 문구(창 제목·단위), 정적 그림은 씬/프리팹에서 고친다. 코드가 덮어쓰거나 런타임에 만들지 않는다.
- 값이 들어가거나 상황마다 바뀌는 문구(가격 형식·설명·툴팁)와 바뀌는 아이콘은 ScriptableObject·컴포넌트 설정으로 제공한다.
- 제공 키트(_ThirdParty) 코드가 문구를 하드코딩했으면 키트는 두고 프로젝트 쪽 설정 컴포넌트로 감싼다.
- 편집 화면에서 글자가 □로 보이지 않도록 고칠 수 있는 문구에는 한글 전체를 가진 폰트를 쓴다.

## 적용 현황 (2026-11-01)
- 적용: 상점(`ShopPanel.prefab`, `CommonWaitingRoomUI`), 소지 칸(`CommonMenuUI`의 C5).
- 남음(사용자가 결과 확인 뒤 지시): 스케줄·설정·자막·배너 패널 등 `00_Visuals`/`Motion`이 꺼진 채 저장된 UI, 코드로 만드는 기물 알림 패널(`WaitingRoomRightPanel`).
