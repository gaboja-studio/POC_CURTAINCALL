# 공통 부상 규칙

## 언제 읽나

절단·사망·부활·신체 복구·부상 패널티·관전을 만들거나, 부상 상태를 공간 사이로 넘길 때. 이 파일과 [body-damage.md](body-damage.md)가 다르면 이 파일이 우선한다.

## 결정

- 2026-10-13 / PM(@MoHoDu), 부상 기획서 기준(2026-10-27 M2 반영):
  1. **절단 순서 고정**: 어디를 맞든 왼다리 → 오른다리 → 왼팔 → 오른팔. 모든 공간·묘기 동일. 한 번에 1곳(2곳 이상은 난이도 3축에서만). 예외: **인간 대포 추락은 2곳**(M2, 절단 순서대로). 묘기 장애물은 기본적으로 즉사가 아니라 절단.
  2. **상태는 잃은 팔다리 수(0~4) 하나**로 관리: 0 온전한 몸 / 1·2 부상 / 3 외팔 상태(오른팔만) / 4 사망. 두 다리를 잃으면 기어가기.
  3. **사망**(M2): ① 4곳 모두 잃음(외팔에서 한 번 더 절단, 인간 대포 추락 2곳 절단으로 4가 됨 포함) ② 묘기 규칙에서 즉사로 정한 추락(외줄은 매달린 뒤 동료가 끌어올리지 못해 버티는 시간이 다 지날 때, 인간 대포 추락은 즉사 아님) ③ 외팔 상태로 쉬는 시간 대기실에서 추격자에게 잡힘. "추락은 사실상 3곳을 한 번에 잃는 것"은 즉사 추락에만 해당. 사망하면 사망 전 호응도의 절반을 인정한 뒤 ×2토큰으로 공연 종료 후 지급한다(중간 버림 없음, 완주 보너스 없음). 전원 사망으로 실패해도 이 보상은 지급하며, 절단 보너스도 호응도에 포함된다([보상 규칙](reward-rules.md), 2026-10-27 확정).
  4. **공연 중 사망 → 묘기 재시작 없음**: 공연 끝까지 관전 → 다음 시간대(쉬는 시간·밤 정비) 시작 때 대기실에서 **외팔 상태로 부활**(사망 전 몸과 무관). 부활은 비용 없음.
  5. **추격자에게 잡힘**(쉬는 시간 대기실, M2에서 백스테이지는 대기실로 통합): 외팔 상태가 될 때까지 절단 후 무대로 끌려가 다음 공연 출연, 이미 외팔이면 사망(쉬는 시간에 잡혀 끌려온 사람의 보상 박탈 없음, 2026-10-28). 추격자 구현 전에는 만료 순간 무대 입구 밖 인원을 바로 잡힘 처리한다([런 규칙](run-rules.md) #1). 대기 중 다른 사람은 추격당하는 사람 시점으로 관전. 탈출로에서 잡힘·사망 = 리타이어.
  6. **신체 복구**(M2): 모든 쉬는 시간·밤 정비에 언제든(공연 중 제외). 한 번에 **1~3개 부위**를 골라 복구, 역순(왼팔→오른다리→왼다리). 가격은 부위당 **기본 100토큰**(공동 자금), 이용할 때마다 다음 부위당 가격 **+25**(한 번에 여러 부위도 1번만 오름), 기준은 팀 전체 이용 횟수, 런마다(세대 교체) 100으로 초기화. 예: 첫 이용 2부위 200 → 부위당 125 → 두 번째 1부위 125 → 부위당 150. 온전한 몸 이용 불가, 부활과 별개. M2에서 바뀜: 이전 의료 스케줄(1·3일차 밤)만·부재 표시. 이용 방식은 [밤 정비와 서비스](Waiting-room/night-maintenance.md). 구현(2026-10-28, Task-076): `ExpertServiceBook`·`ExpertService`, 가격은 `WaitingRoomSettings` 신체 복구 값, 시설 서비스·전문가 일정 삭제.
  7. **패널티**: 팔 = 손 쓰는 행동, 다리 = 이동·달리기·점프·균형. 다친 본인만, 막기보다 느리고 서툴게, 조작키는 바꾸지 않음, UI 행동은 부상 무관, 더 다치면 같거나 커짐, 진행이 막히면 안 됨. **탐색 중 부상 패널티**(대기실·탈출로 묘기 밖, 대기실 담당) / **공연 중 부상 패널티**(묘기별, 공연장 담당; 탈출로 묘기 구간)로 나눈다. 다리 절단 단계에 따라 점프 높이 감소(탐색·공연 일치).
  8. **기물 소지**(2026-10-28 사용자 결정): 팔 개수와 관계없이 **기본 2칸**. 배낭과 팔 1개일 때의 슬롯 감소 규칙을 삭제한다. 기존 2/1/+2 및 더 오래된 3/+3 규칙을 대체한다. 기본 소지 개수는 공통 세팅에서 조정한다([game-settings.md](game-settings.md)). Task-076(2026-10-28) 코드 반영: `BaseGameSettings.ItemCarry.BaseSlots`·`SurvivalRules.ItemSlots()`로 통일, 기존 `twoArmSlots` 값 이관. 배낭 판매·수령·소지/공유 상태·등뒤 표시 제거(기존 씬 품목은 읽을 때 제외). 절단 후 소지/HUD 2칸 유지·가득 찬 배송 거절 포함 W2 PlayMode9건 통과; 전체 검사 실패는 Task log 참조.
  9. **절단 보너스**: 공연 중 절단 1개당 본인 호응도 **+10 고정**. 즉시 토큰이 아니라 호응도이며 상한·사망 정산을 적용한다. 난이도·복구 비용과 연동하지 않고, 복구 비용보다 낮아야 한다는 제한은 삭제([보상 규칙](reward-rules.md)). 추격자로 잃은 팔다리는 보너스 없음.
  10. 세대 교체 시 모두 온전한 몸(잃은 팔다리 수 0).

## 아직 정하지 않은 것

탐색 중 패널티 수치·기어가기 점프 여부·대기실 탐색 장애물 절단 여부(대기실 담당). 절단 호응 +10·신체 복구 100/+25는 [보상 규칙](reward-rules.md)(Confluence 27459631, 2026-10-27)이 M2의 옛 10/+5를 대체한다. 인간 대포는 [부상·함정](Human-cannon/injury-hazards.md)의 v0.5 기준을 따르며 옛 프로토타입 14254259의 재시작/스냅샷을 적용하지 않는다.
