# 탈출로 조작 기준

## 언제 읽나

탈출로의 플레이어·외줄·그네·트램폴린을 연결하거나 조작 전환을 구현할 때.

## 개발 우선순위

- 2026-10-30 사용자 명시 요청: A의12개 수정·외피 정리를 진행하고 AI가 독립 멀티플레이 클라이언트4개로 실제 입력 플레이 테스트하여 문제를 고친다. 이전 AI Play/입력 금지와 다인 검증 후속 제한을 이번 요청에서 대체한다. 위치 이동을 통한 구간 점검과 실제 이동·완주 결과는 구분한다.

- 2026-10-29 최신 결정: A만 먼저 완성한다. B·C 후속 제작·튜닝·폴리싱·플레이 검토는 M2 이후로 미룬다. 기존 B·C 결과는 보존하고 이전 A→B→C 연속 작업 순서를 대체한다. 아래 공통 조작 기준은 유지하며 현재 작업은 A에 집중한다.
- 후속 사용자 승인: A03~06 융합 계획을 구현하고 저장한다. 대포→외줄처럼 앞 묘기에서 다음 묘기로 직접 이어지게 하고 의미 없는 복도·계단을 없앤다. 마지막 질주의 밋밋함은 묘기 융합 이후 다룬다.
- 추가 사용자 요구와 승인:04B를 필요한 만큼 넓혀, 대포를 타이밍에 맞춰 발사하고 공중 조절로 순환 그네를 잡은 뒤 외줄이나 착지대로 내려오게 한다. 배치·공유 시각·하차 관성 연결을 구현했으며 실제 손맛은 사용자 확인 대상이다.
- 중간 피드백은 기존 융합 목표에 누적한다. 그네마다 다음 연결 역할과 적절한 간격을 주고, 외줄 매달림/반동까지 포함해 배관·벽 간섭과 보이지 않는 지지면을 정리한다. 공간 확장 시 옛 벽에 붙은 설비도 함께 옮긴다.

## 확정

- 2026-10-30 최신 공중 조작 정정: 기존 공용 PlayerMover에서 이동 입력이 있을 때만 일반 점프의 수평 이동을 허용한다. 입력을 놓으면 수평 속도를 즉시0으로 만들고 상승/낙하는 계속한다. 입력을 유지하는 동안 달리기 이륙 속력과 방향 조향은 보존한다. 이전 무입력 관성 유지 요청을 대체하며 새 이동 스크립트/설정 없이 외줄 옆점프·외부 묘기 비행은 유지한다.

- 2026-10-30 최신 스위치 지시: 기존 목마용 스위치는 실제 목마 상부에서 누를 수 있는 높이로 올린다. 생존한 절단 상태도 스위치 사용이 가능해야 한다. 탈출로 스위치에는 팔 도달 거리 배율을 적용하지 않고 다리 절단으로 낮아진 몸통 중심을 정상 도달 높이로 보완한다. 물리 몸체·다른 상호작용 부상 규칙·사망/호스트 검증은 유지한다.

- 2026-10-30 상시 사용자 지시: 작업 전 dev 변경 중 탈출로가 재사용하는 기능·UI·에셋을 대조하고 실제 씬 참조·컴포넌트·외형/이펙트 크기까지 최신 정본에 맞춘다. Git 포함 확인만으로 적용 완료로 보지 않는다. 교체한 구형 씬 인스턴스를 정리하며 다른 기능이 참조하는 공유 원본은 보존한다.

- 2026-10-30 최신 사용자 정정: 별도 이동 배율·Solo 이동/점프는 제거 상태를 유지하고, '원래 있던 기능 다시 활성화' 요청에 따라 A의 기존 InspectionSession/Camera와1키 검토 비행만 복원한다. 일반 이동은 원본 공용 시스템과 기존 GameSettings에서 조정한다.

- 2026-10-30 최신 사용자 정정: 버튼·봉의 사용 자체에는 목마·점프·줄 끝·동료 수 등의 퍼즐 선행 조건을 두지 않는다. 유효 거리/점유/생존/호스트 검증은 유지한다. 버튼은 독립적으로 연결 장치를 켠다. 봉을 잡아 대포/다리를 가동하는 연결은 허용하되 대상 이름, 가동·정지·고정 알림, 연결 장치 표시등으로 원인과 결과를 알려준다. 기존 목마 필수 설계보다 이 지시가 우선한다.
- 플레이 검증은 사용자의 후속 중지 지시에 따라 중지 상태를 유지한다. 이번 수정에서는 EditMode 검사만 실행한다.

- 탈출로 전체 기본은 기존 인간대포 조작과 메커니즘이다. 일반 보행·달리기·점프, 대포·공중 이동·트램폴린·그네를 이 기준으로 연결한다.
- 외줄 위에서만 기존 외줄 조작을 사용한다. 외줄을 벗어난 뒤 기본 조작은 인간대포로 복귀한다. 외줄의 균형·추락/매달림 등 기존 판정과 필요한 상태 전이를 보존한다.
- 모든 그네는 인간대포의 잡기·점유·반동·놓기·비행 시스템을 사용한다. 외줄 구간 주변에 있더라도 외줄 전용 그네나 별도 검토용 진자로 대체하지 않는다.
- 2026-10-29 후속: 그네는 점프를 강제하지 않고 지상에서도 가까이 가서 F로 잡는다. 하강 단절마다 그네1개, B는 장거리 대포 연속/중간 그네, C는 그네 연속 횡단, 화염 복도는 마주보는 배출구를 늘리고 좌우 교대한다.
- 기존 입력 설정·공용 플레이어·호스트 판정을 재사용한다. AI가 만든 별도 Solo 조작/피격은 채택된 기준이 아니다.
- 현재 씬의1인 시작과1키 공중 검토 요구는 유지한다. 2026-10-29 사용자는 자유비행과 실제 플레이어 위치가 동기화되도록 명시했다. 비행으로 이동한 위치에서 플레이로 돌아와야 한다. 이 검토 편의가 기본 묘기 메커니즘을 대체하지 않는다.
- 2026-10-29 추가 확정: A/B/C 모두 같은 시스템·조작·실행 환경의 **개발 테스트 씬**이다. 지금은 사용자가 혼자 시험한다. 방 만들기/참가 단계와 게임 오버를 넣지 않고 Play에서 바로 검토할 수 있게 한다. 구조별로 다른 종료 규칙을 두지 않는다.
- 후속 확정: 실제 게임은 2인 이상이다. 혼자 검토하는 편의 때문에 원본 협동/호스트 판정을 제거하지 않는다. A에 네 줄 주기 소실·하부 동료 트램폴린·상부 버튼 복귀 구간을 만든다. 실제 플레이는 사람이 하며 AI는 게임 흐름에 필요한 검사만 한다.
- 작업 전 최신 dev를 반영하고, 끝나기 전 사용자 요구 누락·버그·남은 일을 점검한다. 상시 조작 설명 UI는 없애며 기물 근접 F 안내·테두리는 유지한다. 속도감과 연결 경험을 위해 구조를 수정할 수 있다.
