# 위험한 동료 표시

## 결정(사용자 원문 요지)
- 화면 밖 위험한 동료 = A안: 화면 가장자리 원형. 원 안 아이콘 = 위험 종류, 원 테두리 = 남은 상호작용 시간. 텍스트·프로필 없음, 크기는 작게.
- 화면에 보이는 동료 = B안: 몸 테두리를 벽 뒤에서도 보이게, 그 위에 위험 아이콘. 제한 시간은 몸 테두리로.

## 구현 규칙
- 내 화면 전용(네트워크 메시지 없음). 공연·탈출로(공통 외줄 매달림)·대기실 추격(부상) 공통.
- 대상: 매달림(남은 버티기 시간), 방금 팔다리 손실(절단), 낙하 부상. 우선순위 매달림 > 최근 부상. 사망·리타이어·도착 상태는 제외.
- 부상 원인은 `NetworkPlayer.InjuryMark`(순번+원인)로 모든 화면이 안다. 처음 본 값은 과거 부상이라 표시하지 않는다.
- 몸 테두리 시간: 발끝부터 남은 비율 높이까지만 선명(시간이 줄면 머리부터 흐려짐). 공용 `SilhouetteOutline`의 벽 너머 모드(xray)·Timer 사용.
- 수치·아이콘·프리팹: GameSettings › 월드 UI › '위험한 동료 표시'. 화면 프리팹 `Resources/Prefabs/UIs/Roles/Retained/TeammateDanger/TeammateDangerHud.prefab`.
