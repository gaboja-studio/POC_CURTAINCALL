# 외줄타기 프로토타입 규칙

## 언제 읽나

플레이어 조작(입력), 외줄 이동·균형, 목마, 추락·재시작, 도착 판정을 구현하거나 테스트 항목을 정할 때.
원문 요약: `Docs/References/tightrope-keymap-summary.md`, `Docs/References/tightrope-plan-summary.md`. 균형 세부 규칙: [tightrope-balance.md](tightrope-balance.md).

## 결정

- 2026-10-01 / PM(@MoHoDu):
  1. **조작은 키맵핑 문서를 따른다.** 기획서의 A/D+SB 두 번(옆줄), 마우스 좌+우 유지(목마)는 쓰지 않는다. 옆줄 이동은 **Q/E를 누른 채(홀드) SB**.
  2. **협동/단독 옆줄 이동**: 목마 맨 위 플레이어가 옆줄로 이동하거나, 옆줄에서 목마 쪽으로 이동하면 **협동 이동**. 출발과 도착이 모두 단독이면 **단독 이동**(착지 충격·일정 시간 균형 난도 상승). 착지 후 자동 목마 결합은 없다(합류는 F 짧게).
  3. **목마 연결**: F 짧게를 **누른 사람이 가까운 동료 위로 올라간다.** 올라가는 사람은 **반드시 단독**이어야 한다. 목마에 속한 사람은 먼저 해체한 뒤 한 명씩 올라간다.
  4. **묘기 실패와 게임 오버는 다르다.** 브리프의 "사망 시 첫째 날부터"는 전체 게임의 게임 오버 규칙이다. 줄타기 묘기는 **4명 모두 떨어져야 실패·재시작**하고, 1명이라도 줄 위에 남아 있으면 계속 진행한다.
  5. **1명만 도착해도 성공.** 코스는 곡선·회전 없는 **직선**이며 4줄로 시작해 1줄로 끝난다. 도착 지점은 **출발점에서의 거리**로 정하고, 기획자가 인스펙터에서 바꿀 수 있게 한다. 줄 수(4→1)도 바뀔 수 있으므로 인스펙터 값으로 둔다. 브리프의 "줄 9개 테스트"는 이 코스로 대체한다.
  6. **떨어진 플레이어**는 재시작 전까지 조작 불가로 대기한다(연출 없음).

## 이유

키맵핑 문서가 입력 규칙의 최신 기준이고, 협동이 필요하되 한 사람의 실수로 묘기 전체가 끝나지 않게 하기 위함.

## 바꾸려면

규칙 변경은 기획 결정이 필요하다(`Harness/Core/Policies/human-decision.md`). 이 파일과 관련 Task `plan.md`를 함께 고친다.
