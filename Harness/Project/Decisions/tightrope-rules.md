# 외줄타기 프로토타입 규칙

## 언제 읽나

플레이어 조작(입력), 외줄 이동·균형, 목마, 추락·재시작, 도착 판정을 구현하거나 테스트 항목을 정할 때.
원문 요약: `Docs/References/tightrope-keymap-summary.md`, `Docs/References/tightrope-plan-summary.md`. 균형 세부 규칙: [tightrope-balance.md](tightrope-balance.md), 균형·점프 원문 요약: `Docs/References/tightrope-balance-summary.md`.

## 결정

- 2026-10-01 / PM(@MoHoDu):
  1. **조작은 키맵핑 문서를 따른다.** 기획서의 A/D+SB 두 번(옆줄), 마우스 좌+우 유지(목마)는 쓰지 않는다. 옆줄 이동은 **Q/E를 누른 채(홀드) SB**.
  2. **협동/단독 옆줄 이동** (2026-10-01 기획 문서 rope_balance 반영으로 갱신): 출발·도착 모두 혼자면 **단독 이동** — 착지 충격 ±35 + 3초간 흔들림 ×2.5. 도착점이 **동료의 콜라이더 영역이면 바로 목마 합체**로 이어진다. 합체가 아니어도 도착점이 같은 줄 동료의 **앞뒤 1.0m 이내면 착지 반동 50% 감소**. 합체가 안 되는데 겹치면 **상대 뒤쪽으로 착지**(2026-10-03). (이전의 "착지 후 자동 목마 결합 없음", "목마 맨 위 출발·도착이면 협동"은 대체됨)
  3. **목마 연결**: F 짧게를 **누른 사람이 가까운 동료 위로 올라간다.** 올라가는 사람은 **반드시 단독**이어야 한다. 목마에 속한 사람은 먼저 해체한 뒤 한 명씩 올라간다.
  4. ~~**묘기 실패와 게임 오버는 다르다.**~~ → 실패 조건은 2026-10-03 [코스·진행 결정](tightrope-course-rules.md) #2로 대체(실패 뒤 처리는 보류). 원문: 브리프의 "사망 시 첫째 날부터"는 전체 게임의 게임 오버 규칙이다. 줄타기 묘기는 **4명 모두 떨어져야 실패·재시작**하고, 1명이라도 줄 위에 남아 있으면 계속 진행한다. 기획 문서 rope_balance가 따르는 2차 기획서 §11(한 명 추락 → 팀 전체 재시작)보다 이 결정이 우선한다(2026-10-01 재확인).
  5. ~~**1명만 도착해도 성공.**~~ → 2026-10-03 [코스·진행 결정](tightrope-course-rules.md) #2·#3으로 대체(클리어 판정 변경, 4줄이 도착까지). 원문: 코스는 곡선·회전 없는 **직선**이며 4줄로 시작해 1줄로 끝난다. 도착 지점은 **출발점에서의 거리**로 정하고, 기획자가 인스펙터에서 바꿀 수 있게 한다. 줄 수(4→1)도 바뀔 수 있으므로 인스펙터 값으로 둔다. 브리프의 "줄 9개 테스트"는 이 코스로 대체한다.
  6. **떨어진 플레이어**는 재시작 전까지 조작 불가로 대기한다(연출 없음).
  7. **목마 중 점프** (2026-10-01): 목마에서는 **1층과 맨 위 인원만** 점프할 수 있다(중간층은 불가). 1층 SB = 목마 전체 점프, ~~맨 위 SB = 분리 점프, 맨 위 **W + SB** = 목마 앞으로 멀리 점프하며 분리~~, 상호작용(F) 길게 = 해체. 세부는 목마 작업(006)에서 정한다.
     - 2026-10-04 PM(@MoHoDu, 006) 맨 위 점프 대체: **SB = 제자리 점프**(목마 유지, 아래 사람 머리 위로 다시 착지·재결합). **W + SB = 앞으로 분리 점프**(뛰는 순간 목마에서 빠져 앞쪽 줄에 착지, 수직 톱날을 넘는 용도). **S + SB = 뒤로 분리 점프**(뒤쪽 줄에 착지). 점프 높이는 혼자 점프와 같다(0.8m, 수직 톱날 상단 1.1m 조건 유지). 앞 수평 속도는 수직 톱날(지름 1.0m·상단 1.1m)을 2층 발 높이 1.5m에서 넘을 수 있게 **2.2m/s**(약 2.4m 앞 착지, 톱날 중심 약 1.9m 안이면 넘음), 뒤는 아래 사람과 겹치지 않게 0.7m/s — 둘 다 세팅 값(기획 미정).

## 이유

키맵핑 문서가 입력 규칙의 최신 기준이고, 협동이 필요하되 한 사람의 실수로 묘기 전체가 끝나지 않게 하기 위함.
