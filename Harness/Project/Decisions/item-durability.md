# 기물 내구도와 소진 처리
## 언제 읽나
기물 사용·차감·파괴·슬롯 표시를 만들 때. [기물 원문](https://hrjoo122770.atlassian.net/wiki/spaces/bYmkRlnpusng/pages/27525121)·[보상 원문](https://hrjoo122770.atlassian.net/wiki/spaces/bYmkRlnpusng/pages/27459631)과 함께 관리한다. 기획 확정이며 구현 완료가 아니다.
## 공통 결정
- 실제 효과 발생·개방 성공·새 단서 발견 시 내구도1 차감. 장착·실패·무효 입력만으로 차감하지 않는다.
- 탐색 상호작용 보충(2026-10-29 사용자): F로 상호작용한 대상이 비활성화되며 **파괴되는 연출이 나오거나**, 상호작용으로 **보상을 얻었을 때만** 1 차감한다. 연타 중간 타격은 차감하지 않는다(벽은 무너지는 6번째에만). 구현: `PropItem.Uses`·`ItemCarryBook.Use`·`PropCarry.UseItem`(Task-079), 슬롯 숫자에 남은 횟수 표시.
- **빠루 = 천막 말뚝 뽑개**(2026-10-29 사용자). 숨은 길 벽 파괴에도 쓴다.
- 수치 정본: `Resources/Settings/GameSettings/Items/ItemCatalog.asset`(7종 내구도·발견품 내구도·가격·쿨타임·접두사·효과). 확정 외 값은 초안이며 기획서로 교체한다(2026-10-29 사용자).
- 한 번의 효과를 중복 차감하지 않는다. 개방·발견이 완료되기 전 취소하거나 이미 열린 대상에는 차감하지 않는다.
- **마지막 효과는 끝까지 제공한 뒤 파괴·슬롯 제거**. 내구도0인 기물은 새 효과를 발동하지 못한다. 고장 난 기물은 남기지 않는다.
- 슬롯 아래쪽에 내구도 1을 한 칸으로 나눈 바로 남은 횟수를 표시한다(칸 수 = 새제품 내구도, 2026-11-02 사용자: 숫자 대신 바). 내구도가 줄면 그 칸에 사용 연출, 다 써서 사라지면 파괴 연출. 팔 개수와 관계없이 기본2칸, 배낭 없음([부상 규칙](injury-rules.md) #8).
- **공연 기물 쿨타임 없음**(2026-11-02 사용자). 구조 장갑·끈끈이 장갑·벌룬 바지·스프링 신발 모두 `cooldown` 0. 효과마다 1 차감만 한다.
## 기물별 결정
2026-11-18 공연 4종을 [수동 발동](Performance-equipment/manual-items-and-fire-hoop.md)으로 변경·구현했다. 마지막 내구도는 발동 시 소모하여 슬롯에서 소진 연출을 재생하지만, 이미 발동한 효과는 정해진 수명까지 유지한다.
| 기물 | 새제품 횟수 | 1회 차감 조건 | 마지막 사용 처리 |
|---|---|---|---|
| 구조 장갑 | 5 | 유효한 전방 동료·안전한 착지 공간을 확보한 구조 발동 | 구조 완료, 소진 연출 |
| 끈끈이 장갑 | 3 | 제한시간 있는 매달림 중 수동 발동, 매달림당 최대1회 | 소진 후에도 해당 매달림의 3초 정지 유지 |
| 광대 벌룬 바지 | 4 | 공중에서 유효 발동, 체공당 최대1회 | 소진 후에도 최대3초 효과·원래 슬롯 키의 접기 유지 |
| 스프링 신발(명칭 검토) | 2 (변경 없음) | 공중에서 실제 추가 점프 적용 시 1, 착지 전 최대 1회 | 마지막 추가 점프 적용 후 파괴, 발생한 도약은 취소하지 않음 |
| 마술사의 머리핀 | 5 | 좌물쇠 개방 성공, 실패·부적합 대상 소모 없음 | 개방 완료 후 파괴, 열린 상태 유지 |
| 천막 말뚝 뽑개 | 4 | 판자·덮개·걸린 서랍 등 대상 개방 성공 | 개방 완료 후 파괴, 열린 상태 유지 |
| 서커스 UV 등 | 3 | 새로운 단서 발견, 빈 곳·기발견 단서 소모 없음 | 마지막 단서 표시 후 파괴, 발견 표식은 해당 런 동안 유지 |
- 장갑·바지는 소지만으로 차감하지 않는다. 신발은 일반 트램펄린 사용에 차감하지 않는다.
## 미정·범위 밖
- UV 등으로 여러 단서 동시 발견 시 차감 단위, 끈끈이 장갑의 구조 중 타이머 처리는 미정이다. 신발의 기존 바닥 반동 관련 미정은 공중 추가 점프 기획으로 대체한다.
- 효과 수치·접두사·쿨타임·탐색 발견품 내구도의 기존 초안·미정 상태는 유지한다. 이번 확정은 새제품 횟수·차감·소진 처리다.
- 가격은 [보상 규칙](reward-rules.md). 중고 가격·판매 규칙은 이번 결정에 포함하지 않는다.
