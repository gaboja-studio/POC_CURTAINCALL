# 기물 내구도와 소진 처리
## 언제 읽나
기물 사용·차감·파괴·슬롯 표시를 만들 때. [기물 원문](https://hrjoo122770.atlassian.net/wiki/spaces/bYmkRlnpusng/pages/27525121)·[보상 원문](https://hrjoo122770.atlassian.net/wiki/spaces/bYmkRlnpusng/pages/27459631)과 함께 관리한다. 기획 확정이며 구현 완료가 아니다.
## 공통 결정
- 실제 효과 발생·개방 성공·새 단서 발견 시 내구도1 차감. 장착·실패·무효 입력만으로 차감하지 않는다.
- 한 번의 효과를 중복 차감하지 않는다. 개방·발견이 완료되기 전 취소하거나 이미 열린 대상에는 차감하지 않는다.
- **마지막 효과는 끝까지 제공한 뒤 파괴·슬롯 제거**. 내구도0인 기물은 새 효과를 발동하지 못한다. 고장 난 기물은 남기지 않는다.
- 슬롯에 남은 사용 횟수를 숫자로 표시한다. 팔 개수와 관계없이 기본2칸, 배낭 없음([부상 규칙](injury-rules.md) #8).
## 기물별 결정
| 기물 | 새제품 횟수 | 1회 차감 조건 | 마지막 사용 처리 |
|---|---|---|---|
| 구조 장갑 | 5 | 동료가 내 줄로 착지할 때 균형 손실을 실제 완화 | 마지막 완화 적용 후 파괴 |
| 끈끈이 장갑 | 3 | 기본 버티기 시간을 넘어 추가 시간 진입, 매달림당 최대1회 | 해당 매달림의 추가 시간 유지, 매달림 종료 후 파괴 |
| 광대 벌룬 바지 | 4 | 실제 하강 감속 적용, 대포 발사·트램펄린 반동으로 시작한 비행당 최대1회 | 해당 하강 감속 종료 후 파괴 |
| 스프링 신발 | 3 | 트램펄린 없는 바닥에서 실제 반동 발생, 같은 접촉 중복 없음 | 마지막 반동 적용 후 파괴, 발생한 도약은 취소하지 않음 |
| 마술사의 머리핀 | 5 | 좌물쇠 개방 성공, 실패·부적합 대상 소모 없음 | 개방 완료 후 파괴, 열린 상태 유지 |
| 천막 말뚝 뽑개 | 4 | 판자·덮개·걸린 서랍 등 대상 개방 성공 | 개방 완료 후 파괴, 열린 상태 유지 |
| 서커스 UV 등 | 3 | 새로운 단서 발견, 빈 곳·기발견 단서 소모 없음 | 마지막 단서 표시 후 파괴, 발견 표식은 해당 런 동안 유지 |
- 끈끈이 장갑은 기본 시간 안에 구조·종료되면 차감하지 않는다. 바지는 상승·감속 미적용 비행에 차감하지 않는다. 신발은 일반 트램펄린 사용에 차감하지 않는다.
## 미정·범위 밖
- UV 등으로 여러 단서 동시 발견 시 차감 단위, 끈끈이 장갑의 구조 중 타이머 처리, 신발의 반동 가능한 바닥·추락 피해 판정 순서는 미정이다.
- 효과 수치·접두사·쿨타임·탐색 발견품 내구도의 기존 초안·미정 상태는 유지한다. 이번 확정은 새제품 횟수·차감·소진 처리다.
- 가격은 [보상 규칙](reward-rules.md). 중고 가격·판매 규칙은 이번 결정에 포함하지 않는다.
## 바꾸려면
사람의 결정 후 기물·보상 원문과 이 파일·보상 규칙을 함께 갱신한다.
