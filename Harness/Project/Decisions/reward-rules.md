# 공연 보상과 공동 경제
**기획 기준이며 구현 완료를 뜻하지 않는다.** [보상 원문](https://hrjoo122770.atlassian.net/wiki/spaces/bYmkRlnpusng/pages/27459631)이 옛 크레딧·사망 보상 박탈·실패 보상 0·전원 생존 보너스·복구10/+5를 대체한다.
## 정산
- 화폐는 토큰. 개인 지갑 없이 팀 공동 자금 하나로 합산한다. 개인별 호응도를 색 구간으로 잇는 팀 게이지이며 호응도는 0~단계별 상한, 초과분 별도 지급 없음.
- 완주·사망 시 본인 호응도 고정, 관심 감소 중단. 공연 종료 후 지급한다. 생존자는 확정 호응×2토큰, **실제 도착자만** 완주 보너스 추가.
- 사망자는 사망 전 호응×½×2토큰, 중간 버림 없음(호응15→15토큰). 완주 보너스 없음. 게이지를 지우지 않고 절반 인정 표시.
- **실패=전원 사망**. 실패해도 사망 전 호응 보상 지급. 별도 전원 생존 보너스 삭제.
- 2026-10-28 사용자 결정: 공연당 기본 자금(1인10) 삭제, 쉬는 시간에 잡혀 외팔로 끌려온 사람의 보상 박탈 폐기(일반 지급). 구현: Task-076 2차 묶음(`PerformanceRewardModel`).
| 난이도 | 1인 호응 상한 | 도착자 1명 완주 보너스 | 1인 최대 완주 수입 |
|---|---|---|---|
| 1단계 | 100 | 100토큰 | 300토큰 |
| 2단계 | 150 | 150토큰 | 450토큰 |
| 3단계 | 200 | 200토큰 | 600토큰 |
- 난이도 선택 화면에 상한·완주 보너스 표시. 높은 단계에는 환호 기회도 늘리되 기본 환호·야유 값은 유지.
## 환호·야유
| 상황 | 개인 호응도 | 제한 |
|---|---|---|
| 협동 상호작용 성공 | 참여 양쪽 각 +10 | 단순 입력·대기로 반복 지급 안 함 |
| 오브제 의도 행동 성공 | +5 | 접촉·탑승 자체 아님, 같은 오브제 공연당 최초 1회 |
| 장애물 근접 회피 성공 | +5 | 접근 후 피격 없이 벗어남, 같은 회피 중복 없음 |
| 팔다리 절단 | 1개당 +10 | 즉시 토큰 아님, 단계·복구비와 연동 안 함 |
| 환호 포인트 획득 | +15 | 직접 획득한 사람만 |
| 추락 | −15 | 같은 추락 1회. 외줄 매달림 시작에 적용, 뒤 낙사에 중복 차감 안 함 |
| 시간 끌기 | −10 | 진행 가능한 같은 안전 위치에서 진행 정지 15초마다 반복 |
- 협동+오브제는 협동+10만. 포인트+근접 회피는 +15와 +5 중첩 가능. 추락·시간 끌기로 처리한 장애물 실패에 별도 감점 없음.
- 동료 받기 대기·필수 조준·강제 이동 연출은 시간 끌기 제외. 다치지 않고 잘하는 것 자체에 야유하지 않는다.
- 절단 보너스가 복구비보다 낮아야 한다는 제한 삭제. 추격자로 잃은 팔다리에 공연 절단 보너스를 주지 않는 기존 규칙 유지.
## 개인별 관심 감소
- 공연 시작과 마지막 환호부터 **20초 유예→초당−1**, 최소0. 환호는 관심 감소·시간 끌기 대기를 다시 센다. 동료 환호는 본인 감소를 멈추지 않는다. 2026-10-29 사용자 확정: 0점 야유 금지·본인 반응만 UI, 동료는 게이지만 표시([지정 기획서](https://hrjoo122770.atlassian.net/wiki/spaces/bYmkRlnpusng/pages/28147730) 3장).
- 시간 끌기 야유도 관심 감소 타이머20초 초기화. 완주·사망 시 고정. 매초 야유 음성 대신 관객 소리 감소·게이지로 표현.
## 환호 포인트
- 포기해도 진행 가능한 위험 선택 경로. 도전 전에 위험·포인트가 보이며, 필수 피해·긴 되돌아가기·한 역할 독점을 피하고 지원 역할에도 기회를 둔다.
- 팀 공용, 별도 입력 없이 먼저 닿은1명이 획득 후 소멸. 반복 획득·개인별 균등 획득 의무 없음. 획득자+15, 사망 시 다른 호응과 함께 절반 인정.
- 팀 전체 개수=참여 인원×난이도별 **2/3/4개**. 고정/후보 위치 등 배치 방식은 구현을 보고 결정하며 예시 지형은 확정 기능 아님.
## 신체 복구
- 공동 자금으로 부위당 기본100토큰, 팀 전체 이용1회마다 다음 부위당 가격+25. 런(세대)마다100으로 초기화.
- 1회1~3부위, 절단 역순(왼팔→오른다리→왼다리). 온전한 몸 이용 불가, 부활과 별개. 현재 단가×부위수 지불 후 한 번 인상(첫2부위200→다음1부위125).
- 모든 쉬는 시간·밤 정비에 이용 가능, 공연 중 제외. 기물 구매는 밤 정비만.
## 기물 새 제품 가격·내구도 (가격2026-10-27·내구도2026-10-28 확정)

## 경제 목표와 미정
초반 예상 수입1인 약1,000(4인4,000)토큰은 보장 수입 아님. 예상 지출 복구500/공연 기물300/탐색 기물200은 개인 지갑·지출 의무·한도 아님.
- 최대 목표1인3,000/4인12,000. 현재 첫날·밤 난이도 선택대로 6회 상한 완주하면1→1→2→2→3→3, 실제 계산1인2,700/4인10,800. 차이 조정 미정, 추가 보상 임의 도입 금지.
- 묘기별 성공·회피 거리·고의 반복 방지, 역할별 환호 기회·상한 도달·관심 감소·사망/복구 비용은 후속 구현·플레이테스트 대상. 변경 시 사람의 결정 후 보상 원문·이 파일·[부상 규칙](injury-rules.md)·[게임 흐름](../Facts/game-flow.md)·[공통 시스템 지도](../../../Docs/Domains/common-game-systems.md)를 함께 갱신한다.
