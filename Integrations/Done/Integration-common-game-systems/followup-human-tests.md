# 후속 사람 확인 가이드 (2026-10-16)

AI가 실행할 수 없는 2명 실제 입력 확인 2건. PM 지시로 가이드 제공 후 완료 처리했으며 **사람 실행 결과는 아직 없다(PASS 아님)**. 실행하면 날짜·참여자·결과를 이 파일 맨 아래에 적는다. 문제가 나오면 새 fix Task로 분리한다.

## 공통 준비

- dev 최신을 받고 Unity에서 Play 전에 저장한다.
- 2명은 MPPM(Window > Multiplayer > Multiplayer Play Mode)에서 Player 2를 켜거나, 같은 커밋으로 만든 빌드 2개를 쓴다. 서로 다른 커밋·세팅끼리 섞지 않는다.
- Player 2 창이 켜지자마자 꺼지면 함정 `Harness/Engine/Unity/Pitfalls/mppm-clone-missing-files.md`대로 가상 플레이어를 끄고 `Library/VP/` 복제본을 지운 뒤 다시 켠다.
- 개발자 모드는 끈다(2명 기준 최소 생존 인원 2명으로 확인). Console은 두 창 모두 본다.

## A. 045 공동 테스트 3 — 2명 1인칭 이동

씬: `Assets/Scenes/Tests/Systems/CameraViews/CameraViews.unity` 또는 `Assets/Scenes/Tests/Systems/FirstPersonMovement/FirstPersonMovement.unity`

1. A가 호스트로 방을 만들고 B가 참가한다. 둘 다 1인칭 구역에 들어간다.
2. A는 정면, B는 90° 옆을 보고 동시에 W/S/A/D·대각을 누른다.
   - 예상: 각자 **자기 시선 기준**으로 수평 이동. 상대 화면에서 본 상대 캐릭터도 같은 방향으로 움직이고, 내 시선이 상대 이동 방향을 바꾸지 않는다.
3. 위아래로 마우스를 크게 움직여도 이동 속도·높이가 바뀌지 않는지 본다.
4. A와 B 역할을 바꿔(B 호스트) 1~3을 반복한다.
5. 한 명을 사망/Retired로 만들어 관전으로 바뀌는지, 복구 후 자기 카메라·조작으로 돌아오는지 본다(038 테스트 UI 사용).
6. 통과 기준: 위 예상과 모두 일치, 두 창 Console 오류 0.

## B. 2명 실제 클릭 런 한 바퀴

씬: `Assets/Scenes/Tests/Systems/SpaceLink/SpaceLink.unity` (상단 가운데 `SpaceLinkTestUI`, 공통 세팅 "장소 전환"은 기본값 통째 교체)

1. 접속 패널(좌상단)에서 A가 방을 만들고 B가 참가한 뒤 게임을 시작한다. A가 "도입 끝 → 공연".
2. 공연장(더미): 호스트 창에서 "공연 명부 고정"(실제 접속자 2명 명부) → 참가자 선택 버튼으로 자리 1·2를 번갈아 골라 환호 몇 번 → 둘 다 "도착". 결과 성공·수입이 두 창의 공동 자금에 같게 더해지는지 본다. 판정 입력은 호스트만 된다.
3. 대기실: 지출 1회, 복구 미리보기. 잔액이 지출만큼 줄고 두 창 숫자가 같은지 본다.
4. A가 "백스테이지로 나가기"(호스트만) → 쉬는 시간 만료 또는 무대 입구로 다음 공연 → 밤에서 **두 명 모두** 준비 → 2일차.
5. 쉬는 시간에 A가 "탈출 개시 → 탈출로" → 탈출로에서 수동 결론. 한 번은 성공 → 엔딩, 한 번은 실패 → 세대 교체(공동 자금·일차 초기화)까지 본다.
6. 매 장소 이동마다 확인: 두 명 모두 같은 장소로 이동, 잃은 팔다리·공동 자금·일차가 두 창에서 같고 유지됨.
7. 통과 기준: 끝까지 진행, 두 창 상태 일치, Console 오류 0. (시작 위치 이동·전원 집결 자동 감지는 미구현이라 확인 대상 아님)
