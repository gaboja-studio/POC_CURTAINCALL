## 1. 그대로는 불가능 — 수치 조정 권유

### 1-1. 가로 톱날을 점프로 넘을 수 없다

- 점프 0.8m(중력 9.81)면 공중 0.81초, 그중 발이 톱날 공격 상단(0.2m)보다 높은 시간은 **0.70초**다.
- 가로 톱날은 제자리에서 옆으로 쓸고 지나간다. 톱날 충돌체(지름 1.0m)와 캐릭터(지름 0.6m)가 겹치는 구간은 1.6m이고, 이걸 지나가는 시간은 **기본 0.8m/s에서 2.0초, 후반 1.2m/s에서 1.33초**다.
- 겹치는 동안 계속 공중에 있어야 하므로, 0.70초 점프로는 어떤 타이밍에도 맞는다. "가로 톱날 = 점프로 회피"(원문 4장) 의도가 성립하지 않는다.
- 조건식: `(톱날 충돌체 지름 + 캐릭터 지름) ÷ 톱날 속도 < 점프 체공(0.2m 위)` — 여유를 두려면 왼쪽이 오른쪽의 75% 이하.
- 같이 지켜야 할 조건: 점프 높이 < 수직 톱날 충돌체 상단 1.1m(넘으면 수직 톱날도 점프로 넘어감). 그래서 점프만 크게 올리는 방법은 쓸 수 없다(1.0m에서도 체공 0.81초).

| 안 | 바꾸는 값 | 겹침 시간 / 체공 | 영향 |
|---|---|---|---|
| **A (권장)** | 가로 톱날 속도 기본 **3.0m/s**, 후반 **4.5m/s**(1.5배 유지). 수직 톱날은 **0.8m/s 따로 고정** | 0.53초 / 0.70초 (후반 0.36초) | 한쪽 끝→반대 끝 6.3초. 톱날이 자주 지나가 점프 타이밍이 분명해진다. 줄 하나를 막는 시간은 짧아 걸어서 지나갈 틈도 생긴다 |
| B | 점프 **1.0m** + 가로 톱날 기본 **2.6m/s**, 후반 **3.9m/s** | 0.62초 / 0.81초 | 수직 톱날 상단(1.1m)과 여유가 0.1m뿐. 균형 문서의 점프 1.0m와는 같아짐 |
| C | 가로 톱날 충돌체 **0.6m** + 기본 **2.0m/s**, 후반 **3.0m/s** | 0.60초 / 0.70초 | 외형(1.2m)과 판정 차이가 커서 "맞은 것 같은데 안 맞음"이 생긴다 |

- 원문의 "수직 톱날 속도 = 가로 톱날 기본 속도"는 A·B·C 모두 **연동을 끊고** 수직 0.8m/s를 그대로 두기를 권한다(수직 톱날 출현 주기 1:00·3:10 유지).

## 2. 의도에 맞게 값을 정해야 하는 것

### 2-1. 옆줄 이동 가능 구간 = 외줄 전 구간(0~100m) 권유

- 원문은 옆줄 이동 제한을 말하지 않는다. 수직 톱날은 어느 진행 위치에서든 옆줄 이동으로만 피할 수 있으므로 구간을 막으면 못 피하는 곳이 생긴다.
- 현재 구현은 "옆줄 이동 가능 구간"이 인스펙터 값(지금 0~24m)이다. **0~100m로 두기**를 권한다(시스템은 유지, 나중에 막을 구간이 생기면 다시 쓴다).
