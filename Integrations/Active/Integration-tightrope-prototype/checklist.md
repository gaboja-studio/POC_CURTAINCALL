## PR 하나를 병합할 때마다

1. Squash로 병합한다 (Task 하나 = 기록 한 줄).
2. 다음 PR이 뒤처졌으면 GitHub **Update branch**로 최신 내용을 받게 한다.
3. 충돌이 나면 해당 Task 담당자와 함께 해결한다. 씬·프리팹 충돌은 AI에게 맡기지 않는다.
4. 컴파일 확인 후 다음 PR로 넘어간다.
